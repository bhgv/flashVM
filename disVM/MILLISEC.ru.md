# Sys.millisec в нативном DisVM

[English](MILLISEC.md)

`sys->millisec()` читает настоящие монотонные часы в интерпретаторе и JIT,
включая консольный `disvm` без SDL/Flash. Эпоха произвольная: измеряйте разности,
а не календарное время. Разрешение и учёт suspend зависят от ОС; значение не
обязано меняться при каждом вызове. Результат имеет ширину WORD этого runtime
и переполняется как соответствующий битовый счётчик.

Адаптер сначала копирует/проверяет настоящий кадр Sys через `dvm_sys_capture`.
При ошибке ОС поднимается обычная ошибка VM, фиктивный результат не публикуется.
Нет выделений памяти, пользовательских callbacks, ожиданий scheduler или связи
с кадрами SWF.

Код разделён: `runtime/clock_sys.c`, нативный C99-порт `host/clock_port.c` и
`include/disvm/clock_port.h`. Linux/Android используют CLOCK_MONOTONIC, macOS —
mach_absolute_time, Windows — GetTickCount64. Подмены на wall clock/CPU time нет.
Порт возвращает uint64, допускает независимые нативные вызовы и сохраняет
результат при отказе. Здесь исполнен Linux x64; физическая проверка остальных
платформ не заявляется.

В пакете runtime/editor есть пример:

```sh
./disvm --jit examples/millisec/main.dis
./disvm --no-jit examples/millisec/main.dis
```

Он проверяет 2001 настоящий вызов. Нативный тест проверяет 10000 упорядоченных
измерений, отказ null и ход часов через реальное ожидание 20 мс. Это не замер
точности/задержки. Исходник `.b` и C-файлы включены в SDK. Сигнатура Sys,
разрешения native-вызовов из файлов и IDs форматов Dis64/SWF не меняются.
