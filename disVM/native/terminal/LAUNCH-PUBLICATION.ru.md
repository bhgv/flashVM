# Публикация команды запуска в Styx

[English](LAUNCH-PUBLICATION.md) · [API](launch_publication.h) · [Исполнение](LAUNCH-PROCESS.ru.md) · [Диспетчеризация Unibus](LAUNCH-DISPATCH.ru.md)

`styxlaunchpublicationinit` инициализирует принадлежащее вызывающему состояние
одноразовой команды. Передайте ненулевой тег S-записи, рабочий каталог владельца
и аргументы с абсолютным путём к исполняемому файлу. Храните публикацию по
стабильному адресу, а параметры — до получения запроса. Результат 1 означает
успех, 0 — ошибку аргументов или инициализации.

`styxlaunchpublicationfile` возвращает владеющую ссылку на провайдер одного
файла. Укажите 0 для узла запроса с записью или 1 для узла результата с чтением.
Владелец публикует их обычным сервером VFS или Styx. Узел запроса принимает один
допустимый кадр. Узел результата отдаёт десятичный код завершения, перевод строки
и EOF. Чтение до запуска завершается ошибкой, после принятия может ждать
дочерний процесс. У каждого открытия своя позиция. Метаданные потока указывают
нулевой размер.

`styxlaunchpublicationfinish` освобождает публикацию после закрытия всех
провайдеров и файлов и может ждать дочерний процесс. Результат 1 означает
доступный код выхода в `status`, 0 — процесс не запускался, -1 — ошибка.
Вызывайте один раз для успешно инициализированного состояния. Владелец
решает, кому выдать доступ к каждому из узлов.
