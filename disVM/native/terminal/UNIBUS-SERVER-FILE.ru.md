# styxunibusserverstartfile

[English](UNIBUS-SERVER-FILE.md) · [Заголовок](unibus_server.h) · [Пример с двумя DisVM](../../examples/remote-scalar/STYX.ru.md)

```c
StyxUnibusServer *styxunibusserverstartfile(RemotePhy *channel, unsigned long tag,
    DVM_Provider *original);
```

Подключите `unibus_server.h` и библиотеку `styx_unibus_server`. Передайте
собственный подключённый канал Styx, ненулевой 32-битный тег приёмника
и необязательный заимствованный файловый провайдер. Функция принимает
владение каналом при любом исходе. Исходный узел удерживается и выдаётся
как `implementation.dis` на чтение рядом с `.unibus` на запись. Провайдер
должен поддерживать метаданные и последовательное чтение. Для произвольных
смещений нужна поддержка seek.

Функция читает метаданные и запускает отдельный нативный поток. Она возвращает
собственный сервер или NULL при отказе. Провайдер должен жить до возврата,
потом сервер удерживает свою ссылку. После закрытия соединения вызовите
`styxunibusserverjoin`. Приёмник принимает одну полную запись с указанным тегом.
