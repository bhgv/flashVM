# Индексированный файл массива Styx

[English](INDEXED-VARIABLE.md) · [Заголовок](indexed_variable.h) · [Пример](tests/indexed_variable.c)

Библиотека `styx_terminal` связывает один выбор индекса с контекстом
переменной и соединением Styx. Объект `StyxIntArray` создаётся отдельно
для каждой выданной переменной процесса. Владелец задаёт длину, хранит
данные и подключает обработчики. Вызовы к одному объекту сериализуются
диспетчером или внешней блокировкой.

1. Откройте `.idx` на запись. Одновременно допускается один выбор.
2. Запишите четыре байта индекса с нуля, старший байт первым. Индексы
   начинаются с нуля. Индекс проверяется по длине и закрепляется до закрытия.
3. Пока `.idx` открыт, откройте `.val` на том же соединении. Чтение и
   запись работают с выбранным элементом в [скалярном формате](VARIABLE-FILE.ru.md).
4. Закройте `.val` и `.idx`. Закрытие или обрыв `.idx` отзывает и
   все оставшиеся открытия `.val` этого выбора.

Сервер сохраняет поколение выбора в каждом открытом fid. Обработчик
`freefid` вызывает `styxintarrayclose` только для `.idx`. Старый
`.val` не может обратиться к элементу нового выбора. Стенд также
публикует `.len` и `.type` как файлы только для чтения.

Запустите `ctest -R '^terminal-indexed-variable$' -V`. Тест использует
живое соединение Styx, читает и обновляет элемент, проверяет отказ
параллельному выбору и отзывает старый fid. Нативная часть отдельно
проверяет два соединения, индекс вне диапазона и неполную запись.
