# Индексированный файл массива Styx

[English](INDEXED-VARIABLE.md) · [Заголовок](indexed_variable.h) · [Пример](tests/indexed_variable.c)

Библиотека `styx_terminal` связывает один выбор индекса с контекстом
переменной и соединением Styx. Объект `StyxIntArray` создаётся отдельно
для каждой выданной переменной процесса. Владелец задаёт длину, хранит
данные и подключает обработчики. Вызовы к одному объекту сериализуются
диспетчером или внешней блокировкой.

1. Откройте `.idx` на запись. Одновременно допускается один выбор.
2. Запишите четыре байта индекса с нуля, старший байт первым. Индексы
   начинаются с нуля. Индекс проверяется по длине и закрепляется до закрытия.
3. Пока `.idx` открыт, откройте `.val` на том же соединении. Чтение и
   запись работают с выбранным элементом в [скалярном формате](VARIABLE-FILE.ru.md).
4. Закройте `.val` и `.idx`. Закрытие или обрыв `.idx` отзывает и
   все оставшиеся открытия `.val` этого выбора.

Сервер сохраняет поколение выбора в каждом открытом fid. Обработчик
`freefid` вызывает `styxintarrayclose` только для `.idx`. Старый
`.val` не может обратиться к элементу нового выбора. Адаптер также
публикует `.len` и `.type` как файлы только для чтения.

Запустите `ctest -R '^terminal-indexed-variable$' -V`. Тест использует
живое соединение Styx, читает и обновляет элемент, проверяет отказ
параллельному выбору и отзывает старый fid. Нативная часть отдельно
проверяет два соединения, индекс вне диапазона и неполную запись.

## Подключение к серверу

`styxarrayfilepublish` из `styx_unibus_server` создаёт каталог массива
под уже выданным родительским qid, например в `.prog/<pid>/.var`.
Включите `lib9.h`, `styx.h`, `styxserver.h` и `indexed_styx.h`.
Перед запуском диспетчера передайте имя каталога, владельца, массив и диапазон
свободных последовательных qid. Пересечение qid отклоняется до публикации.
Храните массив и описание публикации до завершения обработки всех fid.

Передайте операции для диапазона qid в `styxarrayfileopen`,
`styxarrayfileread` и `styxarrayfilewrite`. Для этих открытий используйте
`styxarrayfileclose` в `freefid`. Если один сервер обслуживает несколько
типов fid, его диспетчер должен вызывать соответствующее освобождение
для каждого типа. При отсутствии `store` файл `.val` доступен только
для чтения. `.len` и `.type` публикует сама библиотека.


## Изменение длины

Для обычного массива нужны пять qid. При обработчике `insert` нужно семь,
а при `pop` — восемь. Библиотека проверяет весь диапазон до публикации.

| Файл | Операция |
| --- | --- |
| `.ins` | Записать восемь байт с нулевого смещения. Первые четыре — индекс, следующие четыре — значение. Индекс, равный длине, вставляет в конец. |
| `.push` | Записать четыре байта значения с нуля, чтобы добавить его в конец. |
| `.pop` | Прочитать четыре байта с нуля. Первое успешное чтение удаляет последний элемент. Повторное чтение с нуля на том же fid возвращает сохранённое значение. |

Числа передаются старшим байтом вперёд, элементы знаковые. Каждая успешная
мутация меняет `.len` ровно на один. Пока открыт `.idx`, структура массива
зафиксирована и новые мутации отклоняются. `.pop` пустого массива возвращает
ошибку. Владелец обязан выполнять обработчики атомарно: вернуть 1 после
изменения или 0, сохранив исходное состояние. Длина и хранилище должны
оставаться согласованными. Пример проверяет все три операции по Styx.
