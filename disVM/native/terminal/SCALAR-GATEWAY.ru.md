# Нативный скалярный шлюз

[English](SCALAR-GATEWAY.md) · [Заголовок](scalar_gateway.h) · [Тест Styx](tests/scalar/route.c)

Шлюз на C из `styx_terminal` принимает три точных файла. Профиль и ответ
открываются на чтение. Файл запроса открывается на запись только после
проверки профиля по ожидаемому компилированному импорту.

| Функция | Контракт |
| --- | --- |
| `styxscalargateway` | Сверяет запись профиля с переданными именем, сигнатурой и тегом. При успехе удерживает провайдер запроса и открывает ответ. Возвращает собственный шлюз или NULL. |
| `styxscalargatewaysend` | Пытается отправить один знаковый 64-битный аргумент с заданным тегом. Возвращает статус доставки. Повторные отправки отклоняются. |
| `styxscalargatewayreceive` | Читает полную запись ответа с заданным тегом. Возвращает ожидание при пустом чтении, значение или ошибку владельца при успехе, иначе неизвестный исход. Выход меняют лишь значение или ошибка владельца. |
| `styxscalargatewayfree` | Освобождает провайдер запроса и закрывает позицию чтения ответа. NULL допустим. |

Для каждого вызова нужны свежие одноразовые файлы. Операции одного шлюза
выполняются последовательно. I/O может блокироваться и следует активной
области нативной отмены. Хост связывает все три файла с одной публикацией.
Загрузчик и интерпретатор Dis пока не подключены к этому API SDK.

Из каталога сборки SDK выполните
`ctest -R '^terminal-scalar-route$' --output-on-failure`. Тест проверяет
несовпадение профиля, ошибку владельца и отклонение повторной записи
через живые маршруты Styx.
