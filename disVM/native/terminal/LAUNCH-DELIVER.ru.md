# styxlaunchpublicationdeliver

[English](LAUNCH-DELIVER.md) · [API](launch_publication.h) · [TCP-пример](../../examples/vfs-run/TUTORIAL.ru.md)

`DVM_LaunchDelivery styxlaunchpublicationdeliver(StyxLaunchPublication *publication, int wait, DVM_Provider *peer_unibus, unsigned long tag);`

Подключите `styx_terminal`. Передайте живую публикацию, удерживаемый
провайдер файла `.unibus` получателя с правом записи и ненулевой
32-битный тег ответа. Функция заимствует ссылки на время вызова. При
ненулевом `wait` она может ждать дочерний процесс. При нуле проверяет
завершение без блокирующего `waitpid`. Получение статуса сериализовано.

Результат сообщает, доставлена ли запись, не отправлена или исход неизвестен.
При завершении процесса функция пишет в новый fid одну S-запись с десятичным
кодом выхода и переводом строки. Ожидание процесса, неверные параметры и
отказ дают статус «не отправлено». Неопределённость транспорта сохраняется.
Вызывающий определяет момент отправки. Автоматического повтора нет.

TCP-тест публикует по `.unibus` с каждой стороны одного двустороннего
соединения. Клиент пишет команду в файл владельца на логическом канале 0.
Владелец пишет результат в файл клиента на логическом канале 1. Тест также
проверяет прежние интерфейсы упорядоченного потока и файла результата.
