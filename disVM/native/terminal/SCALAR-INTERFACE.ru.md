# Проверка скалярного интерфейса через Styx

[English](SCALAR-INTERFACE.md) · [Заголовок](scalar_interface.h) · [Тест](tests/scalar/route.c)

Общий код на C передаёт имя одного экспорта длиной до 48 байт и точную
32-битную сигнатуру Dis. Публикатор передаёт проверенные данные компилированного
экспорта, а вызывающий сверяет их со своим компилированным импортом.
Запись помещается в существующий одноразовый приёмник `.unibus`.

В библиотеке `styx_terminal` функция `styxscalaroffer` принимает заимствованный
файл записи, ненулевой тег, имя и сигнатуру. Она возвращает статус одной записи.
`styxscalaraccept` сверяет тег, целостность, имя и сигнатуру без I/O.
`styxscalarcallchecked` принимает также тег вызова и один знаковый аргумент.
При несовпадении она возвращает `DVM_LAUNCH_NOT_SENT` до открытия файла запроса.
Запись с неизвестным исходом не повторяется.

Эти функции пока вызываются нативным тестом. Обычный `load`, чтение `.m` и
диспетчеризация экспорта Dis ещё не подключены.
