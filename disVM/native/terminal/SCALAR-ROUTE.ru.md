# Скалярный вызов через Styx Unibus

[English](SCALAR-ROUTE.md) · [API](scalar_route.h) · [Пример](tests/scalar/route.c)

## Отправка запроса и возврат результата

`scalar_route.h` · `styx_terminal`

Хост выдаёт два доступных для записи файла `.unibus`, по одному от каждой
стороны. Вызывающая сторона отправляет S-запись с одним знаковым 64-битным
аргументом через `styxscalarcallfile(request, 17, argument)`. Обработчик записи
на стороне владельца передаёт запись целиком в
`styxscalarreplyfile(reply, 17, bytes, count, 29, method, state)`. Метод
возвращает 1 и записывает результат или возвращает другое значение и записывает
код ошибки. Вызывающая сторона читает отдельный ответ через
`styxscalarread(29, ...)`.

Обе операции используют переданный файловый провайдер и открывают новый fid
на запись одной S-записи. Статус описывает доставку этой записи. К моменту ошибки
отправки ответа метод уже мог выполниться. При неопределённом исходе
автоматического повтора нет. Хост сериализует вызовы и держит не более одного
незавершённого вызова на паре маршрутов.

## Запуск примера

Из каталога настроенной сборки нативного SDK с поддержкой VFS:

```sh
cmake --build . --target terminal-scalar-route
ctest -R '^terminal-scalar-route$' --output-on-failure
```

Пример поднимает две сессии Styx на одном двустороннем соединении. Он проверяет
результат, ошибку метода и отклонение запроса с чужим тегом маршрута.
