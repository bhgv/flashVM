# Записи гибридных таблиц в Styx

[English](MANAGED-TABLE-RECORD.md) · [Объявление](call_record.h) · [Реализация](managed_table_wire.inc) · [Пример с двумя VM](../../examples/remote-scalar/managed-fid/README.ru.md#передача-гибридных-таблиц)

Профиль управляемых вызовов передаёт нативный `Bigtable->Handle` как тип `h`.
Первое описание содержит тег графа 10, однобайтовый индекс и полную запись
таблицы. Повторные ссылки используют тот же индекс. Если результат ссылается
на аргумент, клиент сохраняет исходный дескриптор. Для нового результата
создаётся локальная нативная таблица. Обе стороны вызова используют схему
компилятора и профиль графа с позициями аргументов.

| S-запись | Тег | Содержимое |
| --- | --- | --- |
| Снимок | 20 | Ноль или больше полных записей пар |
| Пара | 21 | Запись ключа и запись знакового значения `big` |
| Патч | 22 | Удаления, затем изменённые и новые пары |
| Удаление | 23 | Одна запись ключа |

Ключом служит неотрицательный `big` (тег 2) либо UTF-8 с явной длиной
(тег 7). В снимке числовые ключи идут по возрастанию, включая плотный
префикс и разреженные индексы. Текстовые ключи следуют в порядке вставки и
могут содержать нулевые байты. Внешнее обновление графа связывает патч с
исходной позицией параметра либо индексом вложенного объекта. Патч может
переместить текстовый ключ удалением и повторной вставкой. Неизменившаяся
таблица записи обновления не получает.

## styxmanaged_table_visit

Подключите [call_record.h](call_record.h) и свяжите программу с библиотекой Styx terminal на C.

```c
int styxmanaged_table_visit(const void *bytes, size_t size, int patch,
    int (*visit)(void *, const StyxTableKey *, int, int64_t), void *state);
```

`bytes` и `size` задают одну полную S-запись в заимствованной памяти.
Нулевой `patch` выбирает снимок, ненулевой — патч. Функция сверяет теги,
длины, кодирование ключей и порядок строк. Возвращает единицу при успехе
и ноль при некорректном вводе либо отказе посетителя. Runtime при
восстановлении снимка дополнительно проверяет уникальность текстовых ключей.

Передайте нулевой `visit`, чтобы проверить формат. Иначе посетитель получает
заимствованный `state`, разобранный ключ, ненулевой признак удаления либо ноль
для пары и знаковое значение. При удалении значение равно нулю. Ключ и его
текст доступны на время callback. Функция не выполняет ввод-вывод. Ошибка
в конце записи может возникнуть после вызовов посетителя. Подготавливайте
изменения в частной памяти и публикуйте их только при успехе функции.

```c
int complete = styxmanaged_table_visit(record, record_size, 0, NULL, NULL);
```

См. [обновление ссылок в профиле вызова](SCALAR-FUNCTION.ru.md) и
[проверки формата](tests/scalar/table_records.inc).
