# Скалярный прокси Styx

[English](VARIABLE-FILE.md) · [Заголовок](variable_file.h) · [Пример](tests/link/images.c)

Модуль `styx_terminal` предоставляет `styxintvariableread` и
`styxintvariablewrite` для обработчиков чтения и записи файла Styx.
`StyxIntVariable` содержит заимствованное состояние владельца и функции
`load` и `store`. Они должны возвращать 1 при успехе. Владелец отвечает
за срок жизни состояния и синхронизацию доступа с другими потоками.

Формат значения — четыре байта знакового целого, старший байт первым.
Чтение с нулевого смещения возвращает целое значение, полученное у
владельца в момент чтения. При смещении от четырёх возвращается EOF.
Запись принимает ровно четыре байта с нулевого смещения и передаёт
декодированное значение владельцу один раз. Неполная запись отклоняется
до вызова `store`. Файловые права задаёт сервер Styx.

Проверка `ctest -R '^terminal-ordered-files-guest$' -V` запускает Dis с
`/.prog/.self/.var/counter`. Родитель пишет отрицательное значение, потомок
читает его и пишет многобайтовое положительное значение. Родитель читает
обновление. [Маршрут контекста процесса](../../runtime/LAUNCH-PROGRAM-ROUTE.ru.md)
