# styxunibusserverstartscopedset

[English](UNIBUS-SERVER-SCOPED-SET.md) · [Заголовок](unibus_server.h) · [Реализация](unibus_loaded.c)

```c
StyxUnibusServer *styxunibusserverstartscopedset(RemotePhy *channel,
    const char *module, const char *const *names, size_t count, DVM_Provider *reverse);
```

Подключите `unibus_server.h` и библиотеку `styx_unibus_server`.
Настройте публикацию и служебные приёмники как у
[styxunibusserverstartloadedset](UNIBUS-SERVER-LOADED.ru.md).
Для дополнительных профилей со значениями и `ref` по схеме требуется
клиентская выдача. Во время выполнения экспорт Dis получает частное
представление `/.prog/.self`.

| Параметр | Условия |
| --- | --- |
| `channel` | Прямой транспорт Styx. Поглощается при любом результате. |
| `module` | Имя каталога в `mounted`. Используется при публикации. |
| `names` | Массив имён экспортов для публикации. |
| `count` | Число имён, от 1 до 8. |
| `reverse` | Ненулевой нативный провайдер встречной сессии Styx этого клиента с корнем над `.prog`. Удерживается до join. |

Функция возвращает собственный сервер либо NULL при неверной настройке
или ошибке запуска диспетчера. Она запускает нативный диспетчер без
ожидания загрузки образа. Доступ к профилю каталога открывается после
[проверки предложения владельца](UNIBUS-SERVER-LOAD-PROFILE.ru.md).
До публикации прямого клиентского маунта свяжите его со встречным через
`styxcallermount`. Сервер проверяет выдачу до передачи запроса VM владельца.
При отсутствии встречной привязки обычный Limbo `load` отклоняет экспорт
с контекстом.

Диспетчер последовательно обслуживает запросы прямой сессии. Выдача
действует в пределах одного вызова, включая встречные чтения до ответа.
По окончании выдачи новые операции через сохранённый fid отклоняются.
Закройте транспорт и вызовите `styxunibusserverjoin`. Для вызова с
контекстом создаётся отдельная очередь Sysevents. Через открытый FD
после ответа можно дочитать накопленное, событие завершения и EOF.
Поток событий клиентской VM живёт отдельно.

См. [рабочий пример](../../examples/remote-scalar/STYX.ru.md#вызов-через-встречный-маунт-styx)
и [формат обмена](SCALAR-FUNCTION.ru.md#контекст-клиента-для-вызовов-по-схеме).

Для нескольких модулей см. [styxunibusserverstartscopedtable](UNIBUS-SERVER-SCOPED-TABLE.ru.md).
