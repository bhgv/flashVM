# Приём скалярного вызова на стороне владельца

[English](SCALAR-OWNER.md) · [Заголовок](scalar_owner.h) · [Тест](tests/scalar/route.c)

Код C в `styx_terminal` позволяет потоку владельца забрать один запрос
из уже опубликованного приёмника `.unibus`. Поток Styx подтверждает запись
в приёмник. Затем владелец читает аргумент, исполняет метод и отправляет
результат по встречному маршруту.

| Функция | Контракт |
| --- | --- |
| `styxscalarowner` | Принимает заимствованные точные провайдеры запроса и ответа с ненулевыми 32-битными тегами. Открывает приёмник на чтение и удерживает файл ответа. Возвращает собственный объект или NULL. |
| `styxscalarownertake` | Проверяет тег и вид полной S-записи. При успехе записывает один знаковый 64-битный аргумент и возвращает `STYX_GATEWAY_VALUE`. Пустой живой приёмник даёт `STYX_GATEWAY_PENDING`. Повторный приём и недостоверные записи дают `STYX_GATEWAY_UNKNOWN`. |
| `styxscalarownersend` | После успешного приёма выполняет одну запись. `success == 1` передаёт результат, другое значение передаёт ошибку. Второй ответ отклоняется. |
| `styxscalarownerfree` | Закрывает приёмник и освобождает файл ответа. NULL допустим. |

Доступ к объекту последовательный. I/O может блокироваться и следует активной
области нативной отмены. Сквозной нативный тест использует обработчик на C.
Для вызова экспорта Dis нужен отдельный вход из потока владельца VM.
