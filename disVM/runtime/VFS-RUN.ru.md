# Vfsctl.run

[English](VFS-RUN.md) · [Интерфейс Limbo](../module/vfsctl.m) · [Runtime](vfs/vfsnative.c)

`run: fn(path: string): int` отправляет запрос запуска через маршрут,
объявленный провайдером выбранного файла. Вызовите `Vfsctl.init` один раз
и передайте видимый абсолютный или относительный путь, включая alias от bind.

```limbo
status := vfs->run("/mounted/app.dis");
```

Результат 1 означает подтверждённую доставку, 0 — отказ или отсутствие
маршрута, -1 — неизвестный исход доставки. Операция может ждать Styx,
посылает пустые стартовые данные и не повторяет запрос автоматически.
Подтверждается доставка запроса. Сам процесс запускает владелец.

В TCP-тесте гость вызывает забинженное имя отдельного командного образа.
Владелец тестового сервера запускает команду при принятии запроса. Её `init`
читает файл из рабочего каталога владельца. Затем гость читает результат
через то же действующее подключение. Проверка идёт в интерпретаторе и JIT.
