# Vfsexport.bigvector

[English](VFS-BIG-VECTOR.md) · [Модуль](../module/vfsexport.m) · [Реализация](vfs/cap_bigtable.c)

```limbo
bigvector: fn(): ref Root;
```

Загрузите `Vfsexport` для создания пустого растущего массива знаковых
значений Limbo `big`. Каждый вызов возвращает отдельный корень VFS или
`nil` при ошибке выделения. Смонтируйте корень или опубликуйте его под
`.var` через `overlay`. Локальные и встречные Styx-открытия этого корня
работают с одним хранилищем. Корень и открытые файлы удерживают хранилище.

| Файл | Доступ и данные |
| --- | --- |
| `.type` | Текст `vector of big\n` только для чтения. |
| `.len` | Десятичная длина с переводом строки, только чтение. |
| `.push` | Записать одно значение, чтобы добавить его в конец. |
| `.ins` | Записать позицию и значение. Вставка сдвигает последующие элементы. Позиция, равная длине, добавляет элемент в конец. |
| `.pop` | Первое непустое чтение извлекает последнее значение. Пустой массив даёт ошибку чтения. Короткие чтения продолжают выдавать то же значение. |
| `.idx` | Записать одну существующую позицию. Держать файл открытым при работе с `.val`. |
| `.val` | Прочитать или перезаписать выбранную позицию. Записывать со смещения 0. |

Позиции и значения передаются знаковыми восьмибайтовыми словами, старшим
байтом вперёд. Нумерация начинается с нуля. Вставка принимает позиции от
нуля до текущей длины включительно. При выборе отрицательные позиции
отсчитываются от конца. Позиция вычисляется при записи в `.idx`. Если последующая вставка
сдвинет элементы, открытый селектор продолжит адресовать ту же позицию.
На локальный процесс или встречный контекст вызова приходится один селектор.
Закрытие селектора отзывает его открытые файлы значений. Для каждой вставки,
добавления в конец или извлечения откройте новый FD команды.

В [примере Styx](../examples/remote-scalar/styx-scoped-calls.b) клиент создаёт
пустой массив. [Провайдер](../examples/remote-scalar/scoped-calls-owner.b)
добавляет 10, вставляет 20, заменяет последнее значение на 21 и извлекает его.
Клиент видит длину 1 в своём VFS. См. также [фиксированные живые ячейки](VFS-INT-ARRAY.ru.md)
и [гибридные таблицы](VFS-HYBRID-TABLE.ru.md).
