# Vfsnative.scalarload

[English](VFS-SCALAR-LOAD.md) · [Интерфейс](../module/vfsnative.m) · [Сервис](SCALAR-OWNER-SERVICE.ru.md)

```limbo
scalarload: fn(path, exportname: string): Scalarimplementation;
```

Используйте встроенный `$Vfsnative`. `path` задаёт исходный образ Dis в текущем
VFS. `exportname` — непустое имя длиной до 48 байт. Обычный загрузчик читает
образ, а обычный линкер связывает именованный экспорт с сигнатурой
`fn(int): int` с единственным слотом `invoke`. Возвращённая ссылка на
модуль подчиняется обычным правилам времени жизни Limbo.

Вызов может ожидать загрузчик. Неверные аргументы вызывают исключение.
Недоступный образ, нативный шлюз вместо реализации, отсутствующий экспорт
или несовместимая сигнатура дают nil. Функция связывает экспорт. Для его
исполнения вызывающий использует `target->invoke(value)`.
