# Vfsexport.record

[English](VFS-VARIABLE-RECORD.md) · [Интерфейс](../module/vfsexport.m) · [Реализация](vfs/cap_record.c)

```limbo
record: fn(fields: list of (string, ref Root)): ref Root;
```

Загрузите `Vfsexport` по `Vfsexport->PATH`. Передайте от 0 до 254
именованных возможностей с уникальными именами. Имя состоит из одного
компонента пути и начинается с символа, отличного от точки. Результат —
каталог с полями. Файлы `.type` и `.len` доступны только на чтение.
Они содержат `record\n` и число полей с переводом строки. При недопустимом
или повторяющемся имени, недействительном корне или нехватке памяти вернётся nil.

Поле удерживает исходную возможность с её правами доступа. Полем может
быть живая [целочисленная ячейка](VFS-INT-VARIABLE.ru.md), фиксированный
[массив](VFS-INT-ARRAY.ru.md) или вложенная запись. Несколько полей могут
указывать на один корень. Состав каталога фиксируется при создании.
Опубликуйте каталог под `.var` для доступа из контекстного вызова.
[Пример Styx](../examples/remote-scalar/styx-scoped-calls.b) публикует
вложенную запись и массив с общими ячейками.

Другие поля могут хранить [строковую ячейку](VFS-STRING-VARIABLE.ru.md), [скаляр big](VFS-BIG-VARIABLE.ru.md) или [вектор big](VFS-BIG-VECTOR.ru.md).
