# Cell.setvalue

[English](setvalue.md) · [Руководство](../STYX-NAMED-VALUES.ru.md) · [Объявление](../../module/styxnamed.m#L67) · [Реализация](../../limbo/styxnamed.b#L308)

```limbo
Cell.setvalue(value: ref Styxvalue->Value)
```

Кодирует заимствованное значение до записи. При подтверждении ячейка заменяет значение целиком, включая тип. Неверный аргумент даёт исключение до ввода-вывода. При обрыве после отправки исход записи может быть неопределён. Перед повтором прочитайте значение. Операции на fid последовательны.

```limbo
cell.setvalue(ref Value.Logical(1));
```
