# decode

[English](decode.md) · [Руководство](../STYX-NAMED-VALUES.ru.md) · [Объявление](../../module/styxvalue.m#L79) · [Реализация](../../limbo/styxvalue.b#L141)

```limbo
decode(frame: array of byte): ref Value
```

Декодирует заимствованный кадр с тегом длиной от 1 до 65 536 байт. Возвращает собственное значение. Текст копируется с нулевыми байтами, граф — после проверки оболочки. Неверная длина, тег, булево значение или кадровая ссылка дают исключение. Транспортного ввода-вывода нет.

```limbo
value := codec->decode(frame);
```
