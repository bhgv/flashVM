# Port.recvvalue

[English](recvvalue.md) · [Руководство](../STYX-NAMED-VALUES.ru.md) · [Объявление](../../module/styxnamed.m) · [Реализация](../../limbo/styxnamed.b)

```limbo
Port.recvvalue(): ref Message
```

Ожидает следующее сообщение. Data содержит значение во владении вызывающего. Shared содержит fid ячейки, открытый до возврата. Intrefdata сохраняет байты дескриптора для явно смонтированного владельца. Modref содержит принятую [ссылку на переменную модуля](../STYX-MODULE-REFS.ru.md) в поле `reference`. Точный экспорт откроется при первой операции со значением. Закройте полученные ячейки и ссылки после использования. Неверный кадр или сбой ввода-вывода дают исключение. Вызовы последовательны.

```limbo
message := port.recvvalue();
```
