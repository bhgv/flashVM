# Скалярный транспорт Vfsnative

[English](VFS-SCALAR-CALL.md) · [Интерфейс](../module/vfsnative.m) · [Пример](../examples/remote-scalar/STYX.ru.md)

Встроенный `$Vfsnative` предоставляет общий транспорт на C для профиля
Styx `fn(int): int`. Типизированный адаптер вызывает его обычным кадром Dis.
Маршруты разрешаются в VFS активного экземпляра модуля. Операции провайдера
поддерживают отмену, а файлы чтения и записи выдаются раздельно.

| Метод | Операция |
| --- | --- |
| `scalarcall(request, reply, requesttag, replytag, value)` | Открывает ответ, записывает один запрос и возвращает число либо вызывает исключение. |
| `scalartake(path, tag)` | Читает и проверяет один запрос, возвращает числовой аргумент. |
| `scalarreply(path, tag, success, value)` | При `success == 1` записывает результат, иначе записывает ошибку. |

Теги — ненулевые беззнаковые 32-битные числа. Целые Limbo передаются как
знаковые 64-битные значения. Файлы рассчитаны на один вызов. Владелец
вызывает `scalartake` и `scalarreply` по одному разу на выданный маршрут.
Повторяется только пустое чтение при ожидании с бюджетом три секунды между
операциями. Запись с неизвестным исходом автоматически не повторяется.
Пример по-прежнему использует типизированные сгенерированные модули для
выбора и вызова экспортированной функции.
