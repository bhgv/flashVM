# Styxmodref.adopt

[English](adopt.md) · [Объявление](../../module/styxmodref.m) · [Реализация](../../limbo/styxmodref.b) · [Руководство](../STYX-MODULE-REFS.ru.md)

`styxmodref.dis`

```limbo
adopt: fn(frame: array of byte): ref Cell;
```

Передайте полный кадр с тегом из именованного канала, например `refs->adopt(pipe.recv())`. Вызов копирует дескриптор, проверяет формат, область соединения и роль владельца и возвращает собственный `ref Cell`. Недопустимый кадр вызывает исключение. Удалённый экспорт открывается при первом чтении или записи значения. В этот момент владелец должен обслуживать запросы. Полученную ячейку можно [закрыть](close.ru.md) обычным способом.
