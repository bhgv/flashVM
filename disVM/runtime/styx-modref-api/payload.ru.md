# Styxmodref.Cell.payload

[English](payload.md) · [Объявление](../../module/styxmodref.m) · [Реализация](../../limbo/styxmodref.b) · [Руководство](../STYX-MODULE-REFS.ru.md)

`styxmodref.dis`

```limbo
payload: fn(cell: self ref Cell): array of byte;
```

Вызовите `port.send(cell.payload())`, чтобы переслать исходную идентичность и режим доступа в той же паре. Вызов копирует полный кадр, включая тег канала, в собственный массив байтов. Значение источника не читается, принятый экспорт не открывается. Закрытая или недоступная ячейка вызывает исключение. Выполняйте чтение кадра последовательно с другими операциями этой ячейки.
