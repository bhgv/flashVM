# Styxmodref.capturelocal

[English](capturelocal.md) · [Объявление](../../module/styxmodref.m) · [Реализация](../../limbo/styxmodref.b) · [Руководство](../STYX-MODULE-REFS.ru.md)

`styxmodref.dis`

```limbo
capturelocal: fn(path: string, writable: int): ref Cell;
```

Передайте канонический относительный путь, например
`mounted/counter.dis/.var/value`. Путь отсчитывается от корня DisVM,
опубликованного для парной FlashVM. Режим `0` разрешает чтение,
режим `1` разрешает чтение и запись. Текущая публикация должна быть
обычным четырёхбайтовым экспортом Int32 с запрошенными правами.

Вызов открывает точный экспорт и возвращает собственный `ref Cell`.
Дескриптор содержит тот же Qid, что и поиск со стороны пары.
Вызов может ждать местного провайдера и выдаёт исключение при неверных
параметрах, отсутствии парной службы, отказе в доступе или подмене
экспорта во время открытия. Для пересылки передайте
`ref Message.Modref(cell)` в [Port.sendvalue](../styx-named-api/sendvalue.ru.md).
Выполняйте операции на ячейке последовательно и
[закройте](close.ru.md) её после использования. Для экспорта FlashVM
вызывайте [capture](capture.ru.md).
