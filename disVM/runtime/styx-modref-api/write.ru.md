# Styxmodref.Cell.write

[English](write.md) · [Объявление](../../module/styxmodref.m) · [Реализация](../../limbo/styxmodref.b) · [Руководство](../STYX-MODULE-REFS.ru.md)

`styxmodref.dis`

```limbo
write: fn(cell: self ref Cell, value: int);
```

Вызовите `cell.write(42)` для живой записываемой ячейки, чтобы заменить исходный Int32 значением `value`. Операция использует удерживаемый fid либо сверяет принятый дескриптор перед первым открытием. Вызов может ждать владельца. Режим только для чтения, закрытая ячейка, отзыв экспорта или ошибка записи вызывают исключение. При обрыве результат записи может быть неопределённым. Выполняйте операции с этой ячейкой последовательно.

В паре с FlashVM родитель может отменить ожидание прямого потомка через `Processctl.cancelwait(pid)`. Отправленное присваивание могло сохраниться. Отдельное чтение получает текущее значение.
[Исполняемый пример Limbo и FlashVM](../../../lib/styxrpc/examples/disvm/REF_PORT_CANCELLATION.ru.md).
