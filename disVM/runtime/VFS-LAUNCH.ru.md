# Запуск Dis через смонтированное пространство имён

[English](VFS-LAUNCH.md) · [Руководство](../examples/vfs-run/TUTORIAL.ru.md) · [DisVM](../README.ru.md)

Приложение указывает команду по видимому имени в VFS. Хост может устроить
запуск рядом с файлами и службами публикующей DisVM. Привязка через bind
может изменить видимое имя, сохранив маршрут запуска выбранного провайдера.

Клиент разрешает путь, получает маршрут выбранного провайдера и отправляет
запрос записью Styx. Владелец выбирает команду и её рабочий каталог. Отдельный
провайдер может выдать код завершения файлом для чтения через обычные
`Sys->open` и `Sys->read`. Публикация результата может пережить вызов запуска.

| Операция | Когда использовать |
| --- | --- |
| [`Vfsctl.run`](VFS-RUN.ru.md) | Отправить команду с пустыми данными. |
| [`Vfsctl.runargs`](VFS-RUNARGS.ru.md) | Отправить бинарные данные маршруту, который их принимает. |
| [Публикация владельца](../native/terminal/LAUNCH-PUBLICATION.ru.md) | Выдать фиксированную команду и её код завершения. |

TCP-пример проверяет забинженный маршрут, `init` у владельца и чтение кода
завершения в интерпретаторе и JIT. Бинарные данные доступны в `init` через `Launchcontext.arguments()`, если
владелец разрешил их для отдельной DisVM. Подключение обычной команды запуска
и прозрачные вызовы удалённых библиотек остаются открытыми.
