# Живые изменения пространства имён в парной сессии Styx

[English](STYX-LIVE-REBIND.md) · [VFS в ActionScript](../../flashVM/doc/STYX_RPC_OS.ru.md) · [Перемотка каталогов](../../flashVM/doc/STYX_VFS_DIR_REWIND.ru.md)

Парная DisVM экспортирует пространство имён выполняемого приложения
Limbo. Поток Limbo из той же группы пространства имён может менять
привязки после подключения FlashVM. При новом поиске пути и открытии
файла FlashVM получает текущий порядок ветвей.

| Изменение на стороне DisVM | Результат нового поиска |
| --- | --- |
| `Sys.bind(source, target, Sys->MAFTER)` | Новая ветвь добавляет имена после исходного каталога. |
| `Sys.bind(source, target, Sys->MBEFORE)` | Новая ветвь получает приоритет для совпадающих имён. |
| `Sys.unmount(source, target)` | Удаляет выбранную ветвь и открывает нижние ветви. |
| `Sys.bind(source, target, Sys->MREPL)` | Разрешает путь через заменяющую ветвь. |
| `Sys.unmount(nil, target)` | Удаляет привязки с точки монтирования и открывает исходный путь. |

Открытый файл удерживает свой исходный объект и работает, пока
объект принимает операции. Первое чтение каталога с нулевого смещения
и каждая перемотка перечисляют актуальное представление удержанного
каталога. Если сам каталог заменили, для доступа к замене откройте
путь заново. Чтение с ненулевого смещения продолжает существующий
обход и сохраняет буфер записей предыдущего чтения. Служебные имена
вроде `.prog` в обычных списках отсутствуют.

[Нативный обход каталога](../native/vfs/tree.h#L41) проверяет
идентификатор нового курсора перед заменой прежнего. Используются
существующие сообщения Styx и штатные исполняемые файлы пары.

## Проверка в паре

Добавьте `--rebind` к [команде парной сборки](STYX-CHANNEL.ru.md#проверка).
Она собирает [проверку на Limbo](../../lib/styxrpc/tests/flashvm/rebind_pair.b)
и [SWF на AS](../../lib/styxrpc/tests/flashvm/rebind_pair.as) компиляторами
и линкером проекта. SWF открывает исходные файл и каталог до сигнала
готовности. Отдельный поток Limbo меняет рабочий каталог и применяет
пять изменений из таблицы. [Колбэк AS](../../lib/styxrpc/tests/flashvm/rebind_signal.as)
получает ожидаемый результат через уже открытую сессию.

Первое чтение открытого каталога видит добавленную ветвь. Последующие
проверки сверяют выбранный файл и его метаданные, читают файл из
резервной ветви и повторно читают исходный дескриптор. При успехе
проверка печатает `PASS native rebind RPC paired VMs`. Для TCP и JIT
добавьте `--tcp` и `--jit`.
