# Styxnodes.publish

[English](styx-nodes-publish.md) · [Руководство](STYX-NODES.ru.md) · [Интерфейс](../module/styxnodes.m#L57) · [Реализация](../limbo/styxnodes.b#L70)

```limbo
include "sys.m";
include "styxnodes.m";
publish: fn(path, permissions: string): ref Node;
```

Опубликовать один файл в живом пространстве имён запуска. `path` —
абсолютный путь в UTF-8 длиной до 1023 байтов. Родительский каталог
должен существовать и разрешать проход и запись, конечное имя
должно быть свободно. Пустые компоненты, `.`, `..` и служебные имена
недопустимы. `permissions` — непустое подмножество `rwx` без повторов.
Порядок букв произвольный. Режим открывает указанные операции всем
участникам, у которых есть доступ к пространству имён.

Результат владеет регистрацией и локальным fid. Вызов может ждать
ввода-вывода VFS и возбуждает исключение при неверных аргументах,
занятом имени, отсутствии прав или службы парного запуска.
Родительские каталоги должны быть готовы заранее.
Обращайтесь к опубликованному узлу последовательно.

```limbo
node := nodes->publish("/tools/mail", "rwx");
```

См. [init](styx-nodes-init.ru.md), [dispatch](styx-nodes-dispatch.ru.md)
и [close](styx-nodes-close.ru.md).
