# disvm --startup-fd

[English](STARTUP-FD.md) · [Лаунчер владельца](../native/terminal/LAUNCH-PROCESS-PAYLOAD.ru.md) · [Чтение](host_runtime/execution.inc)

`disvm --startup-fd=FD [параметры VM] MODULE.dis`

Параметр для нативных лаунчеров Linux. `FD` — обязательный десятичный номер
унаследованного дескриптора от 3 до максимального нативного знакового целого.
Ожидается один запечатанный обычный файл, например Linux memfd с запретом
записи, роста и усечения. Размер файла определяет объём данных до 65 536
байт. Пустой файл передаёт пустые данные. Параметр несовместим с нативным
launch handoff и прежним параметром hex.

DisVM читает с нулевого смещения, принимает дескриптор во владение и закрывает
его до исполнения гостя. Копия доступна в `Launchcontext.arguments()`.
Чтение может ждать I/O. Недействительный FD, отсутствие seals, превышение
размера и ошибка чтения прерывают запуск. Лаунчер в примере получает FD по
маршруту Styx, заданному владельцем. См. [запускаемый TCP-пример](../examples/vfs-run/README.ru.md).
