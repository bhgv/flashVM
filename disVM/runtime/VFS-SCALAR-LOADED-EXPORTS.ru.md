# Vfsnative.scalarloadedexports

[English](VFS-SCALAR-LOADED-EXPORTS.md) ·
[Объявление Limbo](../module/vfsnative.m) ·
[Владелец Dis](vfs/loaded_owner.c)

```limbo
scalarloadedexports: fn(anchor: Scalarloadedanchor): string;
```

Загрузите встроенный модуль `Vfsnative` в работающем процессе DisVM.
Передайте `anchor` из `scalarloadanchor(path)`. Метод копирует имена
вызываемых экспортов в порядке компиляции, разделяя их табуляцией.
Действуют проверки сигнатуры, схемы и кадра шлюза владельца. Экспорты
без подходящего профиля пропускаются. Значение nil, пустой каталог или
более восьми вызываемых экспортов дают nil. Граница совпадает с числом
экспортов одного смонтированного модуля. При переполнении каталог
возвращается целиком либо отклоняется.

Метод читает данные загруженного экземпляра. Он обходится без
файлового ввода-вывода и вызовов методов, удерживая anchor на время
вызова. Строка владеет своими данными. Сохраняйте anchor для дальнейшего
связывания. После замены файла старый anchor продолжает указывать на
исходный образ. Новый `scalarloadanchor(path)` заново разрешит этот путь.

Передайте `nil` в аргументе `offer` методов `scalarloadedview` или
`scalarloadedslot` для приватного связывания. Они выдадут типизированное
представление или шлюз того же экземпляра без записи профиля. Если
путь `offer` задан, действует обычная публикация профиля.

[Проверка на Limbo](tests/loaded_exports/client.b) находит скалярные,
управляемые и канальные экспорты и пропускает неподдерживаемый список.
Она удерживает экземпляр при замене файла и проверяет общие данные
двух связанных скалярных методов. [Сценарий](test_loaded_exports.py)
собирает образы компилятором проекта и запускает тест в обоих режимах.
