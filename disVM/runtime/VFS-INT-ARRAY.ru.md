# Vfsexport.intarray

[English](VFS-INT-ARRAY.md) · [Интерфейс](../module/vfsexport.m) · [Реализация](vfs/cap_array.c)

```limbo
intarray: fn(cells: list of ref Root): ref Root;
```

Загрузите `Vfsexport` по `Vfsexport->PATH`. Передайте от 0 до 252
целочисленных корней, созданных через [intvar](VFS-INT-VARIABLE.ru.md).
Результат — каталог с десятичными именами от нуля. Файлы только для чтения
`.len` и `.type` содержат длину с переводом строки и `array of int\n`.
Элементы читаются и записываются как знаковые четырёхбайтовые числа
со старшим байтом вперёд.

Каталог удерживает переданные ячейки. Один корень в двух позициях даёт
два имени для одной ячейки. Недопустимый корень, превышение длины или
нехватка памяти дают nil. Смонтируйте результат или добавьте его под
опубликованную `.var`. Состав каталога задаётся при создании.
[Пример Styx](../examples/remote-scalar/styx-scoped-calls.b) публикует
три позиции из двух ячеек и проверяет удалённую запись через VFS клиента.

### Выбор элемента через открытый FD

Откройте `.idx` на запись и запишите один индекс как четыре байта со
старшим байтом вперёд. Держа этот FD открытым, откройте `.val` на чтение
или запись. Позиция в `.val` относится к выбранной ячейке. Закрытие
`.idx` отзывает выбор и уже открытые для него `.val`. Другой локальный
процесс или встречный Styx-контекст может независимо выбрать свой индекс.
