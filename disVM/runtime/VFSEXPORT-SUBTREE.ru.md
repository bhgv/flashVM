# Vfsexport.subtree

[English](VFSEXPORT-SUBTREE.md)

Захватите отдельный узел из полномочия VFS, чтобы отобразить его по
другому пути. Сначала монтировать исходный каталог необязательно.

```limbo
include "vfsexport.m";
exports := load Vfsexport Vfsexport->PATH;
pipe := exports->recordpipe();
sender := exports->subtree(pipe, "send");
```

`subtree(root, relative)` заимствует существующий `ref Vfsexport->Root`.
Передайте относительный путь внутри выданного дерева. Одна точка
указывает на корень. Абсолютные пути, переходы в родительский каталог
и пустые компоненты отклоняются. Результат — собственный
`ref Vfsexport->Root` с правами захваченного узла. Он может пережить
исходную ссылку. При отмене, отсутствующем узле или ошибке захвата
функция возвращает `nil`.

Захват может ждать провайдера и подчиняется обычной нативной отмене.
Чтобы опубликовать захваченный узел, передайте его в
`Vfsexport->overlay`, указав нужный путь и предельные права.

В [примере с каналом записей](RECORD-PIPE.ru.md) захваченный конец
публикуется как номерной файл в выдаче дескрипторов клиента по Styx.
[Интерфейс Limbo](../module/vfsexport.m).
[Нативная реализация](vfs/cap_tree.c).
