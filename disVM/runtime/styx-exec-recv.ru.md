# Node.recv

[English](styx-exec-recv.md) · [Руководство](STYX-EXEC-PUBLISH.ru.md) · [Интерфейс](../module/styxexec.m#L30) · [Реализация](../limbo/styxexec.b#L123)

```limbo
node.recv(): ref Request
```

Дождитесь полного запроса на этом Node в вызывающем потоке Limbo. Результат содержит собственную копию входных байтов и точный билет. Используйте одного получателя на Node и завершайте запрос ответом или отказом. Недоступный локальный дескриптор даёт исключение.

```limbo
item := node.recv();
```
