# Styxexec.call

[English](styx-exec-call.md) · [Руководство](STYX-EXEC.ru.md) · [Интерфейс](../module/styxexec.m#L19) · [Исходник](../limbo/styxexec.b#L48)

```limbo
call: fn(mount, path: string, input: array of byte): array of byte;
```

После [init](styx-exec-init.ru.md) передайте абсолютное монтирование,
например `/peer`, непустой путь к исполняемому узлу от его корня и
заимствованные байты аргумента. Длина пути ограничена 1024 байтами UTF-8.
Вход может быть пустым или содержать до 65 536 байт.

Метод открывает отдельный fid, ждёт колбэк и возвращает новый массив
с ответом. Ответ может быть пустым, его длина не превышает длину ввода.
Входной массив остаётся у вызывающего. Неверный путь, отказ провайдера
или сбой транспорта дают исключение. К этому моменту колбэк уже мог
выполниться. Клиент не повторяет вызов. Процессы могут вызывать узлы
одновременно через инициализированный модуль. У каждого вызова свой fid.

```limbo
reply := exec->call("/peer", "tools/apply", array[] of {byte 255, byte 40, byte 0, byte 23});
```

В [парном тесте](../../lib/styxrpc/tests/flashvm/execute_pair.b) результат содержит три байта.
