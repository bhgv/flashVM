# Experimental runnable Dis and IDE services (NC64)

Use `python3 build_menu.py`, select `all` or `disvm-runtime`, and accept the
defaults. After building, choose **4** for the Dis channel example or **5** for
IDE workspace services. Installed commands also work independently:

```sh
bash out/disvm-runtime/run-console.sh
bash out/disvm-runtime/run-ide.sh
```

This is an actual native executable loading and executing compiled Limbo modules:
production Dis decoding, instructions, AMD64 guarded native leaves, stacks,
module linking, reference counting and cycle collector are retained. `up` and its
named `R` subobject use the existing OS TLS context. Blocking Dis channels and
spawned Limbo processes run above one native owner using a FIFO scheduler. This
initial executable does not yet run multiple VM owners concurrently.

The workspace example executes production idecore/ideworkspace modules and the callable
workspace tutorial: it creates document owners, takes a revision-bound build
snapshot and stops all services through channels. It does not fabricate compiler
output. The [interactive terminal editor](../../ide/dis/examples/editor-console/README.md)
also provides editing, Undo/Redo, search, AS/Limbo declarations/call tips and actual
UTF-8 file save/load. The optional `disvm-editor` executable now connects these document/input services to actual FlashVM TextField rendering; see the graphical tutorial below. The FlashVM
windowed examples remain separately launchable from the same build menu.

## Explicit experimental ABI

Classic bootstrap output uses four-byte cells; native host pointers and legacy
WORD are eight bytes on this AMD64 build. Silently mixing them corrupts frames,
pointer maps, alt tables and Sys arguments. This runner therefore uses a separate
**NC64** experimental cell target with magic **819264** (classic **819248**).
Native cells, int slots and pointer-map slots are eight bytes. Sys frames and
maps are generated by the matching compiler. This is not the proposed standard
Dis ABI64 with 32-bit int, nor a claim of complete classic Limbo integer-overflow
semantics. Classic modules are rejected, not reinterpreted. Existing compiler,
SDK and IDE packages keep their classic format unchanged.

`limbo-native` is installed beside `disvm` solely for this target. Example:

```sh
./limbo-native -g -I include/limbo -o console-check.dis examples/console-check/main.b
./disvm console-check.dis
```

The project's own Coco/R-to-FIR compiler remains the intended compiler path.
This selected upstream bootstrap enables runnable integration now. Debug symbols
are shipped beside native modules; a runtime debugger connection is still pending.

## Host boundary

Acceptance is native Linux AMD64. Normal Sys support includes production string
formatting/tokenization/UTF helpers, stdout printing and read-only module/file
opening plus read/readn through FlashVM's file port. Unavailable Sys calls report
explicit failures. One stdout message is bounded to a 4096-byte formatting buffer.
No successful empty Sys service, external emu, Inferno Draw or full
Inferno filesystem is substituted. Create/write supports actual files with OWRITE/0666 plus standard output/error.
Standard descriptors 0/1/2 are borrowed through FlashVM's common standard-stream
port. Other open/create flags and permissions are rejected. Network namespaces, Styx,
process control and Dis exception-handler propagation remain to be connected.

The standalone executable owns one bounded 64 MiB arena. Stable block headers
allow the retained Inferno RC and cycle collector to traverse it; first-fit
allocation currently splits blocks without coalescing, so fragmentation can hit
the limit. The allocator is private to this experimental host and can be replaced.
Cycle collection runs between scheduler slices on the owner, not concurrently;
existing collector-worker/safepoint APIs remain the future shared-owner path.
The runner bounds simultaneous processes and total scheduler slices, diagnoses
blocked-process deadlock, and relies on OS process teardown for its final native
resources. It is not yet a reusable independently destructible embedding object.

`--jit` and `--no-jit` select guarded leaves or interpretation. `--test-control`
explicitly enables an isolated `/dev/sysctl` halt node for unchanged IDE regression
clients. It is disabled during normal examples. Test automation checks exit
status and PASS/FAIL text because those existing tests intentionally halt on both
successful and failed assertions.

Local source-view adaptations are kept in `prepare.py`; imported files retain
manifest hashes. The byte-array descriptor fix is also supplied as an upstream
patch: legal byte arrays have module-local descriptors, so pointer identity with
`Tbyte` cannot be required. Alt headers are adapted only for NC64, with checked
narrowing to internal native counters.


The normal and native-cell bootstrap builds reserve a real sentinel slot in the
old generated yacc parser stack. This avoids forming `&yys[-1]`, which UBSan
identified during Sys-interface compilation. The adaptation runs after either
the pinned parser or a fresh iyacc generation; no grammar action is changed.


Module resource names resolve relative to the entry module's directory. The
runner and launch scripts preserve the caller's working directory for ordinary
Sys file paths. Installed applications can therefore find their sibling modules
while loading/saving relative user paths. This is resource lookup, not a filesystem
sandbox. Embedded NUL paths are rejected before any native open or truncation.


### File positioning and IDE resource windows

Native `Sys->seek` now uses the shared
[`fvm_port_file_seek`](../../flashVM/ports/file_port.h) adapter. `SEEKSTART`,
`SEEKRELA` and `SEEKEND` support negative relative offsets where the resulting
position remains nonnegative. A failed seek returns `big -1` without changing
the logical cursor. The native port currently uses checked `long` positions;
Linux AMD64 supports offsets above 2 GiB. Platforms with narrower `long` reject
unrepresentable offsets rather than truncating them. No wider-platform runtime
acceptance is implied. Standard descriptors and the isolated test-control node
are not seekable. Read-only handles reposition reads; write-only handles
reposition writes and may create holes if a later write extends the file.
Existing FlashVM `rw` channel handles retain independent read/append positions
and explicitly reject this new positioning API.

The installed terminal IDE offers `inspect PATH`: a separate
[Idefiles process](../../ide/dis/bridge/idefiles.README.md) measures the actual
file and returns a bounded binary window over typed channels. The console shows
the first sixteen bytes in hexadecimal. The service can also read arbitrary
start/end-relative windows up to 64 KiB for future debugger and source views.
It closes each file before replying and never retains a descriptor or array
between requests. Measurement/read are not a transactional file snapshot; another
writer may change the file between native operations. This is ordinary native
file access, not complete Inferno namespaces, Styx, or a sandbox.

Позиционирование `Sys->seek` работает через общий файловый порт FlashVM.
Команда IDE `inspect ПУТЬ` читает бинарный заголовок через отдельный Limbo-сервис
с каналом запросов/ответов. Смещения проверяются до сужения типа, ошибки не
меняют логическую позицию, стандартные потоки не перематываются. Для существующих
каналов FlashVM `rw` сохранён прежний режим независимого чтения и дописывания.


### Selected standard modules (runtime 0.2.0)

The package now registers actual $Srv, $Math and $Loader. Eight selected Limbo
libraries are compiled/installed with debug symbols: Bufio, String, Arg, Readdir,
Debug, Dis, Styx and Styxservers. Canonical /dis/lib paths for exactly those names
resolve to package siblings; ordinary Sys file paths keep their original native
meaning. `run-modules.sh` or post-build menu **7** executes the fully commented
[module tutorial](../examples/standard-modules/README.md). It is included in
installed checks. [Per-module executed coverage and open services](../libraries/README.md)
is authoritative: /prog, complete Sys/namespace/directory services and live Styx
serving have not been supplied by copying a library.

$Srv retains upstream error cleanup/GC roots and uses the shared native resolver
with a real lock. $Math retains checked wrappers/vector operations; scalar IEEE
functions use native libm. $Loader returns actual module instruction/type/link
snapshots. Unsupported services still fail explicitly. The default single-owner
scheduler/GC restrictions remain; synchronous DNS is not an asynchronous worker.

The NC64 runtime keeps private eight-byte numeric tables. New upstream classic
native ICASE/ICASEL/IGOTO leaves are deliberately declined for NC64; checked C
adapters execute those forms. The core retains and separately tests upstream
classic native table leaves. Tests verify all three opcodes are actually emitted,
selected destinations are correct and malformed full-width/unaligned table data
cannot silently truncate a destination PC.

Модули доступны без внешнего emu. Наличие debug.dis не означает готовый /prog,
а наличие Styx-кодека — готовую VFS. Проверочный пункт 7 исполняет реальные
поддержанные функции и проверяет ошибочные входы; подробные ограничения указаны
в таблице готовности модулей.

### Graphical editor (runtime 0.3.0)

[English tutorial](../../ide/dis/examples/graphical-editor/README.md) ·
[Русское руководство](../../ide/dis/examples/graphical-editor/README.ru.md).
Build `disvm-editor` with `DVM_RUNTIME_EDITOR=ON`; SDL windows additionally require
`DVM_EDITOR_SDL=ON` and an explicit SDL2 SDK. The console `disvm` keeps its existing
graphics-free build. `$Idehost` is registered only by the editor executable and
borrows stack-rooted channels until Limbo explicitly detaches. No cross-heap
pointers are transmitted. File/save/history policy runs in Limbo; TextField
presentation uses FlashVM, and the thin SDL host only presents pixels/events.
The Dis-selected viewport, mouse/scrolling, search/path fields and bundled-font scaling are documented in the tutorial; AS-worker/debugger integration remains open. `--events` is offscreen replay, not physical UI proof.

### Bundled font and size (runtime 0.4.0)

Noto Sans Mono/OFL is packaged beside the module; no font selection is required.
Default size is 11. Ctrl+wheel and SDL two-finger pinch propose bounded Dis-owned
zoom with actual row geometry, including desktop touch-capable adapters.
[English contract](../../ide/dis/ZOOM.md) · [Русский](../../ide/dis/ZOOM.ru.md).
The signed-int32 envelope fix is exercised by real NC64 codec tests.
