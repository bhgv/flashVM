# Node.close

[English](styx-exec-close.md) · [Руководство](STYX-EXEC-PUBLISH.ru.md) · [Интерфейс](../module/styxexec.m#L42) · [Реализация](../limbo/styxexec.b#L196)

```limbo
node.close()
```

Освободите дескриптор владельца. При закрытии хост снимает точный слой и завершает ожидающий вызов отказом. Повторное закрытие безопасно. Владелец также отзывается при освобождении последней ссылки на дескриптор. Сериализуйте закрытие с остальными операциями Node.

```limbo
node.close();
```
