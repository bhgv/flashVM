# dvm_module_publish

[English](MODULE-PUBLISH.md) · [Заголовок](vfs/module_adapter.h) · [Пример](../examples/remote-scalar/STYX.ru.md)

```c
DVM_Provider *dvm_module_publish(DVM_Provider *original, DVM_Provider *adapter);
```

Нативный хост связывает захваченный файловый узел с адаптером от
[dvm_module_adapter](MODULE-ADAPTER.ru.md). Исходный провайдер должен
поддерживать отменяемые операции по пути и захват точного корня.
Функция может читать метаданные. Она возвращает собственный провайдер
или NULL при отказе, отмене или нехватке памяти. Аргументы заимствуются,
результат удерживает оба источника.

Смонтируйте результат как отдельный файл. Его `bind` удерживает публикацию.
`stat`, открытие на чтение и поиск адреса запуска используют исходный файл. Открытие на запись
отклоняется. Типизированный `load` того же узла VFS использует локальный
адаптер с его пространством имён. Хост связывает исходный файл, адаптер
и маршрут Styx при публикации. Обычное монтирование Styx само такую связь
не создаёт.

Публикатор может выставить файл через каталог VFS и смонтировать весь
каталог. Для `load` каждое представление на пути должно разрешать чтение
и исполнение. Загрузчик проверяет до 32 провайдеров. `bind` файла из
каталога удерживает представление и его правила доступа. Путь с доступом
только на чтение по-прежнему позволяет читать файл.
