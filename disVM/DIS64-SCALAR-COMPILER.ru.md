# Скалярный компилятор Dis64 и проверка полей

[English](DIS64-SCALAR-COMPILER.md) · [Синхронизация](SYNC.ru.md) ·
[Встречный тест](upstream/doc/dis64-external-reader.md)

Выбраны исходники Inferno на коммите
`4fd422043088d9ba8bf697db89d2069ec40ef9f4`: серии INFERNO-0052..0054 и наш
ответ FLASHVM-0050. Bootstrap Limbo собирает ограниченный backend `-6`.
Основным остаётся наш Coco/R Limbo → FIR; исторический парсер используется
только во временном, явно выбранном bootstrap.

## Компиляция и проверка

Пример `examples/firststeps/tools/limbo-scalar/loop.b` содержит
один `init()` без параметров, скалярные данные и цикл с самопроверкой. Он не
импортирует Sys/Draw и не использует управляемые объекты.

```sh
out/limbo-bootstrap/limbo-bootstrap -6 -o loop.dis64 \
    examples/firststeps/tools/limbo-scalar/loop.b
out/disvm/dis64inspect loop.dis64 --pilot --rewrite checked.dis64
```

Подставьте пути выбранных установленных продуктов. Reader проверяет прежний
скалярный pilot и сохраняет `execution_supported=false`. Общий запуск Dis64,
файловые CALL/MCALL, импорты и полноценная оболочка этим не включаются.

Прямые локальные переменные сдвигаются на 32 байта, временные скалярные ячейки
переносятся в отдельный выровненный 16-байтовый хвост кадра. Перекрывающиеся
байты временных ячеек сохраняют перекрытие; доступ к зарезервированному слову
возврата запрещён. Это не метаданные аргументов native-вызова. Неподдерживаемый
исходник отклоняется без частичного результата. Обычный Dis не меняется.

## Повторение проверок

```sh
cmake -S disVM -B build/dis-review \
    -DDVM_NATIVE64_LIMBO_EXECUTABLE=/absolute/build/limbo-bootstrap
cmake --build build/dis-review
ctest --test-dir build/dis-review --output-on-failure \
    -R 'disvm_native64_field_|disvm_dis64_external_reader'
```

Компилятор задаётся явно, необязательно; скрытой зависимости от соседнего дерева
нет. Пять тестов полей проверяют настоящие compiler metadata, witness и Math:
обычный вариант и четыре намеренных удаления защит. Учитываются ограничения
нативного Linux x64/ARM64; cross target автоматически не запускается.

Встречный тест проверяет 64 размещения живых локальных переменных, точную
перезапись файлов, сохранность обычного Dis и отказ 64 повреждённых карт без
перезаписи результата. Два независимо собранных компилятора дали одинаковые
байты. Дополнительный запуск полного x64-эмулятора выполнил 128 корректных
процессов и два процесса с намеренно неверным ответом, проверив настоящую
ошибку и позднее завершение scheduler. Это не физическая проверка ARM64/RV64.

## Границы согласованного решения

Метаданные различают Big, Real и padding по исходному номеру, типу и ширине поля.
Witness связывает их с точным callable, удерживаемыми Module/Type, экземпляром
Modlink и текущей активацией. По 351 условию прошли в двух WORD-моделях; четыре
удаления защит в обеих моделях привели к ожидаемым семантическим отказам.

Принимается только синхронный доверенный C-профиль. Неизменяемые таблицы и
правильное сопоставление конструктора остаются обязательными. Произвольная
C-таблица не аутентифицируется как результат компилятора. Удержание текущего
caller нельзя переносить через асинхронную задачу или ожидание канала.
Detached lifetime, перемещаемые/приостановленные кадры, управляемые графы
аргументов/результатов и прежние замечания ASan по UTF/unwind остаются открытыми.
Новые общие section/feature/kind/opcode IDs не назначаются.
