# Блокировки операций и синхронизация с Inferno

[English](OWNED_SYNC.md) · [Пример владельца с блокировкой](../common/owned/README.ru.md) ·
[Транзакционная замена диапазона](../common/table/SPLICE.ru.md)

Снимки интерпретатора и bootstrap-компилятора закреплены на Inferno experiment
`152ab5ae4f315d1479d3a508796a8b56d5048c66`. Получены проверки CALL/MCALL/RET,
FRAME/MFRAME для приоритетных архитектур, проверка карт указателей и публикации
кадров, диапазонов use/def оптимизатора. Исходники и лицензии сохранены побайтно.
Матрицы машинного кода проверяют AMD64 и ARM64; запуск на физическом ARM64
в этой серии не проверялся.

Исправление теста копирования списков сделано в исходной репозитории Inferno и
сначала опубликовано туда. Проверка разрешает полные восьмибайтовые чтения строго
внутри исходного диапазона, сохраняя запрет выхода за границы и обращения к данным
при отказе быстрого пути. Старый тест ошибочно разрешал только побайтовые чтения.
Защитные проверки самой production VM не ослаблялись.

Отдельные расширения FlashVM: POSIX-блокировка с токеном операции и повторным
входом, защищённый native-владелец scalar-таблицы, C API транзакционной замены
плотного диапазона. Тесты настоящими потоками проверяют read-modify-write через
вложенные callback. Запускаемый пример показывает вставку таблицы в себя и
время жизни владельца. Внедрение ошибок allocator проверяет откат и баланс памяти;
конфликт с разреженным числовым ключом отклоняется без потери значений.

Пока не выполнены: блокировки внутри памяти массивов/строк DisVM, интеграция со
временем жизни удалённых операций и планировщиком, присваивание с изменением длины
среза native-массива, regexp-срезы и замена по группам.
[Присваивания таблицам и строкам через Limbo/FIR](../fir/v1/doc/SLICE_ASSIGNMENT.ru.md)
уже реализованы через проверяемый builtin-интерфейс. Plain Fht по-прежнему
требует внешней сериализации. Штатные Dis array views разделяют память по прежним
правилам. Наличие host-библиотеки блокировок не означает готовую интеграцию с VM
или новую языковую операцию.
