# Отрицательные позиции нативных массивов и строк

[English](README.md) · [Исходник](main.b) ·
[Семантика](../../../fir/v1/doc/RELATIVE_SEQUENCES.ru.md)

Сборка runtime создаёт `relative-test.dis`. Из корня репозитория:

```sh
build/runtime/disvm --jit --quantum 1 --stats build/runtime/relative-test.dis
build/runtime/disvm --no-jit --quantum 1 --stats build/runtime/relative-test.dis
```

Модуль печатает PASS после проверок byte/int/big/real, отрицательной записи и
смещения присваивания среза. `[0:-1]` создаёт независимое хранилище; изменение
полной/частичной копии не меняет источник. Строки mapped-записей живут после
освобождения источника, а ref ADT сохраняют идентичность объектов. Unicode
индексируется скалярами; запись символа сохраняет старые алиасы через COW.
Пустые копии допустимы. Все этапы комментированы.

Массивный пример компилируется опорным компилятором Limbo, а не ограниченным
Coco/R-фронтендом. Table/string пути проверяются через наши source/FIR-сервисы.
Относительный массивный срез пока сначала копирует весь источник; положительный
срез сохраняет старую семантику общего view. Разделение содержимого физическими
потоками ещё требует описанных отдельно токенов владения. Сейчас C-операция
сериализована на потоке-владельце VM.
