# Освобождение блокировки до обработки исключения

[English](README.md) · [Контракт владения](../../PAYLOAD_GUARDS.ru.md)

`main.b` — native-cell программа Limbo с проверяемой библиотекой `$Bigtable`.
Она заполняет таблицу, читает состояние блокировки, ловит ошибку диапазона и
неуспешного splice, затем проверяет доступность объекта и нулевые owner/depth/
waiters. Далее выполняются self-splice, копия плотной части и ключей, удаление
исходного handle и проверка независимого времени жизни снимков.

Сборка через `disVM/runtime` создаёт `tableguards-test.dis`. Команды запуска
из корня репозитории приведены в English README. В обоих режимах выводится
`PASS table guards, exception cleanup and independent snapshots`, статистика
завершается `tables_live=0 keys_live=0`.

Пример компилируется сохранённым native bootstrap для проверки полного синтаксиса
исключений Limbo. Наш ограниченный Coco/R-профиль отдельно проверяется на
присваиваниях таблицам/строкам. Это локальная библиотека, не пример сетевого
прокси. Настоящая одновременная конкуренция за scalar-данные проверяется pthread-
тестами общего C request-слоя.
