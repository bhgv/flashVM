# Исполняемый пример гибридных таблиц

[English](README.md) · [Подробно комментированный код](main.b)

Встроенный модуль `$Bigtable` связывает C99-ядро с `disvm` и `disvm-editor`.
Сейчас исполняется явный модульный API, а не автоматический перевод `table of big`
через FIR. Модуль загружается через `load Bigtable Bigtable->PATH`; `create`
создаёт таблицу, `setindex/settext` записывают, `getindex/gettext` читают.

Чтение возвращает `(статус, big)`. При отсутствии ключа выдаётся Missing, а не
успешный ноль. Перед использованием значения обязательно проверяется статус.
Числовые ключи — неотрицательные big; строки копируются в UTF-8 с явной длиной,
включая нулевые символы. `length` считает непрерывную последовательность от нуля,
`count` — все пары, включая разреженные индексы и словарные ключи.

`slice` копирует полуоткрытый числовой диапазон в самостоятельную таблицу.
`keysof` создаёт независимый неизменяемый снимок: длина `keylen`, доступ `keyat`.
Элемент возвращается как `(вид ключа, число, строка)`. Снимок живёт и после
уничтожения исходной таблицы. Числовые ключи отсортированы, строковые сохраняют
порядок добавления.

Нативные владельцы управляются GC. Публичное поле reserved не содержит указателя;
подделанный ADT не принимается как владелец. Финализатор освобождает C-память,
в которой нет ссылок на кучи VM. Вызов синхронный, на текущем последовательном
владельце планировщика. Это ещё не сетевой прокси или многопоточный общий объект.

После сборки runtime:

```sh
ctest --test-dir build/runtime -R application_hybridtable --output-on-failure
cd build/runtime
./disvm --stats --jit hybridtable-test.dis
./disvm --stats --no-jit hybridtable-test.dis
```

Общий Coco/R-фронтенд Limbo распознаёт синтаксис расширения. Отдельно наш
fir1_source теперь выполняет типизированный lowering создания, индексов, t.k,
срезов, keysof и len в FIR для ограниченного профиля value(): big. См.
[контракт компилятора](../../../fir/v1/doc/TABLES.ru.md). Его C-исполнитель FIR
не является этим нативным примером Dis. [Генерируемые вызовы из Dis](../../../fir/v1/doc/TABLES_DIS.ru.md) уже исполняют
тот же модуль. Вызовы из SWF, индексирование keyseq, парный обход и typeof/any
ещё предстоят. Этот пример продолжает явно использовать модуль и временный bootstrap.
