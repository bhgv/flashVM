# Пример владения кооперативными задачами

[Полный контракт, владение и сборка](../../../compiler/runtime/ASINC-TASKS.ru.md)

`main.b` — переносимое приложение Limbo, собираемое в `tasks-demo.dis`. Оно
загружает asinctasks.dis, передаёт строковый вход, запускает отдельный процесс
Limbo и ждёт по каналу. Обработчик получает задачу со своим ID и токеном,
завершает её, а потребитель забирает результат один раз и удаляет запись Retire.
Так повторяется 96 раз на одном владельце; затем сервис останавливается.
Каждый ответ читается; ожиданий кадра и искусственных задержек нет. Исходный
bootstrap-компилятор нужен только при сборке.

Запуск из каталога собранного runtime: `./disvm --no-jit tasks-demo.dis`, затем
`./disvm --jit tasks-demo.dis`. Оба запуска проверяют 96 результатов и печатают одинаковое число завершённых задач. Установленный пакет содержит
оба модуля и полное руководство по ссылке выше вместо краткого README примера.
Понижение AS-синтаксиса asinc и нативные потоки AS пример не реализует. Полное
руководство описывает отмену, устаревшие ID, ёмкость и приёмочные тесты обоих режимов.
