# Преобразование real и Unicode-дописывание на настоящем Dis

[English](README.md) · [Полностью комментированный пример](main.b) ·
[Рантайм](../../runtime/README.md) ·
[Контракт native-путей](../../upstream/libinterp/tests/README.real-decimal-append.md).

Пример Limbo исполняет преобразование строки в real, различает знак нуля через
Math.realbits64 и дописывает ASCII, евро и не-BMP-символ при сохранённом исходном
владельце строки. Ответы проверяются независимо; PASS печатается только после
успешных реальных операций. В установленном примере не нужны Python, внешний
Inferno или парсер чисел на стороне запускающего скрипта.

Соберите disvm-runtime либо disvm-editor через меню рабочего пространства или
документированные параметры CMake. Временный Limbo bootstrap собирается из
исходников и создаёт подходящий NC64-модуль. Основная собственная цепочка
компилятора/парсера остаётся Limbo/FIR с Coco/R. В установленном пакете:

```sh
./disvm --stats --jit decimal-append.dis
./disvm --stats --no-jit decimal-append.dis

# Перекомпиляция только поставленными компилятором и заголовками:
./limbo-native -g -I include/limbo -o decimal-append.dis examples/decimal-append/main.b
./disvm --stats --jit decimal-append.dis
```

Вывод показывает вычисленные результаты для 123456789, -42, -0, 1.25 и 1e2.
Признак отрицательного нуля равен 1 только для -0. Исходная строка остаётся `AB`,
новая становится `ABC€😀`, её длина в скалярах Limbo — 5. Шрифт терминала может
отобразить символы иначе, но сам модуль проверяет значения до печати.

Guarded CVTCF для AMD64/ARM64 принимает короткие точные десятичные целые;
дроби и экспоненты сохраняют C fallback. Дописывание без выделения возможно при
уникальном владельце и достаточной ёмкости; сохранённая копия и смена ASCII на
Rune в этом примере могут потребовать C-путь. Счётчик native>0 подтверждает
реальное JIT-исполнение в запуске, но не каждый отдельный показанный opcode.
Для native-путей есть независимые C/JIT и эмулируемые проверки инструкций.

Пример использует экспериментальные magic/cells NC64: компилятор, .m и рантайм
должны соответствовать друг другу. Проверено исполнение Linux AMD64; полный
classic ABI и физические ARM64/RV64-порты этим не объявляются. Интерфейсы
передают значения строк/чисел, а не указатели heap другой VM.
