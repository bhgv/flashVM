# Error и преобразование в строку — v0.9

[`fvm_standard_install`](../include/flashvm/standard.h#L20) атомарно устанавливает метаданные конструктора AS2 Error
вместе с Math и Boolean. [`fvm_construct`](../include/flashvm/value.h#L158) с именем Error и AVM1 NewObject создают
объект с обычным изменяемым прототипом. Поля Error.prototype.name и message
по умолчанию равны строке «Error». Пропущенный аргумент и undefined оставляют
унаследованное сообщение; остальные значения сохраняются без преобразования.
Лишние аргументы игнорируются.

Error.toString преобразует message в строку и не добавляет name. Это соответствует
[справочнику AS2 Error](https://open-flash.github.io/mirrors/as2-language-reference/Error.html).
Метод можно заимствовать другим объектом. Нативный getter сообщения или метод
преобразования может возбуждать исключение, перехватываемое AVM1 try/catch.

## API и AVM1

В C89-заголовке `flashvm/standard.h` добавлены [`fvm_value_to_string`](../include/flashvm/standard.h#L30) и
[`fvm_value_instance_of`](../include/flashvm/standard.h#L34). Преобразование копирует входные строки в память контекста,
допускает совпадение входа и выхода, форматирует примитивы и вызывает нативные
методы toString/valueOf объектов. Глубина рекурсии ограничена 64 вызовами.
Для конечного числа подбирается до 17 значащих цифр с проверкой обратного
преобразования libc; разделитель и запись экспоненты нормализуются. Проверяются
границы форматов и 256 воспроизводимых двоичных чисел binary64. Это не доказательство
полного совпадения с Flash для всех чисел и версий SWF. Изменять локаль параллельно
с преобразованием нельзя.

Операция instanceof и opcode AVM1 0x54 сравнивают идентичность прототипов нативных
классов Boolean, Error, TextFormat и TextField. Обычный объект с полем prototype
не становится конструктором. Примитив слева даёт false; некорректный конструктор
отклоняется. Обход прототипов ограничен.

Ресурсные исключения сохраняют code, message и context. При установленном Error
они получают текущий зарегистрированный прототип класса. Собственный нативный
метод toString доступен и без установки стандартной библиотеки. Нативные операции
с ресурсами сохраняют контракт C-кодов результата; вызовы из ActionScript создают
ожидающее исключение, как описано в [EXCEPTIONS.ru.md](EXCEPTIONS.ru.md).

## GC и передача по каналам

GC отслеживает захваченный конструктор, прототипы, объекты в message, корни методов
и ожидающие исключения. Сериализатор графов сохраняет циклы, общие ссылки,
прототипы и встроенный callback Error.toString с идентификатором 301. Восстановление
из очереди и файлового канала сохраняет метод без стандартной библиотеки на
принимающей стороне. Запись и чтение файла проверены независимыми процессами.
Снимок ресурсного исключения передаёт диагностические данные, а не неявную живую
копию закрытого ресурса.

Полученный граф имеет новую идентичность: экземпляр соответствует переданному
вместе с ним конструктору, но не отдельно установленному Error получателя.
Передача конструктора не регистрирует его в глобальном пространстве получателя.
Версии читателя до v0.9 не поддерживают новые виды Error и идентификатор метода.

## Примеры, проверки и ограничения

Пример API: [examples/actionscript/error.as](../examples/actionscript/error.as).
Тесты: `standard_error.c`, `actionscript_error.cpp`, `string_conversion.c`,
`error_allocation.cpp`, `error_transfer_process.c`; межпроцессный драйвер —
`scripts/test_error_process.py`. Инъекция отказов памяти проверяет отсутствие
частичных глобальных объектов после неудачной установки, очистку выхода
конструктора и повторное создание исключения из сохранённого сбоя после GC.

Это этап реализации нативного Error. Он ещё не является полноценным Function;
вызов Error без new и методы преобразования, заданные скриптовыми функциями,
не реализованы. Полные Object/Function, атрибуты и преобразования по версиям SWF,
Function2, строковые API, все стандартные объекты, JIT и экранные адаптеры остаются
в работе. Компилятора исходного ActionScript нет: пример .as описывает API,
а исполняемые тесты самостоятельно формируют записи AVM1.
