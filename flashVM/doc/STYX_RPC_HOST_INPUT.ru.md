# Оконный ввод для парных фильмов

[English](STYX_RPC_HOST_INPUT.md) · [Парный плеер](STYX_RPC_PLAYER.ru.md) · [IDE](../../ide/DESKTOP-PAIRED.ru.md)

При запуске парного плеера с `--window` загруженный фильм получает объект
`hostInput`. Он подходит, когда удалённое приложение владеет редактором или
задаёт правила обработки ввода. FlashVM опрашивает SDL2 в потоке окна.
ActionScript решает, какие события посылать в существующее соединение приложения.

| Операция | Поведение |
| --- | --- |
| `hostInput.enable()` | Возвращает true. На следующем шаге владелец окна переключает фильм на опрос одной очереди вместо доставки Key, Mouse и ClipActions. |
| `hostInput.take()` | Копирует и снимает одно событие. Возвращает числовой вид события либо ноль при пустой очереди. |
| `hostInput.get(name)` | Читает именованное поле последнего снятого события. Используйте его после ненулевого результата `take()`. |
| `hostInput.enableResize(minWidth, minHeight, maxWidth, maxHeight)` | В режиме опроса включает события изменения размера и координаты в пикселях окна. Размеры задаются целыми числами от 1 до 4096. При успехе возвращает true. |
| `hostInput.commitViewport(width, height)` | Публикует размер растра в целых пикселях в пределах правил фильма. Новый размер используется при следующей отрисовке и записи PPM. При успехе возвращает true. |
| `hostInput.publishFrame(revision)` | Публикует целую ревизию от 0 до 4294967295. Положительное значение запрашивает один растр последней подтверждённой сцены. Ноль выбирает непрерывную отрисовку. При успехе возвращает true. |

| Вид | Событие и поля |
| --- | --- |
| 1 | Клавиша. `code` содержит виртуальный код Flash, `phase` равен 1 при нажатии и повторе или 0 при отпускании. |
| 2 | Указатель. `x` и `y` содержат логические пиксели сцены. `code` равен 1 для основной кнопки и 2 для средней. `phase` равен 1 при движении, 2 при нажатии или 3 при отпускании. Первое касание поступает как основной указатель. |
| 3 | Вертикальное колесо. `wheel` содержит число строк со знаком, положительное для прокрутки вверх. `x` и `y` содержат логические пиксели, а `control` — состояние Ctrl при событии. |
| 4 | Подтверждённый текст. `text` содержит строку Unicode с длиной из текстового ввода SDL. |
| 5 | Фокус. `phase` равен 1 при получении и 0 при потере. |
| 6 | Запрос закрытия окна. Подписанный фильм обрабатывает его как событие приложения. |
| 7 | Изменение размера окна. `x` и `y` содержат новую ширину и высоту в пикселях окна. |

Очередь вмещает 128 событий. Соседние движения с той же зажатой кнопкой
могут объединяться до последней позиции. При заполнении плеер уступает
управление до снятия нового события из SDL. Escape поступает в подписанный
фильм как клавиша. Потеря фокуса сбрасывает нативные модификаторы и
доставляется в порядке очереди. При замене фильма его события удаляются.
Методы вызываются в потоке владельца VM и окна. Снимок содержит копии чисел
и строк.

После `enableResize` координаты указателя задаются в пикселях окна. Соседние
ещё не снятые события размера могут объединяться до последнего значения.
Фильм с удалённой компоновкой может показывать предыдущий кадр до ответа,
затем подтвердить размеры вызовом `commitViewport`. Недопустимые аргументы
вызывают ошибку ввода. SDL обновляет текстуру в потоке владельца и сохраняет
окно и очередь событий.

Задавайте новую положительную ревизию при изменении завершённой сцены.
Плеер показывает последнюю ревизию и использует её растр при опросе ввода.
SDL может вывести его повторно при открытии окна после перекрытия и при
восстановлении устройства. Изменение размера также запускает отрисовку,
а явная запись PPM рисует текущий снимок. Парный IDE использует этот метод
вместе со [снимками MovieClip](MOVIECLIP_SNAPSHOT_BITMAP.ru.md).

`MovieClip.getChildDepthAtPoint(x, y)` принимает мировые пиксели и по границам
возвращает глубину верхнего видимого прямого дочернего клипа.
`MovieClip.getTextScalarAtPoint(depth, x, y)` проверяет TextField на указанной
глубине и возвращает индекс вставки в кодовых точках Unicode либо `-1` вне
поля. `TextField.getScalarCount()` использует такую же единицу.
`TextField.setSelectionPreview(anchor, caret, highlightRGB, caretRGB)` задаёт
границы выделения и 24-битные цвета для следующего кадра. При равных границах
рисуется каретка. Значение `-1` у любой границы скрывает выделение и каретку.
Растер рисует подсветку шагов глифов под текстом, а каретку поверх. Оба слоя
ограничены областью просмотра поля. Правка, фокус и выделение принадлежат
приложению. При объединении соседних кодовых точек шрифтом подсветка следует
кластерам глифов.
