# Владение SDL при встраивании

Начиная с v0.670 fvm_desktop_window_open отдельно получает ссылки TIMER и VIDEO.
fvm_desktop_window_close уничтожает только ресурсы своего окна и освобождает
только успешно полученные ссылки подсистем. Закрытие null безопасно. Глобальный
SDL_Quit не вызывается ни при обычном закрытии, ни при ошибке запуска.
Окна и ранее полученные ссылки приложения сохраняются. Несколько окон плеера
можно создавать и закрывать независимо.

Окончательный SDL_Quit принадлежит встраивающему приложению. Оконные вызовы
выполняются на основном UI-потоке. Это не маршрутизатор событий для нескольких
окон: синхронный плеер по-прежнему читает общую очередь SDL. Курсор и прочие
глобальные настройки требуют отдельного согласования.

Сама SDL 2.30.12 может оставить внутреннюю ссылку EVENTS после неудачного запуска
VIDEO. FlashVM освобождает свои успешно полученные ссылки, но не угадывает
внутренние счётчики SDL. Завершая собственный сеанс SDL, приложение вызывает
SDL_Quit.

Регрессия C89 sdl_ownership проверяет ошибку VIDEO при живых ссылках приложения
на таймер и события. Затем в отдельном сеансе dummy-video она многократно
открывает два окна плеера рядом с окном приложения, закрывает их, проверяет
идентичность оставшихся окон и полное завершение подсистем после освобождения
ссылок приложения. Это не проверка физического дисплея.

```sh
cmake --build build-player --target flashvm_frontend_sdl_ownership
ctest --test-dir build-player -R frontend_sdl_ownership --output-on-failure
```

## Политика ввода приложения с v0.671

Открытие окна больше не меняет SDL_TOUCH_MOUSE_EVENTS и SDL_MOUSE_TOUCH_EVENTS.
Значения и приоритеты остаются у приложения, в том числе при ошибке запуска.
Адаптер локально отбрасывает синтетические события мыши SDL_TOUCH_MOUSEID и,
при наличии поддержки SDK, пальца SDL_MOUSE_TOUCHID. Отслеживание основного
пальца также подавляет дублирующие переходы мыши. Регрессия владения проверяет
значения normal-priority и их защиту от записи с меньшим приоритетом; pointer
проверяет подавление повторного ввода. Сохранение и восстановление глобальных
hint не используется: оно могло бы затереть обновление приложения.
