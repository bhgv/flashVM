# vfs.resultChannel

[English](STYX_RPC_RESULT_CHANNEL.md) · [Руководство](STYX_RPC_RESULT_CHANNELS.ru.md) · [Реализация](../src/styxrpc/channel_result_endpoint.c#L247)

## Синтаксис

```actionscript
vfs.resultChannel(elementType:String, slots:Number):Object
```

## Параметры

| Параметр | Значение |
| --- | --- |
| `elementType` | Компактный тип одного копируемого элемента без внешних скобок. Примеры `i`, `s`, `b`, `a[s]`, `l[(sb)]`. Укажите тот же тип, что в скомпилированном `chan of T`. |
| `slots` | Точное целое от 0 до 8. Положительное число задаёт ёмкость каждого направления отдельно. Ноль выбирает rendezvous. |

## Результат и время жизни

Возвращает объект моста с методами `trySend`, `tryReceive`, `active` и `close`. При первой успешной передаче из экспортированного метода публикация переходит fid результата. Для работы с локальным концом сохраните ссылку AS. Обычные значения, включая строки nil, используют [типизированное соответствие](STYX_RPC_VALUE_TYPES.ru.md). Для типов с вложенными каналами и ссылками служат отдельные API.

Используйте смонтированный плеер или зарегистрируйте [конструктор в хосте C](STYX_RPC_RESULT_CHANNEL_FACTORY.ru.md). Вызывайте у владельца контекста. Ошибка типа или ёмкости выявляется до публикации. При ошибке памяти или подготовки живой объект не выдаётся. Конструктор работает без обмена по Styx. Закрытый, уже выданный или несовместимый конец в результате вызывает удалённую ошибку.

## Пример

```actionscript
var owner = vfs.resultChannel("i", 1); // Один элемент в каждом направлении.
owner.trySend(21);                     // Сохраните owner и верните его из fn(): chan of int.
```
