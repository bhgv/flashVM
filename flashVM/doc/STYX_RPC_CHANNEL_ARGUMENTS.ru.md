# Передача каналов FlashVM в DisVM

[English](STYX_RPC_CHANNEL_ARGUMENTS.md) · [Живые каналы результата](STYX_RPC_CHANNELS.ru.md) · [Независимый C SDK](../../lib/styxrpc/reference/channel_argument_scopes.ru.md)

Контекстная функция Limbo может получать живые каналы FlashVM и работать с ними, пока вызывающий ждёт ответа. FlashVM временно передаёт типизированные очереди через libstyxrpc. Встречный диспетчер Styx обслуживает операции во время ожидания владельца контекста. Диспетчер не вызывает методы ActionScript.

## Настройка хоста и вызов из ActionScript

1. Используйте одно двустороннее соединение с прямым монтированием DisVM и встречным сервером Styx. Зарегистрируйте PID вызывающего [в дереве процессов C SDK](../../lib/styxrpc/reference/program_add.ru.md).
2. Создайте [шину аргументов](../../lib/styxrpc/reference/argument_bus_create.ru.md) для этого PID и опубликуйте её ресурс как [`.prog/<pid>/.unibus`](../../lib/styxrpc/reference/program_unibus.ru.md) до запуска сервера. Удерживайте шину на этом соединении до остановки встречного сервера.
3. Установите [конструктор локальных каналов](STYX_RPC_CHANNEL_FACTORY.ru.md) и [импорт с аргументами](STYX_RPC_CHANNEL_ARGUMENTS_IMPORT.ru.md) в контексте владельца FlashVM. Используйте точную компилированную схему, подпись и PID.
4. Создайте типизированный канал, поместите в него начальные значения и передайте импортированной функции. Например, для импорта `exchange` с формой `fn(port: chan of int): int`:

```actionscript
var port = newRpcChannel("i", 1);
port.trySend(41);
var observed = exchange(port);
var reply = port.tryReceive();
```

Функция может принять значение из `port` и отправить ответ в ту же очередь до возврата. Limbo также использует обычный `alt` с выданными каналами. Ссылки на каналы могут находиться в массивах и кортежах. Повторная ссылка получает тот же ключ и ту же очередь. Значение AS `null` обозначает nil-канал.

## Срок жизни и ошибки

SDK сверяет контекстное предложение, PID и ключи, затем активирует шину непосредственно перед первой записью. При завершении, истечении срока или ошибке SDK отзывает поколение и снимает незавершённые встречные операции. Изменения очереди от завершённых операций доступны в AS. При удалённом исключении или неопределённом исходе отправка либо приём уже могли состояться. Канал, отдельно возвращённый DisVM, может продолжить работу по своей аренде результата.

Один вызов допускает до восьми разных очередей. В каждой локальной очереди от нуля до восьми слотов. Нулевая ёмкость позволяет синхронизировать две операции DisVM во время вызова. Привязка принимает элементы каналов по значению. Каналы-аргументы из DisVM в FlashVM и делегирование каналов внутри элементов остаются открытыми.
