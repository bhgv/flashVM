# vfs.cd(path)

[English](STYX_VFS_CD.md) · [pwd](STYX_VFS_PWD.ru.md) · [Реализация](../src/styxrpc/session_paths.c)

`vfs.cd(path)` и `os.cd(path)` устанавливают общий рабочий каталог.
Путь передаётся непустой строкой. Абсолютный путь начинается от корня
подключения, относительный — от текущего каталога. При разрешении
учитываются `.`, `..` и повторные косые черты. Переход выше корня
остаётся в корне. Вызов проверяет открытие обычного каталога и
возвращает `true`. При ошибке текущий каталог сохраняется.

Следующие относительные файловые и канальные вызовы используют этот путь
в живой VFS. Служебные пути и рабочий каталог другой стороны независимы.
Ранее открытые файлы и каталоги сохраняют свои fid.

```actionscript
var entered = vfs.cd("/work");
var file = os.open("readme.txt");
file.close();
```
