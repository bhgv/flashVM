# Async.run(function[, ...args])

[English](ASINC_RUN.md) · [Руководство](ASINC_TASK.ru.md) ·
[Реализация](../src/standard/async_tasks.cpp)

Передайте сериализуемую функцию AVM1 из текущего контекста и до восьми
позиционных значений. Вызов синхронно копирует окружение и аргументы одним
графом и возвращает задачу после запуска системного потока. Поддерживаемые
кодеком общие объекты и циклы сохраняются в копии. Поток вызывает функцию
с этими аргументами в отдельном runtime. В копии
нет указателей на кучу запускающего контекста. Изменения одного контекста
не меняют другой. Ошибки сериализации и создания потока сообщаются при
запуске. Нативные функции, функции с присоединённым нативным телом и захваты
ресурсов без отделяемой копии отклоняются. Один контекст удерживает до 16 задач.

Владелец читает примитивный результат через [poll](ASINC_POLL.ru.md) и
может запросить [отмену](ASINC_CANCEL.ru.md). Возврат объекта завершает
задачу ошибкой. Плеер предоставляет задаче [обычную VFS](ASINC_VFS.ru.md) с отдельным рабочим каталогом. Шкала фильма остаётся у владельца.
Встраивающая программа устанавливает API через
[`fvm_async_install`](../include/flashvm/async.h#L15).
