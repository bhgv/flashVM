# Free-format MPEG Layer III в SWF

[English](FREE_FORMAT_MP3.md).

## Строгая разметка (v0.806)

Приватная [fvm_swf_mp3_probe](../src/swf/sound_mp3.cpp#L52) принимает нулевой индекс битрейта, если три
последовательных согласованных заголовка задают наименьшую подтверждённую длину пакета с позиции
ноль. Мусор перед пакетом не пропускается. Частота, число отсчётов и каналов
должны совпадать; padding добавляет байт отдельно для каждого пакета. Длина
строго меньше 2304 байт согласно закреплённому minimp3. Повреждённые заголовки дают
INVALID_ARGUMENT, недостаток данных — UNSUPPORTED. Ошибки сохраняют выходные
метаданные. Нет выделений, устройств, VM и callbacks.

Оригинальные аналитические сигналы закодированы системным LAME 3.100 в режиме
free-format; независимые S16-эталоны получены libmpg123. Runtime использует
прежний статический скалярный minimp3 без новых библиотечных зависимостей.
Приёмка устройств учитывается отдельно.


## Декодирование событий (v0.807)

DefineSound передаёт подтверждённую длину первого пакета нативному декодеру, затем
сохраняет длину без padding и битовый резервуар до конца. Весь источник проверяется
до записи выбранного PCM, включая запросы нулевой длины. Начальная задержка, границы
и двухпроходное чтение без выделений сохраняют прежние контракты. Отдельные события
из одного/двух пакетов без достаточных заголовков остаются UNSUPPORTED: нулевой
индекс битрейта не сообщает их длину.


## Потоковые блоки со счётчиком (v0.808)

SoundStreamBlock содержит точное UI16-число декодированных отсчётов. Перед первым
free-format-декодированием подготовка вычисляет число MPEG-пакетов и проверяет
кандидатные длины по всем заголовкам и полной длине блока. Ровно один кандидат
должен покрыть объявленное число пакетов. Поэтому поддерживаются первые блоки
из одного пакета, группы из двух и больше без чтения через SWF-префиксы. Пустые
блоки сохраняют историю. Длина и битовый резервуар переходят к следующим блокам;
число декодированных отсчётов каждого блока по-прежнему проверяется точно.
Новые выделения и кеш не добавлены; контракты raw/PCM/пикового бюджета сохраняются.


## Ограничение работы определения длины (v0.809)

Проверяются максимум две длины без padding: floor(bytes/packets) и предыдущая,
поскольку каждый пакет добавляет не больше одного байта padding. Каждый заголовок
и точный конец проверяются до изменения состояния декодера. Усечение, некратные
счётчики, нулевой счётчик с данными и выход за UI16 отвергаются. Проверки групп
пакетов и повторов после ошибок покрывают четыре набора. Перебор отказов выделения
подтверждает прежние приобретения памяти; скопированный PCM читается и закрывается
после уничтожения VM с полностью запрещёнными выделениями.
