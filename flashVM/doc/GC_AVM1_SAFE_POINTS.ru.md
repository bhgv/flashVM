# Безопасные точки автоматической сборки мусора AVM1

Интерпретатор AVM1 проверяет порог выделений между инструкциями, сейчас раз
в 64 инструкции (в том числе на первой). Проверка не означает обязательную
сборку: она запускается только при достижении порога.

К этому моменту стек операндов, локальные переменные и получатель (`this`)
зарегистрированы как корни GC. Во время вызова нативного расширения и в режиме
`suspended` автоматическая сборка не выполняется. Режим `full` выполняет
отдельную однократную сборку, не изменяя установленный режим.

## Использование из C/C++

Возвращённый через C API объект не закрепляется автоматически. Если ссылка
должна пережить выполнение AVM1 или сборку, используйте закрепление либо
временную область корней. Указатели на уже удалённые объекты недействительны.
Одновременное использование одного контекста из нескольких потоков запрещено.

## Проверка

`tests/gc_avm1_safe_point.c` создаёт недостижимые объекты, исполняет инструкцию
AVM1 End и проверяет их освобождение с сохранением глобального объекта.

## Ограничения

GC ещё не полностью завершён: требуют дополнительной проверки владение
нативными значениями, повторный вход финализаторов, ActionScript `__gc`,
время жизни строк и передача объектов между контекстами.
