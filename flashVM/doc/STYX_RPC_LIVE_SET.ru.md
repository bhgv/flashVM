# binding.set

[English](STYX_RPC_LIVE_SET.md) · [Живые переменные](STYX_RPC_LIVE_VARIABLES.ru.md) · [Типы моста](STYX_RPC_VALUE_TYPES.ru.md) · [Реализация](../src/styxrpc/session_live_values.c#L152)

## Синтаксис

```actionscript
binding.set([index, ]value):Boolean
```


## Параметры

Индекс задаётся по правилам [`get`](STYX_RPC_LIVE_GET.ru.md). Ячейка и элемент массива Int32 принимают целый `Number` из знакового диапазона Int32. Для `big` передайте точный целый `Number` или знаковый десятичный `String`. Для строковой ячейки передайте `null` для nil либо `String` до 1024 байт UTF-8. Пустая строка отличается от nil. Нулевой символ сохраняется.

## Результат и эффект

После подтверждения замены возвращает `true`. Скаляру или выбранной ячейке исходного владельца отправляется одна полная запись. Массив Int32 имеет фиксированную длину. Вектор `big` допускает существующие позиции, включая относительные. Для числовой части гибридной таблицы действуют правила владельца. При правах только на чтение запись может быть отклонена.

## Ошибки и ожидание

Неверное количество аргументов, тип или диапазон приводят к ошибке аргумента. Устаревшая привязка, отказ выбора, ошибка записи и отмена приводят к исключению. Синхронный вызов учитывает остановку `asinc`. Запись с неопределённым исходом могла исполниться. Проверьте ту же действующую привязку или состояние приложения перед повтором. Реализация сама запись не повторяет.

## Пример

```actionscript
// Записываем в скаляр big точный знаковый максимум.
var magnitude = vfs.liveVariable("/live/.var/details/magnitude", true);
var acknowledged = magnitude.set("9223372036854775807");
var closed = magnitude.close();
```
