# styxrpc.loadModule

[English](STYX_RPC_LOAD_MODULE.md) · [Сессия](STYX_RPC_SESSION.ru.md) · [Реализация](../src/styxrpc/session_modules.c)

```actionscript
var peer = styxrpc.loadModule("/mounted/peer.dis", ["magnitude"],
    ["realMagnitude", "managed", 0xbb977cfa, "(fs)", "(f)"]);
var value = peer.realMagnitude(-12.5, "sample");
```

Передайте путь от корня сессии с необязательной начальной косой чертой
и от одного до восьми описателей методов. Одно поле обозначает функцию
Int32 с компилированной сигнатурой `fn(int): int`. Пять полей содержат имя
экспорта, `"managed"` или `"graph"`, точную ненулевую сигнатуру UInt32 и
схемы списков аргументов и результата.

Загрузчик сверяет весь запрошенный контракт с текущим образом и возвращает
объект с именованными методами, вызывающими удалённые функции. Недоступный
образ или расхождение контракта дают ошибку загрузки. Объект заимствует
сессию на время жизни контекста. Каждый вызов проверяет удалённую функцию
у владельца фильма и может ждать I/O. Бюджет опроса ответа после отправки
составляет 1000 мс. Для контекстных импортов нужен встречный PID, выданный
хостом. Штатный плеер пока выполняет скалярные импорты и типизированные
импорты без встречного PID. См. [publishObject](STYX_RPC_PUBLISH_OBJECT.ru.md).
