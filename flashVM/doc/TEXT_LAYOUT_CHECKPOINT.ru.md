# Контрольная точка: компоновка текста

Добавлен API flashvm/text_layout.h для горизонтального текста с одним шрифтом.
Разрешаются уровни bidi абзаца, выделяются логические фрагменты письменности и
уровня, выполняется shaping с контекстом строки, измерение кандидатов переноса
и повторное формирование окончательных строк. Сохраняются исходные байтовые
кластеры, пробелы, пустые строки и CRLF. Доступны отдельные измерения продвижения
и точных границ рисунка, выравнивание, межстрочный интервал и независимые
редактируемые контуры блока/глифов, не требующие сохранения шрифта.

## Подтверждающие проверки

Linux x86_64, GCC/G++ 13.3.0, строгие C89/C++98 с pedantic-errors,
CMake 3.31.10. Статические библиотеки сохранены при BUILD_SHARED_LIBS=ON.

| Профиль | Пройдено тестов/примеров |
| --- | ---: |
| AGG | 117 |
| Cairo | 117 |
| NO_FONTS | 113 |
| NO_GRAPHICS и NO_IMAGE_CODECS | 111 |
| Полная пересборка scripts/check.py --sanitize | 117 |

Доказательства: validation/text-layout-*.log и *.json. Для санитайзеров полностью
пересобраны ядро, библиотеки и программы. Восстановленные диагностические ошибки
также приводят к отказу проверки. LeakSanitizer отключён из-за недоступного /proc;
старый тест исключений собственного аллокатора проверяется только UBSan.
Новых диагностических ошибок санитайзеров не обнаружено.

Проверяются лигатуры/кернинг, переносы без разрыва графем, пустые строки/CRLF,
латиница/иврит/арабский, арабские соединения после переноса, bidi override/isolate,
точные границы кривого глифа, владение и редактирование независимых копий,
ошибочный UTF-8/options/enum и ограничение бюджета формирования строк.
128 дополнительных смешанных строк при AUTO/LTR/RTL дают 384 сравнения
визуальных карт с FriBidi. Восемь потоков создают независимые блоки и одновременно
читают/экспортируют общий результат после освобождения его шрифта.
Пример C89 работает во всех четырёх профилях. Проверены 2094 файла манифеста
внешних исходников; исходники внешних библиотек на этом шаге не менялись.

## Незавершённая часть

SWF TextField/TextFormat пока не готовы. Компоновщик использует один шрифт/стиль,
горизонтальное направление и простое наследование письменности. Подстановка
шрифтов, стили, каретка/hit testing, полное назначение письменности, табуляция,
условные дефисы, вертикальный текст и выключка по ширине остаются ограничениями.
Бюджет и жадный алгоритм переноса описаны в TEXT_LAYOUT.ru.md.
Windows/macOS/Android не проверены запуском. Зеркало не обновлялось.
