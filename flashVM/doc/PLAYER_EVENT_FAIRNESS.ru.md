# Ограниченная обработка событий SDL

[English](PLAYER_EVENT_FAIRNESS.md). С v0.658 один вызов
fvm_desktop_window_events обрабатывает не более 64 записей SDL. При достижении
предела он возвращается без ожидания, оставляя остальную очередь. Проигрыватель
может доставить ввод, опросить таймеры, выполнить безопасный шаг GC и продолжить
кадры. Поток window/expose/user events не удерживает хост в бесконечном drain.
Закрытие за большим хвостом задерживается ограниченными порциями, не теряется.
Если записей меньше, сохраняется прежнее ожидание.

Бюджет независим от FIFO копированного ввода на 128 записей. Он не ограничивает
всю память очереди SDL, не объединяет события и не обещает lossless при злонамеренном
производителе. Переполнение FIFO по-прежнему явно ошибочно. SDL и VM остаются
в потоке владельца; новый VM worker или конкурентные callback не создаются.

flashvm_frontend_event_budget использует настоящую dummy-очередь, проверяет остаток
после порции и сохранение keyboard/quit за большим хвостом. Переданное длинное
ожидание не должно блокировать при исчерпанной порции. Это контракт очереди и
планирования, а не нативная приёмка устройства или длительной нагрузки.

## Принадлежность касания окну (v0.659)

SDL 2.0.12+ указывает окно касания. Общий фильтр теперь охватывает finger
 down/motion/up: чужое отпускание даже с совпавшими device/finger ID не прекращает
наш контакт. Нулевые ID остаются явным синтетическим вводом; прежние SDK
сохраняют маршрутизацию только по device/finger. Выбор основного контакта и отмена
по focus/background не меняются. Lifecycle-тест проверяет чужое начало,
чужое отпускание и корректное отпускание своего контакта.

## Граница владения курсором (v0.660)

Запрос фильма применяется, только пока указатель принадлежит его foreground-окну.
Leave, потеря фокуса и фон немедленно восстанавливают сохранённую при открытии
видимость, не меняя запрос VM. После возврата указателя обычная синхронизация
основного потока снова применяет запрос. Возврат foreground/focus обновляет
принадлежность через SDL_GetMouseFocus. Mouse.hide больше не оставляет глобальный
курсор SDL скрытым над другим окном. Отсутствие физического курсора не ошибочно.
Тест проверяет состояние настоящего SDL при enter/leave/background.
