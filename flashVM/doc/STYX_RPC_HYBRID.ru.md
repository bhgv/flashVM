# Гибридные таблицы через Styx RPC

[English](STYX_RPC_HYBRID.md) · [Позиционные графы](STYX_RPC_GRAPH.ru.md) · [Независимый SDK для C](../../lib/styxrpc/reference/hybrid_tables.ru.md)

Нативный `ref Bigtable->Handle` Limbo обозначается токеном `h` в графовом профиле Dis. Он может быть аргументом, результатом, элементом массива или полем ADT. При первом появлении ссылки передаётся упорядоченный снимок, при повторных — её идентификатор. Если таблицу передать несколько раз или вернуть вызывающему, каждый алиас указывает на тот же локальный объект владельца. Таблица, созданная в экспортированной функции, становится новым локальным объектом у вызывающего.

Установите [конструктор](STYX_RPC_HYBRID_BIND.ru.md) на владельце FlashVM. Вызовите его без аргументов и используйте полученный объект с действующим графовым [импортом](STYX_RPC_IMPORT_GRAPH.ru.md) или [экспортом](STYX_RPC_EXPORT_GRAPH.ru.md). Компилированный модуль Limbo использует обычные операции Bigtable.

| Метод | Аргументы | Результат |
| --- | --- | --- |
| `getIndex` | Точный числовой индекс | Значение или `undefined`, если ключ отсутствует |
| `setIndex` | Точный числовой индекс, знаковый `big` | Булев признак успеха |
| `deleteIndex` | Точный числовой индекс | Булев признак успеха |
| `getText` | Ключ UTF-8 с длиной | Значение или `undefined`, если ключ отсутствует |
| `setText` | Ключ UTF-8 с длиной, знаковый `big` | Булев признак успеха |
| `deleteText` | Ключ UTF-8 с длиной | Булев признак успеха |
| `length` | Без аргументов | Число записей в непрерывной последовательности с нуля |
| `count` | Без аргументов | Общее число записей |

Для целых в пределах ±(2⁵³−1) подходит `Number`. Для всего знакового 64-битного диапазона используйте точные десятичные строки в индексных методах или в качестве значений. Чтение возвращает точный `Number` в указанном диапазоне и десятичную строку за его пределами. Отрицательный индекс отсчитывается от текущей длины плотной части. Удаление оставляет пропуск без сдвига следующих ключей. Строковые и числовые ключи раздельны. Строковые ключи могут содержать U+0000.

Владелец передаёт числовые ключи по возрастанию, строковые в порядке вставки. В патче сначала идут удаления, затем записи. Патч подготавливается по текущему содержимому таблицы вызывающего и сохраняет ключи, которых он не касается. Подготовленная таблица публикуется вместе с правками полей ADT только после проверки всех слотов назначения. При ошибке содержимое таблиц и поля ref вызывающего сохраняются. Локальный отказ возможен после исполнения функции провайдером.

Объект таблицы и его методы принадлежат одному контексту FlashVM. Сборщик мусора этого контекста освобождает хранилище C. Для транспорта действует предел графового кадра 64 КиБ. Публикация живой таблицы во встречном каталоге — отдельная операция SDK. Объявление встречных ресурсов из AS и привязка живых каналов остаются открытыми.
