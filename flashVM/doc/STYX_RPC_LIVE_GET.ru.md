# binding.get

[English](STYX_RPC_LIVE_GET.md) · [Живые переменные](STYX_RPC_LIVE_VARIABLES.ru.md) · [Типы моста](STYX_RPC_VALUE_TYPES.ru.md) · [Реализация](../src/styxrpc/session_live_values.c#L84)

## Синтаксис

```actionscript
binding.get([index]):Object
```


## Параметры и результат

Для скаляра Int32, `big` или строки вызовите без `index`. Массив Int32 принимает неотрицательный целый `Number` меньше текущей длины. Вектор `big` принимает знаковый индекс. `-1` выбирает последний элемент. Числовая часть гибридной таблицы принимает точный знаковый ключ. Отрицательные индексы отсчитываются от конца плотной части. Для индекса или ключа `big` действуют те же формы точного `Number` и десятичного `String`, что и для значения.

Возвращает текущий `Number`, канонический десятичный `String` для большого `big`, строку Unicode с длиной или `null` для строки nil. Полученное значение принадлежит фильму. Следующий вызов читает актуальное значение владельца.

## Ошибки и ожидание

Неверный тип или количество аргументов приводят к ошибке аргумента. Недопустимый или отсутствующий элемент, закрытая или устаревшая привязка, повреждённый ответ и ошибка обмена приводят к исключению. Для записи сначала выберите [поле](STYX_RPC_LIVE_FIELD.ru.md). Синхронный вызов учитывает остановку задания `asinc`. После отмены чтения привязка пригодна, пока совпадает публикация.

## Пример

```actionscript
// Каждый вызов читает актуальное состояние вектора владельца.
var vector = vfs.liveVariable("/live/.var/details/wide");
var last = vector.get(-1);
var closed = vector.close();
```
