# Обычные аргументы ref Dis во FlashVM

[English](STYX_RPC_REFS.md) · [Управляемый импорт](STYX_RPC_IMPORT_MANAGED.ru.md) · [Управляемый экспорт](STYX_RPC_EXPORT_MANAGED.ru.md)

Обычный управляемый профиль передаёт первое определение ссылки,
алиасы на это определение и маску изменённых исходных аргументов.
В обоих направлениях используется существующий кодек запросов и ответов
libstyxrpc. Для ADT из двух полей, например `text: string` и
`bytes: array of byte`, значение `ref` в AS — плотный нативный Array
`[text, bytes]`. Позиции соответствуют порядку полей компилированной схемы.
`null` в AS соответствует nil в Dis. При передаче одного Array дважды
внутри принимающего вызова сохраняется идентичность.

Допускается до восьми позиций ref и до восьми непосредственных полей в
каждом ref. Ссылка может быть аргументом или полем кортежа аргументов.
Её поля копируются по значению. Сохраняйте плотный Array исходной длины
с собственными полями данных. Watch и пользовательские аксессоры для
такого Array не допускаются. Поля, в которые должна прийти запись,
должны оставаться доступными на запись.

Сервер сравнивает закодированные поля с исходным снимком и выдаёт
одно обновление на изменившееся определение. Импорт AS проверяет и
декодирует весь ответ и все обновления перед изменением исходных
Array. Он сверяет текущую структуру, исходные слоты и права записи,
затем применяет все подготовленные изменения без колбэков и
выделения памяти. Неизменившиеся поля сохраняют текущее значение.
Например, неизменившийся массив сохраняет идентичность. Результат
и новые значения удерживаются GC-корнями. При удалённом исключении
или локальном отказе записи все участвующие поля вызывающего
сохраняются. Локальный отказ возможен после выполнения функции.

Этот выпуск поддерживает обычную обратную запись ref. Возвращаемые
ссылки, ссылки внутри ADT или массивов, разреженные дельты графов
и живые каналы пока не привязаны к FlashVM. Внешним программам
по-прежнему доступны действующие API графов и каналов в SDK.

[Интерфейс Limbo](https://github.com/bhgv/flashVM/blob/master/lib/styxrpc/tests/flashvm/refs.m) и
[проверка FlashVM](../tests/styxrpc/refs.c) охватывают алиасы,
неизменившиеся поля и отказ в обоих направлениях. DisVM запускается
в интерпретаторе и JIT.
