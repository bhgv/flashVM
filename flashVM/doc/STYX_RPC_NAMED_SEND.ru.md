# send(value) именованного канала

[English](STYX_RPC_NAMED_SEND.md) · [vfs.chan](STYX_RPC_NAMED_CHANNEL.ru.md) · [Код](../src/styxrpc/session_named_values.cpp)

`port.send(value)` ждёт, пока другой участник примет значение, и возвращает
`undefined`. Обычная переменная передаёт текущее значение. Строки, числа,
булевы значения, null и undefined используют переносимые теги. Массивы,
таблицы и объекты используют графовый кодек FlashVM. Кодек сохраняет
поддерживаемые общие узлы и циклы. Размер кадра с тегом ограничен 65 536
байтами. Неподдерживаемое значение и превышение размера дают ошибку до
отправки.

При передаче по значению читаются поддерживаемые живые записи во всём графе.
Это именованные ячейки, адаптер переменных Int32 и прозрачные привязки AS
к собственным данным или к одной из этих ячеек. Сторонние геттеры при снятии
снимка не вызываются. Исчезнувшее собственное поле или ошибка чтения ячейки
прерывают отправку до встречи с получателем. У
[самостоятельного API сериализации](../include/flashvm/serialization.h)
свои правила.

Снимок сохраняет циклы и общие объекты. Именованная ячейка StyxRPC читается
один раз на граф, в том числе если её привязки получены по разным арендам.
Разные ячейки читаются отдельно. У получателя записи содержат обычные
значения, поэтому их изменение не обновляет исходную ячейку.
Числовые индексы и строковые имена нативной таблицы сохраняются раздельно.
Эти же правила действуют, когда граф становится значением общей ячейки.

`port.send(ref counter)` передаёт ссылку на обычную записываемую переменную
AS или собственное свойство через ячейку
[libstyxrpc](../../lib/styxrpc/reference/named_cell.ru.md). При первой
отправке исходный слот подключается к ячейке. Чтение и присваивание обращаются
к её текущему значению. Получатель может принять ссылку в новое имя, менять
значение и его тип, а также пересылать ту же ячейку через `ref`.

Ячейка принимает те же скаляры и сериализуемые графы, что и обычное сообщение.
Чтение графа создаёт локальный снимок. Чтобы опубликовать правки, присвойте
изменённый снимок общей переменной. Для прямых обновлений отдельного поля
локального объекта передайте `port.send(ref model.count)`. Для вычисляемого
имени или индекса используйте `port.send(ref rows[index])`. Свойство,
элемент Array или числовая запись нативной таблицы должны существовать и допускать запись. Обычные чтение и
присваивание, например `rows[index] = 42`, обращаются к общей ячейке. Свойства с пользовательским
аксессором или наблюдателем и значения, которые отвергает графовый кодек,
указать при публикации нельзя. Ранее выданные ссылки Int32 продолжают
пересылаться в выдавшей сессии.

```actionscript
var port = vfs.chan("/jobs");
var counter = 7;
var sent = port.send(ref counter); // Передаём ссылку.
var current = counter; // Читаем значение на этот момент.
var released = port.delete();
```

[Пример получателя](STYX_RPC_NAMED_RECV.ru.md) читает и меняет переданное
число. [Полный пример C и Limbo](../../lib/styxrpc/examples/shared-cell/README.ru.md)
показывает то же время жизни аренды и явную отмену присваивания.
