# send(value) именованного канала

[English](STYX_RPC_NAMED_SEND.md) · [vfs.chan](STYX_RPC_NAMED_CHANNEL.ru.md) · [Код](../src/styxrpc/session_named_values.cpp)

`port.send(value)` ждёт, пока другой участник примет значение, и возвращает
`undefined`. Обычная переменная передаёт текущее значение. Строки, числа,
булевы значения, null и undefined используют переносимые теги. Массивы,
таблицы и объекты используют графовый кодек FlashVM. Кодек сохраняет
поддерживаемые общие узлы и циклы. Размер кадра с тегом ограничен 65 536
байтами. Неподдерживаемое значение и превышение размера дают ошибку до
отправки.

`port.send(ref counter)` передаёт ссылку на доступную для записи скалярную
переменную AS. При первой отправке исходный слот подключается к ячейке
[libstyxrpc](../../lib/styxrpc/reference/named_cell.ru.md). После этого
обычные чтение и присваивание в AS работают с её текущим значением.
Повторная отправка `ref counter` сохраняет идентичность. Получатель может
принять ссылку в новое имя, изменить скаляр и переслать ту же ссылку.
Тип скаляра может изменяться при присваивании.

Живыми слотами могут быть обычные записываемые переменные и собственные
свойства со скалярным значением. Доступны числа, строки, Boolean, null и
undefined. Слоты с пользовательским аксессором или наблюдателем и объектные
значения исключены из этой формы публикации. Графы объектов доступны
через обычный `send(value)`. Ранее выданные ссылки Int32 продолжают
пересылаться в выдавшей сессии.

```actionscript
var counter = 7;
var sent = port.send(ref counter);
var current = counter;
```
