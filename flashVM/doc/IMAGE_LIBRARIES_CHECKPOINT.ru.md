# Проверка библиотек изображений — 11 октября 2026

Добавлены исходники libpng 1.6.59, giflib 5.2.2, IJG JPEG 9f и NanoSVG с
зафиксированным коммитом. Настроена статическая офлайн-сборка и публичные
заголовки/зависимости, ключи IMAGE_CODECS/NO_IMAGE_CODECS, PNG/SVG в Cairo,
C89-обёртка SVG и пример SVG → RGBA → PNG в памяти. Сохранены лицензии,
происхождение, патчи и манифест SHA-256. Исправлена обнаруженная тестом ошибка
атомарного доступа к статусу Cairo на LP64. После преобразования таблицы имён
глифов в C89-инициализатор проверено точное сохранение всех 1590 исходных байтов.
См. [API и ограничения](IMAGE_CODECS.ru.md).

Linux x86_64, GCC/G++ 13.3.0, CMake 3.31.10:

| Конфигурация | Успешные тесты и примеры |
| --- | --- |
| AGG + IMAGE_CODECS | 108/108 |
| Cairo + IMAGE_CODECS | 108/108 |
| NO_GRAPHICS + IMAGE_CODECS | 108/108 |
| AGG + NO_IMAGE_CODECS | 102/102 |
| Cairo + NO_IMAGE_CODECS | 102/102 |
| Отдельный прогон C89/C++98 с ASan/UBSan | 108/108 |

Во всех сборках включены строгие языковые режимы и pedantic-errors. В тесте
контейнеров с собственными new/delete применяется только UBSan; LeakSanitizer
отключён из-за недоступности /proc в среде. Проверка утечек не заявляется.
Пройдены 23 сценария конфигурации CMake и SHA-256 для 1044 файлов зависимостей.
Логи и JSON: doc/validation/image-libraries-*. Первичные ошибки запуска CTest
из-за потерянных прав исполнения устранены; полные наборы запущены повторно.

Повторная проверка: CMake configure/build/ctest с выбранными ключами DEFS.txt
или копией FVM_DEFS_FILE, scripts/check_definitions.py,
scripts/check_vendor_sources.py и scripts/check.py --sanitize. Скачивание
библиотек при сборке и подмена системными установками не выполняются.

Windows/macOS/Android и другие архитектуры здесь не проверены. Полная поддержка
SVG, новые объекты изображений ActionScript, завершённость Flash/SWF и JIT этим
этапом не заявляются. Зеркало Git не обновлялось. В полном архиве Git сохранён
предыдущий stash незавершённой разработки; он не применён к этому этапу.
