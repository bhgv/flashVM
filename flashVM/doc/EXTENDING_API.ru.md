# EXTENDING_API — русская документация

Нативные функции регистрируются через API из `flashvm/value.h` и вызываются из поддерживаемого подмножества AVM1. Обрабатывайте ошибки, проверяйте типы и не храните указатели на объекты после уничтожения контекста. Динамическая загрузка модулей и полноценная регистрация классов пока отсутствуют.

Подробные сигнатуры и ограничения см. в `EXTENDING_API.md` и заголовках `include/flashvm/`. Примеры расположены в `examples/embedding/` и `examples/extending/`.
