# Стандартная табуляция из метрик шрифта

Функция [fvm_font_average_width](../include/flashvm/font.h#L65) читает положительный OS/2 xAvgCharWidth и масштабирует через FreeType до нехинтованных пикселей 26.6. Пробел, максимальная ширина и среднее по произвольной строке не подставляются. Живой шрифт заимствуется на время вызова; доступ к изменяемому face сериализует вызывающий. Выделений памяти, VM и корней GC нет. Обязательный out обнуляется при ошибке. Неверные указатели дают INVALID_ARGUMENT, отсутствующая/неположительная метрика — UNSUPPORTED; NO_FONTS с корректным out возвращает UNSUPPORTED. Структуры и прежний ABI не меняются.

В тестовом шрифте независимо записаны 547 единиц при 1000 units/em: размер 40 даёт 21.875, размер 20 — 10.9375 пикселя. Первый коммит v0.915 добавлял только метрику; v0.917 ниже включает default-табуляции.

Источник: [спецификация OS/2 OpenType](https://learn.microsoft.com/en-us/typography/opentype/spec/os2#xavgcharwidth). Эталонная приёмка Flash и устройств остаётся открытой.

v0.916: [fvm_text_layout_create_periodic](../include/flashvm/text_layout.h#L155) принимает конечный положительный интервал до 1 000 000 пикселей. U+0009 переходит к положительному кратному строго правее пера с учётом indent и интервала букв. Позиции начинаются заново на каждой визуальной строке; таблица на 64 элемента и её выделение не нужны. Сохраняются пределы глифов/работы/геометрии, пустой контур табуляции, переносы, владение и статусы custom API. Нужны LTR с уровнями bidi 0 и выравнивание не JUSTIFY. Прежние API по-прежнему отклоняют табуляцию без таблицы. NO_FONTS проверяет интервал/флаги/spacing/indent, затем возвращает UNSUPPORTED без чтения font/text/options. NULL out и неверный интервал дают INVALID_ARGUMENT; выход обнуляется.

v0.917: TextField и TextFormat.getTextExtent при пустой собственной таблице и наличии U+0009 используют четыре средние ширины выбранного настоящего face и размера. Отсутствующая метрика даёт UNSUPPORTED. Без табуляций дополнительных требований к шрифту нет. Явная таблица имеет приоритет. Пустой Array включает default; null/undefined сохраняют прежний стиль. Текущий и будущий стили независимы; снимки default возвращают пустой Array. Правки заранее проверяют табуляции даже без autoSize: ошибка сохраняет текст/стиль/кэш/якоря. Новые поля снимка и wire-биты не нужны: интервал вычисляется из встроенного шрифта повторно. Bidi/justify с табуляцией не поддержаны. Эта ограниченная политика OS/2 ещё не сверена с бинарным Flash Player. Источник: [Adobe AS2 TextFormat](https://open-flash.github.io/mirrors/as2-language-reference/TextFormat.html#tabStops).

v0.918: исчерпание предела повторяемой позиции участвует в пробах переноса: две табуляции по миллиону пикселей помещаются на отдельные строки вместо преждевременного отказа. Native-тесты проверяют это восстановление, oversized-tab, CRLF, знаковый indent, spacing, четыре выравнивания, дробный период, малые/неконечные аргументы, отказы bidi/justify и независимые пустые контуры tab. Неограниченная строка с переполнением остаётся UNSUPPORTED.

v0.919: независимые изменения тестового шрифта проверяют отсутствие OS/2, sentinel FreeType, нулевую и отрицательную среднюю ширину; обычное shaping остаётся рабочим. Присваивание TextField, replaceText и очистка явной таблицы при отсутствии default-метрики сохраняют текст, текущую таблицу, контур, авторазмер и правый якорь. Явная таблица работает с таким шрифтом; текст без tab не требует средней ширины.

v0.920: бинарные и канальные тесты передают текущий default-стиль с будущим default либо явной таблицей. Проверены отсутствие custom wire-бита, перерасчёт при другом размере после уничтожения исходного контекста и GC получателя, правый якорь и независимый контур. Шрифт передаётся существующим проверяемым протоколом; новый формат wire не вводится.

v0.921: перебор границ отказа C++-выделений покрывает native periodic layout, изменение размера текущего стиля, присваивание текста и replaceText. Ошибка построения обнуляет выход и сохраняет пригодность шрифта; ошибка правки сохраняет текст, метрики, авторазмер и рабочий контур после GC. Эти проверки выполняются обычной сборкой отдельно от санитайзеров.

v0.922: настоящие AVM1-записи size с setTextFormat дают одинаковые default-метрики при 40/20px в интерпретаторе, attached native JIT и automatic JIT (общий runner проверяет входы). Четыре настоящих OS-потока независимо владеют шрифтами и по 64 раза вычисляют интервалы 40/20px, проверяя spacing, indent и время жизни контуров. Разделять изменяемый шрифт или VM-контекст между потоками это не разрешает.

v0.925: отдельный встроенный bold-face с независимо изменённой OS/2 average доказывает выбор интервала именно этого face, а не regular-слота семейства или максимального глифа. Три выравнивания, знаковый indent, поля/blockIndent, дробный spacing, размеры 40/20px и контуры согласуются с аналитическими intrinsic/outer ширинами. Режимы --default-tabs проверяются в native и managed примерах.

Проверки v0.926: 145/145 native text/font/GC/JIT/serialization/tutorial, 50/50 выбранных ASan/UBSan и 21/21 NO_FONTS. Четыре новых fault-sweep выполнены отдельно обычной сборкой. LeakSanitizer отключён из-за недоступного /proc; проверки утечек не заявлены. Native JIT доступен, общий AVM1-runner проверяет реальные входы. Переименованный отделённый компонент конфигурируется со своим профилем; оба скопированных checker проходят на native-бинарниках. Отдельная detached-сборка не выполнялась. Ссылки на исходники и checker каталога/примеров проходят.

Прежние custom-table API и ABI структуры options сохраняются. Старый reader может отклонить новый default-tab текст при восстановлении раскладки: смена wire-версии не добавляет ему реализацию. Не подтверждены внешние/device fonts, bidi-tab, wrapped-justify и точное поведение/пиксели оригинального Player. Аудио, видео, таймлайн и остальные стадии этим текстовым циклом не реализовывались и заново не принимались. Все девять стадий и приёмка реальных платформ остаются открытыми.
