# select и trySelect на живом канале UniBus

[English](STYX_RPC_CHANNEL_SELECT.md) · [Живые каналы](STYX_RPC_CHANNELS.ru.md) · [Реализация](../src/styxrpc/channel_select.c)

```actionscript
anchor.select(guards)
anchor.trySelect(guards)
```

Используйте открытый удалённый канал как `anchor`. Передайте плотный Array из 1–8 веток. Ветка задаётся плотным Array из `[channel]` для приёма либо `[channel, value]` для отправки. Значение сценария должно соответствовать компилированной схеме элемента канала. В массивах веток используются собственные индексные свойства со значениями. Мост читает эти свойства без вызова сценария.

Все каналы веток должны быть открыты и принадлежать точной шине UniBus канала `anchor`. Они могут иметь общий токен результата модуля, общий PID входящего вызова или один допущенный PID очереди результата. Сам `anchor` может отсутствовать в списке. Для отдельных вызовов, токенов и PID нужны отдельные операции выбора. Разные типы каналов и допустимые вложенные каналы используют те же форматы кадров, что и отдельные операции.

Libstyxrpc отправляет владельцу шины один запрос. Владелец выбирает не более одной ветки. `select()` ожидает выбора в пределах бюджета, заданного хостом. `trySelect()` запрашивает немедленный выбор. При отсутствии готовой ветки `trySelect()` возвращает `undefined`. При подтверждённом выборе оба метода возвращают `[номер, значение]`. Номер ветки считается от единицы в порядке списка. Для отправки второй элемент равен `undefined`. Приём может вернуть `null` для канала nil.

Неверный список веток даёт ошибку аргумента. Закрытый канал, ветка другой шины или несовместимое отправляемое значение отклоняются до отправки. После отправки таймаут или сбой могут совпасть с исполнением ветки. Оба метода синхронно выполняются в потоке-владельце и используют один временный fid. Срок действия маршрута определяется исходным вызовом либо результатом. При потере подтверждения исход может быть неопределённым, поэтому автоматический повтор может выполнить операцию второй раз.

## Приём или отправка на одной шине результата

```actionscript
var chosen = ints.trySelect([[ints], [messages, "ready"]]);
if (chosen != undefined) {
    if (chosen[0] == 1) {
        trace(chosen[1]);
    }
}
```

Здесь `ints` и `messages` получены из одного результата модуля. Первая ветка принимает целое число, вторая отправляет строку. Выбор ветки 2 подтверждает отправку строки. Пустой ответ означает, что ни одна ветка не сработала.

[Нативная проверка](../tests/styxrpc/channel.c) охватывает целые числа, строки с точной длиной, вложенные значения общего токена и пустой выбор. Те же методы работают во [входящих колбэках](../tests/styxrpc/channel-incoming.c) и на [каналах очереди PID](../tests/styxrpc/channel-pid-result.c).
