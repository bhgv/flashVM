# Корни сборщика мусора в активных кадрах AVM1

Сборщик теперь обходит операндный стек, локальные переменные и объект-получатель `this` каждого активного кадра исполнения AVM1. Кадры связаны с [`FVM_Context`](../src/core/runtime.hpp#L257) и автоматически снимаются при выходе из функции, включая выход по ошибке. Вложенные вызовы имеют собственные кадры.

Сохраняются корни глобального объекта и объекты, явно закреплённые из C API. Недостижимые циклические ссылки обрабатываются алгоритмом mark-and-sweep. После финализаторов выполняется повторная маркировка, учитывающая восстановление достижимости.

## Ограничения

Это **ещё не полностью законченный GC**. Нужна защита временных значений C API, результатов нативных вызовов и объектов, удерживаемых расширениями. Перед явной сборкой C-код должен закреплять используемые объекты. Автоматическая сборка внутри цикла AVM1 пока не включена до проверки всех нативных вызовов. Строки управляются отдельно от сборщика объектов. Объект ActionScript `gc` пока не реализован.

Сборка относится к одному контексту и должна запускаться в его потоке. Нельзя вызывать [`fvm_gc_collect`](../include/flashvm/gc.h#L54) параллельно с исполнением того же контекста. Публичный C ABI не изменён.
