# Сертифицированные линейные Bezier-штрихи

Точные bounds теперь используют геометрию отрезка для quadratic/cubic с коллинеарными controls внутри прямоугольника концов. Для неосевого пути все координаты должны точно принадлежать сетке 1/16 и оставаться в исходном домене ±1 000 000; требуется DBL_MANT_DIG ≥53. Умножение на 16 даёт точные целые, разности не превышают 32 000 000, произведения меньше 2^50, их разности меньше 2^51. Проверка cross product поэтому не теряет ненулевое отклонение из-за округления. Epsilon не используется. Домен публичного path API не расширен; предел вынесен в общий [заголовок](../src/capi/path_geometry_constants.h).

Для горизонтальных/вертикальных путей сохраняются произвольные допустимые конечные координаты без требования сетки. Controls должны быть внутри интервала концов, но cubic-controls теперь могут быть неупорядоченными. После нормализации u,v∈[0,1] производная кубической координаты линейна по u,v; в четырёх вершинах квадрата она пропорциональна t², 2t(1-t), (1-2t)² и (1-t)². Все выражения неотрицательны; поэтому весь такой класс монотонен. В частности, controls в противоположных концах дают допустимую нулевую производную в середине.

## Контракт

[fvm_path_stroke_bounds_style](../src/capi/path_hit_c.cpp#L454) сохраняет существующий контракт: неизменяемый заимствованный путь, положительная конечная ширина ≤1 000 000, поддержанные cap/join, два обязательных принадлежащих вызывающему результата. Проверка и обход не выделяют память, не вызывают callbacks/GC и не требуют контекста. Ошибки аргументов и неподдержанные кривые сохраняют оба результата. Совместная мутация пути запрещена. Используются прежние конечные тела, round/none/square торцы, round/bevel joins и Close. Constant и одиночный Move не добавляют штрих.

Внеосевые координаты вне сетки, отклонения от коллинеарности и controls вне интервала не сокращаются; для non-round сохраняется [FVM_UNSUPPORTED](../include/flashvm/flashvm.h#L46) с managed fallback. Round/round сохраняет общие аналитические кривые. Поворот или масштаб могут вывести путь с сетки. Неравномерная метрика ширины остаётся прежней.

Managed quadratic автоматически использует новые bounds в getBounds, размерах и hitTest без shape. getRect и смешанная заливка сохраняют прежний учёт исходной рамки. Cubic остаётся нативной возможностью; MovieClip его не принимает. Пиксели, shape-hit subdivision, C89 ABI, wire и callback ID не меняются. [C89-пример](../examples/embedding/stroke_styles/README.ru.md) добавляет настоящий диагональный curveTo с none/bevel и игнорируемым одиночным moveTo.

Общие non-round кривые, произвольная точная collinearity вне сетки, неравномерный масштаб/shear, miter/hinting/non-scaling, полная Flash-reference-приёмка, Cairo и устройства остаются открытыми. Все девять этапов roadmap открыты.
