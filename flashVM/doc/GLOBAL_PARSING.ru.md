# Глобальные преобразования и разбор числового префикса — v0.11

[`fvm_standard_install`](../include/flashvm/standard.h#L19) добавляет нативные функции parseInt, parseFloat и String.
Они вызываются по имени через [`fvm_call`](../include/flashvm/value.h#L138) и AVM1 CallFunction. Конфликты имён
проверяются до установки; публикация атомарна, повторная установка проверяет методы.

String() без аргументов возвращает пустую строку. С аргументом используется
существующее преобразование ToString, лишние аргументы игнорируются. У объектов
поддерживаются нативные toString/valueOf с распространением исключений. Это функция
преобразования: полноценный класс String и строковые обёртки ещё не реализованы.

parseInt преобразует вход в строку, пропускает начальные пробелы, читает знак
и цифры до первого недопустимого символа. Явное основание допускает 2–36;
после ToNumber выполняется ограниченное преобразование ToInt32 без опасного
приведения слишком большого double к целому C. Пропущенное основание, ноль,
NaN и бесконечность включают автоопределение. Префикс 0x выбирает 16, иначе
начальный ноль выбирает 8 по правилу старого AS2. Явное основание 16 также
допускает префикс. Если цифр нет или основание недопустимо, результат — NaN.
Десятичная точка завершает целое; знак отрицательного нуля сохраняется.

parseFloat после преобразования и пропуска пробелов читает максимальный
десятичный префикс со знаком, точкой и необязательной экспонентой. Незавершённая
экспонента считается хвостом: `1e+tail` даёт 1. Infinity распознаётся с учётом
регистра. Шестнадцатеричная/восьмеричная форма не определяется: 0x даёт начальный
десятичный ноль. Недопустимый префикс даёт NaN.

Начальные пробелы включают ASCII, NBSP, Unicode-разделители, разделители строки
и абзаца, BOM. Некорректный UTF-8 не пропускается. Примеры и восьмеричное правило:
[справочник глобальных функций AS2](https://open-flash.github.io/mirrors/as2-language-reference/global_functions.html).

## Проверки и оставшаяся работа

Проверены C API и исполняемые записи AVM1, основания и их автоопределение,
переполнение ToInt32, все основания 2–36 независимым кодировщиком целых,
хвосты, незавершённые экспоненты, Unicode-пробелы, исключения нативного
преобразования, конфликты установки и отказы выделения памяти в каждой новой
функции. Тесты: global_parsing.c, global_parsing_avm1.cpp, error_allocation.cpp.
Мост вызова C теперь перехватывает std::bad_alloc при поиске имени и выполнении
callback, возвращая [FVM_OUT_OF_MEMORY](../include/flashvm/flashvm.h#L44).

Десятичный префикс использует прежний независимый от локали парсер: правильное
округление на всех границах binary64 пока не доказано. Последовательное накопление
цифр также не доказывает совпадение с Flash для произвольно длинных целых.
Пробельные символы и автоопределение восьмеричной формы ещё не выбираются по версии
SWF. Полные String/Object/Function, скриптовые методы преобразования и вызовы
методов примитивов остаются в работе.

Функции являются зарегистрированными нативными callback, а не полноценными
Function-значениями. GC и каналы не изменены. Пример .as иллюстрирует API;
компилятора исходного ActionScript здесь нет. Это проверенный ограниченный этап,
а не полная совместимость SWF 8.

В v0.12 добавлена нативная обёртка String; описанная здесь функция преобразования
сохранена. Подробности: [STANDARD_STRING.ru.md](STANDARD_STRING.ru.md).

## Загруженный parseInt — v0.412

Для SWF4–8 добавлен отдельный путь AVM1. Пропущенный аргумент возвращает undefined.
Указанное основание преобразуется раньше строки через AVM1 Number и Int32;
принимаются только 2–36. Нулевое/undefined/NaN основание не включает автоопределение,
а сразу даёт NaN без преобразования первого аргумента. Затем применяется ToString
загруженного SWF. Правила host API без загруженного SWF сохранены.

Префикс проверяется до удаления только TAB/LF/CR/пробела. Начальный unsigned 0x
снимается даже при явном основании 10; signed 0x отклоняется, кроме оснований
34–36, где x является цифрой и исходный знак игнорируется. Восьмеричная форма
автоматически выбирается только для полной исходной строки: хвостовой пробел,
NUL или иной символ переключает её на десятичную. Длина строки учитывается явно.
Отрицательный ноль сохраняется; точное округление длинных чисел ещё не доказано.

Сравнение привязано к исходникам и ожидаемому выводу Ruffle, указанным в
[английском описании](GLOBAL_PARSING.md); новый запуск Adobe Player не заявляется.
Тест global_parse_int_loaded проверяет SWF4–8, порядок callbacks, короткий выход
при неверном основании, исключения, запрет GC внутри native callback, сборку после вызова и очистку областей.
Все девять стадий остаются открытыми; цель по поручению пользователя — SWF ≤8.

Validation v0.412 / Проверка: Linux minimal Release 823/823 CTests; AGG Release
and heap/global ASan+UBSan each passed all three global-parsing executables.
Native launchers restore workspace executable modes; stack ASan/LSan disabled.
Other-platform runtime and all nine stage acceptance remain open.

## Загруженный parseFloat — v0.413

В SWF4–8 применяется AVM1 ToString; пропущенный аргумент даёт undefined.
Цифры накапливаются отдельно с порядком десятичного масштабирования из эталона,
вместо host-парсера: проверено точное значение .1499999. Infinity даёт NaN,
одиночная точка — ноль; последующие точки пропускаются при накоплении, но
экспонента распознаётся только после первой корректной дробной части.
Экспонента, её знак и степени цифр явно оборачиваются в 32 бита без signed overflow,
включая INT32_MIN. Все проходы учитывают длину, NUL останавливает накопление.
Правила host API без загруженного SWF сохранены. Источники сравнения и MIT-атрибуция
указаны в [EN](GLOBAL_PARSING.md). Тест global_parse_float_loaded покрывает SWF4–8,
точное округление контрольного числа, точки, экспоненты, NUL, суррогат, незавершённый
буфер, callbacks, исключения и native GC barrier. Полные числовые границы и набор
пробелов всех версий Flash пока не подтверждены; все стадии остаются открытыми.

Validation v0.413 / Проверка: minimal Release 824/824; AGG Release and
heap/global ASan+UBSan each passed all four global-parsing executables.
Native mode-restoring launchers used; stack ASan/LSan disabled.
Other-platform runtime acceptance and all nine stages remain open.

## Общий бюджет обходов — v0.414

parseInt/parseFloat загруженного SWF делят бюджет AVM1 с преобразованием основания,
ToString и вложенными вызовами. Учитываются проходы восьмеричной проверки,
пробелов, цифр, дроби/экспоненты и накопления; счётчик не переполняется. Это политика
FlashVM, а не эмуляция числа инструкций Adobe. Масштабирование одной цифры имеет
не более 32 шагов; общая валидация/преобразования ещё учитываются не полностью.
Host API без SWF сохраняет прежнюю политику без такого лимита.

Тесты global_parsing_loaded_work проверяют пороги, 65537 цифр, вложенность,
насыщение счётчика и повторный вызов. global_parsing_loaded_allocation перебирает
отказы выделений до успеха, проверяя GC/work-области и сборку после каждого отказа.
jit_global_parsing сверяет интерпретатор, подключённый и автоматический JIT для
SWF4–8, включая вход в машинный код, точный результат, лимит, ошибку и восстановление.
Другие архитектуры и полная совместимость остаются открытыми.

Validation v0.414 / Проверка: minimal Release 827/827; AGG Release 7/7 and
heap/global ASan+UBSan 7/7 parsing/JIT tests. Native mode-restoring launchers
used; stack ASan/LSan disabled. All nine stage acceptances remain open.

## Ведущие пробелы Flash — v0.415

Загруженные parseFloat, Number и действие ToNumber пропускают только TAB/LF/CR
и U+0020, как закреплённый эталон Ruffle (ссылки в [EN](GLOBAL_PARSING.md)).
Это заменяет широкое множество пробелов, сохранённое в v0.413. VT/FF, NBSP, BOM,
Unicode-разделители, NUL и суррогаты не пропускаются. Некорректная строка даёт
ноль при числовом преобразовании SWF4 и NaN в SWF5–8; оба parse-метода дают NaN.
Host API сохраняет свои прежние правила. avm1_numeric_whitespace проверяет 30
значений для SWF4–8, три встроенные функции, действие ToNumber и GC строк между
случаями. jit_numeric_whitespace проверяет ToNumber/parseFloat в интерпретаторе,
подключённом и автоматическом JIT с подтверждением входов в машинный код.
Полная совместимость и запуск Adobe Player не заявляются; все стадии открыты.

Validation v0.415 / Проверка: minimal Release 829/829; AGG Release 9/9 and
heap/global ASan+UBSan 9/9 parsing/whitespace/JIT tests. Native mode-restoring
launchers used; stack ASan/LSan disabled. Other-platform acceptance remains open.

## Общий десятичный алгоритм Number — v0.416

Number, ToNumber и числовые операнды AVM1 загруженного SWF теперь используют общий
с parseFloat алгоритм накопления. В SWF5–8 требуется конец грамматики; SWF4
сохраняет разбор префикса и ноль для некорректного ввода. Правила восьмеричных/
шестнадцатеричных строк SWF6–8 и host API сохранены. Убраны промежуточные строковые
буферы мантиссы и экспоненты: прямое преобразование примитивной десятичной строки
работает даже при запрете C++-выделений. Учёт работы parseFloat сохранён; общий
учёт работы числового преобразования пока не добавлен.

avm1_decimal_numbers проверяет точное значение .1499999, строгий/префиксный режим,
точки, экспоненты, NUL и отрицательный ноль; avm1_decimal_allocation — запрет
выделений; jit_decimal_numbers — Number/ToNumber/Subtract в интерпретаторе и двух
режимах реального JIT. Источник сравнения и MIT-атрибуция сохранены в decimal.cpp.
Полные границы binary64, крайние переполнения и все стадии остаются открытыми.

Validation v0.416 / Проверка: minimal Release 832/832; AGG Release 12/12 and
heap/global ASan+UBSan 12/12 parsing/decimal/whitespace/JIT tests. Native launchers
restore workspace executable modes; stack ASan/LSan disabled. No other-platform
runtime acceptance or complete stage closure is claimed.
