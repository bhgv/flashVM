# binding.length

[English](STYX_RPC_LIVE_LENGTH.md) · [Живые переменные](STYX_RPC_LIVE_VARIABLES.ru.md) · [Типы моста](STYX_RPC_VALUE_TYPES.ru.md) · [Реализация](../src/styxrpc/session_live_values.c#L183)

## Синтаксис

```actionscript
binding.length():Number
```


## Результат

Читает текущий счётчик проверенной проекции как неотрицательный `Number` до 4 294 967 295. Для массива Int32 или вектора `big` это число элементов, для записи — число опубликованных именованных полей. Для гибридной таблицы используется длина плотной части из `.len` провайдера. Это снимок числа на момент чтения. Перед следующей операцией длина может измениться. Метод не принимает аргументов.

## Ошибки и ожидание

У скаляра и строки нет длины коллекции. Закрытая или устаревшая привязка, неверный счётчик, сбой обмена и остановка приводят к исключению. Метаданные читаются синхронно, ожидание в `asinc` можно отменить.

## Пример

```actionscript
// Считываем текущий размер коллекции перед выбором индекса.
var scores = vfs.liveVariable("/live/.var/numbers");
var count = scores.length();
var closed = scores.close();
```
