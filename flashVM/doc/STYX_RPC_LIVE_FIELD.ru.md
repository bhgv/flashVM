# binding.field

[English](STYX_RPC_LIVE_FIELD.md) · [Живые переменные](STYX_RPC_LIVE_VARIABLES.ru.md) · [Типы моста](STYX_RPC_VALUE_TYPES.ru.md) · [Реализация](../src/styxrpc/session_live_values.c#L233)

## Синтаксис

```actionscript
binding.field(name:String):Object
```


## Параметр и результат

Передайте непустое имя непосредственного поля без слеша и начальной точки. Привязка должна относиться к опубликованной записи. Возвращает новый прокси поля, которое само может быть записью. Поле держит собственный fid и наследует ограничение прав записи родителя и собственные права узла. Закрытие родителя сохраняет дочернюю привязку пригодной, пока доступны её публикация и сессия.

## Ошибки и ожидание

Неверный тип аргумента выявляется локально. Отсутствующее, нечитаемое или неподдерживаемое поле, обращение к узлу другого типа или устаревшая публикация вызывают исключение. Синхронные проверка и обход учитывают остановку `asinc`. При ошибке дочерняя привязка не выдаётся.

## Пример

```actionscript
// Удерживаем поле и сразу освобождаем fid родителя.
var details = vfs.liveVariable("/live/.var/details");
var name = details.field("name");
var parentClosed = details.close();
var initial = name.get();
var fieldClosed = name.close();
```
