# Проверки Boolean/прототипов, версия разработки 0.2

Добавлены конструктор оболочки Boolean, закрытый примитив, методы valueOf/toString
прототипа, метаданные класс/прототип, корень захвата конструктора и прямое числовое
преобразование оболочки. Boolean как функция по-прежнему возвращает примитив.
Новый API нативных методов ищет по прототипам, сохраняет исходный receiver и
копирует запись callback перед вызовом. Данные/accessor перекрывают вызов;
нативный метод имеет приоритет перед одноимённой скриптовой функцией AVM1.
ToNumber теперь проверяет байты C enum до чтения скалярного enum в C++.
Контракт и ограничения: STANDARD_BOOLEAN.ru.md.

## Проверенные сборки и тесты

Linux x86_64, GCC/G++ 13.3.0, CMake 3.31.10, C89/C++98 с pedantic-errors.
CMake читает VERSION.txt: версия проекта 0.2. Встроенные библиотеки статические.

| Профиль | Успешные тесты/примеры |
| --- | ---: |
| AGG | 125 |
| Cairo | 125 |
| NO_FONTS | 121 |
| NO_GRAPHICS и NO_IMAGE_CODECS | 119 |
| ASan/UBSan (AGG) | 125 |

scripts/check.py --sanitize заново собрал все выбранные исходники ядра и
библиотек, затем скомпилировал, связал и выполнил каждый тест/пример.
Восстановленные диагностики тоже считаются отказом. LeakSanitizer отключён
из-за недоступного /proc; прежний тест исключений своего аллокатора — только UBSan.
Итоговые исходники изменены до сборки их инструментированных объектов, включая
переопределение родительского метода в тесте потоков. GCC выдаёт прежнее
предупреждение об адресе локального корня AVM1: guard восстанавливает предыдущий
кадр, проверки явного/автоматического GC проходят. Отсутствие предупреждений
сборки не заявлено.

tests/standard_boolean.c проверяет все типы входов, отсутствие аргумента,
NaN/бесконечность/знаковый ноль, истинность оболочки и извлечение примитива,
числовое преобразование, метаданные и неверный receiver, лишние аргументы,
захват конструктора после удаления глобального имени, явный GC и автоматический
GC при AVM1, запрет передачи оболочки через канал, чужие объекты, неверный C enum
и сохранение имён при конфликте установки. tests/native_prototype_methods.c
проверяет receiver/аргументы, приоритет нативного метода, собственные методы,
перекрытие данными/accessor, удержание/замену/освобождение захвата, замену метода
самим собой, прежний fallback и границу цепочки 1024/1025 объектов.
tests/actionscript_extensions.cpp запускает восемь независимых контекстов Boolean
после переопределения метода родителя: создание, GC с живым локальным корнем и
примитивная строка результата проходят в каждом потоке.

C89-пример реально исполняется. example.as — иллюстрация; выполнение подтверждают
отдельные AVM1-фикстуры. Отчёты/логи: validation/boolean-*.json и *.log.
Два прежних бинарника сначала не запускались из-за execute-битов; права
восстановлены, итоговые полные проверки прошли. Манифест подтверждает 2094 файла
встроенных библиотек без изменений.

## Версии, архивы и зеркало

Правило пользователя записано в AGENTS.md: перед каждым новым коммитом повышать
VERSION.txt, начинать английское сообщение новой версией и завершать имя архива
постфиксом -v<версия>.zip. Версия ABI независима.

По прямой команде зеркало обновлено с 0a9c53d до 6831bf4 с HTTP-буфером 64 МиБ,
без force push. Получение серверной ветки, проверка предка и сравнение хешей
подтвердили совпадение с внутренним Git. Последующая разработка 0.2 не отправлена.
Основным остаётся внутренний репозиторий/архив.
