# recv() именованного канала

[English](STYX_RPC_NAMED_RECV.md) · [vfs.chan](STYX_RPC_NAMED_CHANNEL.ru.md) · [Реализация](../src/styxrpc/session_named_channel.cpp)

Ожидает первого отправителя из очереди именованного канала.

## Синтаксис

```actionscript
port.recv()
```

## Доступность

Метод доступен в плеере с поддержкой StyxRPC и в парных отделённых
задачах, когда сессия предоставляет именованные каналы. `port` —
объект от [`vfs.chan(path)`](STYX_RPC_NAMED_CHANNEL.ru.md).
Аргументы не требуются.

## Возвращаемое значение и ошибки

Обычное сообщение возвращает декодированное значение. Дескриптор
живой ячейки этой сессии открывает новую аренду и возвращает
прозрачную ссылку. Чтение и присваивание через неё обращаются к ячейке.
Аренда может оставаться доступной после закрытия участия в канале.

Закрытый канал, неверный кадр, отказ присоединения или разрыв
соединения вызывают исключение. Вызов из фильма может задержать
следующий кадр. В [задаче asinc](ASINC_TASK.ru.md)
[`cancel()`](ASINC_CANCEL.ru.md) может прервать и присоединение к
принятой ячейке. Встреча могла уже передать дескриптор к моменту отмены.

Ссылка на удалённый экспорт Int32 открывает исходный fid при первом
чтении или присваивании. В задаче `asinc` эти операции поддерживают
отмену. Ссылки на локальные экспорты доступны в контексте фильма.
[Парный пример FlashVM и DisVM](../../lib/styxrpc/examples/disvm/INT32_REFERENCES.ru.md).

## Пример

Отправитель публикует числовую ячейку через
[`send(ref counter)`](STYX_RPC_NAMED_SEND.ru.md). Получатель читает
и меняет число. Запустите отправителя в другом потоке или в парной VM.

```actionscript
var port = vfs.chan("/jobs");
var counter = port.recv();
var previous = counter + 0; // Читаем общее значение в этой строке.
counter = previous + 1;   // Пишем через принятую ссылку.
var released = port.delete(); // Закрываем участие в канале.
```

После подтверждения присваивания новое значение видно через обе аренды.
Если требуется атомарная последовательность чтения, изменения и записи,
согласуйте действия участников на уровне приложения.
