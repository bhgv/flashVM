# Нативные литералы Array/Object — v0.358

[English](JIT_LITERALS.md)

InitArray и InitObject используют общий нормализатор счётчика и сервисы создания
Array/Object. Исходные операнды остаются на защищённом нативном стеке во время
преобразования счётчика, конструктора, преобразования имён и setter. Копии
элементов сохраняют порядок снятия со стека. Результат заменяет поглощённый
операнд до сокращения стека без выделения памяти после снятия временных корней
сервиса.

Host требует целый числовой счётчик и достаточное число операндов. Загруженные
SWF сохраняют усечение дроби, NaN → 0, отклонение невалидного знакового счётчика
и предел материализации 65536 элементов. Отклонённый счётчик заменяется на
undefined без поглощения элементов. Недостающие входы дополняются undefined;
имя и значение пары Object дополняются независимо. Элементы Array создаются
собственными, включая undefined, обходя унаследованные setter/readonly-индексы.
Для Object сохранены порядок преобразования имён, повторные присваивания,
ключи с NUL и пропуск пустых имён в загруженных SWF.

`jit_literals` сравнивает три режима исполнения в host/SWF4–8: порядок стека,
повторные/пустые/counted-NUL ключи, нехватку входов и частей пары, отклонённые
счётчики и точное поглощение, дробь/NaN/бесконечность/строковый счётчик, превышение
предела материализации и жизнь результата после освобождения кода и GC.
`jit_literals_callbacks` проверяет GC и исключения в счётчике/имени, унаследованные
аксессоры и readonly-индексы Array, восстановление корней и состояния.
`jit_literals_allocation` перебирает отказы памяти при callback, конструировании
и публикации, проверяя восстановление состояния и сохранение результата.

Побочные эффекты callback при ошибках сохраняются, как в интерпретаторе:
присваивания и пользовательские вызовы не являются транзакцией. Определения
функций, With/Try, остальные инструкции и полная совместимость ещё требуют
работы. Ни одна стадия роудмапа не объявляется завершённой.

Linux Release: прошли все 726 проверок AGG, 726 Cairo и 707 минимального
профиля после восстановления прав запуска ELF. Три теста литералов прошли
heap/global ASan+UBSan; stack ASan и LSan отключены.
