# Первый этап числовой стандартной библиотеки

Заголовок: `flashvm/standard.h`; установка: `fvm_standard_install(context)` до
исполнения фильма. Установка явная, поэтому прежние встраивания сохраняют свои
глобальные имена и число объектов GC. Конфликт с существующим глобальным именем,
нативной/стековой регистрацией или именованной скриптовой функцией отклоняет первую
установку. Карты глобальных значений и функций публикуются вместе после подготовки.
Повторная установка проверяет регистрации методов/функций, но не восстанавливает
изменённые пользователем константы.

Добавлены Math, NaN, Infinity и вызываемые по имени Number, Boolean, isNaN,
isFinite и объектная оболочка Boolean с конструктором/прототипом.
Number пока остаётся функцией преобразования без boxed-конструктора.
Описание Boolean: [STANDARD_BOOLEAN.ru.md](STANDARD_BOOLEAN.ru.md).
Функции и методы ещё не представлены первоклассными
function-valued свойствами. Константы пока изменяемые; атрибуты read-only и
non-enumerable ещё предстоит реализовать.

Math: abs, acos, asin, atan, atan2, ceil, cos, exp, floor, log, max, min,
pow, random, round, sin, sqrt, tan. Константы: E, LN10, LN2, LOG10E,
LOG2E, PI, SQRT1_2, SQRT2. Вызов: [fvm_object_call](../include/flashvm/value.h#L126) и AVM1 ActionCallMethod.
Недостающие аргументы дают NaN; лишние игнорируются методами фиксированной арности.
min/max принимают любое число аргументов, возвращают +/-Infinity без аргументов,
распространяют NaN и выбирают правильный знак нуля. round при равенстве выбирает
округление к +Infinity и сохраняет -0 на интервале [-0.5,0). pow(NaN,0)=1,
pow(+/-1,+/-Infinity)=NaN. Остальные операции используют C math библиотеки
платформы; побитовая согласованность между целевыми платформами не проверена.

Math.random использует независимый для контекста 32-битный LCG, диапазон [0,1).
Начальное состояние каждого контекста — 1: последовательности воспроизводимы.
Потоки не разделяют libc rand или состояние генератора. Это не криптографический
генератор и не точная копия PRNG Flash Player.

[`fvm_value_to_number`](../include/flashvm/standard.h#L23): undefined → NaN, null → +0, boolean → 0/1; числа
сохраняются. Строки разбираются независимо от locale: ASCII-пробелы, десятичные
числа с дробью/экспонентой, беззнаковый 0x hex, Infinity и пустая строка → 0.
Неверный синтаксис даёт NaN; отрицательный ноль сохраняется. Оболочка Boolean
преобразует свой примитив в 0/1 без вызова пользовательских переопределений.
Общее Object
ToPrimitive/valueOf/toString возвращает UNSUPPORTED. Unicode-пробелы, все
различия версий SWF и правильно округлённое преобразование произвольной длины
ещё не завершены: десятичный parser сохраняет до 19 значащих цифр и использует
ограниченные счётчики экспоненты. Это явное подмножество преобразования строк.

Скриптовые workers запоминают, установлена ли библиотека в родительском
контексте, и создают собственную Math. Объекты и состояние PRNG не разделяются.

Источник для числовых граничных случаев: ECMA-262, раздел 15.8,
https://262.ecma-international.org/5.1/#sec-15.8 . Это образец для тестов,
а не подтверждение полной совместимости Flash<=8.

`tests/standard_numeric.c` проверяет каждый Math-метод, константы, NaN/Infinity,
знаки нуля, округление, subnormal-строки, преобразования, сохранность имён
при конфликте, GC и настоящий AVM1 CallMethod. Интеграционный тест расширений
проверяет Math.pow в отдельном script worker. Остальные стандартные/системные
объекты остаются в SWF8_ROADMAP.
