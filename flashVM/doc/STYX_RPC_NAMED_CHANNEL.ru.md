# vfs.chan(path)

[English](STYX_RPC_NAMED_CHANNEL.md) · [Штатная сессия](STYX_RPC_DEFAULT.ru.md) · [Реализация FlashVM](../src/styxrpc/session_named_channel.cpp) · [Протокол и Limbo](../../lib/styxrpc/reference/named_channel.ru.md)

`vfs.chan(path)` открывает именованный канал в пространстве имён парной
сессии. `os.chan(path)` использует ту же сессию. Абсолютный путь отсчитывается от её корня,
относительный — от [`pwd()`](STYX_VFS_PWD.ru.md). Каждый вызов получает одного участника.
Если имя свободно, текущее пространство имён получает привязку канала.
В DisVM родительский каталог должен разрешать запись и проход. Существующий обычный
файл, каталог или служебный путь даёт ошибку. Существующий канал принимает
нового участника.

[Две FlashVM](STYX_RPC_PEER_CHANNELS.ru.md) используют пространство имён
плеера `forward` с общими резервами и арендами ячеек.

| Метод | Действие |
| --- | --- |
| [`recv()`](STYX_RPC_NAMED_RECV.ru.md) | Ждёт отправителя и возвращает его значение. |
| [`send(value)`](STYX_RPC_NAMED_SEND.ru.md) | Ждёт, пока читатель примет значение. |
| [`delete()`](STYX_RPC_NAMED_DELETE.ru.md) | Закрывает участие этого объекта. |

Последнее закрытие снимает точную привязку из VFS. Сборщик мусора ставит
такое же закрытие в очередь для недостижимого объекта. Завершение сессии
закрывает её дескрипторы. Извлечённый метод удерживает объект канала.
Обычные операции FlashVM скрывают служебный узел и отклоняют доступ
к имени канала.

```actionscript
var work = vfs.chan("/jobs");
var job = work.recv();
var sent = work.send(job);
var released = work.delete();
```

Встречная операция выполняется в другом потоке либо в парной VM.
При вызове из потока фильма штатный плеер ждёт результата перед
следующим кадром. DisVM продолжает работать во время ожидания.
Плеер подтверждает `.state start` перед выполнением первого кадра.

В парной [задаче asinc](ASINC_VFS.ru.md) методы ждут в рабочем потоке.
[`cancel()`](ASINC_CANCEL.ru.md) отправляет `Tflush` по тегу ожидающего
обмена данными и закрывает участие задачи в канале. Если участники уже
встретились, другая сторона могла получить значение.
