# Отделённые задачи AS2 в системных потоках

[English](ASINC_TASK.md) · [Профили компилятора](../../compiler/ASINC.ru.md) ·
[Очередь владельца](ASYNC.md) · [C API потоков](WORKER_FUNCTION.ru.md)

Проектный компилятор AS2 view принимает модуль с одной функцией без внешнего
окружения. Соберите её штатными AS2 view, FIR и SWL.

```actionscript
asinc function compute(value) {
    return value + 2;
}
```

Инициализатор SWF устанавливает `_root.compute`. Вызов `_root.compute(40)`
создаёт отдельный контекст FlashVM в системном потоке и возвращает задачу.
Родительская сессия и окно продолжают работать. Поток выполняет отделённый
байткод со своей стандартной библиотекой. Компилируемый профиль видит
параметры, ранее объявленные привязки `var` и собственный `Math`.
Вызов принимает столько аргументов, сколько объявлено параметров, до восьми.
Аргументы копируются одним графом. Профиль отклоняет внешние привязки,
`ref` и остальные формы `asinc`. Совместные захваты и доступ
из задачи к живой VFS ещё предстоит подключить.

## Операции задачи

| Операция | Результат |
| --- | --- |
| [`Async.run(function[, ...args])`](ASINC_RUN.ru.md) | Скопировать сериализуемое AVM1-замыкание и запустить его тело в потоке. |
| [`task.poll()`](ASINC_POLL.ru.md) | Прочитать снимок состояния без ожидания потока или кадра. |
| [`task.cancel()`](ASINC_CANCEL.ru.md) | Запросить кооперативную отмену в контрольной точке VM. |

Компилятор устанавливает отделённый шаблон через `Async.wrap`. Эта часть
контракта компилятора и плеера копирует байткод, параметры и константы функции без
исходной шкалы или захватов. Нативное тело импортированной функции не
переносится. Контекст удерживает до 16 задач, считая уже снятые обёртки,
потоки которых ещё нужно освободить. Сборщик запрашивает отмену недостижимой
задачи без ожидания потока. Владелец освобождает завершившиеся потоки при
следующем запуске, опросе таймеров или уничтожении контекста. При уничтожении
контекста владелец запрашивает остановку и ждёт завершения удерживаемых потоков.

Штатный парный плеер устанавливает пространство имён до исполнения SWF.
Встраивающая программа может вызвать [`fvm_async_install`](../include/flashvm/async.h#L15).
[Парный тест](../../ide/tests/check_flash_peers.py) собирает
[рабочий модуль](../tests/styxrpc/peer-asinc.as) и
[вызывающий модуль](../tests/styxrpc/peer-asinc-frame.as) и исполняет их
штатным плеером. Укажите `--asinc-only` и обычные пути к плееру, AS2, FIR
и SWL. Добавьте `--tcp`, чтобы проверить TCP вместо локальной пары сокетов.
[Нативный тест](../tests/asinc_tasks.cpp) проверяет, что зацикленный поток
можно опрашивать и остановить из работающего контекста, а строка результата
сохраняет свои байты после завершения потока.
