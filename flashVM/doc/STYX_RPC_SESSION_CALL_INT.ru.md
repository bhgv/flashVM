# styxrpc.callInt

[English](STYX_RPC_SESSION_CALL_INT.md) · [Привязка сессии](STYX_RPC_SESSION.ru.md) · [Реализация](../src/styxrpc/session_calls.c)

```actionscript
result = styxrpc.callInt("mounted/peer.dis", "magnitude", -12);
```

Метод вызывает экспортированную `fn(int): int` через текущую смонтированную
сессию. `module` — относительный путь к опубликованному модулю. `method` —
один компонент имени экспорта. `argument` должен быть точным знаковым
32-битным целым. Пример вернёт 12, если вторая сторона экспортирует
`Math.abs` под именем `magnitude`.

Вызов заимствует сессию и сверяет сигнатуру собранного модуля перед записью
запроса. Он возвращает точное знаковое 32-битное число или выдаёт ошибку при
неверных аргументах, отказе до отправки, ошибке на второй стороне либо
неопределённом исходе. При неопределённом исходе функция могла выполниться.
При выходе вызов закрывает свой fid функции.

Операция блокирует владельца вызывающего фильма. Бюджет опроса ответа —
1 000 мс в дополнение к срокам ввода-вывода сессии. Планируйте вызовы так,
чтобы второй владелец мог принимать запросы. Одновременные встречные
вызовы, в которых каждый ждёт владельца другой стороны, могут завершиться
по тайм-ауту.
