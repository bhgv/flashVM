# vfs.rm(path)

[English](STYX_VFS_RM.md) · [Файловый API](STYX_RPC_OS.ru.md) · [Реализация](../src/styxrpc/session_paths.c) · [API C](../../lib/styxrpc/reference/vfs_remove.ru.md)

`vfs.rm(path)` и `os.rm(path)` удаляют один обычный файл либо пустой
каталог. Относительные пути начинаются от общего
[рабочего каталога](STYX_VFS_CD.ru.md). Вызов возвращает `true` после
подтверждения и выдаёт ошибку при отказе. Непустые каталоги, корень
подключения и служебные пути защищены. В штатной паре DisVM операция
действует на узлы нативной файловой системы. Вызов ждёт ответа Styx и
возвращает ошибку при неопределённом результате. Перед повтором проверьте путь.

```actionscript
var removed = os.rm("drafts/old.txt");
```
