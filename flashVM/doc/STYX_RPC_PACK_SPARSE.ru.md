# vfs.packSparse

[English](STYX_RPC_PACK_SPARSE.md) · [Живые переменные](STYX_RPC_LIVE_VARIABLES.ru.md) · [Типы моста](STYX_RPC_VALUE_TYPES.ru.md) · [Реализация](../src/styxrpc/session_sparse.cpp#L34)

## Синтаксис

```actionscript
vfs.packSparse(array:Array):Array
```


## Параметр и результат

Передайте нативный Array данных из текущего контекста. Допустимая длина от 0 до 2 147 483 647, занятых собственных индексов до 2048. Стандартный аксессор длины Array допустим. Пользовательские аксессоры и наблюдатели приводят к отказу. Метод читает собственные индексные слоты напрямую. Именованные и унаследованные свойства не участвуют.

Возвращает `[длина, [[индекс, значение], …]]` со строго возрастающими индексами. Контейнер и каждая пара создаются заново. Значения остаются исходными локальными значениями до копирования RPC по схеме `T`. Канонический кортеж имеет вид `(ia[(iT)])`. В Limbo ему соответствует `(int, array of (int, T))`. Занятый слот с `undefined` сохраняется в локальном кортеже. Для передачи его значение должно допускаться заявленным `T`.

## Ошибки и доступность

Неверный аргумент или форма массива приводят к ошибке аргумента. При нехватке памяти VM сообщает о сбое. Фильм и задание `asinc` могут использовать метод после появления своего `vfs`, без удалённого обмена. Типизированный вызов сохраняет пределы глубины и размера кадра.

## Пример

```actionscript
// Сохраняем пропуски перед элементом и два пропуска после него.
var samples = new Array(6);
samples[3] = "ready";
var encoded = vfs.packSparse(samples); // [6, [[3, "ready"]]]
```
