# Пулы констант JIT — v0.353

[English reference](JIT_POOLS.md)

ConstantPool, Push-constant8 и Push-constant16 компилируются в прямые нативные
вызовы. Начальный пул берётся из снимка подготовленной функции; корневой блок
начинается без наследуемого пула. Публичный ABI кадра не менялся: частный scoped
указатель передаёт уже принадлежащий активации снимок байтовых строк и восстанавливает
родительский указатель при любом выходе.

Каждая запись ConstantPool копируется в неизменяемый набор code handle. Набор
выбирается только при фактическом выполнении инструкции. Push читает текущий пул
вызова, а не ближайшую запись исходника. Поэтому переход вперёд может пропустить
замену, а переход назад — прочитать строку из более позднего выполненного пула.
Одинаковый кешированный машинный код не объединяет захваченные пулы разных функций.

Отсутствующий элемент даёт undefined для загруженного SWF и INVALID_ARGUMENT
в host-режиме. Пустой пул очищает выбор, не возвращается к захваченному пулу.
Строка становится собственностью контекста до помещения в корни стека и живёт
после освобождения code handle. Как прежний own_string интерпретатора, наследуемые
элементы используют строки до NUL; новый синтаксис pool-строк со встроенным NUL
не вводится.

Компилятор проверяет длины, терминаторы и ширину индексов. Независимый лимит
[`FVM_JIT_MAX_POOL_ENTRIES`](../src/jit/constants.h#L7) ограничивает сумму элементов всех замен числом 65536.
Он отличается от UI16-длины/счётчика отдельной записи и от таблицы литералов.
Ошибка не заменяет прежний code handle.

`jit_pool` сравнивает интерпретатор, явный и автоматический JIT для host/SWF4–8:
наследование/замену/очистку/пропуски, переходы в обе стороны, индекс 256,
смешанный Push и общий машинный код при разных захваченных пулах.
`jit_pool_callbacks` проверяет вложенную функцию и корневой блок внутри getter,
GC/исключение, восстановление родителя и строку после освобождения машинного кода.
`jit_pool_allocation` проходит отказы компиляции/вызова, проверяет указатель пула,
корни, глубины и активность handle. `jit_pool_bounds` проверяет повреждённые записи
и точный суммарный предел с отказом при превышении.

Десять целевых heap/global ASan+UBSan проверок проходят, включая script bridges
и диагностический replay. Stack ASan и LeakSanitizer отключены по прежним
ограничениям среды. Fallback-набор execution_modes теперь использует пока
неподдержанный StringLength вместо ConstantPool.

В нативном подмножестве представлены все форматы операндов Push. Полнота Action
этим не достигнута: определения/вызовы функций, создание объектов/массивов, With/Try
и другие операции ещё интерпретируются. Реальные другие ОС/CPU и завершение стадий
roadmap не объявляются подтверждёнными.

Linux Release: 713 AGG, 713 Cairo and 694 minimal checks pass. AGG/Cairo
test objects were rebuilt for the changed private context layout. Generated
ELF execute permissions were restored for AGG/minimal launch failures.
