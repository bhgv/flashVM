# vfs.unpackSparse

[English](STYX_RPC_UNPACK_SPARSE.md) · [Живые переменные](STYX_RPC_LIVE_VARIABLES.ru.md) · [Типы моста](STYX_RPC_VALUE_TYPES.ru.md) · [Реализация](../src/styxrpc/session_sparse.cpp#L133)

## Синтаксис

```actionscript
vfs.unpackSparse(tuple:Array):Array
```


## Параметр и результат

Передайте нативный Array из двух слотов, полученный из [`packSparse`](STYX_RPC_PACK_SPARSE.ru.md) или декодированный по такой схеме RPC. Первый слот хранит логическую длину от 0 до 2 147 483 647. Второй хранит плотный Array из не более 2048 двухэлементных пар. Индекс — целый `Number` в `[0, длина)`. Индексы строго возрастают. Для массива без занятых слотов используйте пустой Array пар.

Возвращает новый локальный Array с указанной длиной и собственным слотом для каждой пары. На пропущенных индексах собственных слотов нет. Значения пар удерживаются как локальные значения AS.

## Ошибки и доступность

Повторные, неупорядоченные или запредельные индексы, пропуски среди пар, nil вместо списка пар, пользовательские аксессоры, наблюдатели и неправильная структура приводят к ошибке аргумента. Частично заполненный Array остаётся внутри вызова. О нехватке памяти сообщает VM. Метод доступен через `vfs` фильма или задания и работает синхронно без обмена по сети.

## Пример

```actionscript
// В кортеже ответа индекс 5 может отсутствовать при длине 12.
var restored = vfs.unpackSparse(tuple);
var hasOwnFive = restored.hasOwnProperty("5");
```
