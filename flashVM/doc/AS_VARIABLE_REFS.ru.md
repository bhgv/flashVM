# Ссылки на переменные ActionScript

[English](AS_VARIABLE_REFS.md) · [Компилятор AS2](../../compiler/as2/view/README.ru.md) · [Исполняемая проверка](../tests/styxrpc/peer-ref.as)

В профиле представления AS2 оператор `ref counter` берёт ссылку на
существующую переменную корневого фильма. `ref model.count` запоминает
вычисленный объект `model` и имя собственного свойства. `ref rows[index]`
один раз вычисляет владельца и ключ при захвате. Если переменная с индексом
позже меняется, ссылка по-прежнему указывает на захваченный слот. Выражения
вроде `ref (counter + 1)` не имеют места хранения и отклоняются.

```actionscript
var counter = 41;
var ch = channel.create("ref", 2);
var queued = ch.send(ref counter);
var alias = ch.recv();
alias = alias + 1;
var snapshot = alias;
var forwarded = ch.send(ref alias);
```

Приём ссылки в новое имя устанавливает привязку. Чтение имени получает
текущее значение исходной ячейки. Запись вызывает правила присваивания
исходному имени или свойству. Оператор `ref alias` достаёт исходную ссылку
из привязки, в том числе после пересылки. `ch.send(alias)` читает значение
и передаёт его как самостоятельное сообщение.

`channel.create("ref", capacity)` создаёт FIFO одного контекста с ёмкостью
от 1 до 65536 сообщений. `send` принимает скаляр или ссылку и возвращает
`false` при заполнении. `recv()` возвращает первое сообщение или
`undefined`, пока очередь пуста. `close()` освобождает очередь. Очередь
и привязки удерживают владельца через сборщик мусора.

Обычная очередь ссылок работает в одном контексте. Для живых Int32 из
другого процесса доступны [сетевые дескрипторы](../../lib/styxrpc/reference/int_variable_refs.ru.md).
Чтение с последующей записью выполняется двумя операциями.

[Именованные каналы VFS](STYX_RPC_NAMED_SEND.ru.md) также публикуют
новые записываемые слоты в сессии StyxRPC. Слот может содержать скаляр или
сериализуемый граф. Чтение графа даёт снимок, присваивание публикует снимок целиком.
Поддержаны существующие элементы Array и свойства Object. Число `1` и строка
`"1"` обозначают один элемент Array, а `"01"` служит отдельным именем свойства.
Отдельное пространство числовых индексов нативных таблиц пока не поддерживает
такие ссылки. [Исполняемый парный сценарий](../../lib/styxrpc/tests/flashvm/named_pair.as).
