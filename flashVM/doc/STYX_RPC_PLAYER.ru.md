# Штатный парный плеер Styx

[English](STYX_RPC_PLAYER.md) · [Протокол плеера](STYX_RPC_MODULES.ru.md) · [Файлы и модули](STYX_RPC.ru.md)

Программа `flashvm_styx_player` запускает владельца FlashVM с монотонным тактовым циклом. Она принимает уже соединённый двусторонний поток на унаследованном дескрипторе от 3. По двум направлениям одного соединения Styx идут управление FlashVM и файловая система DisVM. Команда ActionScript `trace` пишет в stdout плеера. Для сборки установите хостовые SDK Styx и libstyxrpc.

```sh
cmake -S flashVM -B build/flash -DFVM_ENABLE_STYXRPC=ON -DCMAKE_PREFIX_PATH=/path/to/sdk
cmake --build build/flash --target flashvm_styx_player
```

## Запуск владельцев

Создайте связанную пару сокетов в запускающей программе и передайте по одному концу каждой команде. Числа обозначают унаследованные дескрипторы в соответствующих процессах. После запуска закройте копии дескрипторов в запускающей программе.

```sh
flashvm_styx_player --fd 3 --no-jit
disvm --styx-mount-fd 4 --at /flash --share-vfs ./movies -- \
    --native-spawn --no-jit controller.dis
```

`controller.dis` управляет FlashVM через `/flash/.upload` и `/flash/.state`. Поместите файлы, доступные FlashVM, в `./movies`. Например, `./movies/intro/child.swf` виден во FlashVM как `/intro/child.swf`. `--share-vfs` разрешает чтение и проход по каталогам. `--share-vfs-rw` дополнительно разрешает запись в существующие файлы, если у хоста есть соответствующие права. Путь выбирает хост DisVM. Удерживаемый каталог ограничивает область поиска, исключает символьные ссылки ниже корня и скрывает физические компоненты `.prog`. Сессия удерживает до 510 идентификаторов пройденных обычных узлов. Кеш освобождается при закрытии сессии.

Программа управления записывает в `/flash/.upload` длину стартового SWF четырьмя байтами big-endian и сам SWF. Затем достаточно один раз записать `start` в `/flash/.state`. Плеер берёт частоту из заголовка SWF. При нулевой частоте используется 12 кадров в секунду. Плеер ждёт следующего кадра или запроса Styx. `pause` останавливает кадры и оставляет файлы управления доступными. `restart` запускает сохранённый стартовый SWF заново. В этой программе `debug` приостанавливает фильм и выбирает интерпретатор. Встраиваемый API также поддерживает подключаемый отладчик. Для каждой VM можно выбрать `--jit`, если он доступен в этой сборке.

Эта команда запускает плеер без окна. Окно, интерфейс отладчика и каталог типизированных импортов Dis подключаются встраивающим приложением. Контракт управления и VFS для владельцев единый.

## Нативная проверка

При настройке тестов SDK укажите исходники и сборку DisVM, а также `-DSTYXRPC_FLASHVM_PLAYER=/path/to/flashvm_styx_player`. Тесты запускают штатные двоичные файлы, проверяют тактовый цикл, паузу, вложенные SWF, отсутствие скрытых и внешних путей и запись существующего файла по явному разрешению.

```sh
ctest --test-dir build/styxrpc -R 'styxrpc-native-player' --output-on-failure
```
