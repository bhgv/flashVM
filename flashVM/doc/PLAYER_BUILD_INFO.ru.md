# Метаданные сборки проигрывателя

С v0.669 `flashvm_player --version` выводит версию из VERSION.txt, ABI связанной
VM, ширину указателя целевой сборки, доступность JIT-бэкенда, наличие собранного
SDL-аудиомоста и версии заголовков/связанной SDL. Файлы, окно и аудиоустройство
не открываются; отсутствующий видеодрайвер не мешает запросу. Состояние локали
не изменяется. Это метаданные сборки, не проверка устройства или совместимости.

Версия разработки и ABI — разные величины. Разрядность указателя не определяет
модель процессора. Доступность JIT не означает поддержку каждой программы или
успешное выделение исполняемой памяти позже. Наличие аудиомоста не гарантирует
драйвер, декодер, устройство или воспроизведение потокового звука.

Для C-хоста `fvm_desktop_build_info` заполняет `FVM_DesktopBuildInfo` без выделений
памяти; нулевой out возвращает [FVM_INVALID_ARGUMENT](../include/flashvm/flashvm.h#L45). Строка версии статическая,
её нельзя освобождать. Интерфейс расположен в frontend/common/player.h и является
внутренним интерфейсом хоста, не новым стабильным ABI библиотеки VM. Заголовок
содержит extern C для C++98; отдельный тест действительно связывает C++-хост с
C89-проигрывателем и вызывает оба интерфейса без доступных SDL-драйверов.

CMake генерирует desktop_build_version.h в каталоге сборки. Изменение VERSION.txt
переконфигурирует его при следующей сборке. Не копируйте этот заголовок в исходники
и не используйте заголовок от другой целевой сборки. Для включения player.c в свой
хост нужно передать каталог generated из соответствующей frontend-сборки вместе
с обычными заголовками FlashVM и SDL.

`--version` завершает разбор так же, как `--help`: ранее обнаруженная ошибка не
подавляется, последующие корректные аргументы не используются. Все указатели
argv проверяются заранее. После `--` строка `--version` является именем файла.

```sh
./build-player/frontend/flashvm_player --version
cmake --build build-player --target flashvm_frontend_build_info
ctest --test-dir build-player -R frontend_build_info --output-on-failure
```

## Проверка v0.669

На Linux x86-64 прошли 62 выбранных теста: 47 проверок frontend/player/capture
и 15 связанных проверок сцены/звука VM. Это не полный набор тестов проекта.
Проигрыватель использует SDL 2.30.12 с dummy video и программным renderer;
SDL-аудиомост отключён. Метаданные проверены без доступных драйверов. Реальное
освобождение объектов проверено отдельно в интерпретаторе и JIT; старое условие
сборки только после таймера проваливает оба теста.

Полный проигрыватель также слинкован с целевой статической SDL для ARM64 Linux
(musl), RISC-V64 Linux (musl) и x86-64 Windows (GNU). Проверены типы ELF/PE и коды
архитектур 183, 243 и 0x8664. Использовался прежний адаптированный для среды Zig
0.13; это не проверка неизменённого SDK. Иностранные бинарники не запускались.
Нет новой приёмки macOS/Android, физического окна/звука или длительной нагрузки.
