# ch.send

[English](STYX_RPC_CHAN_SEND.md) · [Открытие](STYX_RPC_NEWCHAN.ru.md) · [Приём](STYX_RPC_CHAN_RECV.ru.md) · [Реализация](../src/styxrpc/session_channel.c)

`ch.send(value)` отправляет снимок числа AS, логического значения,
строки с длиной (до 16 384 байт) или `null`. `ch.send(ref counter)`
пересылает живую ссылку Int32, ранее полученную в той же сессии Styx.
Исходная идентичность и права сохраняются. Для расшаривания локальной
переменной AS нужна опубликованная ячейка. Этот API пока не выдаёт
дескрипторы для локальных переменных AS.

[Схема передачи](../../lib/styxrpc/reference/channel_messages.ru.md)
выбирается по значению. При `ch.send(counter)` AS выполняет обычное
чтение привязки и передаёт текущее значение. Согласование типов и
автоприведение по запросу получателя ещё предстоит добавить.

Вызывайте в потоке владельца фильма. Метод пишет через Styx со сроком
ожидания сессии и возвращает `true` после подтверждения записи. Приём
в этом вызове не выполняется. Неподдерживаемые значения и закрытые
каналы дают ошибку аргумента. Ошибка транспорта завершает работу
канала. Другая сторона могла принять запись даже при ошибке, поэтому
повтор может продублировать действие.
