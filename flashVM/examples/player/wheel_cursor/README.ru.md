# Учебный фильм: колесо и нативный курсор

Запустите готовый [SWF8](wheel-cursor.swf) в SDL-проигрывателе. Остановленная
сине-серая сцена 320×200 продолжает принимать ввод: колесо печатает строки со
знаком, основная кнопка скрывает курсор при нажатии и показывает при отпускании.
Это пример ввода на остановленном timeline без дополнительных скриптовых кадров.
[Эквивалент AS](wheel_cursor.as), [автономный генератор](make_movie.py),
[точный контракт](../../../doc/PLAYER_WHEEL_CURSOR.ru.md).

Соберите player с AGG и своим SDK SDL2 по
[руководству обычной/cross-сборки](../../../../BUILDING.ru.md), затем из корня:

```sh
python3 flashVM/examples/player/wheel_cursor/make_movie.py
build/player/frontend/flashvm_player --interpreter --mute \
  flashVM/examples/player/wheel_cursor/wheel-cursor.swf
```

Для доступного нативного backend можно выбрать `--jit`. Escape/close освобождает
VM, корни слушателей, поверхность, сохранённый кадр и SDL; исходная видимость
курсора восстанавливается хостом. Аудиоустройство не нужно. Без окна/устройства:

```sh
SDL_VIDEODRIVER=dummy build/player/frontend/flashvm_player --interpreter \
  --mute --frames 3 --fps 1000 flashVM/examples/player/wheel_cursor/wheel-cursor.swf
```

Ограниченный запуск проверяет загрузку, не инжектирует ввод и не подтверждает
физическое устройство. Отдельные wheel movie tests посылают сообщения очереди SDL.
Обычная единица колеса даёт trace `3` вверх или `-3` вниз; точные устройства могут
давать дробь. Горизонталь игнорируется. На touch-устройстве курсора может не быть.
Пример не добавляет hit target, прокрутку текстовых полей, IME и полную модель Flash.

| Скриптовый API | Действие и владение |
| --- | --- |
| Mouse.addListener | Однократная регистрация; сильный корень слушателя принадлежит контексту. |
| onMouseWheel(delta) | Синхронный вызов с числовой дельтой в строках хоста; нативное событие не заимствуется после возврата. |
| Mouse.hide / Mouse.show | Меняют запрос контекста; SDL применяется основным потоком player. |
| trace | Выводит дельту через трассировку VM. |
| stop | Останавливает timeline, не завершает цикл ввода хоста. |

Генератор владеет байтами и зависит только от стандартной библиотеки Python.
Он прямо создаёт маленькую детерминированную фикстуру, не является AS-компилятором
и не меняет архитектуру FIR → SWO → линкер → SWF. Файл .as объясняет семантику;
числовой FIR-профиль пока не компилирует такой объектный скрипт. При потере фокуса
до отпускания синтетический release не создаётся: закройте окно или повторите
нажатие/отпускание. Cross-программу запускают на своей цели с её SDL video backend.
