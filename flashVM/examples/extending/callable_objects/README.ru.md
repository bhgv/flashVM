# Вызываемые объекты (C89)

Пример создаёт нативную вызываемую функцию, привязанную к одному контексту
интерпретатора, сохраняет её в обычном свойстве объекта, читает свойство и
вызывает функцию с двумя числовыми аргументами. Функция получает контекст и
стек аргументов в стиле Lua. Перед возвратом она очищает аргументы и помещает
в стек не более одного результата.

Сборка выполняется через CMake из корня проекта. Код `main.c` также проверяется
регрессионным тестом `flashvm_tests_callable`.

**Ограничения:** пока поддерживаются только C-функции. Интерпретатор AVM1 ещё
не вызывает такие значения напрямую. Регистрация принадлежит контексту;
время жизни `userdata` контролирует приложение. Одновременное обращение к
одному контексту из нескольких потоков не поддерживается.
