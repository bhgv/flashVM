# Linker development rules

- Implement the future linker in C99, with an independent build and documented
  input/output formats. No implicit sibling source dependencies.
- Keep source readable and commented, docs in Russian and English, with source
  links for described functions/types. Do not present the current empty project
  configuration as a working linker.
- Preserve the shared root MIT LICENSE in detached distributions.
- Author and committer: bhgv <bhgv@bhgv.bhgv>. Commit on master and use the full
  GitHub URL https://github.com/bhgv/flashVM.git for authorized publication.
