# Импорт прямоугольника SVG

[English](SVG.md) · [Ресурсы](ASSETS.ru.md)

`swl link OUTPUT.swf --svg NAME FILE` добавляет прямоугольник из `FILE` под
экспортируемым именем `NAME`. Чтобы разместить его на сцене, добавьте
`--place NAME X Y DEPTH` после ресурса. В тот же SWF можно включить код из
SWO или SWA.

```sh
swl link panel.swf --svg panel linker/examples/panel.svg --place panel 20 30 1
```

Линкер принимает SVG размером до 8 КиБ. Документ содержит один элемент
`<rect>` внутри `<svg>` с пространством имён `http://www.w3.org/2000/svg`.
Оба элемента задают одинаковую ширину и высоту целыми числами от 1 до 3276
пикселей. Суффикс `px` необязателен. Координаты `x` и `y` можно опустить
или задать нулём. Цвет по умолчанию чёрный. Атрибут `fill` принимает
`#RGB` и `#RRGGBB`. Необязательный `fill-opacity` задаёт число от 0 до 1
с точностью до шести знаков после точки. Линкер округляет его до байта альфа-канала.
Поддерживаются BOM UTF-8, объявление XML 1.0 с необязательным
`encoding="UTF-8"` и комментарии XML. Остальные элементы, атрибуты,
ссылки на сущности и объявления отклоняются.

## C API

```c
#include "swl.h"

int swl_add_svg(SwlContext *context, const char *name, const void *data,
                size_t size, char *error, size_t capacity);
```

`context` принадлежит вызывающему коду. `name` задаёт новое имя ресурса.
`data` и `size` передают заимствованные байты XML. `error` и `capacity`
задают необязательный буфер диагностики, допустима пара `NULL` и ноль.
Синхронный вызов возвращает 1 после добавления `DefineShape3` и 0 при
ошибке. Ошибка сохраняет ранее добавленные ресурсы. Входные байты можно
освободить после возврата. Вызовы, меняющие один контекст, нужно выполнять
последовательно. [Объявление](include/swl.h) · [Реализация](src/svg_rect.c).
