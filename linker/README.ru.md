# Линкер SWL 0.3.11

Рабочий независимый C99-компонент. FIR компилируется в `.swo`, SWL связывает
объекты и библиотеки `.swa` в SWF8. Компилятор больше не создаёт SWF.
Инициализаторы выполняются по порядку входов и членов библиотеки. Имена модулей
должны быть уникальны; их локальные SSA-хранилища имеют префикс модуля.
Библиотеки включаются целиком: поиска по путям и ленивого разрешения функций нет.
Межмодульные вызовы FIR, imports/exports функций пока отсутствуют.

```sh
cmake -S linker -B build/linker
cmake --build build/linker
ctest --test-dir build/linker --output-on-failure
build/fir1/fir1 object input.fir input.swo
build/linker/swl archive library.swa first.swo second.swo
build/linker/swl link movie.swf library.swa third.swo
build/linker/swl --help
```

API: [include/swl.h](include/swl.h). `swl_create`/`swl_destroy` управляют контекстом;
`swl_add_object`/`swl_add_archive` копируют и проверяют вход, `swl_emit` вызывает
переданный callback вывода после полной сборки. `swl_archive` создаёт библиотеку.
Библиотека не печатает сообщения, не открывает пути и не завершает процесс.
Неудачное добавление откатывается; контекст можно использовать дальше.
Разные контексты независимы, один контекст нельзя менять одновременно.
По умолчанию отвергаются требования FlashVM; разрешить их можно через
`SwlOptions.allow_flashvm_extensions` или `--extensions`.

[Форматы](FORMAT.ru.md). Стандарт C99; нет зависимостей от FIR, Coco/R или VM.
Для отделённой копии сохраните корневую MIT LICENSE. Коды CLI: 0 успех,
1 ошибка входа/связывания/записи, 2 неверные аргументы. Входы и выход ограничены
64 MiB, максимум 1024 объекта. Ошибки валидации не перезаписывают выходной файл;
ошибка самой записи может оставить частичный файл.

[Ресурсы, SVF1 и сцена](ASSETS.ru.md).

[Проверка и ограничения](TESTING.ru.md).

Исходники C99 оформлены с отступом 4 пробела, раскрытыми блоками и явными
секциями обработки ошибок. Локальная [.clang-format](.clang-format) сохраняется
при отделении проекта. Генерируемый Coco/R и внешние библиотеки не форматируются.

[Сборка для своей и другой ОС/CPU](../BUILDING.ru.md).

[Проверка объектов и библиотек](INSPECTION.ru.md).

Параметры сцены доступны и в консоли:

```sh
build/linker/swl link movie.swf --size 640 480 --fps 30 library.swa
build/linker/swl inspect library.swa
```

Размер каждой оси — 1..3276 пикселей; частота — целое число 1..255 кадров/с.
По умолчанию 550×400 и 12 кадров/с. Опции допустимы до и после входов;
при повторении параметра сцены действует последнее значение. Неверное или
пропущенное значение возвращает код 2 до открытия файлов. Операнды ресурсов
не интерпретируются как опции: файл с именем `--extensions` не разрешает
расширения FlashVM. Для C API по-прежнему используется `SwlOptions`.
