# Линковщик SWF

Версия 0.1.0. [English](README.md).

Место для независимого проекта на C99. Реализация линковщика, объектный формат
и публичный API пока отсутствуют. `cmake -S . -B build` проверяет конфигурацию;
`cmake --build build` пока не содержит целей из исходников и не создаёт SWF.
Будущий линковщик получает результаты компиляторов через явные форматы,
без зависимости от исходников VM и относительных путей к соседним проектам.
При отделении сохранять общую лицензию MIT и уведомления сторонних компонентов.
