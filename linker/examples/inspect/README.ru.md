# Просмотр из C-программы

Исполняемый учебный пример проверяет SWO1/SWA1 и выводит модули без запуска
внешних процессов и без генерации SWF. Подходит для просмотра входов в IDE.
Нужен только публичный C99 API SWL, без внутренних структур FIR и компиляторов.
[Исходник](main.c), [контракт API и сроков жизни](../../INSPECTION.ru.md).

```sh
cmake -S linker/examples/inspect -B build/inspect -DSWL_ROOT="$PWD/linker"
cmake --build build/inspect
build/inspect/inspect_example library.swa
```

Для cross SDK добавьте параметры toolchain/системы/CPU/компилятора из
[руководства сборки](../../../BUILDING.ru.md). SWL_ROOT — доступные на хосте
исходники SWL. Результат запускают только на целевой ОС/CPU. Пример и SDK можно
переносить и переименовывать независимо благодаря явному SWL_ROOT.

| API | Назначение и владение |
| --- | --- |
| `swl_inspect` | Синхронная полная проверка и посещение. Заимствует неизменный вход до возврата; 0 при ошибке формата, памяти или обработчика. Не работает с файлами и консолью. |
| `SwlModuleVisitor` | Обработчик хоста; 0 отменяет обход. Метаданные и имя действуют только внутри вызова. Пример сохраняет счётчик, не указатели. |
| `SwlModuleInfo` | Имя, размер кода и требования расширений. Сообщение требований не разрешает выполнение. |

Для модуля alpha с единственным ActionEnd ожидается:

```text
alpha: 1 code bytes; requirements=0
modules: 1
```

Каждая непустая строка исходника объясняет владение, вывод или освобождение.
Хост читает обычный файл размером 1..64 МиБ, закрывает его, проверяет и
освобождает буфер. Изменение длины обнаруживается, но атомарный снимок при
параллельной перезаписи той же длины не гарантирован. Вход должен быть стабилен.
Код 0 — весь вывод выполнен; 1 — ошибка чтения, формата, памяти или вывода;
2 — использование. Ошибка предварительной проверки не выводит модули.
Ошибка обработчика/вывода может оставить часть текста. Баланс стека AVM1 и
завершение программы не проверяются.
