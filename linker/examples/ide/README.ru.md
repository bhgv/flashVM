# Пример встраивания в IDE

[main.c](main.c) связывает компиляторы, оптимайзер и линкер в одном C-процессе.
Компилирует AS2 и Limbo с разными именами модулей; получает снимки FIR до/после
оптимизации; создаёт `.swo`, упаковывает их в `.swa`, добавляет фигуру и пишет SWF.
При заданном FRONTENDS_ROOT в тот же процесс включены четыре широких синтаксических
фронтенда. Дочерние процессы и команды оболочки в коде примера не используются.

```sh
cmake -S linker/examples/ide -B build/ide \
  -DFIR_ROOT="$PWD/fir/v1" -DSWL_ROOT="$PWD/linker" \
  -DFRONTENDS_ROOT="$PWD/compiler" \
  -DCOCOR_ROOT="$COCO_DIR" -DCOCOR_EXECUTABLE="$COCO_DIR/sources/cocor"
cmake --build build/ide --target ide_pipeline
build/ide/ide_pipeline build/ide/movie.swf
```

SWF выводит 42, затем 36; зелёная фигура размещается в (20,30), depth=1.
Это пример управления, не готовая IDE. Возвращаемый указатель на модуль snapshot
заимствован на время callback. Подкомпоненты задаются явными путями и могут
быть отделены/переименованы; нужен внешний Coco/R и корневая MIT LICENSE.

## Владение, ошибки и API по шагам

[main.c](main.c) теперь разделяет подготовку, преобразование и очистку. Memory
владеет malloc-буфером; capture копирует единственный вызов writer до возврата;
publish проверяет fwrite и fclose. compile владеет тремя временными потоками и
передаёт готовый SWO вызывающему только после полного чтения. snapshot не сохраняет
указатель на заимствованный FirModule. Каждая ошибка идёт к общей очистке;
swl_destroy(NULL) допустим. Выходной файл при ошибке записи может быть частичным.

| API | Назначение и владение |
| --- | --- |
| fir_temporary / fir_source | Потоки принадлежат compile; числовой исходник преобразуется в FIR |
| fir_run(FIR_OBJECT) | Проверка/оптимизация по options, снимки before/after, выдача SWO |
| swl_archive | Заимствует входные объекты на время вызова; capture делает собственную копию |
| swl_create / swl_add_archive | Контекст линкера владеет копиями принятых членов |
| swl_add_rect / swl_place | Создаёт зелёную фигуру и ставит её на сцену |
| swl_emit | Заимствует writer/userdata на время полной публикации SWF |
| swl_destroy | Освобождает контекст; независимые буферы first/second/library очищаются отдельно |

Точные объявления: [fir.h](../../../fir/v1/include/fir.h),
[swl.h](../../include/swl.h). Парсеры не reentrant; сериализуйте вызовы одного
языка. Пример не требует консоли внутри API и не запускает подпроцессов.
Код 0 — успешная запись SWF, 1 — ошибка этапа/I/O, 2 — неверные CLI-аргументы.
Тест требует четыре снимка и успешную публикацию; VM отдельно подтверждает 42/36.
[Нативная/cross сборка](../../../BUILDING.ru.md) описывает смену ОС/CPU; передавайте
тот же toolchain при сборке всех библиотек, не смешивайте host и target архивы.
