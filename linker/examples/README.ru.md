# Каталог примеров SWL

Все примеры используют публичный API или документированную консоль. Не нужны
неявные подключения реализации соседних проектов. [Руководство](../README.ru.md),
[обычная и cross-сборка](../../BUILDING.ru.md).

| Пример | Назначение и требования |
| --- | --- |
| [Тракт IDE](ide/README.ru.md) | Явные SDK четырёх парсеров, FIR и SWL для C-программы; путь исходник/FIR/SWO/библиотека/фильм в памяти, владение и запись через callback. Только числовой профиль. |
| [Просмотр](inspect/README.ru.md) | Автономный C99-хост, только SDK SWL; проверка SWO/SWA до выдачи упорядоченных метаданных. Подробно описаны сроки жизни входа и данных обработчика. |

Ресурсы [panel.svf](panel.svf), [tile.jpg](tile.jpg), [tone.wav](tone.wav) служат
[инструкциям ресурсов](../ASSETS.md) и тестам: залитый прямоугольник, JPEG 8×8 и
PCM WAV. Это ресурсы, не компиляторы исходников и не полная поддержка SVG/MPEG.
Команды импорта, размещения и проигрывания приведены в указанном руководстве.
