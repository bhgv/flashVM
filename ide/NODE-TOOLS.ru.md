# Панель узлов и графический буфер

IDE0.7.15 / серия v0.1731. [English](NODE-TOOLS.md).
Включите **Nodes** слева. Над страницей появляются девять кнопок. Иконки —
собственные небольшие векторные схемы знакомых операций, не файлы CorelDRAW.

| Слева направо | Действие |
| --- | --- |
| Добавить | Делит следующий явный сегмент выбранного узла пополам; для Безье применяется de Casteljau. |
| Удалить | Удаляет выбранные опорные узлы. |
| Разорвать | Создаёт независимые конечные точки. Замкнутый контур разворачивается от разрыва и открывается без повторной аппроксимации сегментов. |
| Объединить | Сваривает соседние узлы/концы в средней точке либо замыкает один открытый контур, сводя начало и конец. Неподходящие несоседние внутренние узлы отклоняются. |
| Прямая | Делает участок между двумя соседними выделенными узлами прямым. |
| Безье | Делает его кубическим. Для прямой контролы коллинеарны; преобразование Q→C сохраняет форму с округлением до логических координат. |
| Острый | Хэндлы независимы. |
| Плавный | Хэндлы лежат на одной прямой в противоположных направлениях; длины могут различаться. |
| Симметричный | Направления противоположны, длины равны и изменяются совместно. |

Выделение: щелчок, Ctrl+щелчок, рамка. Команды работают с опорными узлами;
некорректное выделение не изменяет документ. Каждая принятая команда — одна
операция Undo. Режимы хэндлов входят в неизменяемые фигуры и сохраняются в SVG
необязательным атрибутом `data-flashvm-joins`. Обычные программы могут игнорировать
эти настройки редактора; сами кубические кривые — стандартный SVG. Координаты и
отражённые хэндлы должны оставаться внутри логической страницы1000×600.

**Delete и Backspace** удаляют выбранные опорные точки и группы. Без выделенных
точек/хэндлов удаляется вся выбранная фигура/составной контур. Выделение только
хэндла не превращается в удаление фигуры. Если удаляются все пригодные узлы,
удаляется фигура. Кнопка удаления на верхней панели — именно команда узлов.

**Ctrl+C/X/V** и прежняя палитра Edit работают с графикой через сессионный буфер
IDE. Копируется вся выбранная фигура в самодостаточный SVG. Cut удаляет её после
подтверждения записи в буфер. Paste сначала проверяет SVG; выбранная фигура
заменяется на прежнем месте в порядке наложения, без выделения данные добавляются
и выбираются. Ошибка не меняет исходную геометрию. Сохраняется лимит64KiB UTF-8
и проверка актуальности revision/выделения. Это сессионный буфер, не системный
clipboard и не множественное выделение независимых объектов.

## Отзывчивость

Для выбранного контура заранее публикуется локальный план. Захват видимой точки
или хэндла обычным щелчком начинает движение до ответа Dis на Begin. Сам Begin
и отпускание остаются у владельца документа для истории. Ctrl и неподготовленные
попадания проходят обычное согласование. Подтверждение не откатывает текущую
позицию. Даже щелчок без движения завершает захват. Незавершённые снимки сцены
не используются для попаданий мыши.

После допуска локально работают также перенос фигуры, масштабирование за угол,
вращение и рамка выбора узлов. Промежуточные движения не отправляются в Dis;
итог документа/выделения передаётся при отпускании. Отрисовка запрашивается вне
кадров SWF, растеризация остаётся в настоящих фоновых потоках. При предельной
ёмкости, когда не помещается оверлей, сохраняется безопасный прежний маршрут.
Это ещё не полный перенос всех действий IDE в asinc.

В C передаются связи точек и параметры маркеров: он восстанавливает декорации,
а Limbo не пересылает заново координаты каждого квадратика. При неизменившемся
выделении переиспользуется оверлей, обновляется только небольшой заголовок.
Форматы SWF/Dis64 не менялись. Частные флаги рабочего стола0x80000/0x100000/
0x200000 обозначают подготовленный, компактный и расширенный планы. Нужны
одновременно пересобранные исполняемый файл и Dis-модули.

Замер `dis/examples/vector/pick-benchmark.b`, x64/JIT,20 начал для256 квадратичных
сегментов: до оптимизаций123мс на выбор /26002мс на представление; после129мс /
374мс. Размер ASCII-снимка172632→39232 байт. Это суммарное время модели на нашем
host, без UI/передачи; не обещание таких задержек на физическом телефоне.

SDL-проверка делает600 движений узлов и по100 движений масштаба/рамки без
промежуточных запросов в Dis; проверяется движение до ответа на Begin. Проверки
модели/владельца выполняют настоящие операции и Undo в interpreter/JIT; отдельные
C-проверки — координаты, отражения, границы и откат. SVG/pixel replay сохраняет
полный маршрут через каналы как независимую проверку.

**Потоки:** подготовка up/REG/TLS сохранена. Текущий графический host всё ещё
поочерёдно вызывает Dis-планировщик и FlashVM из одного OS-потока. Отдельные
потоки растеризации настоящие. Полноценные многопоточные scheduler/GC/channels
DisVM и lowering asinc с синхронизацией захватов ещё не закончены.
