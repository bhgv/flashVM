# Рабочий стол: жесты и оформление

[English](DESKTOP-WORKSPACE.md) · [Стол](DESKTOP.ru.md) · [Запуск](ENTRYPOINTS.md) · [Сессионный буфер](DESKTOP-CLIPBOARD.ru.md)

![Actual MovieClip workspace / Рабочий стол](assets/desktop-v0.1677.png)

Запуск: **8** в build-menu, `--launch desktop` или `run-desktop-ide.sh`.
Владельцы документов и политика интерфейса работают отдельными процессами Limbo;
FlashVM владеет настоящими MovieClip/TextField. Python нужен для проверок разработки.

| Действие | Результат |
| --- | --- |
| Драг шапки | Перемещение окна |
| Драг пустого места центрального стола | Вертикальная прокрутка стола |
| Драг двумя контактами за тело окна | Перемещение окна без редактирования текста |
| Драг тремя контактами поверх окна | Прокрутка стола без редактирования текста |
| Двойной тап/щелчок по шапке или Max/N справа | Развернуть на видимую область стола / вернуть нормальную геометрию |
| Сдвиг окна к левой границе | Спрятать в живую миниатюру с сохранением положения до драга |
| Тап миниатюры или свайп её вправо | Открыть окно и прокрутить стол к нему |
| All справа | Показать все открытые окна, включая спрятанные, общим масштабом без перестановки |
| Ctrl+колесо или щипок на столе/теле окна | Общий масштаб родительского MovieClip без изменения координат модели |
| Ctrl+колесо над неперекрытой шапкой | Размеры окна от 50 до 180% базовой сетки, шаг 10 процентных пунктов |
| Щипок двумя контактами, хотя бы один на шапке | То же ограниченное изменение размеров |
| Драг миниатюры слева вверх/вниз | Изменение порядка миниатюр, без смены каналов и владельцев документов |
| Правая кнопка Help | Скрытие/возврат существующего окна справки без остановки его процесса |

Проверка шапки учитывает координаты стола и текущую прокрутку. Перекрытый заголовок
не меняет размеры окна за свитком. Меняются размеры окна, а не исходный текст или
размер шрифта. Активное окно выделено синей рамкой; содержимое остаётся светлым.
У окон и виджетов округлённые контуры, у окна есть отдельная заметная шапка.
Название редактора красное, сохраняет имя файла и `*` несохранённых изменений.
Номера логических строк вычисляет владелец полного исходника; перенос длинной строки
не создаёт фиктивного номера. Правые кнопки уменьшены с 88×54 до 44×27 пикселей.

При движении окно имеет непрозрачность 90%. Для неизменившегося окна используется
последний полный растровый снимок; текст и глифы во время такого перемещения заново
не рисуются. Ключ включает текст, размеры, выделение, каретку и начало нумерации.
При несовпадении выполняется обычная рисовка. Частично обрезанное окно не записывается
как полный снимок. Лимит кеша — 4 МиБ на окно; при закрытии он освобождается.
После отпускания выполняется обычная полная сцена. Отдельно кешируются контуры
глифов. Движение геометрии не опрашивает повторно все процессы документов.

SDL хранит идентификаторы контактов только у владельца ввода. Через каналы идут
значения количества контактов, фазы и координат. Потеря фокуса сбрасывает контакты.
Проверки воспроизведения проходят через настоящие Dis и MovieClip; это не проверка
физического сенсорного экрана. Удобство жестов и задержку кадров следует измерять
на целевом устройстве. Сессионный Copy/Cut/Paste не является системным буфером ОС.

Max/Norm сохраняет нормальные смещения и размеры отдельно от развёрнутого режима.
При изменении геометрии приложения пересчитываются развёрнутые окна. Общий масштаб
стола — 10–180%; All вычисляет его по полным границам окон. Глифы, выделение и hit
используют одно преобразование родительского MovieClip. Скрытое окно остаётся
источником миниатюры, но не передаётся в растеризатор стола. Двойной тап считается
по времени события SDL, а не по задержке обработки кадра. Нативная проверка
переходов контактов дополняет реальные Dis/MovieClip-проверки воспроизведения.

Перед кадром SDL объединяет до 256 подряд идущих абсолютных движений одного
указателя/контакта. Клавиша, отпускание кнопки, смена фокуса или другой контакт
останавливают объединение. Проверка настоящей очереди SDL подтверждает сохранение
порядка отпускания. Финальные координаты окна учитывают само событие отпускания.
