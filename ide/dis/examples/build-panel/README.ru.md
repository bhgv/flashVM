# Пример сборки существующего документа

`main.b` исполняется нашим интерпретатором/JIT Dis и компилирует числовое
подмножество Limbo через Idebuildpanel. Строки подробно объясняют обязанности
клиента: открыть документ редактора, получить ревизию, создать частные сервисы,
запросить оптимизированный Dis, проверить допуск и стадию компиляции, получить
копии бинарника/debug, завершить панель и отдельно принадлежащий клиенту документ.
Файлы не создаются, результат не загружается и не исполняется.

Запуск: `disvm --jit build-panel.dis` либо `disvm --no-jit build-panel.dis` с
совместимой установленной коллекцией модулей и `Fircompiler=ON`. Успех печатает
`PASS build panel tutorial: revision=ok binary=ok debug=ok owners=closed`.
При отсутствии библиотеки документ завершается перед сообщением об ошибке.

Для другого формата явно замените target на Fircompiler->Fir или
Fircompiler->Swf. Для AS1/AS2/AS3 меняйте одновременно исходник и language.
Реализованы подмножества языков. Формат указан в метаданных артефакта; переименование
файла не меняет контейнер. После правки собирайте новую ревизию. Diagnostic
возвращает только актуальный символьный диапазон Idecore.Utf8Span, а старая ревизия
не может получить бинарник.

Контракт, ограничения конкурентности/владения и графические F7/F8 описаны в
BUILD-PANEL.md каталога ide либо установленного SDK.
