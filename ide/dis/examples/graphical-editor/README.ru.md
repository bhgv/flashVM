Контроллер исполняется как настоящий NC64 Dis-байткод на нашем интерпретаторе/JIT.
Документ и история принадлежат отдельному процессу Idecore, курсор/навигация —
Ideinput, видимое Unicode-окно — Ideviewport. Idefileops и Idesearch дают вызываемые
файловые операции и действия документа без зависимости от renderer. Поля, пути,
dirty-защита и масштаб управляются на Limbo. Python/Node, Draw/Tk и внешний emu
для исполнения не нужны. AS-workers пока не запускаются этим target.

## Сборка и запуск

```sh
./build-workspace.sh --projects disvm-editor --jobs 4
sh out/disvm-editor/run-graphical-editor.sh --new example.b
sh out/disvm-editor/run-graphical-editor.sh --document existing.b
```

Компонент меню — `disvm-editor`, запуск после сборки — **8**. Свободный Noto Sans
Mono/OFL включён в пакет; размер по умолчанию **11 пикселей**, вопроса о пути к
шрифту нет. `--font`/`FVM_EDITOR_FONT` остаются необязательной заменой. Шрифт,
лицензия и происхождение находятся в `fonts/`. Модули и шрифт ищутся рядом с
входным Dis, пользовательские пути — относительно cwd. Перенос пакета не требует
исходников, сети или системного поиска шрифтов.

Прямой CMake: `DVM_RUNTIME_EDITOR=ON`, для окна `DVM_EDITOR_SDL=ON` и `SDL2_DIR`.
Консольный runtime сохраняет сборку без графического SDK. Без SDL графический
вариант поддерживает воспроизведение и настоящую внеэкранную растеризацию.
`--jit`/`--no-jit` выбирают реальный режим Dis; `.dis/.sbl` собираются из исходников.
Подробные команды CMake приведены в английском руководстве.

## Управление

| Действие | Результат на Dis |
| --- | --- |
| Текст/IME, Enter, Tab | Unicode-вставка по каналу документа. |
| Стрелки, Home/End, Shift | Навигация/выделение; вертикальная колонка сохраняется через короткие строки. |
| PageUp/PageDown, Ctrl+Home/End | Текущее число видимых LF-строк либо граница документа. |
| Мышь, Shift+click, drag | Предложение реальной glyph-позиции, проверяемое по ревизии/ticket. |
| Колесо | Прокрутка строк без изменения текста и курсора. |
| Ctrl+колесо, двухпальцевый щипок | Размер 6..48, стартовый 11; число строк пересчитывается по настоящей метрике. |
| Backspace/Delete, Ctrl+A | Удаление диапазона либо выделение исходника. |
| Ctrl+Z, Ctrl+Shift+Z, Ctrl+Y | Undo/Redo настоящего владельца истории. |
| Ctrl+F, F3 | Точный поиск через поле и повтор с одним переходом к началу. |
| Ctrl+H | Отдельные поля иглы и замены; ReplaceAll отменяется одним Undo. |
| Ctrl+O | Открытие проверенного UTF-8 файла после dirty-проверки. |
| Ctrl+S, Ctrl+Shift+S | Сохранение либо Save As с принятием пути только после успеха. |
| Ctrl+A, Backspace, Enter, Escape в поле | Выделение/редактирование/принятие/отмена без вставки в документ. |
| Закрытие / Shift+закрытие | Отказ при dirty / явное отбрасывание правок. |

Заголовок показывает текущую/сохранённую ревизии, статус и верхнюю LF-строку.
Статусы: 0 успех, 1 конфликт, 2 диапазон, 3 размер, 4 invalid/I/O, 8 не найдено.
Начальный/Open ввод ограничен 64 KiB, неправильный UTF-8 отвергается до закрытия
старого документа. Библиотечный API Idefileops ограничен 4 MiB. `--new ПУТЬ`
выбирает назначение, но не создаёт файл до Save; буфер без пути использует Save As.
Это проверенная перезапись, не атомарная замена: при I/O-ошибке возможен частичный
выходной файл, гарантии при потере питания нет.

## Владение, проверки и границы

Панель, размер и границы окна приходят значениями по каналам до снимка; финальное
выделение завершает представление. Ticket меняется даже при прокрутке/масштабе без
правок, устаревшая геометрия отвергается. Видимый интервал ограничен 4096 UTF-8
байт без разрезания символа; весь исходник хранится и сохраняется в Dis. Каретка
может раскрыть хвост длинной строки. Нативные указатели между кучами не передаются;
каналы удерживает стек Limbo до Shutdown/detach, GC двух VM не смешиваются.

Регрессии `test_graphical_editor.py`, `test_graphical_actions.py` и
`test_graphical_zoom.py` в `disVM/runtime/` исполняют настоящие модули, каналы/GC,
FlashVM layout/raster и файлы. `--events ФАЙЛ` читает ограниченные кадры длина +
`fvd1:`; EOF без подтверждённого Quit — ошибка. `--capture ФАЙЛ.ppm` сохраняет
реальные пиксели. `--window-events` дополнительно проверяет SDL upload; dummy
не заменяет физическое устройство. Проверки масштаба запускаются со встроенным
Noto и сравнивают настоящие растры.

Текущая приёмка — Linux AMD64 NC64, один нативный владелец. SDL-щипок не привязан
к Android и рассчитан также на сенсорные Windows/macOS/Linux-фронтенды; физические
устройства и полные порты runtime этих ОС проверяются отдельно. Окно 960×640,
навигация по LF, не мягким переносам. Полная bidi/grapheme-семантика, resize,
цветная подсветка, popup, AS-workers, команды компилятора и отладчика ещё открыты.
Покрытие Noto конечно; отсутствующий глиф не меняет исходные Unicode-байты.
Синхронный I/O может блокировать единственного владельца.
