# Пример входа в MovieClip-стол

main.b — полностью прокомментированный типизированный launcher настоящего
приложения desktop-ide.dis. Модуль удерживается до подтверждённого завершения
окон и layout-процесса. Внешних emu, Python, CLI-компиляторов и HTML UI нет.

Запуск из совместимого графического SDK:
`./disvm-editor --jit --document example.b desktop-example.dis` либо
`./run-desktop-ide.sh --new another.b`. Для физического окна нужен SDL-enabled
host. Headless-приёмка использует --events/--capture и настоящий MovieClip renderer.

Стартуют два независимых редактора, build-консоль и Help. Клик фокусирует окно,
живые миниатюры слева переводят к нему, drag пустого места двигает стол, инструменты
справа разворачивают свитки. F1 — Help, Ctrl+N — новый редактор, Ctrl+O — Open,
Ctrl+S — Save, F7 — настоящая сборка, F8 — исходная диагностика. Полный
[контракт](../../../DESKTOP.ru.md) объясняет каналы, владение и ограничения.

Первый вариант использует клавиатурное редактирование и ограниченное окно текста
около каретки. Полные mouse selection/clipboard, графические документы и debug
сессии ещё интегрируются. Debug честно сообщает об отсутствии сессии. Save пишет
только явный путь текущего редактора; Open защищает dirty, Quit требует явного
discard. Простой запуск примера не создаёт исходник и не исполняет артефакты сборки.

Заголовок перемещает окно; `x`/Ctrl+W закрывает только редактор. Dirty требует
явного discard, Cancel/Escape оставляет окно. Пустое место по-прежнему двигает стол.
