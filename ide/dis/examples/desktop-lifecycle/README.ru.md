# Пример завершения независимого владельца

[main.b](main.b) полностью комментирует последовательность: создать два настоящих
процесса окна, изменить один через канал ввода, проверить неизменность другого,
опубликовать значения layout, получить терминальный ответ Shutdown, убрать
представление и создать нового владельца. Используются собственные строки;
файлы не читаются, не записываются и не компилируются.

Запуск: `./disvm --jit desktop-lifecycle.dis`, затем повторить с `--no-jit`.
Совместимый runtime поставляет модуль и зависимости. Это переносимый клиент
сервисов, не графический макет: он не подключает FlashVM и не изображает диалог
подтверждения. Интерактивное dirty-close обрабатывает настоящее desktop-приложение.

Каждый helper ждёт единственное подтверждение. После Shutdown старый канал
терминален и больше не используется. Новый start создаёт новый документ Idecore;
его чистая начальная revision независима от второго документа и прежнего undo.
Layout Remove следует после завершения владельца и запрещает системные слоты 2/3.
Ошибки явно поднимаются, PASS выводится после подтверждённого завершения.
