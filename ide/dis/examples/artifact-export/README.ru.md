# Экспорт собранного документа в новые файлы

В main.b подробно прокомментирован весь цикл: создание документа редактора,
сборка конкретной ревизии через каналы, получение метаданных, запуск exporter,
явное создание example.dis/example.firdbg и подтверждённое завершение exporter,
panel и документа в порядке зависимостей. Внешних компиляторов и автозапуска нет.

Запускайте `disvm --jit artifact-export.dis` или `disvm --no-jit artifact-export.dis`
в отдельном доступном для записи каталоге с совместимыми модулями и Fircompiler=ON.
Пример создаёт два **новых** файла в рабочем каталоге. Существующие имена приводят
к ошибке без перезаписи; для повторения используйте новый каталог. Ошибка второго
файла не удаляет первый. Ошибка нативной записи может оставить частичный новый
файл. Исходник, история и отметка сохранения не изменяются.

Успех: `PASS artifact tutorial: binary/debug=new revision=ok owners=closed`.
example.dis — полноценный native-cell Dis с результатом 42 при отдельном запуске,
.firdbg — оригинальный FIRDBG1, не Inferno .sbl. Запуск результата — отдельное явное
действие клиента. При смене формата меняйте target и суффикс вместе и проверяйте
формат/ревизию ответа.
