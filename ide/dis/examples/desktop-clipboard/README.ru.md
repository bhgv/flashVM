# Пример владельца сессионного буфера

[main.b](main.b) комментирует весь порядок: два настоящих процесса окна, Unicode-
выделение, Export, подтверждённый Put, Cut с проверкой revision/диапазона, Paste в
независимый документ, отклонение stale generation/source и неизменность старого
значения после Clear. Все три владельца подтверждают терминальный Shutdown.

Запуск: `sh run-desktop-clipboard.sh --jit`, затем `--no-jit`. Это также пункт
build-menu **12** или `--launch clipboard`. Пример поставляется в графическом
и headless runtime; встроенный компилятор ему не нужен.

Меняются только собственные приватные строки. Файлы, системный clipboard и GUI
не читаются/не пишутся. Используются обычные каналы, не локальная подмена Idecore.
Диапазон считается в Unicode-символах, лимит переноса и Reply.bytes — в UTF-8 байтах.
π/😀 — два символа и шесть байт. Успешный Put предшествует Cut; отказ документа
после Put сохраняет копию в буфере и исходник без изменения.
