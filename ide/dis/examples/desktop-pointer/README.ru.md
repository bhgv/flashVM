# Переносимый пример владельца выделения

[main.b](main.b) комментирует каждую часть настоящего сеанса сервиса окна: создаёт
приватный документ `aπ😀z`, допускает begin/move/end при текущей revision, выделяет
два Unicode-символа, заменяет их через Ideinput и отвергает старую revision без
перемещения каретки. Завершение подтверждается терминальным Shutdown.

Запуск: `./disvm --jit desktop-pointer.dis`, затем `--no-jit`. Runtime поставляет
согласованные `.m`/`.dis`. Встроенный компилятор необязателен. Исходник существует
только в приватном документе примера; файлы не читаются/не пишутся, сборка не вызывается.

Это типизированный клиент сервисов, не GUI и не приближение ширины глифа. Он явно
передаёт предложения координат исходника. Настоящий графический стол дополнительно
проверяет геометрию FlashVM, ticket, layout identity и преобразование caption/
viewport. Этот пример не заменяет физические mouse/touch проверки.

Позиции считаются в Unicode-символах, не UTF-8 байтах. Выделение не добавляет undo
и не меняет revision. Замена — одно настоящее изменение владельца. Stale отменяет
продолжение и сохраняет исходник/выделение. После терминального ответа Shutdown
старый канал больше не используется.
