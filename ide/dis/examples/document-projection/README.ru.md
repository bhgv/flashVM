# Проекция настоящего документа IDE

[Контракт](../../LIVE-PROJECTIONS.ru.md) · [Сборка и подробности](README.md)

В подробно комментированном `main.b` создаётся настоящий владелец Idecore.
Адаптер держит только его канал: второго документа и доступа к внутреннему ADT нет.

Проверяются копия Unicode-текста, снимок метаданных, отказ устаревшему Undo,
явное разрешение выполнения, настоящий Undo у владельца истории, запись по
значению и кооперативная пауза адаптера. Для документа свыше квоты скалярной
копии текст отклоняется целиком, а длина и остальные метаданные доступны.

Освобождение адаптера не останавливает документ. Пример после этого выполняет
обычное редактирование, затем отдельно завершает владельца документа.

```sh
ctest --test-dir build/runtime -R application_docprojection --output-on-failure
```

Проверки работают в интерпретаторе и JIT и сверяют фактические счётчики.
Установленный пакет содержит исходник, интерфейсы и зависимые модули; пример
повторно компилируется после переноса пакета. Это реальные локальные Dis-процессы,
а не сетевой RPC и не общий отладчик переменных произвольной программы.

Типизированные функции readint/readtext возвращают (статус, типизированное значение, ревизия). Они явно запрашивают преобразование у владельца, отклоняют несовместимое значение и сохраняют ревизию для последующей записи. Пример также проверяет неизменность прежнего снимка после редактирования документа другим клиентом.
