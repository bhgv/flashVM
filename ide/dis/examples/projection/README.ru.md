# Проверка канальных проекций инспектора

[Контракт](../../PROJECTIONS.md) · [Сборка и подробное описание](README.md)

`main.b` подробно комментирует все операции. Два настоящих Dis-процесса владеют
независимыми объектами; отдельный процесс владеет строками инспектора. Обмен
производится типизированными запросами и ответами, без передачи указателей.

Проверяются чтение/запись, Unicode, явное разрешение вызова метода, результат
метода, отказ устаревшему поколению, чтение при кооперативной паузе, запрет записи
и выполнения при паузе, возобновление и освобождение владельцев. Модель отдельно
отклоняет старый и повторный ответ, защищается от смены выбранного объекта и
возвращает независимую копию строки для отрисовки.

После сборки `build/runtime` выполните:

```sh
ctest --test-dir build/runtime -R projection_inspector --output-on-failure
```

Проверка запускается в интерпретаторе и JIT; обёртка проверяет реальные счётчики
исполнения. Пример не использует сеть и не считается готовой графической панелью.
Для любого запроса необходимо получить ответ: брошенный rendezvous может
заблокировать обслуживающий процесс. После Release endpoint больше не используют.


Расширенная проверка включает `idevalue.m`: точную big-константу, tofloat/real,
типизированную запись по значению, независимые снимки таблицы и модель отрисовки.
Ссылка на метод сохраняет получателя; попытка выполнить её на другом объекте
отклоняется даже при совпадающем номере поколения. Полный контракт:
[типы, преобразования и границы поддержки](../../VALUES.ru.md).
