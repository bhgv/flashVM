# Графический браузер каталогов — v0.1653

[English](GRAPHICAL-BROWSER.md) · [Интерфейс модели](bridge/idebrowser.m) ·
[Реализация](bridge/idebrowser.b) · [Контроллер Dis](examples/graphical-editor/main.b) ·
[Владелец каталогов](DIRECTORIES.ru.md) · [Пример](examples/directory-browser/README.ru.md)

Браузер показывает до восьми записей одновременно: метки каталог/файл,
выделение строки и нажимаемую панель действий. Ctrl+B открывает путь, Enter
загружает порцию до 32 записей. При движении выделения окно из восьми строк
смещается автоматически. История документа от просмотра не меняется.

Контроллер и владелец файлов — **Limbo**. [AS-исходник](../as/editor-view.as)
компилируется [нашим AS2-компилятором и библиотекой](../../compiler/as2/view/README.ru.md)
через FIR → SWO → SWL → SWF и исполняется FlashVM при каждом завершённом представлении.
Он задаёт текст TextField и геометрию виджета. Нативный адаптер пока рисует
шрифты/диапазоны, даёт ограниченные метрики поверхности и отображает координаты
на готовые глифы. Перенос всего прежнего рендера редактора в AS **ещё не завершён**.
Нативного файлового диалога и GUI Inferno здесь нет.

| Клавиша в браузере | Действие |
| --- | --- |
| Нажатие строки | Выбрать запись, не открывая её и не меняя документ. |
| Кнопка Open | Войти в выбранный каталог либо открыть файл с проверкой несохранённого текста. |
| Backspace / кнопка Up | Родительский каталог. |
| Up / Down | Выбор внутри текущей порции, без перехода через границы. |
| Page Down / кнопка Next | Следующая порция; после EOF последняя остаётся доступной для выбора. |
| Enter | Вход в каталог либо выбор файла для загрузки. |
| B / Ctrl+B | Редактирование пути; прежний курсор сохраняется до успешного открытия. |
| R / кнопка Refresh | Повторный обход текущего пути с первой порции. |
| Escape / кнопка Close | Закрытие курсора и возврат к документу. |

Поле пути использует прежнюю политику Idefield: максимум 256 Unicode-скаляров.
Escape из поля возвращает к открытому браузеру либо к документу, если каталога нет.
Порядок файлов остаётся нативным. Истории предыдущих порций, сортировки,
раскрываемого дерева, перетаскивания, стандартных колонок с иконками и двойного
щелчка по таймеру пока нет. Это базовый графический список, не законченный файловый
менеджер. Выбор мышью и кнопка Open работают. Текст, вставка и Delete не поступают
в документ во время просмотра. Изменение размеров, масштаб и закрытие окна
используют прежние проверяемые каналы.

## Владение и проверки

`Idebrowser.create(files, sys)` создаёт эксклюзивный `ref State` контроллера и
одного владельца Idefiles. Состояние нельзя разделять с другим процессом или
нативным рендером. `open` сначала получает новый FD и первую порцию, затем
закрывает старый курсор. Неверный путь, обычный файл и ошибка первой порции
сохраняют прежний путь и выбор. `advance` принимает только целые порции;
ошибка удаляет курсор и массив, EOF оставляет последнюю страницу и освобождает FD.
`move` принимает только -1/+1 и ограничивает индекс.

`choose` входит в каталог либо возвращает PickFile с **полным** путём. Документ
эта функция не загружает. Контроллер проверяет несохранённые изменения, реально
читает и проверяет исходник, получает подтверждения Close/Open, и лишь затем
принимает новый путь сохранения. Ошибка или несохранённый текст оставляют
документ и браузер доступными. Успех начинает новую сессию документа и закрывает
курсор. Метаданные каталога не являются блокировкой файла: изменение/удаление
проверяется последующим настоящим чтением, а не доверяется старой записи.

Все штатные и принудительные пути закрытия приложения вызывают `shutdown` до
освобождения каналов нативного владельца. Повторное завершение не отправляет
сообщения мёртвому процессу. ID запросов не переполняется; последний зарезервирован
для завершения. Для открытия заранее оставляется место под запросы допуска,
первого чтения и закрытия: исчерпание ID не оставляет новый курсор без очистки.
Номер курсора по-прежнему локален для endpoint, это не сетевая аренда.

`summary` выдаёт скопированный экранированный UTF-8 текст меньше 1024 байтов.
Выбранное имя показывается раньше пути, чтобы длинный абсолютный путь его не
скрывал. Сокращается только представление; рабочий путь и имя не обрезаются.
Модель принимает до 4096 UTF-8 байтов пути через Idefiles; поле GUI — 256 скаляров,
вызываемый конверт — до 1024 байтов. Обычный путь соединяется через slash и
передаётся OS-порту без канонизации. Нативная проверка Windows/macOS/Android
ещё предстоит.

## Вызовы графического интерфейса

[Idehost](bridge/idehost.m) использует обычные Request-конверты Uibridge.
Для всех пяти операций flags — текущая ревизия документа, second — ticket
последнего завершённого представления. Старые значения возвращают Conflict
без выбора/загрузки. Некорректные параметры — Invalid. Ticket меняется после
каждого представления, даже если текст документа прежний.

| Код | Операция | first / text |
| --- | --- | --- |
| 65564 | Browse | 0 / путь каталога |
| 65565 | BrowseMove | -1 либо +1 / пусто |
| 65566 | BrowseNext | 0 / пусто |
| 65567 | BrowseChoose | 0 / пусто |
| 65568 | BrowseClose | 0 / пусто |

Начать вне браузера может только Browse. Рендер принимает Panel 9 для просмотра
и 10 для поля пути с обычной кареткой/выбором. Ему передаётся только ограниченная
копия текста, без массивов Sys.Dir, FD и callback с логикой. Решения принимает Dis.

Проверки обоих режимов выполняют реальные каналы, загрузку/сохранение Unicode-
файла, переход в подкаталог, обход 40 элементов, отказ старым ticket и сохранение
несохранённого документа. Сравниваются реальные пиксели. Пример дополнительно
проверяет границы выбора/текста, завершение и исчерпание ID с quantum 1/2048.
Отдельная сборка использует явные зависимости; компиляция классического образа
не означает его исполнение.

Нативный I/O пока блокирует единственного владельца VM. Replay проверен на Linux
AMD64, а не на всех физических окнах/сенсорах. Асинхронная отмена, /prog,
сетевое время жизни и полная самокомпиляция IDE остаются отдельной работой.
Legacy Limbo остаётся временным source-built bootstrap; наш Coco/R-компилятор
развивается отдельно.

## Мышь и происхождение команды

`summary` возвращает многострочную копию меньше 1024 байт UTF-8. Limbo вычисляет
скалярные границы выделения и назначение кнопок/строк. Нативная геометрия даёт
только позицию глифа. FieldPlace принимается с точными ревизией и билетом текущего
представления; устаревшее нажатие не выбирает и не открывает файл. Полное имя
используется для действия, сокращённый экранированный текст — только для показа.
