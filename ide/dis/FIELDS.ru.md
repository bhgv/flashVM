# Unicode-поля под управлением Dis

[English](FIELDS.md) · [Интерфейс](bridge/idefield.m) ·
[Реализация](bridge/idefield.b) · [Контроллер](examples/graphical-editor/main.b) ·
[Исполняемый пример](examples/graphical-editor/field-demo.b) · [Буфер обмена](CLIPBOARD.ru.md).

Find, Open, Save As, оба поля замены и Go To используют общую библиотеку
Idefield. Единственный Limbo-контроллер владеет текстом, курсором, якорем
выделения и поколением состояния. Правка поля не создаёт Replace документа,
записей Undo, новой сохранённой ревизии и не меняет путь файла. Enter передаёт
принятое значение соответствующей операции; Escape завершает сеанс поля.
Закрытие окна по-прежнему защищает несохранённый исходник даже внутри поля.

Позиции измеряются Unicode-скалярами, а не байтами UTF-8. Обратное выделение
допустимо. Работают Left/Right, Home/End, Shift, Ctrl+переход по словам, Ctrl+A,
Backspace/Delete и удаление слова с Ctrl. Границы слов общие с редактором
исходника. Ввод заменяет выделенный диапазон. Отдельного Undo полей пока нет.

Предел — 256 скаляров на полное значение. NUL, суррогаты, значения вне Unicode,
табуляция и жёсткие разделители строк CR/LF/VT/FF/NEL/LS/PS отвергаются до
изменения состояния. Ошибка сохраняет весь текст, оба конца выделения и
поколение. Исчерпание поколения возвращает Invalid без переполнения; операция
без фактического изменения поколение не увеличивает. Новый сеанс создаёт новое
состояние. Некорректное начальное значение пути оставляет пустое поле с ошибкой,
не обрезает и не меняет настоящий путь документа.

## Представление и мышь

Компонент runtime 0.7.0 требует совместного обновления хоста, контроллера,
Idefield, Ideinput и интерфейсов. Расширен словарь существующего канала;
форматы SWF и Dis не изменены.

| Код | Направление | Передаваемые значения |
| --- | --- | --- |
| 65560 PanelSelection | Dis View → native | flags=ревизия документа, first=курсор поля, second=якорь, пустой text |
| 65561 ClipboardFieldWrite | Dis View → native | ревизия/ticket и упорядоченный диапазон поля без подписи |
| 65562 FieldPlace | native Request → Dis | ревизия/ticket, first=скаляр либо -1 вне нижней панели, second=начало/движение/конец (1/2/3) |

Текст и выделение поля публикуются перед завершением представления документа.
Native рисует курсор и выделенные глифы по настоящей раскладке комплектного
шрифта; курсор исходника в это время скрыт. Горизонтальная прокрутка следует
курсору поля. Проверка мыши использует ту же завершённую раскладку, смещение
подписи и прокрутку. Dis отклоняет устаревшие ticket, неверные границы и
движение без принятого начала. Shift+клик сохраняет якорь. Потеря фокуса,
resize, zoom и смена режима прекращают перетаскивание.

Ctrl+C/X/V адресуют открытое поле. Copy копирует только выделенное значение;
Cut удаляет его лишь после успешного native-подтверждения. Paste собирает
полный неизменяемый буфер до проверки однострочности. К ревизии и ticket
добавлены захваченные режим и поколение поля; посторонний ввод отменяет
ожидающий перенос. Пустая вставка сохраняет выделение. В режиме исходника
сохраняется прежняя вставка одним Undo.

## Запуск и проверки

Соберите и установите `disvm-editor` скриптами workspace. Из каталога поставки:

```sh
./limbo-native -g -I include/limbo -o field-demo.dis examples/graphical-editor/field-demo.b
./disvm --jit field-demo.dis
./disvm --no-jit field-demo.dis
```

Ожидается `PASS field tutorial: ЯX / atomic single-line rejection`. Пример
подробно комментирует владение и ошибки, не открывает виджеты, документ или
системный буфер и не требует Python при исполнении.

`field_test.b` проверяет библиотеку на настоящем Dis. Графические тесты
проверяют пиксели, мышь, Unicode между полем и исходником, атомарный отказ
вставки, resize/zoom и Undo документа в обоих режимах исполнения. SDL dummy
проверяет clipboard API, но не физический рабочий стол и сенсорное устройство.
Редактирование графем, двунаправленное отображение курсора и IME preedit
остаются отдельными задачами; скалярные операции их не подменяют.
