# Выбор плотных контуров и кэш выделения

[English](VECTOR-PICKING.md) · [Стрелки объектов/узлов](VECTOR-EDITING.ru.md)

Прежний поиск шёл по фигурам сверху вниз, а каждую квадратичную кривую разбивал
на 32 отрезка для проверки расстояния до штриха и пересечений луча заливки.
Это делал Limbo-владелец даже для кривых далеко от указателя; плотный контур
мог надолго занять CPU до появления рамки.

Теперь попадание внутрь кистевой фигуры проверяется по её сохранённой маске
за O(1), если размер маски точно соответствует сетке. Без подходящей маски
используется геометрия. Границы с учётом управляющих точек кэшируются по
неизменяемой фигуре. Далёкие фигуры и выпуклые оболочки кривых отсекаются до
разбиения. Для оставшихся коротких кривых достаточно 8 отрезков, для длинных
сохранены 32. Допуск штриха и even/odd для отверстий сохранены. Отпускание без
сдвига возвращает исходный массив без обхода всех узлов.

Кэш `idevectorpresentation.b` повторно использует исходную геометрию и overlay
в неизменных Snapshot. Исходные байты готовятся один раз на геометрическую
версию, перестраивается только изменённое выделение. Инвалидация учитывает
указатель/маску/инструмент/выбранную фигуру, Undo и публикацию геометрии worker.
Пустая отмена не сбрасывает кэш. Передача остаётся через прежний отдельный
bulk sender; изменяемые кэши и Dis-указатели в растровые потоки не передаются.

Падение вызвал переход между подконтурами: открытая направляющая хэндлера
Move/Segment сменялась квадратом точки, а native-reader требовал между ними
Close. Теперь последний presentation-путь редакторских режимов допускает
такой корректный Move. Проверки исходных путей, координат, лимитов и переходов
после Close сохранены. Хэндлеры ограничены со всех четырёх сторон, включая
ручку вращения выше края холста. В SVG/Undo выделение не попадает.

Регрессия открывает контур из 256 квадратичных сегментов, выбирает объект,
переключает Nodes, щёлкает контур и сохраняет SVG. Старый установленный v0.1724
падает с wire65577; исправленный выполняет сценарий в JIT и интерпретаторе.
Также тест рисует заполненный овал и соединённый штрих кисти того же цвета,
выбирает объединение и включает Nodes. В файле остаётся одна исходная фигура.

`dis/examples/vector/pick-benchmark.b` — повторяемый замер 20 внутренних кликов
по 256 кривым без маски кисти. На одном и том же x64 JIT executable старая модель
заняла 6390 мс, новая — 112 мс. Инициализация, UI/передача и растеризация в интервал
не входят. Это один синтетический замер, не универсальный коэффициент и не
физический input-latency benchmark. Кэш Snapshot проверяется отдельно.

Нужна полная пересборка `disvm-editor`: изменился частный layout документа Limbo.
Общие IDs SWF/Dis64 и разрешения native-вызовов из файлов не меняются.
