# Отмена устаревшей векторизации

[English](VECTOR-CANCELLATION.md) · [Viewport](VECTOR-VIEWPORT.ru.md)

Допуск кисти — 1/100 размера всей составной фигуры отдельно по X/Y. Проверяются
исходные точки обведённой маски. Предварительное упрощение на0,75 точки убрано:
для маленьких фигур оно могло превышать новый допуск. До65536 исходных точек,
до4096 команд результата; при превышении бюджета сохраняется сырой след.
Овалы-примитивы остаются четырьмя кубическими Безье.

Получение штрихов и fitting разделены. ideinkacquire.b сохраняет каждый отпущенный
нативный буфер и историю. ideinkworker.b при новом задании помечает старый расчёт
отменённым, сбрасывает его ожидающий результат и запускает новый полный снимок.
Штрихи из отменённой обработки не теряются: новое задание включает весь ввод.
ideinkfit.b считает приватную копию. Старые процессы завершаются на контрольных
точках объединения, трассировки, подбора кривых и сериализации. Их ответы
принимаются для освобождения ресурсов, но не публикуются и не меняют сырой снимок.

idevectorcancel.b возвращает Cancelled с восстановлением исходного массива фигур.
Капсула отмены принадлежит одному заданию и не переиспользуется. Это кооперативная
отмена в отдельных процессах Dis, без привязки к кадрам, без обещания отдельного
OS-потока для каждой задачи или фиксированного времени отмены в миллисекундах.

Сохранение, Undo, Open и операции выбора дожидаются последнего результата.
Новый штрих кисти/пера по тому же пути ввода прежнего fitting не ждёт. При смешанном
portable/native-вводе сначала принимаются ожидающие нативные траектории, которых
ещё нет у владельца документа. Сам ввод не отменяется; токены preview освобождаются
только после публикации полной актуальной геометрии.

Проверки: отмена до/во время расчёта, три последовательных задания, публикация
только последнего, сохранность всех штрихов/Undo, реальные нативные Begin с токеном,
SVG и Undo/Redo. Независимый геометрический тест проверяет волнистый контур по
обеим осям; погрешность его собственной32-шаговой проверки учитывается отдельно.
Обратная проверка кривой дискретная, не непрерывное доказательство расстояния.
