# Исходники внешних зависимостей

Единая папка зависимостей — `external/`. Существующий mini_regex перенесён из
`extern/`; папки-переадресации удалены. Пути сборки и действующая документация
обновлены; исторические отчёты проверок оставлены без изменения.

| Зависимость | Версия | Подключение |
| --- | --- | --- |
| mini_regex | Существующий байтовый subset | Всегда |
| zlib | 1.3.1 | Ограниченная распаковка CWS |
| AGG | Ядро 2.4, зафиксированный коммит fork | Растеризация полигонов RGBA8 |
| Cairo | 1.16.0 | Альтернативный растеризатор, image/recording/user-font |
| Pixman | 0.38.4 | Скалярная зависимость Cairo |
| SQLite | 3.50.4 | Встроенный статический C-адаптер, включён по умолчанию |

Все исходники для выбранных профилей включены. Сетевых загрузок во время
конфигурации и подмены системными библиотеками нет. Сохранены лицензии upstream,
официальные URL архивов, SHA-256 и полные патчи локальных изменений.
`python3 scripts/check_vendor_sources.py` проверяет исходники по манифесту офлайн.

Сохранены строгие режимы C89/C++98; GCC/Clang используют pedantic-errors и ошибку
для неявных объявлений C-функций. Внутренние реализации библиотек всё ещё требуют
нативных 64-битных типов системы и поддерживаемых компилятором inline/visibility.
Это не обещание поддержки любого исторического ANSI-компилятора. Вместо upstream
C11-сборки Cairo 1.18.4 проверен выбранный профиль 1.16.0 с явными патчами
совместимости. Зафиксированные версии обеспечивают воспроизводимость; они не
объявляются новейшими и не прошли полный аудит upstream.

Профиль Cairo не включает GUI, GL, PNG, системные шрифты и PDF/PS/SVG. Ассемблер
и SIMD Pixman отключены. Динамическая загрузка расширений SQLite отключена.
Системные адаптеры FlashVM остаются в `ports/`; собственные платформенные реализации
сторонних библиотек — в `external/`. Массовое переформатирование upstream не
выполнялось. Выполнение на Windows/macOS/Android пока не проверено. См.
[ключи сборки](BUILD_DEFINITIONS.ru.md) и [проверки коммита](DEPENDENCY_CHECKPOINT.ru.md).
