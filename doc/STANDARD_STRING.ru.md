# Проверенный этап нативного String — v0.12

Стандартная библиотека теперь устанавливает метаданные конструктора и прототипа
String. Функция String(value) сохраняет возврат примитивной строки; new String
через `fvm_construct` или AVM1 NewObject создаёт обёртку. Без аргумента получается
пустая строка, явный undefined даёт «undefined». Внутреннее содержимое независимо
от изменяемых обычных свойств. Вход должен быть корректным UTF-8.

Добавлены valueOf, toString, charAt, charCodeAt, substring, slice, substr, indexOf,
lastIndexOf и concat. Статический нативный String.fromCharCode принимает несколько
чисел и преобразует их по модулю 65536. Getter length находится на каждом экземпляре
и прототипе; обычная запись не меняет вычисляемую длину. Полные атрибуты свойств
Flash и поведение перечисления ещё не реализованы.

## Индексы UTF-16

Длина, индексы и диапазоны считаются в кодовых единицах UTF-16, а не байтах или
скалярных символах Unicode. Символ вне BMP занимает две единицы; charCodeAt
возвращает любую половину суррогатной пары. Подстрока сохраняет пару при выборе
обеих единиц. Поиск возвращает позиции в тех же единицах. Числовые аргументы
используют существующий ToNumber, усечение дробной части и ограничение диапазоном.
Отрицательные начала slice/substr отсчитываются от конца; substring меняет
перепутанные границы местами. Пропущенный/undefined конец означает длину строки.
Пустой поисковый шаблон и выход за границы проверены.

API сверяется со [справочником AS2 String](https://open-flash.github.io/mirrors/as2-language-reference/String.html).
Используются индексы UTF-16; байтовые индексы старых плееров и преобразования
по версиям SWF остаются в работе.

**Ограничение представления:** C ABI хранит строки как UTF-8 скалярных символов
с завершающим NUL. Встроенный NUL и одиночный суррогат UTF-16 не представимы.
fromCharCode, создающий их, charAt на одной половине пары и диапазон, разрезающий
пару, возвращают FVM_UNSUPPORTED без замены или усечения. charCodeAt сообщает
эти кодовые единицы. Для полного String нужна строковая модель с явной длиной
и полным UTF-16.

valueOf/toString и length требуют объект String. Остальные методы могут
преобразовать обычного получателя через его нативные методы. Исключения
преобразования распространяются в AVM1. Скриптовые методы и вызовы методов
примитивных строк ещё не поддержаны. Ошибочный аргумент/получатель даёт код C API;
стандартные TypeError/RangeError остаются в работе.

## GC, передача и отказы памяти

Захваченный конструктор и прототипы отслеживаются GC. Строковое поле принадлежит
контексту; отдельный сбор строк пока не реализован. Удаление глобального String
не уничтожает зарегистрированный конструктор. Нативный instanceof распознаёт
класс. Очередь и файловый канал сохраняют содержимое, циклы, прототипы, методы
и getter длины. Независимые процессы записи/чтения восстанавливают String без
установки стандартной библиотеки получателя. Экземпляр соответствует собственному
импортированному классу, а не отдельно установленному классу.

Сериализатор добавляет виды 26/27 и методы с идентификаторами 501, 502, 510–519;
valueOf/toString используют общий идентификатор функции. Версия оболочки прежняя,
старые читатели новые виды отклоняют. Некорректный UTF-8 и встроенный NUL
отклоняются до восстановления. Контрольная сумма не является аутентификацией.
Импорт не регистрирует новый глобальный конструктор.

Инъекция отказов памяти проверяет атомарную установку, создание Error/Number/String,
методы String и чтение length. Мосты нативного вызова и чтения свойств теперь
перехватывают отказ памяти при поиске, getter и callback: FVM_OUT_OF_MEMORY
с undefined на выходе вместо выхода C++-исключения за C ABI.

Тесты: standard_string.c, standard_string_avm1.cpp, string_edges.c, string_wire.c,
error_allocation.cpp и дополненный error_transfer_process.c. Числа проверок
и ограничения санитайзеров описаны в STRING_CHECKPOINT.md. Пример .as описывает
API; исполняемые тесты формируют записи AVM1 напрямую.

Остаются split и Array, Unicode-преобразование регистра, полные Object/Function,
методы примитивных строк, семантика версий, полное строковое представление и
реальные запуски Windows/macOS/Android. Завершённость String или SWF 8 не заявляется.
