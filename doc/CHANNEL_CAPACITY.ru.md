# Ограниченная ёмкость каналов (C API)

`fvm_channel_set_capacity(channel, count)` задаёт максимальное количество сообщений в очереди. Ноль (значение по умолчанию) означает отсутствие ограничения. При заполнении очереди `fvm_channel_send()` блокируется до получения сообщения потребителем либо закрытия канала. `fvm_channel_pending()` возвращает синхронизированный снимок длины очереди. `fvm_channel_close()` пробуждает ожидающих отправителей и получателей; заблокированная отправка после закрытия возвращает `FVM_ERROR`. Уже накопленные сообщения можно прочитать.

Функции доступны из C89 и C++98. Нельзя уничтожать канал, пока им пользуется другой поток. Для предсказуемого ограничения нагрузки задавайте ёмкость до запуска отправителей. Операторы каналов ActionScript этим изменением не реализуются.
