# Версия разработки и автоматическое обновление CMake

`VERSION.txt` обозначает версию разрабатываемого среза. С v0.408 корневой проект
читает его через `cmake/ProjectVersion.cmake` и отмечает как вход конфигурации.
Поэтому изменение только этого файла вызывает обновление `PROJECT_VERSION`
и метаданных при обычном `cmake --build`, без отдельного ручного configure.
ABI, версии сериализации и статус совместимости этим не изменяются.

Используется
[свойство каталога CMake 3.10](https://github.com/Kitware/CMake/blob/v3.10.0/Help/prop_dir/CMAKE_CONFIGURE_DEPENDS.rst),
соответствующее минимальной версии CMake в проекте.

`flashvm_build_version_refresh` подключает рабочий модуль к отдельному временному
проекту без компиляторов: configure/build версии 1.2.3, изменение только его
VERSION.txt на 1.2.4, обычная сборка, проверка обновления и ещё одна сборка для
проверки стабильности. VERSION.txt настоящего репозитория не меняется. Проверка
получает генератор, программу сборки и параметры platform/toolset из основного
проекта. Регистрация в CTest требует Python 3, включённых тестов и нативной сборки.

```sh
ctest --test-dir build -C Release -R "^flashvm_build_version_refresh$" --output-on-failure
```

Проверяется зависимость метаданных версии, а не исполнение в другой ОС или
полная приёмка выпуска. Все стадии плана остаются открытыми.
