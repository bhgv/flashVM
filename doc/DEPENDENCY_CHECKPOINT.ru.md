# Контрольный коммит зависимостей — 2026-10-11

Этот этап оформлен одним отдельным Git-коммитом, после которого разработка
приостановлена для проверки. Незавершённая работа над стандартными объектами
сохранена отдельно в Git stash и не входит в проверяемое рабочее дерево.
Зеркало не обновлялось. Архив исходников содержит полную .git-историю, включая stash.

Изменения: extern/ объединена с external/; включены настоящие исходники Cairo
1.16.0, Pixman 0.38.4 и SQLite 3.50.4; выбранные библиотеки собираются статически
офлайн. Cairo подключён к существующему API полигонов RGBA8, SQLite по умолчанию
берётся из встроенной amalgamation. DEFS.txt выбирает конкурирующие варианты
графики, платформы, вывода, базы данных, адаптеров и исполнения. Выбор ещё не
реализованных backend завершается явной ошибкой. Включены сведения о происхождении,
лицензии, полные патчи и контрольные суммы исходников. Новый код и скрипты имеют
читаемое форматирование и комментарии; upstream массово не переформатирован.

Все выбранные библиотеки собраны в C89/C90 либо C++98 с pedantic-errors;
неявные объявления C-функций запрещены. assert сохранён в Release. Новые тесты
проверяют разрешённые макросы, версию и настройки связанной SQLite, привязку
64-битных значений, rollback и восстановление после SQL-ошибки, версию/recording
Cairo и soft-light compositing Pixman, смешивание straight-alpha, сохранение
отступов и скрытых RGB. Также выполнены существующие тесты VM/GC/потоков/каналов.

Подтверждение: сводка (`validation/dependencies-summary.json`),
ключи (`validation/dependencies-definitions.json`),
строгая сборка (`validation/dependencies-strict-linux.json`),
sanitizer (`validation/dependencies-sanitizers-cairo-linux.json`),
логи CMake configure/build/test: validation/dependencies-*-<профиль>.log.
Команды Linux: python3 scripts/check.py; python3 scripts/check.py --sanitize
--defs /путь/cairo-defs.txt. Конфигурация: python3 scripts/check_definitions.py;
манифест: python3 scripts/check_vendor_sources.py. См.
[инструкции выбора](BUILD_DEFINITIONS.ru.md).

Ограничения: LeakSanitizer отключён из-за отсутствия доступа /proc task.
container_exceptions.cpp заменяет операторы выделения памяти и проверен только
UBSan. Сохранены нативные fixed-width-типы и внутренние помощники компилятора
сторонних библиотек; строгий режим языка не гарантирует поддержку любого
исторического компилятора. Выполнение и кросс-сборки Windows/macOS/Android
не проверялись. Версии зафиксированы ради совместимости/воспроизводимости;
они не объявлены новейшими и не прошли полный аудит upstream. Cairo включает
image/recording/user-font; GL/GUI/системные шрифты/PNG/документный вывод и SIMD
Pixman выключены. Промежуточный premultiplied-буфер Cairo может иначе округлять
RGB при малой альфе. FB/GLES/OGL/DX/SDL1/SDL2/SDL3, JIT и мультимедиа пока не
реализованы. Полный проигрыватель SWF <= 8 и все стандартные объекты ActionScript
не объявляются завершёнными.

Указанные выше имена исторических отчётов — метки, а не ссылки на файлы этого
checkout: сгенерированные отчёты проверок не хранятся в исходном репозитории.
