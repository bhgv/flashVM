# Режимы GC

- `0`: обычный порог — 1000 созданных объектов.
- `-100`: порог 1900; `100`: порог 100.
- `101` (`FVM_GC_SUSPENDED`): автоматические шаги не выполняются.
- `102` (`FVM_GC_FULL`): один принудительный проход без смены режима.

Порог не означает немедленную сборку: приложение должно вызывать `fvm_gc_step` в безопасных точках. Не запускайте GC во время исполнения AVM1, пока не реализована полная трассировка его стеков.
