# Числовые литералы и унарные операции JIT — v0.351

[English reference](JIT_NUMBERS.md)

JIT принимает float/double в ActionPush и ToInteger, ToNumber, ToString, TypeOf,
Increment, Decrement, Not. Машинные блоки вызывают общие C-сервисы с версионной
семантикой; сохраняются контроль бюджета, исходные смещения и нативные переходы.

Формулы IEEE-декодирования вынесены без изменения из интерпретатора в
`src/avm1/number_decode.hpp` и используются обоими путями. Float читается одним
little-endian словом. Double AVM1 хранит сначала старшее слово, затем младшее,
каждое little-endian. Не используются невыравненные приведения указателей,
предположение о native float или расширенные 64-битные целые. Сохраняются
отрицательный ноль, денормализованные/обычные значения, бесконечности и прежняя
канонизация NaN; идентичность payload NaN не обещается. Усечённые записи отвергаются
до публикации нового code handle.

Вход унарной операции остаётся в корнях нативного стека до завершения callback,
преобразований и выделения строки. Успешный результат заменяет верхний операнд
без нового выделения вектора. При ошибке выход не публикуется. Пустой стек
загруженного SWF дополняется undefined, host-режим остаётся строгим.

`jit_numbers` проверяет 20 исходных IEEE-наборов: ±0, минимальные обычные и
денормализованные значения, максимальные денормализованные/конечные числа,
бесконечности и NaN. Литералы имеют независимые ожидаемые числовые значения.
Семь унарных операций сравниваются для десяти примитивных входов, пустого стека
и object coercion со сборкой мусора/исключением, в host и SWF4–8. Проверяются
интерпретатор, явный JIT и автоматический JIT; счётчики подтверждают настоящий
нативный вход. Группы литералов используют разные контексты, чтобы не исчерпывать
ограниченный автоматический кеш и не подменять проверку JIT штатным fallback.

`jit_numbers_allocation` проходит отказы выделения памяти через все новые операции
и оба формата, проверяет корни, глубины вызовов и освобождение активного code handle.
`jit_invalid` проверяет усечённые литералы и сохранение прежнего handle. Девять
целевых heap/global ASan+UBSan проверок проходят; stack ASan и LeakSanitizer
остаются отключёнными из-за ограничений среды, описанных в JIT_REFERENCES.md.

Register/constant-pool Push, определения/вызовы функций, создание объектов/массивов,
блоки исключений и прочие неподдержанные операции пока используют fallback.
Полнота AVM1, сравнение с эталоном Flash и реальные запуски остальных ОС ещё
не подтверждены. Контрольная точка не закрывает стадии roadmap.

Итоговые полные Linux Release прогоны прошли напрямую: AGG 706/706,
Cairo 706/706, minimal 687/687. В промежуточных прогонах восстанавливались права
ELF и обнаружен устаревший fallback-набор execution_modes: ToNumber теперь
поддерживается, поэтому проверка неподдерживаемого тела использует ConstantPool.
Нативный ToNumber отдельно подтверждается jit_numbers. Ошибки поведения не
списывались на права запуска и не скрывались повтором.
