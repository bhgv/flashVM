# Проверенный этап Number — v0.10

Устанавливаемая стандартная библиотека теперь содержит метаданные нативного класса
Number и его прототипа. Глобальная функция Number(value) сохраняет прежнее поведение
и возвращает примитивное число. `fvm_construct` с именем Number и AVM1 NewObject
создают объект-обёртку. Без аргумента получается ноль; аргумент преобразуется
существующим ToNumber, включая undefined → NaN и распаковку Boolean/Number.

Прототип хранит ноль. Числовое значение экземпляра находится во внутреннем поле,
независимом от изменяемых свойств. valueOf возвращает это значение, toString
преобразует его в строку. Методы требуют объект Number. У класса доступны
MAX_VALUE, MIN_VALUE — минимальное положительное субнормальное число double,
NaN, NEGATIVE_INFINITY и POSITIVE_INFINITY. Используется принятая в проекте модель
IEEE-754 double. [Справочник AS2](https://open-flash.github.io/mirrors/as2-language-reference/Number.html).

## Форматирование и ограничения

Пропущенное основание или undefined означает 10. Основание преобразуется в число,
дробная часть отбрасывается; значения вне поддерживаемого интервала 2–36 отклоняются.
Десятичная запись использует преобразователь v0.9. В других основаниях поддержаны
точные целые с модулем до 2^53−1, цифры выше девяти записываются строчными буквами.
Ноль, NaN и бесконечности обработаны отдельно. Дробные и более крупные конечные
значения в недесятичных основаниях возвращают FVM_UNSUPPORTED без потери разрядов.
Неверный получатель/основание пока возвращают коды C API: стандартные TypeError
и RangeError ещё не реализованы. Полное соответствие форматированию всех версий
Flash не заявляется.

## GC и передача

GC отслеживает захваченный класс и прототипы; внутреннее число сохраняется.
Удаление глобального Number не уничтожает зарегистрированный конструктор после
GC. Нативный instanceof распознаёт Number. Сериализатор поддерживает виды 24/25
и методы с идентификаторами 401/402; старые читатели их отклоняют. Циклы, общие
ссылки и идентичность импортированных прототипов работают по модели Error.

Проверены очередь и файл, записываемый/читаемый независимыми процессами: числовое
поле, valueOf и toString восстанавливаются без стандартной библиотеки получателя.
Импорт не регистрирует глобальный конструктор. Экземпляр соответствует своему
импортированному классу, а не другому установленному классу получателя.

Установка подготавливается вместе с другими стандартными объектами и публикует
глобальные имена лишь после успеха всех этапов. Инъекция отказов памяти проверяет
отсутствие частичных Math/Boolean/Number/Error, затем GC и успешный повтор.
Тесты: tests/standard_number.c и дополненный tests/error_transfer_process.c.

Остаются полноценный Function, атрибуты свойств, вызовы методов примитивных чисел,
полное преобразование произвольных объектов в число, недесятичные дроби и проверки
исполнения на Windows/macOS/Android.
