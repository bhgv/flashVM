# Загрузка SWF 1–8 и расширение AVM1

Поддерживаются FWS версий 1–8 и CWS со сжатием zlib версий 6–8. ZWS и версии
выше 8 не поддерживаются. До успешной загрузки данные распаковываются в
канонический FWS; при ошибке прежний фильм сохраняется. Информация инспектора
также заменяется только при успехе.

FileLength проверяется до выделения памяти. По умолчанию предел — 64 МиБ
(FVM_SWF_DEFAULT_LIMIT). Ненулевой FVM_Config.memory_limit_bytes ограничивает
буфер распакованного фильма; **общий учёт всей памяти VM пока отсутствует**.
Превышение возвращает OUT_OF_MEMORY. CWS должен содержать один полный поток
zlib, без лишних входных байтов, с ровно FileLength-8 выходными байтами.
Обрезанные и повреждённые данные, несоответствие длины и хвост отклоняются.
Проверяются границы тегов, расширенная длина, ненулевая разрядность RECT,
пустые End и ShowFrame; End должен завершать файл.

`fvm_swf_execute_actions` выполняет верхнеуровневые DoAction нормализованного
FWS, включая исходный CWS. Это пока не проигрыватель временной шкалы: спрайты,
события, display list и декодирование фигур не реализованы этой функцией.
Структурно корректный неизвестный тег может быть не реализован.
`fvm_advance` пока возвращает UNSUPPORTED.

## Значения AVM1

ActionPush поддерживает строки, float, null, undefined, регистры, boolean,
double, знаковые 32-битные целые, Constant8 и Constant16. Float/double
декодируются арифметически из IEEE-полей, без невыровненных обращений и
зависимости от порядка байтов хоста. Double AVM1 хранит сначала старшее
little-endian слово, затем младшее. Нужны проверки и на целевых архитектурах.

ActionConstantPool заменяет пул с проверкой числа строк и полного потребления
payload. Именованный DefineFunction сохраняет пул места определения.
ActionStoreRegister работает с четырьмя регистрами, не удаляет вершину.
Объекты в регистрах трассируются, включая явную сборку GC. DefineFunction2
с дополнительными регистрами и preload-флагами пока отсутствует.

Строковые литералы и строки пула копируются в память контекста. Глобальное
значение больше не ссылается на освобождённый байткод или временный снимок
функции. Строки пока освобождаются только при уничтожении контекста.

Проверки: `swf_compressed.c`, `avm1_push_values.cpp` и прежние SWF/AVM1-тесты.
Они проверяют повреждённые потоки, лимиты, сохранение фильма при ошибке,
float/double, индексы пула, захват пула функцией, регистры через GC и время
жизни строк после перезаписи исходного буфера.
