# Контрольная точка: шрифтовые библиотеки

Добавлены FreeType 2.14.3, HarfBuzz 1.8.8 с сохранёнными адаптациями C++98,
libunibreak 6.1 и FriBidi 1.0.16. HarfBuzz 10.4.0 требует более нового C++.
Все выбранные библиотеки external собираются статически, включая настройку
BUILD_SHARED_LIBS=ON.

Реализованы собственные редактируемые векторные контуры, точные границы кривых,
аффинные преобразования, контуры и метрики глифов, OpenType shaping, классификация
переносов, двунаправленный текст с картой индексов, заливка и обводка AGG/Cairo,
маски для изображений. Добавлены пример C89, собственный воспроизводимый шрифт
CC0 и документация API на русском и английском.

## Проверки

Linux x86_64, GCC/G++ 13.3.0, строгие C89/C++98 с pedantic-errors:

| Профиль | Пройдено программ |
| --- | ---: |
| AGG со шрифтами | 114 |
| Cairo со шрифтами | 114 |
| NO_FONTS | 110 |
| NO_GRAPHICS и NO_IMAGE_CODECS со шрифтами | 108 |
| ASan/UBSan | 114 |

Журналы и отчёты: validation/font-libraries-*.log и *.json. Проверяются владение
памятью, сохранение контуров и результатов shaping, экстремумы кривых, составные
глифы, лигатуры, кернинг, арабские формы, иврит и bidi, переносы, маски и обводки,
ошибочные данные, пустые буферы и восемь независимых рабочих потоков.
Статическое подключение подтверждено проверками архивов, readelf и nm.
Манифест проверяет 2094 файла внешних исходников.

Проверяющий скрипт теперь отклоняет и диагностические сообщения санитайзеров
при успешном коде выхода. LeakSanitizer отключён из-за ограниченного /proc;
старый тест исключений собственного аллокатора проверен только UBSan.
Инструментированные ядро и библиотеки пересобраны scripts/check.py; затем все
программы пересобраны и перелинкованы после исправлений пустого буфера HarfBuzz
и валидации enum в корнях GC. Исправление GC выделено в отдельный коммит.
Лицензии, происхождение исходников и патчи включены. Зеркало не обновлялось.

## Границы результата

Запуск на Windows, macOS и Android здесь не проверен. Полная компоновка абзацев
с переносами и интеграция ActionScript TextField ещё не объявлены готовыми.
Таблицы Unicode библиотек имеют разные документированные версии.
Подробности сборки, владения памятью и ограничений: FONT_LIBRARIES.ru.md.
