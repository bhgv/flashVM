# Контрольная точка: текстовые объекты ActionScript

Добавлены отдельный реестр нативных конструкторов и accessor-свойства на объекте
и прототипе с корнями GC. AVM1 NewObject сохраняет порядок аргументов и проверяет
объектный результат своего контекста. Ошибочные enum значений от C проверяются
по байтам до чтения как C++ enum. Захваты конструктора/getter/setter отслеживаются
GC и освобождаются при замене привязок. Передача нативных accessor через каналы
отклоняется вместо потери callback.

Добавлены TextFormat/getTextExtent и создаваемый приложением мост TextField,
использующий копируемые шрифты контекста и собственную компоновку текста.
Текущий/будущий формат всего поля независим; экспортированные контуры переживают
GC поля и уничтожение контекста. Неподдержанные функции отображения явно дают
ошибку. API/ограничения: STANDARD_TEXT.ru.md; пример C89: standard_text.

## Проверки

Linux x86_64, GCC/G++ 13.3.0, строгие C89/C++98, pedantic-errors,
CMake 3.31.10, BUILD_SHARED_LIBS=ON:

| Профиль | Пройдено программ |
| --- | ---: |
| AGG | 121 |
| Cairo | 121 |
| NO_FONTS | 117 |
| NO_GRAPHICS и NO_IMAGE_CODECS | 115 |
| ASan/UBSan | 121 |

Доказательства: validation/standard-text-*.log и *.json. scripts/check.py
пересобрал инструментированные ядро/библиотеки; затем обновлённый value_c был
пересобран, а все программы заново собраны и перелинкованы с итоговым архивом.
Восстановленные диагностики также отклоняются. После добавления давления
автоматического GC AVM1 отдельно пересобран/перепроверен native_properties.
LeakSanitizer отключён из-за недоступного /proc; старый тест исключений
собственного аллокатора проверен только UBSan.

Проверены конструктор/метод/свойства AVM1, порядок и нехватка аргументов,
ошибочные результаты конструктора, отличие от обычных нативных функций,
receiver прототипа, read-only/write-only, захваты/замена, автоматический и явный
GC, ошибочные C enum, копирование шрифта, метрики/переносы/отрицательный leading,
снимки текущего/будущего формата, UTF-16 length, откат ошибочного UTF-8,
неподдержанные функции, освобождение поля и независимость контуров.
Статические символы шрифтовых библиотек включены в исполняемый пример;
динамические зависимости — только системные. Проверены 2094 внешних файла.

## Зеркало

По прямой команде master обновлён с 969ae9c до 2cdedd6, включая шрифтовые
библиотеки и нативную компоновку. Проверены удалённые HEAD/master и новая bare-копия:
92 коммита, git fsck --full. После ошибки HTTP/2 успешная отправка выполнена через
HTTP/1.1 с буферизацией запроса. Автоматическая проверка отклонила отправку
refs/stash; успешное обновление включало только master. Stash остался в основном
внутреннем репозитории/архиве. Последующая разработка этой контрольной точки
в зеркало НЕ отправлялась. Основным остаётся внутренний Git; обновления —
только по прямым командам.

## Незавершённая часть

Это поднабор Flash 6–8 с внешними нативными шрифтами. Полное соответствие
TextField/TextFormat ещё не готово. MovieClip/display list, SWF-шрифты/текст,
диапазоны стилей, HTML, выделение/каретка/ввод, прокрутка, подстановка шрифтов,
все свойства формата и coercion по версиям остаются задачами разработки.
Реестры шрифтов принадлежат контекстам и не наследуются автоматически потоками.
Windows/macOS/Android не проверены запуском. Подробные ограничения —
STANDARD_TEXT.ru.md и TEXT_LAYOUT.ru.md.
