# Проверки редактирования диапазонов TextField

Созданный приложением TextField теперь поддерживает replaceText и чтение
getTextFormat для символа/диапазона через C callback и AVM1 CallMethod.
Конечный индекс не входит в диапазон; индексы согласованы с length в UTF-16.
В непустом поле сохраняется единый текущий формат; вставка в пустое поле берёт
будущий формат. Это временная явно описанная политика, без заявления полного
совпадения форматирования с Flash. Контракт и ограничения: STANDARD_TEXT.ru.md.

Проверки выполняются до изменения поля. Некорректная UTF-8, неверные индексы,
граница внутри суррогатной пары и превышенный бюджет оставляют текст/формат/кэш
прежними. Лимиты: 4096 Unicode-скаляров / 16384 UTF-8-байт, до 8192 единиц UTF-16.
Память принадлежит контексту либо временным RAII-контейнерам. Старые строковые
снимки переживают изменения и GC поля; экспортированные контуры независимы.
Успешная замена сбрасывает кэш, обновляя ширину, высоту и контуры.

## Проверки

Linux x86_64, GCC/G++ 13.3.0, CMake 3.31.10, строгие C89/C++98 с pedantic-errors.
Встроенные библиотеки по-прежнему подключаются статически.

| Профиль | Успешные тесты/примеры |
| --- | ---: |
| AGG | 122 |
| Cairo | 122 |
| NO_FONTS | 118 |
| NO_GRAPHICS и NO_IMAGE_CODECS | 116 |
| ASan/UBSan (AGG) | 122 |

Санитайзер заново собрал все выбранные исходники ядра/библиотек, затем
скомпилировал, связал и выполнил все программы с итоговым инструментированным
архивом. Восстановленные диагностики санитайзера тоже считаются отказом.
LeakSanitizer отключён из-за недоступного /proc; прежний тест исключений своего
аллокатора использует только UBSan. Объекты итогового теста редактирования и
обновлённого C89-примера собраны после последних правок соответствующих исходников.
Неизменённый манифест подтверждает 2094 файла встроенных библиотек.

tests/standard_textfield_editing.c проверяет нативное редактирование и AVM1,
все допустимые диапазоны строки из пяти ASCII-символов, удаление/вставку и
конечную границу, кириллицу и дополнительные Unicode-символы, обратные,
дробные, бесконечные и выходящие за границы индексы, разрыв суррогатной пары,
отказ без изменений при неверной UTF-8, текущий/будущий формат, чтение формата,
высоту перенесённых строк, замену старым снимком той же строки, лимиты
скаляров/байтов, строки после GC и независимые контуры после следующих изменений.
Шрифтовые операции проверяются во включённых профилях. C89-пример действительно
выполняет редактирование и чтение; editing.as — иллюстрация, не внешняя сборка AS.

Отчёты/логи: validation/text-editing-*.json и *.log. Первый запуск CTest не смог
запустить один прежний тест из-за отсутствующего execute-бита в рабочем каталоге.
После восстановления прав и повторного полного запуска все проверки профилей
прошли, как указано выше.

## Оставшиеся работы и зеркало

Частичная запись стилей, HTML/CSS, выделение/replaceSel, display list/timeline,
встроенные SWF-шрифты, полное coercion и различия версий ещё не реализованы.
UTF-8-модель не хранит отдельные суррогаты UTF-16; граница внутри пары явно даёт
UNSUPPORTED. Выполнение Windows/macOS/Android, полный TextField и SWF 8 не заявлены.

Основным остаётся внутренний Git/архив. Эти изменения не отправлены в зеркало:
его последняя явно запрошенная версия — 0a9c53d. Следующие обновления только
по прямой команде, с документированной схемой HTTP-буфера 64 МиБ.
