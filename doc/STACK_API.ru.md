# Стековый API расширений в стиле Lua (C89 и C++98)

API **вдохновлён Lua**, но не совместим с Lua на уровне исходного кода или ABI. Обработчик получает `FVM_Context*` конкретного интерпретатора и отдельный `FVM_Stack*` с аргументами.

## Интерфейс C

Подключите `flashvm/stack.h`. Зарегистрируйте обработчик через `fvm_stack_register(context, name, callback, userdata)`, вызовите его через `fvm_stack_call(context, name, argc, argv, result)`.

При вызове стек содержит ровно `argc` аргументов. Положительные индексы начинаются с 1, отрицательные отсчитываются от вершины (`-1` — последний элемент). Индекс 0 запрещён. Для чтения используйте `fvm_stack_get`, добавления — `fvm_stack_push`, удаления — `fvm_stack_pop`, очистки — `fvm_stack_clear`. Успешный обработчик возвращает `FVM_OK` и оставляет **ровно одно** значение результата. Пустой стек означает `undefined`; более одного значения пока считается ошибкой.

Объекты должны принадлежать текущему контексту. Строки в стеке **заимствуются**, а не копируются: память строки должна оставаться действительной на протяжении вызова. Нельзя сохранять указатель на стек после завершения обработчика. Для доступа к состоянию ActionScript используются существующие `fvm_object_get`, `fvm_object_set`, `fvm_get_global`, `fvm_set_global`.

Рабочий пример: `examples/extending/stack_c/main.c`.

## Интерфейс C++98

`flashvm/stack.hpp` предоставляет RAII-обёртку `flashvm::Stack`, которая освобождает стек при выходе из области видимости. Реализация использует только C++98. Пример: `examples/embedding/cpp98_stack/main.cpp`.

## Несколько интерпретаторов и потоки

Каждый контекст имеет собственный реестр функций. Можно создавать несколько контекстов в одном runtime, но **одновременное обращение к одному контексту из разных потоков запрещено** без внешней синхронизации. Обмен данными между контекстами должен организовывать хост. Указатели объектов нельзя передавать между контекстами.

## Ограничения

Это дополнительный интерфейс вызова C-функций. Пока нет полноценных значений-функций, замыканий Lua, userdata, registry references, нескольких возвращаемых значений, корутин и автоматического вызова зарегистрированных стековых функций из ActionScript. Старый `FVM_NativeFunction` сохранён. Полной совместимости с Lua нет.
