# SQLITE_API — русская документация

SQLite — необязательная внешняя зависимость. C-адаптер позволяет открыть базу, выполнить SQL и получить ограниченные типы результатов. SQLite не доступен из ActionScript автоматически. SQL из недоверенных сценариев должен контролироваться хостом.

Подробные сигнатуры и ограничения см. в `SQLITE_API.md` и заголовках `include/flashvm/`. Примеры расположены в `examples/embedding/` и `examples/extending/`.
