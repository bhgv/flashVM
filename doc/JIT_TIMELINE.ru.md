# Нативное управление таймлайном — v0.365

[English description](JIT_TIMELINE.md)

NextFrame, PreviousFrame, Play, Stop, GotoFrame, GotoLabel и GotoFrame2 используют
из нативных помощников общий встроенный сервис кадров, обходя подменяемые методы
скрипта. Фиксированные команды работают с активным display target. Отсутствующий
выбранный клип при существующем базовом таймлайне означает отсутствие действия;
без базового таймлайна возвращается [FVM_UNSUPPORTED](../include/flashvm/flashvm.h#L46). Отсутствующая метка
игнорируется, как в интерпретаторе.

GotoFrame сохраняет UI16 с нулевой базой как числовую константу с базой один.
GotoLabel проверяет полностью терминированную запись и копирует текст в код.
При исполнении запрос удерживается временными корнями GC, байты метки
усваиваются контекстом. Эти две операции не занимают дополнительных слотов
стека скрипта. GotoFrame2 проверяет флаги и смещение сцены при компиляции;
при исполнении удерживает вход во время преобразования, затем разрешает target,
удаляет операнд и применяет политику воспроизведения. Именно динамическая
операция восстанавливает корневой target после отсутствующего выбранного клипа.
Смещение добавляется к числу, но не к метке. Сохранены общие ограничения кадров
и правила преобразований.

| Проверка | Покрытие |
| --- | --- |
| `jit_timeline` | Отдельные host/SWF4–8 контексты и три режима; границы кадров, UI16 ноль/максимум, play/stop, прямой переход, метки и отсутствующие метки, десятичные запросы, числовое смещение и его игнорирование для меток, максимальное смещение, отрицательные кадры, выбранный child, отсутствующий target и восстановление root в динамической операции, отсутствующие входы/таймлайн, сохранение нижнего операнда, обход подменённых методов |
| `jit_timeline_callbacks` | Ровно один toString с GC/исключением без valueOf, отделённый receiver запроса, число/метка со смещением, отсутствие перехода при ошибке преобразования, нативный callback преобразования меняет выбранный target до перехода |
| `jit_timeline_allocation` | Все семь операций в host/loaded; отказы компиляции сохраняют старый handle; отказы вызова восстанавливают корни/глубины/активность; успешное состояние сохраняется после удаления кода и GC |
| `jit_invalid` | Неверная ширина прямого кадра, пустая/нетерминированная/NUL-внутри метка, неверные флаги и несогласованный размер смещения сцены сохраняют старый handle |

Проверка отказа компиляции теперь использует неподдерживаемый ToggleQuality
вместо Play. WaitForFrame остаётся проверкой автоматического fallback.
Это расширение нативного исполнения существующей семантики FlashVM, а не полная
интеграция display list SWF, совместимость кадровых событий с Flash, реализация
остальных инструкций или приёмка других платформ. Все стадии остаются открытыми.

Linux Release: все 744 проверки AGG, 744 Cairo и 725 minimal прошли после
восстановления прав сгенерированных ELF перед графическими прогонами. Четыре
проверки timeline/allocation/callback/invalid проходят ограниченный heap/global
ASan+UBSan; stack ASan и LeakSanitizer отключены. Запуск других ОС/VM не заявлен.

С v0.367 WaitForFrame нативный; автоматический fallback использует невызываемый
анонимный DefineFunction. См. JIT_WAIT_FRAMES.ru.md.
