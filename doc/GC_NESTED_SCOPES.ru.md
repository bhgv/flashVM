# Вложенные области временных корней GC

Нативные расширения могут открывать несколько областей временных корней. Области закрываются строго в обратном порядке (LIFO). Попытка закрыть внешнюю область при открытой внутренней возвращает `FVM_INVALID_ARGUMENT`, сохраняя обе области.

Область копирует значения `FVM_Value`. Ссылки на объекты удерживают соответствующие объекты от удаления до закрытия области. Это не передаёт владение объектами и не гарантирует безопасность указателя после последующей сборки.

Тест `tests/gc_nested_scopes.c` проверяет вложенность, неправильный порядок закрытия, сохранение объектов при сборке и освобождение после закрытия областей. **Полная интеграция корней AVM1 и нативных вызовов ещё не завершена.**
