# Нативные вызовы методов — v0.354

[English](JIT_METHODS.md)

CallMethod и NewMethod используют общий сервис AVM1 с защитой корней GC.
Сохранены порядок преобразования числа аргументов перед проверкой получателя,
обратный порядок аргументов на стеке, выбор получателя готовой активации и
ограничения типа имени в host-режиме. В загруженных SWF null/undefined дают
undefined; host NewMethod сохраняет ошибку общего сервиса. Для nullish
CallMethod аргументы отбрасываются без выделения их отдельной копии.

Объект, имя и аргументы остаются на защищённом стеке во время преобразований,
поиска свойств, callback и конструктора. Результат записывается в первый
поглощённый операнд до сокращения стека: после снятия временных корней сервиса
не требуется новое выделение памяти. Ошибки передаются без записи результата;
существующая безопасная граница переводит отказы памяти и восстанавливает
состояние нативного исполнения.

`jit_methods` сравнивает интерпретацию, явное и автоматическое нативное
исполнение для host/SWF4–8: порядок аргументов, GC в callback, исключения,
запрет освобождения активного кода, методы строкового примитива, null/undefined
и строковый счётчик аргументов. `jit_methods_allocation` перебирает отказы
памяти при вызовах, создании экземпляров и GC внутри callback, проверяя кадры
корней, глубины исполнения и счётчик активного кода после каждого выхода.

Именованные CallFunction/NewObject и определения функций ещё интерпретируются.
Все стадии роудмапа остаются открытыми. Реальных запусков на других CPU/ОС
эти проверки не заменяют. Публичный C API и ABI готового кадра не изменены.

Linux Release: 715 AGG, 715 Cairo and 696 minimal checks pass after restoring
generated ELF execute permissions and rebuilding the corrected method fixture.
Both new tests pass restricted heap/global ASan+UBSan; stack ASan and
LeakSanitizer remain disabled by the existing environment restrictions.
