# Отчёт: мутексы и диагностика синхронизации — v0.5

Добавлены `mutex.new/list`, общий нативный ресурс, поля state/origin только для
чтения, set/reset/touch, ID скриптовых потоков и передача общих mutex/channel в
графах объектов. Отладчик получает согласованные снимки владения/ожидания,
находит циклы ожидания мутексов, фиксирует функцию и смещение AVM1, использует
карты исходника, показывает ожидания каналов, замораживает выдачу посылок и
позволяет читать их без извлечения. Числовой доступ AVM1 к слотам таблиц делает
возможным `mutex.list()[0]`; это ещё не полная стандартная реализация Array.

[Описание API и ограничений](MUTEX_CHANNEL_DEBUG.ru.md),
[English](MUTEX_CHANNEL_DEBUG.md). ABI значений остаётся 2.

## Выполненные проверки

Linux, GCC/G++ 13.3, строгие C89/C++98, статические внешние библиотеки.
В тестах и примерах assertions включены и при оптимизированной сборке.

| Конфигурация | Успешных тестов и примеров |
|---|---:|
| AGG, шрифты, кодеки изображений | 138 |
| Cairo, шрифты, кодеки изображений | 138 |
| AGG, кодеки, без шрифтов | 134 |
| Без графики и кодеков, со шрифтами | 132 |
| Основная AGG с ASan/UBSan и указанными исключениями | 138 |

Добавлены пять тестов и один собираемый пример C89. Помимо полного набора,
конкурентный тест отладчика прошёл 25 повторов под санитайзерами: сроки жизни
строк, заморозка примитивного C API, одновременные передача/просмотр графов с
общим мутексом, закрытие и явное возобновление очереди. Четыре OS-потока
выполняют 8000 защищённых инкрементов. Реальный цикл двух потоков проверяет
диагностику мест захвата и ожидания, остановку, join и освобождение при выходе.
ActionScript-проверки исполняют байткод AVM1. `.as` — пример интерфейса;
компилятора исходного ActionScript в этом этапе нет.

Воспроизведение санитайзеров:
`python3 scripts/check.py --sanitize --limited-asan-stack`.
Последний ключ явно обходит ограничение окружения: libasan не может через
`/proc` обнаружить и очистить стек после раскрутки C++-исключений.
Стековый ASan отключён **только** для `src/capi/serialization_c.cpp`; проверки
кучи/глобальных данных ASan и UBSan остаются. `tests/container_exceptions.cpp`
проверяется только UBSan. LeakSanitizer отключён. Полное покрытие стековым ASan
и проверка утечек не заявляются. Независимый пример этого ограничения сохранён
в `doc/validation/file-sanitizer-exception-probe.cpp` с пояснением прошлого этапа.
Для окончательной проверки пересобраны все VM/платформенные объекты и каждый
тест/пример; неизменившиеся внешние instrumented-объекты взяты из полного запуска.

Логи CTest, конфигурации, JSON/логи санитайзеров, результат 25 повторов и хеши
исходников сохранены в `doc/validation/mutex-*`.
`python3 scripts/check_vendor_sources.py` подтвердил все 2094 внешних файла.
Проверка whitespace Git выполнена. При упаковке проверяются CRC ZIP, чистый
извлечённый checkout, целостность полного Git, совпадение HEAD и сохранность stash.

## Что ещё не реализовано или не подтверждено

Нет удалённых mutex-прокси с интернет-адресом в origin, распределённого владения
и восстановления живых ресурсов через файл или другой процесс. Файловый канал
отвергает такие посылки до записи. Циклы только на каналах, смешанные циклы
«канал + мутекс» и дедлоки join не доказываются: показываются ожидания каналов,
а точный детектор работает для циклов владения мутексами. Заморозка запрещает
извлечение посылки, не останавливает все потоки и не замораживает живой ресурс.
Интерактивный UI, автоматическое восстановление исходника и полный стек вызовов
не завершены. Карты исходника предоставляет хост/внешний компилятор.

Дополнительные свойства оболочек ресурсов остаются локальными. Циклы очередей,
удерживающих каналы, запрещены во избежание утечек; обычные циклические графы
сериализуются. Мутексы нерекурсивные, без гарантии справедливой очередности.
`mutex.list` ограничен интерпретатором, а не лексической областью.

Версия не подтверждает полную совместимость SWF <=8, готовность всех стандартных
объектов или JIT. Для Windows/macOS/Android изменены адаптеры в `ports/`,
но здесь исполнялись только Linux-сборки. Полный основной Git включён в
`FlashVM-with-history-v0.5.zip`. Зеркало не обновлялось: в этой команде обновление
зеркала не запрашивалось.
