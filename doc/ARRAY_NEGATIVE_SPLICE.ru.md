# Заимствованный splice с отрицательной длиной — v0.373

В загруженных SWF 4–8 заимствованный `Array.splice` принимает собственную
длину, преобразующуюся в отрицательный Int32. При неотрицательном начале
удаление пустое; вставка использует знаковые собственные ключи, включая переход
через ноль. Итоговая длина равна захваченной длине плюс числу вставок.
Начало, собственная длина и число удалений преобразуются однократно по порядку;
изменение длины последним преобразованием не меняет захваченные границы.
Отрицательное начало без переполнения сложения, отрицательное число удалений
и явно переданный undefined дают undefined. Пропущенное число удалений даёт
пустой массив. Посторонние хвостовые свойства сохраняются. Запись учитывает
существующие флаги без вызова геттеров, сеттеров и наблюдателей.

Результат временно укоренён; вставки учитывают бюджет. Ошибка выделения памяти
или бюджета не откатывает уже выполненные вставки. Отрицательное хранение
настоящего Array и переполнение знакового сложения пока не поддерживаются.
Этап 1 остаётся открытым. Ссылка на сравнительную реализацию и перечень
проверок: [английский контракт](ARRAY_NEGATIVE_SPLICE.md).

Проверяются также readonly-свойства, исчерпание бюджета и последовательный
отказ каждого выделения памяти до успешного вызова, сборка после ошибки
и повторный вызов после частичной мутации.

Подтверждение v0.373: 769 AGG / 769 Cairo / 750 minimal Release проверок
прошли после пересборки потребителей заголовка и исправления прав ELF
с повторными запусками. Пять проверок splice прошли ограниченный
heap/global ASan+UBSan; stack ASan и LSan отключены.
