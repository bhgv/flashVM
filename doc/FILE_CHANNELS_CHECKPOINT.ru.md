# Этап 0.3: файловые каналы, кодеки графов и метаданные значений

Этап реализует проверенное подмножество новой задачи сериализации и метатаблиц. Полный каталог объектов Flash ещё не завершён. Сообщение коммита: `v0.3 Add persistent file channels and serializable value metatables`. Исходный внутренний коммит: `8918bc1371cb2e51cf8d902a133abc80962b8b92`. ABI изменён с 1 на 2: нативные клиенты надо пересобрать. Зеркало на этом этапе не обновлялось.

Сделано:

- Переносимый stdio-адаптер `ports/file_port.c`, C89 API сообщений и необработанных байтов, удерживаемые синхронизированные handle, `r`/`w`/`rw` по умолчанию, ветка UTF-8 путей Windows, конечное чтение EOF и создание файлового канала из ActionScript.
- Версионированный бинарный формат с фиксированным порядком байтов и CRC для графов в памяти и в файле. Циклы, общие ссылки, прототипы, метатаблицы, зарегистрированные callbacks/методы/аксессоры и их корни. Проверяемые ограничения и откат при ошибке.
- Кодеки Boolean, Math, TextFormat/метаданных классов и реализованного подмножества TextField хоста. TextField переносит байты используемых шрифтов, текст, текущий/будущий стиль, размеры и флаги; кэши получателя пересчитываются. Конфликт имени шрифта отвергает восстановление.
- Метатаблицы всех существующих примитивных типов и объектов. GC отслеживает их через корни, стеки, регистры, локальные переменные, свойства и индексы. API C и ActionScript для привязки/получения; обработчики свойств примитивов, арифметики и сравнения AVM1. Ссылки/результаты другого контекста отвергаются.
- Исполняемый пример C89, пример API ActionScript и документация RU/EN. Отдельные процессы записи/чтения подтверждают сохранение после завершения отправителя.

## Фактические проверки

Linux x86-64, GCC/G++ 13.3.0, CMake 3.31.10, строгие C89/C++98, статические встроенные зависимости. После последних изменений проверки выполнены повторно.

| Профиль | Тесты/примеры | Результат |
| --- | ---: | --- |
| AGG, шрифты/изображения/SQLite | 132 | Пройдены |
| Cairo, шрифты/изображения/SQLite | 132 | Пройдены |
| AGG без шрифтов | 128 | Пройдены |
| Без графики/шрифтов/кодеков изображений | 126 | Пройдены |
| AGG с sanitizer и явным ограничением ниже | 132 | Пройдены |

Логи, DEFS профилей и метаданные sanitizer: `doc/validation/file-*`. Манифест подтвердил неизменность 2094 файлов внешних библиотек. `git diff --check` пройден. Проверена целостность Git; ранее существовавшие недостижимые blobs — информационные сообщения, история приватного stash сохранена.

Новые тесты проверяют циклы/общие ссылки после уничтожения VM-источника, callbacks Boolean/Math между разными процессами, перенос метатаблиц примитивов, зарегистрированный `__index` с корнем, знаковый ноль/NaN/infinity, неверное представление enum, каждую границу обрезания пакета, CRC/ссылки/циклы прототипов, откат неизвестного callback, редактирование/измерение/контуры восстановленного TextField со встроенным шрифтом, откат регистрации шрифта и счётчика выделений, режимы файла, очистку/сохранение, NUL в байтах, EOF, close и примитивное чтение графа. Существующие тесты GC/потоков/каналов/нативных прототипов также проходят.

Обычный полный ASan завершился ошибкой при раскрутке C++-исключения в ограниченной среде. Независимый от FlashVM `file-sanitizer-exception-probe.cpp` воспроизводит предупреждение libasan об определении границ стека и ошибку; лог сохранён. Тот же probe проходит с GCC `--param=asan-stack=0`. Итоговая команда: `python3 scripts/check.py --sanitize --limited-asan-stack`. Явный флаг отключает **только проверку стека ASan в `src/capi/serialization_c.cpp`**; проверки heap/global ASan и UBSan сохраняются. Прочие исходники VM/тестов проверяются обычным образом. Историческое исключение `container_exceptions.cpp` остаётся UBSan-only; LeakSanitizer отключён из-за недоступного `/proc`. Полное покрытие stack-ASan и LeakSanitizer не заявлено. Ошибки ASan/UBSan в успешном запуске не игнорировались.

Старые каталоги сборки первоначально сохранили часть объектов ABI 1. Все объекты VM и клиентов пересобраны перед успешными результатами. При смене ABI используйте чистую сборку. Существующее предупреждение GCC о локальном корне AVM1 может сохраняться; отсутствие предупреждений не заявлено.

Воспроизведение: новый каталог `cmake -S . -B build-file-agg`, сборка, затем `ctest --test-dir build-file-agg --output-on-failure`. Для других профилей добавьте `-DFVM_DEFS_FILE=$PWD/doc/validation/file-DEFS-cairo.txt` либо файл no-fonts/minimal. Проверку манифеста и указанную sanitizer-команду запускайте отдельно. Fixtures CTest запускают процесс записи до процесса чтения, включая параллельный запуск.

## Что остаётся по задаче

MovieClip и значительная часть стандартных объектов SWF <=8 ещё отсутствуют: сериализация всех объектов не завершена. Живые ресурсы потоков/каналов, пространства расширений, произвольный userdata, стековые callable и окружения AVM1-функций/замыканий не имеют переносимых кодеков. Самостоятельный TextFormat для измерений требует регистрации шрифта получателя. Для TextField нужно заранее установить текстовый мост. ActionScript workers не устанавливают автоматически текстовый мост и пользовательский реестр callbacks. Обобщённые метаметоды ещё не подключены ко всем опкодам/преобразованиям; копии примитивов не имеют индивидуальной идентичности `__gc`. Литералы `<...>` и операторы каналов требуют компилятора. Атомарность при аварии, блокировки писателей между процессами и адаптер больших файлов остаются будущей работой. Нативное исполнение Windows/macOS/Android, полная совместимость Flash и JIT запрошенных архитектур этими Linux-тестами не подтверждаются.

Архив: `FlashVM-with-history-v0.3.zip`. Внутри отслеживаемые исходники, статические зависимости, документация/тесты и полный внутренний `.git`, включая существующий приватный stash. Бинарные результаты сборки не включены. Проверка архива: ZIP CRC, чистое распакованное дерево, совпадение HEAD, целостность всех Git-объектов, наличие stash и проверка внешних исходников.
