# Явные SDK/toolchain файлы

[English](README.md). [Полное руководство](../BUILDING.ru.md),
[доказательства и ограничения](VALIDATION.ru.md).

[explicit.cmake](explicit.cmake) принимает абсолютные пути компиляторов/SDK,
сохраняет параметры в try_compile и разделяет хостовые программы и целевые
библиотеки. Копируйте файл явно к отделённому проекту; соседние исходники ему
не нужны. Для NDK используйте toolchain самого NDK.

Версия шаблона: 0.1.0. C-only проектам C++ SDK не нужен; если проект включает
C++, FVM_TARGET_CXX обязателен. Вместо неявного host g++ конфигурация выдаёт
явную ошибку FVM_TARGET_CXX_REQUIRED.
