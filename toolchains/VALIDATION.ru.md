[English](VALIDATION.md). База серии — GitHub master
b0884d12244c72680dd8941e46379de40e942e6a (VM v0.645).

| Цель | Минимальное статическое ядро FlashVM | Реальный C89-клиент | Фронтенды/FIR/оптимизатор/SWL | Общий C-пример IDE |
| --- | --- | --- | --- | --- |
| Linux ARM64, musl | собрано | слинкован | собраны/слинкованы | слинкован |
| Linux RISC-V64, musl | собрано | слинкован | собраны/слинкованы | слинкован |
| Windows x64, GNU ABI | собрано | слинкован | собраны/слинкованы | слинкован |

Для каждой цели получены четыре синтаксических executable, fir1/fir1_source/
fir1_opt и swl. Проверены отдельные проекты и общий IDE с явным toolchain-файлом.
Архитектуры сверяются по ELF/PE, не имени файла. Пробы C/C++ определили целевой
8-байтовый указатель. Это сборки из Linux, без исполнения чужих бинарников.

Windows SAPI fixture компилируется в строгом C++98 и линкуется с реальным SDK.
Независимые младшее/старшее слова подтверждают recognition bit 38 и reserved bits
30/33. Старый исходник не проходит строгий Clang из-за ull в макросе SPFEI.
Новая запись сохраняет те же биты. Диагностика ULLONG_MAX неизменённого zlib
ограничена его Windows-целью; строгие C89/C++98 проверки своего кода сохранены.
Исходники SDK не изменялись и не импортировались.

Хостовые инструменты: CMake/CTest 4.4.4, внешний bhgv/coco-r-C revision
b91b65233c264d92c63a5c8cd855e7fc784bca53, clang-format 23.1.3, Zig 0.13.0 /
Clang 18.1.6. В окружении недоступен /proc/self/exe: для Zig потребовалась только
хостовая адаптация поиска собственного пути и wrapper, исключающий неподдержанный
диагностический -Wl,-v в пробах ABI CMake. TMPDIR/cache направлены в доступные
папки. Адаптации хоста, бинарники SDK/инструментов и генерируемые парсеры не
включены в исходники/патч. Это не подтверждение неизменённого stock Zig; обычная
SDK-установка использует свои доступные хостовые инструменты.

Нативно прошли 22 CTest C99-компонентов: 16 фронтендов, 3 FIR, 2 SWL, 1 общего
IDE. Семь тестов форматтера успешны; потоки токенов шести исходных грамматик,
C-прелюдий и действий после оформления совпали. FIR/SWL проверяют реальные трассы
FlashVM, объекты и ресурсы. Новая sanitizer-приёмка форматирования не заявляется.

VM собрана с NO_GRAPHICS/NO_FONTS/NO_IMAGE_CODECS/NO_SQLITE, с OS ports и render
jobs. Это не проверка AGG/Cairo/SDL/шрифтов/media SDK, устройств Windows speech,
Android NDK/APK/устройства, macOS SDK/подписи/нативного запуска, foreign JIT или
выпускных длительных испытаний. Команды Android/macOS — инструкция, не результат
исполнения. Все девять стадий открыты. [Инструкция сборки](../BUILDING.ru.md).
