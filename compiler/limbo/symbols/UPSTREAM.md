# Explicit source revisions

- Inferno experiment inspected at [371e3a94](https://github.com/bhgv/Inferno-OS-bhgv/tree/371e3a94ff35fe177143c8fea271114fb9b79b0e). It advanced since the earlier architecture revision; recheck the branch before importing runtime/JIT code.
- Existing [Debug interface](https://github.com/bhgv/Inferno-OS-bhgv/blob/371e3a94ff35fe177143c8fea271114fb9b79b0e/module/debug.m) and [implementation](https://github.com/bhgv/Inferno-OS-bhgv/blob/371e3a94ff35fe177143c8fea271114fb9b79b0e/appl/lib/debug.b) already provide process status, stop/start/continue/step, breakpoint and stack/heap access. Their /prog controls need a host/channel adapter; they are not automatically available in FlashVM.
- [wm/deb](https://github.com/bhgv/Inferno-OS-bhgv/blob/371e3a94ff35fe177143c8fea271114fb9b79b0e/appl/wm/deb.b), [debdata](https://github.com/bhgv/Inferno-OS-bhgv/blob/371e3a94ff35fe177143c8fea271114fb9b79b0e/appl/wm/debdata.b) and [debsrc](https://github.com/bhgv/Inferno-OS-bhgv/blob/371e3a94ff35fe177143c8fea271114fb9b79b0e/appl/wm/debsrc.b) are reference clients, not UI dependencies to import: they use Tk/Draw.
- [limbo/sbl.c](https://github.com/bhgv/Inferno-OS-bhgv/blob/371e3a94ff35fe177143c8fea271114fb9b79b0e/limbo/sbl.c) writes .sbl 2.1. The unchanged sblsrcconv body is read only by an optional explicit-path test harness, never copied into this component's Git source.
- [coco-r-limbo a7364dcd](https://github.com/bhgv/coco-r-limbo/tree/a7364dcdfe8b7926b0e8473cdc1b81797d380a89) is the existing C/Limbo generator port. Its C-host/C-output path was built and used for this reader. Native Limbo execution was not rerun here. C semantic actions are not automatically translated into Limbo.

No Inferno GUI/crypto code, Coco/R sources, templates, manuals or runtime binaries are vendored.
