# LIMBO

Версия 0.2.0. [English](README.md).

Независимый проект компилятора на C99. Сейчас реализован синтаксический
фронтенд: [грамматика, сборка и ограничения](frontend/README.ru.md).
Семантический анализ, AST, генерация байткода и SWF пока не реализованы.

Сборка из этой папки с теми же явными путями к генератору:

```sh
cmake -S . -B build \
  -DCOCOR_ROOT=/path/to/coco-r-C \
  -DCOCOR_EXECUTABLE=/path/to/coco-r-C/cocor
cmake --build build
ctest --test-dir build --output-on-failure
```

CLI: `--help`, `--version` (без входного файла; код 0).

## C API

`frontend/frontend.h`: `limbo_check(bytes, size, diagnostic)` и
`limbo_read(FILE*, diagnostic)` возвращают 1 при принятии, 0 при отказе.
Буфер и поток принадлежат вызывающему коду; библиотека не печатает сообщения,
не закрывает вход и не завершает процесс. Диагностика: код, строка/колонка,
байтовое смещение, сообщение. NULL вместо диагностики допустим. Максимум 2 MiB.
CMake target: `limbo_frontend`. Глобальные символы генератора имеют префикс языка;
несколько библиотек могут линковаться в одну IDE. Состояние сбрасывается перед
каждым вызовом, но один парсер требует внешней сериализации (не reentrant).
`tests/embed.c` проверяет восстановление после ошибки в одном процессе.
