# limbo_styx_client

[English](STYX-CLIENT.md) · [Заголовок](remote_owner.h) · [Реализация](remote_owner.c) · [Руководство](../../../disVM/examples/remote-scalar/STYX.ru.md)

```c
#include "remote_owner.h"
int limbo_styx_client(FILE *output, const LimboInterface *catalog,
    const char *include_name, const char *request, const char *reply,
    const char *request_tag, const char *reply_tag, char *error, size_t capacity);
```

Функция доступна в C99-библиотеке `limbo_remote_owner_lib`. Заимствованный
`catalog` описывает один модуль с одним экспортом `fn(int): int`. Допускаются
скалярные псевдонимы типов и константы. `include_name` задаёт имя исходного
интерфейса. Сгенерированный модуль также подключает `vfsnative.m`. `request`
и `reply` задают разные абсолютные пути VFS. Путь ограничен 255 байтами ASCII
из букв, цифр, точек, дефисов, подчёркиваний и косых черт. В имени include
косые черты запрещены. Теги задаются десятичными строками со значениями
от 1 до 4294967295.

При успехе функция возвращает 1 и пишет в заимствованный поток модуль с
исходным именем и сигнатурой. NULL запускает только проверку. Ошибка
параметров, конфликт имён или ошибка записи дают 0. Необязательный буфер
`error` имеет `capacity` байт вместе с завершающим нулём. При неверных
параметрах запись не начинается. Ошибка потока может оставить часть
вывода. Вызывающий владеет каталогом, потоком и публикацией результата
и синхронизирует доступ к общему потоку. Генератор не монтирует файловые
системы, не обращается к сети и не запускает Dis.
