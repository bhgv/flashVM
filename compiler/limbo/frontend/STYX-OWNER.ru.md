# limbo_styx_owner

[English](STYX-OWNER.md) · [Заголовок](remote_owner.h) · [Реализация](remote_owner.c) · [Пример](../../../disVM/examples/remote-scalar/STYX.ru.md)

```c
#include "remote_owner.h"
int limbo_styx_owner(FILE *output, const LimboInterface *catalog, const char *include_name,
    const char *implementation, const char *request, const char *reply,
    const char *request_tag, const char *reply_tag, char *error, size_t capacity);
```

Функция C99 из `limbo_remote_owner_lib` генерирует исполняемый модуль
владельца с одним экспортом `fn(int): int`. Заимствованный каталог, имя
include, абсолютные пути VFS и десятичные теги следуют правилам
[генератора клиента](STYX-CLIENT.ru.md). Владелец читает запрос и пишет ответ.
`implementation` задаёт путь для типизированного `load` у владельца, до
255 символов ASCII из букв, цифр, точек, дефисов, подчёркиваний и косых черт.

Выход NULL только проверяет параметры. Функция возвращает 1 при успехе
и 0 при неверном вводе, конфликте имён или ошибке потока. Буфер диагностики
необязателен, `capacity` учитывает завершающий нуль. Вызывающий владеет
параметрами, синхронизует работу с общим потоком и проверяет его закрытие.
При неверном вводе запись не начинается. Сбой потока может оставить префикс.

Сгенерированный Dis загружает реализацию и обрабатывает один допустимый
запрос. Он возвращает значение или преобразует исключение метода в код
ошибки 1. Генерация не выдаёт файлов и не запускает код. Монтирование
и запуск описаны в примере.
