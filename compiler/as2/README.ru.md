# AS2

Версия 0.2.6. [English](README.md).

Независимый проект компилятора на C99. Сейчас реализован синтаксический
фронтенд: [грамматика, сборка и ограничения](frontend/README.ru.md).
Семантический анализ, AST, генерация байткода и SWF пока не реализованы.

Сборка из этой папки с теми же явными путями к генератору:

```sh
cmake -S . -B build \
  -DCOCOR_ROOT=/path/to/coco-r-C \
  -DCOCOR_EXECUTABLE=/path/to/coco-r-C/cocor
cmake --build build
ctest --test-dir build --output-on-failure
```

CLI: `--help`, `--version` (без входного файла; код 0).

## C API

`frontend/frontend.h`: `as2_check(bytes, size, diagnostic)` и
`as2_read(FILE*, diagnostic)` возвращают 1 при принятии, 0 при отказе.
Буфер и поток принадлежат вызывающему коду; библиотека не печатает сообщения,
не закрывает вход и не завершает процесс. Диагностика: код, строка/колонка,
байтовое смещение, сообщение. NULL вместо диагностики допустим. Максимум 2 MiB.
CMake target: `as2_frontend`. Глобальные символы генератора имеют префикс языка;
несколько библиотек могут линковаться в одну IDE. Состояние сбрасывается перед
каждым вызовом, но один парсер требует внешней сериализации (не reentrant).
`tests/embed.c` проверяет восстановление после ошибки в одном процессе.

### Оператор in

Поддержан `in` в выражениях и различение `for-in`/обычного for. В заголовке
for до разделителя действует NoIn; скобки, аргументы, индексирование и литералы
восстанавливают обычную грамматику локально. Функция имеет свой контекст.
Производства: Relational, ForStatement, GroupedExpression, Arguments, Subscript.
Это проверка синтаксиса, не перечисление свойств и не lowering в FIR.

[Grammar](frontend/as2.atg): Relational/ForStatement. [Example](examples/in.as).

### Ограничения разбора для C API

Рекурсивные границы грамматики ограничены 512 активными вызовами, работа —
4000000 посещениями таких границ. Превышение возвращает -3/-4 в diagnostic.code,
а не завершает IDE; после отказа можно разбирать следующий файл. Счётчики и
Coco/R сбрасываются перед каждым вызовом. Координаты при ресурсном отказе могут
быть нулевыми. Точные лимиты — не число скобок: один уровень выражения проходит
несколько правил. Это ограничение реализации, не изменение синтаксиса языка.
Проверка/разбор по-прежнему задаются .atg, guard-функции написаны на C99.
