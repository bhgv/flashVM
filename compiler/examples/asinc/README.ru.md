# Пример синтаксиса `asinc`

[English](README.md) · [Контракт и статус](../../ASINC.ru.md)

[captured.as](captured.as) полностью прокомментирован. Coco/R-парсеры AS1/AS2/AS3
принимают именованную функцию, блок, лексические обращения и выражение-задачу.
Это **синтаксический** пример, а не готовый SWF/Dis: lowering замыканий/задач ещё
нет. Команды приведены в English README. Три `as*_parse` завершаются успешно;
`fir1_source` обязан явно отказать на первом префиксе, сохранив прежний output.fir.

Настоящий внекадровый callback с рисованием уже выполняет
[нативная проверка](../../../disVM/runtime/test_frame_free_drawing.c) через
существующий Async.post API. Инструкции запуска находятся в контракте.
