# Проекты компиляторов на C99

Версия 0.1.0. [English](README.md).

| Проект | Реализованный компонент |
| --- | --- |
| [AS1](as1/README.ru.md) | [Синтаксический фронтенд](as1/frontend/README.ru.md) |
| [AS2](as2/README.ru.md) | [Синтаксический фронтенд](as2/frontend/README.ru.md) |
| [Limbo](limbo/README.ru.md) | [Синтаксический фронтенд](limbo/frontend/README.ru.md) |

Каждый язык и каждый фронтенд отдельно конфигурируются CMake. Необязательный
CMakeLists.txt этой папки собирает три программы с теми же явными параметрами
внешнего генератора, что указаны в руководствах фронтендов. Здесь используется
C99; правила C89/C++98 для VM на компиляторы не распространяются. Общего C-runtime
и неявного подключения соседних исходников нет. Байткод/SWF пока не генерируются;
покрытие и ограничения описаны отдельно для каждого языка.
[Линковщик](../linker/README.ru.md) пока представлен независимой границей проекта.

При отделении сохранять общую корневую MIT LICENSE и уведомления авторов
генерируемого кода. Общая сборка рабочего пространства и история Git необязательны.
