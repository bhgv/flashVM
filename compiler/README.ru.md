Каждый язык и каждый фронтенд отдельно конфигурируются CMake. Необязательный
CMakeLists.txt этой папки собирает четыре программы с теми же явными параметрами
внешнего генератора, что указаны в руководствах фронтендов. Здесь используется
C99; правила C89/C++98 для VM на компиляторы не распространяются. Общего C-runtime
и неявного подключения соседних исходников нет. Эти четыре фронтенда проверяют синтаксис. Отдельный числовой адаптер
[fir1_source](../fir/v1/doc/SOURCE_SYNTAX.ru.md) действительно выдаёт FIR,
fir1 компилирует его в SWO, а [SWL](../linker/README.ru.md) линкует SWF.

При отделении сохранять общую корневую MIT LICENSE и уведомления авторов
генерируемого кода. Общая сборка рабочего пространства и история Git необязательны.

при отделении проекта. Генерируемый Coco/R и внешние библиотеки не форматируются.
