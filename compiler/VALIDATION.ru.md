# Проверка серии синтаксиса

2026-10-20, Linux C99; [English](VALIDATION.md).

- База: GitHub master `39921ad099fc74253b9f6c9d39b72687a520de34`.
- Внешний bhgv/coco-r-C: `b91b65233c264d92c63a5c8cd855e7fc784bca53`.
  Генерируемые парсеры и runtime в патч не включены.
- Обычная и санитарная сборки: по 22 успешных теста CTest — 16 компиляторов,
  3 FIR, 2 линкера, 1 общего C-примера IDE.
- Внутри FIR — по 732 проверки подпроцессов с реальным исполнением FlashVM,
  у линкера и ресурсов — по 97. Это внутренние проверки, а не дополнительные
  тесты в счётчике CTest.
- Включены ASan для кучи/глобальных данных и UBSan. Инструментирование стека и
  проверка утечек отключены из-за ограничений окружения: их покрытие не заявлено.
  Глубина разбора, бюджет работы и повторный вызов после отказа проверяются
  отдельно тестами встраивания на C.
- Скопированные и переименованные AS1/AS2/AS3/Limbo/FIR/линкер отдельно собраны
  и прошли тесты с явно указанным внешним генератором, без включения соседних
  исходников. Отделённый FIR проверен на генерацию объектов без линкера и VM.
- Общий C-пример IDE использует четыре синтаксических API, числовой компилятор,
  оптимизатор FIR, генератор SWO и SWL. Полученный SWF вывел `42` и `36`.
- Проверены 667 относительных ссылок документации. Сборки Windows и Android
  не запускались; приложенные команды Termux применяют серию Git.

Для повторения следуйте CMake/CTest-инструкциям проектов. Если стандартной
временной папки нет, задайте TMPDIR на доступную для записи папку. Интеграционные
проверки FIR явно принимают FIR_SWL и FIR_FLASHVM_RUNNER. Принятый синтаксис сам
по себе не подтверждает поддержку конструкции backend.
