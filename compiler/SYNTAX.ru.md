# Серия синтаксиса 0.3.1

[English](SYNTAX.md). Парсеры задаются читаемыми грамматиками Coco/R и собираются
внешним [bhgv/coco-r-C](https://github.com/bhgv/coco-r-C). Действия, преобразования
и библиотечные обёртки написаны на C99. Генерируемый runtime остаётся в сборке.

| Компонент | Расширение | Пример / грамматика |
| --- | --- | --- |
| AS1, AS2, AS3 | `in` в выражениях; локальный NoIn в инициализации for | [AS1](as1/examples/in.as), [AS2](as2/examples/in.as), [AS3](as3/examples/in.as); .atg каждого фронтенда |
| AS3 | Параметры по умолчанию и завершающий rest, возврат void, контекстные get/set и each, for-each, namespace/use/доступ, несколько catch | [Functions.as](as3/examples/Functions.as), [as3.atg](as3/frontend/as3.atg) |
| Limbo | Метки шести управляющих конструкций, непустые списки, разыменование, инициализаторы массивов и завершающая запятая, проверяемые формы срезов | [Syntax.b](limbo/examples/Syntax.b), [limbo.atg](limbo/frontend/limbo.atg) |

Четыре широких фронтенда проверяют синтаксис. Для генерации FIR пока доступен
отдельный числовой профиль: новые широкие конструкции не объявлены реализованным
backend. FIR компилируется в SWO; SWL собирает объекты, библиотеки и ресурсы в SWF.
Числовой профиль AS3 сохраняет совместимость с AVM1, без ABC. Фронтенда AS4 и
определённого диалекта AS4 в проекте нет.

Диагностики AS3 1201/1203 запрещают обязательный параметр после необязательного
и параметры после rest; 1202 отклоняет трёхчастный заголовок for-each. Limbo 1301
отклоняет `array[] of Type` без размера или инициализатора. Пустой список — `nil`;
`list of {}` отклоняется. Wildcard записывается `* =>`: слитное `*=>` начинается
с существующего токена `*=` по правилу самого длинного совпадения.

Каждый язык предоставляет C API `*_check` / `*_read`, которым пользуется CLI.
Глобальные данные парсера требуют внешней сериализации вызовов одного языка.
Последовательные вызовы, включая корректный ввод после ошибки, сбрасывают
состояние. Ввод ограничен 2 MiB UTF-8. Рекурсивные границы правил ограничены 512
активными вызовами (-3) и 4000000 посещениями (-4). При ресурсном отказе координаты
могут быть нулевыми. Действия охватывают всю группу альтернатив, чтобы каждому
успешному входу соответствовал один выход. Список параметров AS3 итеративный.

Тестируются принятие/отклонение, комментарии и восстановление NoIn, параметры и
агрегаты, усечённые файлы с таймаутами, глубокий ввод и исчерпание бюджета с
последующим корректным разбором в том же процессе. Отдельно проверяются генерация
FIR, const, диапазоны, профили, оптимизация и реальные трассы SWO/SWL/VM, включая
знаковый ноль, бесконечность и NaN.

Ограничения серии: явные AS-точки с запятой, без regexp/E4X/Vector/метаданных,
без полного анализа типов, символов и контекста; без общего backend модулей и
каналов Limbo. Подробное покрытие приведено в README каждого языка.
