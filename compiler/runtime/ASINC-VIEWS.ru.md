# Исполняемый прототип представлений захватов

[English](ASINC-VIEWS.md) · [Контракт языка](../ASINC.ru.md)

`asincviews.dis` — обычный Limbo-модуль на нашем интерпретаторе/JIT DisVM.
Он исполняет протокол обмена **неизменяемыми строковыми скалярами**, но пока не
запускает синтаксис AS asinc, не подключён к реальным кадрам и не создаёт потоки ОС.
Нативные указатели, Draw/Tk и новые Dis64 ABI ему не нужны.

Владелец0 и восемь задач имеют16 привязок. BeforeFrame передаёт собственные dirty
изменения задач владельцу. AfterFrame обновляет чистые представления задач.
Получение версии не создаёт dirty-записи и сохраняет исходного автора/версию.
Запись задачи во время кадра сохраняется, если кадр менял другую привязку.
Повторное присваивание того же значения не создаёт новой версии ячейки.
Неизменённые ячейки разделяются, изменённая заменяется новой: scalar copy-on-write.
COW графов объектов, вложенных путей и сохранение изменяемых aliases пока не сделаны.

Конфликт нескольких dirty-писателей одной привязки возвращает Conflict **до**
частичных изменений. Политика победителя не назначается. Discard(task,binding)
явно отбрасывает локальную запись задачи и принимает текущую версию владельца.

Subscribe(target,binding,"on"/"off") включает наблюдение удалённых публикаций.
Drain(target) возвращает очередь событий конкретного подписчика: привязка, автор,
версия записи, старое/новое значение. Собственные записи, равные значения и эхо не
вызывают события. Отписка запрещает будущие события, уже поставленные сохраняются.
Обработчики callbacks и intrinsic onChangeVarAsinc ещё предстоит подключить.

Глобальная очередь ограничена256 событиями. Перед фазой проверяется её полная
ёмкость. Full сохраняет фазу, все значения и dirty-биты: можно забрать события
и повторить обмен. События относятся к публикациям, не к каждому промежуточному
присваиванию. Invalid/Stale/Conflict/Full логически атомарны; ошибки выделения
памяти VM этот модуль в восстанавливаемые статусы не преобразует.

Snapshot возвращает отдельные массивы values/versions/sources/dirty с индексом
`task*Bindings+binding` и active-состояния задач. Массивы нельзя использовать для
изменения владельца. Это согласованный снимок текущих представлений, включая
собственные неопубликованные записи; будущий публичный просмотр должен отдельно
обозначать private и last-published значения.

Spawn допускается между кадрами для ещё не использованных ID1..8. Retire снимает
корни представления, dirty, подписки и его события; ID не переиспользуется.
У других подписчиков могут оставаться события от уже завершённого автора.
Shutdown подтверждается перед завершением владельца. Мутации требуют точной
revision, Snapshot — нет. Успешная команда увеличивает revision даже для пустого
Drain или равного Write. Владелец пишет только внутри фазы кадра. Строка — до4096
символов. Ответы обязательно принимать; процесс Dis здесь планируемый, а не поток ОС.

Команды сборки, запуска установленного SDK и подробный перечень сценариев приведены
в [английском README](ASINC-VIEWS.md). В пакете рядом находится подробно
прокомментированный acceptance.b; исходный модуль — source/asincviews.b,
интерфейс — include/limbo/asincviews.m. Проверка использует настоящие Dis-каналы,
интерпретатор и JIT; это отдельный этап до compiler closure/task lowering.
