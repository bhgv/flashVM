## Параметры

| Параметр | Объявление | Назначение и ограничения |
| --- | --- | --- |
| `output` | `void *output` | Буфер/cursor этого алгоритма; направление, границы и удерживаемые views заданы описанием. |
| `capacity` | `size_t capacity` | Фактическая ёмкость буфера вызывающего; выход за неё недопустим. |
| `used` | `size_t *used` | Место вызывающего для точного принятого/выданного размера; правила публикации при отказе приведены ниже. |

## Описание

walk_export: реализация walk/wire и нативное состояние.

### Сохранённый контракт implementation/header

EN/RU: Encode active scalar history into caller bytes;1 success/0 invalid/capacity/local-only identity.
used receives exact extent only on success. No pointers/layout serialized; empty history is valid.
Кодировать active scalar history в bytes;1/0 invalid/capacity/local-only, used меняется лишь при success.

## Возвращаемое значение

`int`; прямые константы результата тела: 0, 1. Пересылаемый результат сохраняет статус вызываемого API.

## Ошибки и владение

Соблюдать точный контракт выше: overlap input/output, capacity, отмену и правила освобождения. Протокольное подтверждение, результат native queue и завершённый удалённый эффект — разные результаты. Уведомление не даёт прав, неопределённая запись не повторяется автоматически.
