# styxclientmkdir

[English](styxclientmkdir.md) · [Заголовок](../../client/client.h) · [Исходник](../../client/open.c)

Подключите хостовую цель `Styx::client`. Передайте неоткрытый fid каталога,
непустое имя короче `STYX_NAME_MAX` байтов, права в пределах 0777 и место
для результата. Имя исключает косую черту, точку и две точки. Фактические
права определяет другая сторона. Функция отправляет один `Tcreate`
каталога для чтения и ждёт до истечения срока запроса.
Подтверждение возвращает единицу. Тот же fid обозначает открытый каталог.
Сериализуйте работу с ним и закрытие. При неопределённости освободите fid
и проверьте родительский каталог.
