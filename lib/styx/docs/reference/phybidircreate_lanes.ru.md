# phybidircreate_lanes

[English](phybidircreate_lanes.md) · [Заголовок](../../remote_phy/mux/bidir.h#L34) · [Реализация](../../remote_phy/mux/life.c) · [Кадры](../../remote_phy/mux/pump.c)

```c
#include <mux/bidir.h>

PhyBidir *phybidircreate_lanes(RemotePhy *carrier, size_t capacity, unsigned lanes);
```

Операция всегда принимает владение подключённым, надёжным и упорядоченным
байтовым `carrier`. `capacity` задаёт ёмкость каждой очереди в каждом
направлении в байтах от 1024 до 1048576. `lanes` выбирает два или три
потока с номерами от нуля. Первые два готовы сразу. Дополнительный выдаёт
кредит только после взятия через `phybidirchannel`. Перед взятием согласуйте
его с другой стороной. Исходный двухпоточный профиль доступен через
`phybidircreate` с тем же форматом кадров.

Результат — свой мультиплексор либо NULL при ошибке аргументов,
выделения памяти или запуска потока. Владелец выдаёт логические потоки
и вызывает `phybidirfree` после завершения их диспетчеров. Нативный поток
передаёт байты независимо от пользователей. Выданные объекты удерживают
время жизни носителя до своего закрытия. В хостовой сборке линковать с
`Styx::bidir`.
