# styxclientcreate

[English](styxclientcreate.md) · [Заголовок](../../client/client.h) · [Исходник](../../client/open.c) · [Открыть существующий fid](styxclientopen.ru.md)

```c
#include <client.h>
int styxclientcreate(StyxFid *directory, const char *name, unsigned permissions,
    int mode, StyxTransfer *result);
```

Подключите цель `Styx::client` для нативной сборки. Передайте неоткрытый
fid каталога, непустое имя дочернего узла короче `STYX_NAME_MAX` байтов,
права в пределах 0777, режим доступа от 0 до 2 и место для результата.
Имя не может содержать косую черту либо быть `.` или `..`.

Вызов отправляет один `Tcreate` и ждёт до окончания срока запроса.
При успехе возвращается единица, а переданный fid указывает на открытый
дочерний узел. Владение fid остаётся у вызывающего. При отказе возвращается
ноль. Отсутствующее или непригодное подтверждение может заблокировать
дальнейшие операции с fid. Проверьте `result` перед повтором и освободите
fid через clunk. Сериализуйте другие операции с тем же fid и clunk.
