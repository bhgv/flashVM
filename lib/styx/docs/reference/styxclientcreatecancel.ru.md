# styxclientcreatecancel

[English](styxclientcreatecancel.md) · [Указатель API](../index.ru.md) · [Создание с обычным сроком ожидания](styxclientcreate.ru.md)

```c
#include <styx/client/client.h>

int styxclientcreatecancel(StyxFid *directory, const char *name, unsigned permissions,
    int mode, StyxCancel *cancel, StyxTransfer *result);
```

Хостовая сборка C99, цель `Styx::client`.

| Параметр | Значение |
| --- | --- |
| `directory` | Свой неоткрытый fid каталога. Согласуйте его использование и clunk в одном потоке. |
| `name` | Заимствованное непустое имя одного потомка, кроме точки и двух точек, короче `STYX_NAME_MAX` байт. |
| `permissions` | Запрашиваемые биты прав обычного файла в пределах восьмеричного `0777`. |
| `mode` | Режим 9P. `0` чтение, `1` запись, `2` чтение и запись. Сервер может принимать меньше режимов. |
| `cancel` | Необязательный заимствованный одноразовый токен мультиплексного клиента. `NULL` сохраняет обычный срок ожидания и работает на старом транспорте. |
| `result` | Обязательный выходной `StyxTransfer`. Фиксирует подтверждение, отмену и возможное изменение. Число байт равно нулю. |

Функция отправляет один `Tcreate`. При `Rcreate` возвращает `1` и оставляет тот же fid открытым на новом файле. При локальном отказе, `Rerror`, отмене или отсутствии надёжного ответа возвращает `0`. Исходный ответ, полученный до завершения flush, определяет результат. Отправленный запрос без подтверждения выставляет `uncertain` и закрывает этому fid дальнейшие операции открытия и передачи данных. Fid остаётся у вызывающего, который обязан его освободить. Если остановка замечена до допуска операции, `Tcreate` не отправляется.

Используйте новый fid и токен, который может подать другой нативный поток. Функция в примере создаёт пустой файл и ставит закрытие писателя в очередь. Вызывающий удерживает `session` и переданный `stop` до возврата.

```c
int create_empty(StyxClient *session, StyxCancel *stop, StyxTransfer *out)
{
    StyxFid *directory = styxclientwalk(session, ".");
    int created = styxclientcreatecancel(directory, "empty", 0666, 1, stop, out);
    styxclientclunklater(directory);
    return created;
}
```

Проверяйте подробный результат, чтобы отличить отказ от операции с возможным эффектом. См. [отменяемое удаление](styxclientremovecancel.ru.md), [заголовок](../../client/client.h) и [реализацию](../../client/open.c).
