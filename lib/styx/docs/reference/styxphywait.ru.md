# styxphywait

[English](styxphywait.md) · [Объявление](../../server/phy/server.h#L227) · [Реализация](../../server/phy/backend.c#L229)

Используйте установленный `server.h` из `Styx::phy_server`.

```c
char *styxphywait(struct Styxserver *server, int timeout);
```

Нативный владелец ждёт полный запрос, продвижение вывода, пробуждение или истечение единого монотонного бюджета. `timeout` равен `-1` для бессрочного ожидания, нулю для шага без ожидания или положительному числу миллисекунд. Передайте живой сервер PHY. NULL означает возможность вызвать `styxprocess`, в том числе после истечения срока или при разрыве, который сообщит диспетчер. Неверный сервер, бюджет или ошибка часов дают строку ошибки. Функция не исполняет колбэки запросов. Ожидание и обработка выполняются одним владельцем.
