# styxclientremove

[English](styxclientremove.md) · [Заголовок](../../client/client.h) · [Исходник](../../client/clunk.c)

Подключите `Styx::client`. Передайте собственный fid и при необходимости
место для результата. Функция отправляет один `Tremove` и поглощает fid
при любом исходе. Только `Rremove` возвращает единицу. Потеря ответа
может оставить исход неопределённым. Повторно использовать fid нельзя.
Если закрытие на сервере не подтверждено, клиент ставит clunk в очередь.
Сериализуйте вызов со всеми остальными операциями на fid.
