# phytcplisten

[English](phytcplisten.md) · [Объявление](../../remote_phy/drivers/posix/tcp.h) · [Исходник](../../remote_phy/drivers/posix/tcp.c)

Подключите `<styx/phy/drivers/posix/tcp.h>` и `Styx::carrier` в хостовой сборке Linux64.

```c
int phytcplisten(const char *host, const char *port, unsigned *bound_port);
```

`host` задаёт интерфейс или локальный адрес. `port` — десятичная строка
от 0 до 65535. При `0` порт выбирает ОС. `bound_port` указывает на доступную
для записи переменную вызывающего. Разрешение имени может блокировать.
Функция использует первый адрес, на котором удалось открыть слушатель.

Успех возвращает собственный блокирующий слушатель с close-on-exec и записывает
выбранный порт. При ошибке функция возвращает `-1`, закрывает временные сокеты
и оставляет `bound_port` прежним. Например, откройте `"127.0.0.1", "0"`, затем
вызовите [`phytcpaccept`](phytcpaccept.ru.md). Закройте слушатель, когда новые
подключения больше не нужны. TCP передаёт данные открытым текстом, поэтому
адрес привязки определяет, из какой сети доступен слушатель.
