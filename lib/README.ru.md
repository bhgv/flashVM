# Независимые библиотеки связи

Copyright (c) 2026 bhgv

[English](README.md)

Это два отдельных исходных проекта для включения во внешние программы. Ни один
из них не собирает и не импортирует DisVM, FlashVM, Limbo, SWF, GUI или соседнюю
папку репозитория. Любую папку можно скопировать отдельно и собрать на новом месте.

| Проект | Назначение | Минимальный вариант | Нативный вариант |
| --- | --- | --- | --- |
| [Styx](styx/README.ru.md) | Исходные codec Inferno 9P2000, клиент/сервер, заменяемый физический носитель | C99, стандартные операции с байтами/строками, без OS/threads/allocator | Linux64, libc/libm/pthread; примерам необязательно нужен Python3 |
| [libunibus](libunibus/README.ru.md) | Существующие binary S-record codec, вложенные пространства клиентов, номера/CRC5, очереди тегов | C89 wire-функции без выделений памяти | C99/pthread очереди; необязательный POSIX-пример шлюза |

Пример соединения библиотек использует только wire-интерфейс. Это не зависимость
при линковке: шлюз Unibus не линкует libstyx, сервер Styx не линкует Unibus. Одни
и те же модели файлового сервера можно выдавать обычным 9P либо в явно согласованных
вложенных S-записях.

## Происхождение исходников

В `SOURCES.jsonl` указаны исходные пути, checksums и явные преобразования экспорта.
Это комплекты исходников для внешних проектов, а не скрытые includes к движкам.
Существующие публичные имена сохранены, чтобы выделение не меняло wire-формат.

Команда `python3 lib/export.py --check` проверяет выделение по каноническим
реализациям. Это инструмент сопровождения рабочего репозитория, не зависимость
сборки скопированной библиотеки. Лицензии Inferno сохранены; MIT основного проекта
не заменяет лицензии импортированных компонентов.

## Проверка

У каждого пакета собственные CMake/CTest. Дополнительная межпроектная проверка:

```sh
python3 lib/tests/interoperability.py build/standalone-styx build/standalone-unibus
```

Она прогоняет пять моделей файловых серверов через отдельно связанные проекты,
включая двух клиентов с одинаковыми внутренними tag/fid. Это дополнение к их
самостоятельным проверкам, а не замена этих проверок.
