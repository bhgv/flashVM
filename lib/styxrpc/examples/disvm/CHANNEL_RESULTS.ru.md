# Каналы результата вместе с копиями и изменениями графа

[English](CHANNEL_RESULTS.md) · [Примеры SDK](../README.ru.md) · [Контракт провайдера](../../reference/channel_module_init.ru.md)

Нативный клиент Limbo загружает тот же скомпилированный интерфейс у двух провайдеров. Первый — SWF, собранный из исходника AS2 и запущенный в штатном плеере FlashVM. Второй — программа C с отдельно собранным хостовым SDK. Оба возвращают кортеж с алиасом ref и двумя очередями, двустороннюю строковую очередь и двусторонний rendezvous для int.

## Сборка и запуск

Запускайте из корня репозитория. В примерах используются собранные нативные DisVM и Limbo bootstrap, парный плеер FlashVM и инструменты AS2, FIR и SWL. Для C настройте [хостовый SDK](../../README.ru.md#сборка) с `STYXRPC_EXAMPLES=ON` и соберите цель `styxrpc-channel-results-device`.

```sh
python3 lib/styxrpc/tests/flashvm/mixed_pair.py \
    --source disVM --runtime build/disvm/disvm \
    --limbo build/disvm/bootstrap/limbo-bootstrap \
    --player build/flash/flashvm_styx_player \
    --as2 out/as2/as2_viewc --fir out/fir/fir1 \
    --fir-opt out/fir/fir1_opt --swl out/linker/swl --result-channels
```

```sh
python3 lib/styxrpc/examples/disvm/channel_results.py \
    --source disVM --runtime build/disvm/disvm \
    --limbo build/disvm/bootstrap/limbo-bootstrap \
    --device build/rpc/styxrpc-channel-results-device
```

Добавьте `--jit` для JIT. Флаг `--tcp` включает локальный TCP. Без этих параметров работают интерпретатор и Unix-сокет. В обоих сценариях появляется `PASS native result-channels RPC paired VMs`. Запуск с C также требует `PASS independent C result provider` от провайдера. Ошибка обмена, отзыва или завершения процесса приводит к отказу. Оба сценария закрывают подключение и удаляют временный каталог.

## Ход типизированного вызова

1. [Контракт Limbo](../../tests/flashvm/result-channels_pair.b) объявляет `compose(box, option, absent)` со схемой аргументов `(r[i]is)` и результата `((r[i]a[c[i]]c[s]))`. `absent` — строка nil, которую AS получает как `null`. Это явное пустое значение для канальных позиций в SWF, собранном фронтендом View. [Точка входа AS2](../../tests/flashvm/result-channels_pair.as) публикует точную скомпилированную сигнатуру под именем `channel-results.dis`.
2. [Колбэк AS](../../tests/flashvm/result-channels_compose.as) увеличивает поле исходной записи на пять. Он возвращает запись, массив с двумя алиасами одной очереди Int32 и nil, а также отдельную строковую очередь. Колбэк C применяет [`styxrpc_graph_diff`](../../reference/graph_diff.ru.md) с позиционным ID ref и записывает ключи группы в потомка результата.
3. Провайдер проверяет результат и обновления вместе. Каждая живая позиция получает новый токен модуля. Клиент присваивает поле через возвращённый алиас и видит его у исходной записи. Число 71 приходит из первой очереди, `"label"` из второй. Отправка через один числовой алиас читается через другой.
4. Следующая попытка готовит изменение ref и возвращает ошибочный результат. AS отклоняет описатель с девятью слотами, C выдаёт один ключ в позициях с разными типами. Клиент получает удалённую ошибку, а значение записи равно 41. Третий вызов возвращает только nil в канальных позициях и обновляет поле до 46 без аренды.

## Два направления после возврата колбэка

[Строковый инициализатор](../../tests/flashvm/result-channels_buffered.as) сохраняет свой конец очереди и возвращает его из метода. Он ставит `"hello"` в исходящий буфер на один слот. Вторая отправка возвращает false. Limbo считывает начальное значение и отправляет `"from-dis"` в другую сторону. Между кадрами код AS2 принимает его из входящего FIFO и отвечает `"echo:from-dis"`.

[Инициализатор rendezvous](../../tests/flashvm/result-channels_meeting.as) создаёт конец с нулём слотов. В `alt` Limbo одна ветка отправляет по этому каналу результата, а другая ждёт отдельный локальный канал. Срабатывает отправка удалённому владельцу. Второй `alt` принимает сумму 47. Владелец хранит вычисленный ответ, пока отправка возвращает false, и освобождает его после подтверждения. В проверке используются непустая строка и ненулевые числа, чтобы воспользоваться условиями View. В обычном AS2 сравните результат опроса с `undefined`, чтобы различить отсутствие значения и принятые null, ноль или пустую строку.

```limbo
# Локальный канал не готов. Владелец принимает удалённую отправку.
idle := chan of int;
alt {
sync <-= 42 => ;
unexpected := <-idle => raise "idle branch selected";
}
```

[Провайдер C](channel_results_device.c) создаёт модуль с теми же сигнатурами и собственным реестром. Он обрабатывает очереди между вызовами [`styxrpc_server_step_for`](../../reference/server_step_for.ru.md). Публикация принадлежит выдавшему её fid функции. Гость освобождает алиасы каналов, а проба `retired` подтверждает отзыв обоих результатов. Провайдер сначала уничтожает сервер, затем снимает две ссылки владельца и освобождает модуль и транспорт.
