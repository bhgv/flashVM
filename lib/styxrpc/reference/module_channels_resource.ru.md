# styxrpc_module_channels_resource

[English](module_channels_resource.md) · [libstyxrpc](../README.ru.md)

## Синтаксис

```c
#include <styxrpc/module_channels.h>
StyxRpcResource styxrpc_module_channels_resource(StyxRpcModuleChannels *channels);
```

Получите описатель файла `.unibus` модуля. `channels` — инициализированный
реестр, который заимствуют все fid шины. Функция возвращает описатель
по значению. Держите реестр и массив в памяти, пока узел опубликован.
Колбэк открытия отклоняет отсутствующий или неинициализированный
реестр и режимы без одновременного чтения и записи.

У нового fid одна попытка входа. Первая запись должна содержать ровно
16 байтов токена со смещения ноль. После отказа это открытие уже
не обслуживает операции. При успехе выполняется колбэк открытия ресурса,
если он задан. Следующая запись начинается со смещения 16. Шина вычитает
длину токена перед вызовом колбэка ресурса. Ответ читается со смещения
ноль. Ресурс обрабатывает позиционные чтение и запись и владеет данными
операции. Получение описателя обходится без ввода-вывода. При открытии
диспетчер выделяет обёртку fid и вызывает колбэки синхронно.

Библиотека `StyxRpc::serve`.
