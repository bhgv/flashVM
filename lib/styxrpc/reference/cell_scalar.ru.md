# styxrpc_cell_scalar

[English](cell_scalar.md) · [Заголовок](../include/styxrpc/named_cell.h) · [Реализация](../src/named_cell_wire.c) · [Ячейки](named_cell.ru.md)

Передайте заимствованный кадр и число его байтов. Единица означает полный поддерживаемый скаляр, ноль — отказ. Проверяются размеры фиксированных форм и предел строки с длиной. I/O не выполняется. Подключите `StyxRpc::rpc`.
