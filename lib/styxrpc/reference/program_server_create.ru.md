# styxrpc_program_server_create

[English](program_server_create.md) · [libstyxrpc](../README.ru.md) · [Объявление](../include/styxrpc/program.h#L127) · [Реализация](../src/serve.c#L350)

## Синтаксис

```c
#include <styxrpc/program.h>
StyxRpcServer *styxrpc_program_server_create(struct RemotePhy *phy, StyxRpcPrograms *programs);
```

Обслуживает реестр процессов с выдачей временных PID из другого потока. Линкуйте `StyxRpc::serve` из хостовой сборки. До создания сервера [инициализируйте](programs_init.ru.md) `programs` с выделенными хостом слотами и добавьте постоянные регистрации. В `phy` передайте разрешённый надёжный упорядоченный поток Styx на встречной половине соединения. Вызов принимает владение `phy` при любом исходе и заимствует реестр со слотами до уничтожения сервера.

Возвращает диспетчер либо NULL при неверной инициализации, ошибке выделения памяти, мьютекса или настройки носителя. Поток-владелец выполняет [шаги сервера](server_step.ru.md). Сервер держит свой мьютекс при обработке запроса и освобождает его на время ожидания транспорта. Память реестра должна оставаться на месте. В это время выдавайте и отзывайте PID через синхронизированные функции. Колбэки ресурсов должны быстро возвращать управление и не могут повторно входить в API реестра того же сервера. Передавайте сервер для [уничтожения](server_destroy.ru.md), когда все вызовы закончены и выдачи отозваны.

[Проверка на C](../tests/program_server.c) показывает настройку пары сокетов и остановку диспетчера. [Выдать PID](program_server_grant.ru.md) · [Отозвать PID](program_server_revoke.ru.md)
