# styxrpc_module_exports

[English](module_exports.md) · [Заголовок](../include/styxrpc/module_client.h) · [Реализация](../src/client_exchange.c)

```c
StyxRpcStatus styxrpc_module_exports(struct StyxClient *session, const char *path,
    uint32_t pid, StyxRpcModuleExports *out);
```

Прочитать опубликованный интерфейс видимого модуля по относительному пути.
Функция удерживает один fid каталога, пока читает профиль и проверяет узлы
функций. Для контекстного профиля передайте встречный PID вызывающей стороны,
для остальных вызовов передайте ноль. При успехе `STYXRPC_OK` в `out`
записываются контракты с собственными именами. Сохраняйте адрес результата
пока используете указатели на имена. Недоступный или неподдерживаемый
интерфейс даёт `STYXRPC_INVALID` и сохраняет `out`. Операция может ждать
сессию и не запускает экспортируемые функции.
