# styxrpc_channel_invoke

[English](channel_invoke.md) · [Объявление](../include/styxrpc/channel_client.h#L26) · [Реализация](../src/channel_client.c) · [Описание аренды](channel_leases.ru.md)

Подключите `StyxRpc::launch`.

```c
#include <styxrpc/channel_client.h>
StyxRpcOutcome styxrpc_channel_invoke(const StyxRpcManagedTarget *target, const void *arguments,
    size_t size, void *reply, size_t capacity, StyxRpcLeasedReply *result);
```

Передайте смонтированный `target` с точным путём модуля, именем экспорта, подписью Limbo, схемой, ненулевым опубликованным PID и бюджетом опроса 1–60 000 мс. `arguments` содержит подряд записанные типизированные аргументы, для пустого списка допустимы `NULL, 0`. `reply` указывает на отдельный буфер записи длиной 1–65 536 байт. Контекстный профиль принимает копируемые значения, графовые ref, гибридные таблицы и каналы в допущенных позициях. Вызывающий владеет сессией, сериализует вызовы и сохраняет встречную публикацию.

`STYXRPC_CALL_OK` записывает в `result` представления результата и обновлений из `reply`, копию разных маршрутов и одну собственную ссылку на аренду при возврате канала. Освободите её через [lease release](channel_lease_release.ru.md). До записи функция сверяет контекстное предложение и оба маркера по одному fid модуля. `STYXRPC_CALL_NOT_SENT` означает подтверждённый отказ до отправки. `STYXRPC_CALL_REMOTE_ERROR` подтверждает удалённую ошибку. При `STYXRPC_CALL_UNCERTAIN` исход неизвестен. Функция отправляет один вызов. Для локальных очередей аргументов используйте [вызов с областью](argument_scope_invoke.ru.md).

[Исполняемая проверка](../examples/disvm/routed_client.c)

В `result->updates` находится запись с тегом 19. Она заимствует `reply` даже при пустой аренде. Подготовьте её дочерние изменения по исходному графу перед применением к данным приложения. Повторные ссылки результата могут использовать исходные индексы аргументов. SDK проверяет идентичность, маршруты и обновления до выдачи результата. Пересоберите вызывающий код с текущим `StyxRpcLeasedReply`. [Проверяемый индекс обновления](graph_update_index.ru.md) · [Пример C](../examples/disvm/LIVE_STAGE.ru.md#клиент-c-с-нативной-disvm).
