# styxrpc_cell_create_until

[English](cell_create_until.md) · [Объявление](../include/styxrpc/named_cell.h#L66) · [Реализация](../src/named_channel_client.c#L240)

Создаёт ячейку с отменяемым открытием, запросом и чтением жетона.

## Синтаксис

```c
#include <styxrpc/named_cell.h>

StyxRpcIoOutcome styxrpc_cell_create_until(struct StyxClient *session,
    const void *frame, size_t size, void *token, StyxRpcVfsFile **out,
    StyxRpcNamedStop stop, void *state);
```

## Доступность

Хостовый C SDK, цель `StyxRpc::launch`. Нужны подключённый клиент Styx и поддержка общих ячеек на `/.channels` у провайдера. Пример проверен с Linux64 и DisVM.

## Параметры

| Имя | Описание |
| --- | --- |
| `session` | Заимствованный подключённый клиент службы `/.channels` выдавшей стороны. Удерживайте его до возврата. |
| `frame` | Заимствованный кадр значения с тегом. Доступен для чтения до возврата. |
| `size` | Длина кадра вместе с тегом от 1 до `STYXRPC_NAMED_MAX` байтов. Дополнительные ограничения зависят от тега. |
| `token` | Записываемый буфер на `STYXRPC_CELL_TOKEN` байтов (24). Заполняется при успехе. |
| `out` | Записываемый указатель. Получает собственный fid чтения и записи только при успехе. |
| `stop` | Необязательный колбэк `StyxRpcNamedStop` в потоке вызова. Ненулевой результат запрашивает остановку. NULL оставляет обычное блокирующее ожидание. |
| `state` | Заимствованный контекст `stop`. Допустим NULL, если колбэк его принимает. Удерживайте до возврата. |

## Возвращаемое значение

| Результат | Условие |
| --- | --- |
| `STYXRPC_IO_OK` | Оба выхода заполняются после получения полного жетона. `*out` принадлежит вызывающему. |
| `STYXRPC_IO_NOT_OPEN` | Неверные аргументы, недопустимый локальный кадр или недоступная служба. |
| `STYXRPC_IO_FAILED` | Определённый отказ, неполный подтверждённый обмен или неверный ответ с жетоном. |
| `STYXRPC_IO_CANCELLED` | Остановка при обходе, открытии, отправке создания или чтении жетона. |
| `STYXRPC_IO_UNCERTAIN` | Команда или ответ остались без надёжного положительного подтверждения. |

## Поведение и время жизни

Используйте раздельное хранилище для `token` и `out`. При отказе оба выхода сохраняются. Отменённый запрос мог создать ячейку. Временный fid удерживает её до получения закрытия сервером. Закройте выданный fid после получения аренды остальными участниками.

Колбэк должен завершаться быстро и не обращаться к той же сессии. В мультиплексированной сессии ожидающий запрос можно отменить по тегу. В последовательной сессии флаг проверяется между обменами. Освобождение временного fid может продолжиться после возврата.

## Пример

Передайте подключённую сессию. В полном примере определён колбэк срока и показано закрытие аренды после передачи жетона.

```c
unsigned char token[STYXRPC_CELL_TOKEN];
const unsigned char initial[] = {STYXRPC_NAMED_BOOLEAN, 1};
StyxRpcVfsFile *owner = NULL;
StyxRpcIoOutcome result = styxrpc_cell_create_until(session, initial,
    sizeof(initial), token, &owner, deadline_reached, &end);
```

После успеха удерживайте `owner` при передаче жетона. В полном примере он закрывается после подтверждения новой аренды.
