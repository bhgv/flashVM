# styxrpc_module_open

[English](module_open.md) · [API](../include/styxrpc/module_client.h) · [styxrpc_module_check](module_check.ru.md)

`styxrpc_module_open(session, path)`

Пройти видимый относительный путь модуля в существующей сессии. Сервер должен выдать каталог с правами чтения и поиска.

Однократно разрешить каталог для последующих проверок интерфейса и вызовов.

При успехе вернуть свой неоткрытый fid, при отказе поиска, прав или проверки метаданных вернуть NULL. Fid удерживает соединение. Закрыть через styxclientclunk или отложить закрытие через styxrpc_vfs_close. Открытие и освобождение сериализуются со всеми заимствованиями. Возможны ожидания Styx.
