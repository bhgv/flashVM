# styxrpc_cell_attach_until

[English](cell_attach_until.md) · [Объявление](../include/styxrpc/named_cell.h#L74) · [Реализация](../src/named_channel_client.c#L283)

Получает независимый fid ячейки с поддержкой отмены.

## Синтаксис

```c
#include <styxrpc/named_cell.h>

StyxRpcIoOutcome styxrpc_cell_attach_until(struct StyxClient *session,
    const void *token, StyxRpcVfsFile **out, StyxRpcNamedStop stop, void *state);
```

## Доступность

Хостовый C SDK, цель `StyxRpc::launch`. Нужны подключённый клиент Styx и поддержка общих ячеек на `/.channels` у провайдера. Пример проверен с Linux64 и DisVM.

## Параметры

| Имя | Описание |
| --- | --- |
| `session` | Заимствованный подключённый клиент службы `/.channels` выдавшей стороны. Удерживайте его до возврата. |
| `token` | Заимствованный жетон из `STYXRPC_CELL_TOKEN` байтов (24). До возврата удерживайте аренду или ссылку переданного дескриптора. |
| `out` | Записываемый указатель. Получает собственный fid чтения и записи только при успехе. |
| `stop` | Необязательный колбэк `StyxRpcNamedStop` в потоке вызова. Ненулевой результат запрашивает остановку. NULL оставляет обычное блокирующее ожидание. |
| `state` | Заимствованный контекст `stop`. Допустим NULL, если колбэк его принимает. Удерживайте до возврата. |

## Возвращаемое значение

| Результат | Условие |
| --- | --- |
| `STYXRPC_IO_OK` | Выдаёт собственный fid после полного подтверждения жетона. |
| `STYXRPC_IO_NOT_OPEN` | Неверные аргументы или недоступная служба. |
| `STYXRPC_IO_FAILED` | Определённый локальный отказ или короткая подтверждённая команда. |
| `STYXRPC_IO_CANCELLED` | Остановка при открытии службы или передаче жетона. |
| `STYXRPC_IO_UNCERTAIN` | Запись жетона осталась без положительного подтверждения. Это возможно и при Styx `Rerror` для чужого или отозванного жетона. |

## Поведение и время жизни

Завершите присоединение до следующего запроса канала, который может освободить переданную ссылку. При отказе `out` сохраняется, временный fid закрывается. При успехе освободите собственный fid через `styxrpc_vfs_close`.

Колбэк должен завершаться быстро и не обращаться к той же сессии. В мультиплексированной сессии ожидающий запрос можно отменить по тегу. В последовательной сессии флаг проверяется между обменами. Освобождение временного fid может продолжиться после возврата.

## Пример

Передайте полученный живой жетон и подключённую сессию. Колбэк срока определён в полном примере.

```c
StyxRpcVfsFile *alias = NULL;
StyxRpcIoOutcome result = styxrpc_cell_attach_until(session, token, &alias,
    deadline_reached, &end);
```

Жетон выдаётся тем же реестром. После успеха используйте новую аренду либо удерживайте её для чтения по жетону.
