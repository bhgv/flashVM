# styxrpc_cell_get

[English](cell_get.md) · [Заголовок](../include/styxrpc/named_cell.h) · [Реализация](../src/named_channel_client.c) · [Ячейки](named_cell.ru.md)

Передайте собственный fid ячейки и указатели для кадра и длины. При `STYXRPC_IO_OK` вызывающий получает полный кадр во владение. Освободите кадр через free. Остальные исходы сохраняют выходные параметры. Сериализуйте работу с fid и подключите `StyxRpc::launch`.

Операции I/O используют сроки запросов сессии.
