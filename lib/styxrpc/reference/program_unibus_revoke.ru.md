# styxrpc_program_unibus_revoke

[English](program_unibus_revoke.md) · [libstyxrpc](../README.ru.md)

## Синтаксис

```c
#include <styxrpc/program.h>
int styxrpc_program_unibus_revoke(StyxRpcPrograms *programs, uint32_t pid);
```

Отозвать двусторонний `.unibus` процесса `pid` в инициализированном дереве
`programs`. Функция скрывает файл, обновляет ревизию каталога и синхронно
вызывает колбэк закрытия по одному разу на каждое активное открытие.
Если колбэк закрывает fid канала, ожидающие ветки отменяются до возврата.
Уже выполненные операции сохраняют свой эффект.

Старые fid отклоняют чтение, запись и открытие. Последующий clunk
освобождает состояние Styx без повторного вызова приложения. Для временной
выдачи весь каталог скрывается, его слоты освобождаются, а PID остаётся
зарезервированным до конца сессии. При отзыве обычного `.unibus` остальные
файлы процесса доступны, а слот шины остаётся зарезервированным. После возврата приложение может освободить состояние колбэков,
если его больше никто не использует.

Первый отзыв возвращает 1. Ноль означает отсутствие процесса или шины,
повторный отзыв либо неверное состояние реестра. Вызывайте функцию в
диспетчере вне колбэков целевого ресурса. Колбэки закрытия выполняются
синхронно и определяют, может ли функция блокироваться. Подключите
`StyxRpc::serve`.
