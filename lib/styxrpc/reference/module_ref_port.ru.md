# Позиционный порт ссылки на модуль

[English](module_ref_port.md) · [Парные ссылки на модули](module_refs.ru.md) · [Пример Limbo](https://github.com/bhgv/flashVM/blob/master/disVM/runtime/STYX-MODULE-REFS.ru.md)

Порт ссылок позволяет приложению работать с экспортированным Int32 через
байтовый дескриптор. Порт удерживает подключение к владельцу и использует
общий кодек ссылок, проверку прав и Qid. Один порт привязывается к одному
экспорту. Роль владельца и область задаются парой, а свой канал можно
закрыть после получения порта.

| Операция | Позиция | Байты |
| --- | --- | --- |
| Захват | Запись с 0 до привязки | Код `1`, режим `0` или `1`, затем канонический относительный путь без NUL |
| Приём | Запись с 0 до привязки | Код `2`, затем полный кадр именованного канала с тегом 9 |
| Местный захват | Запись с 0 до привязки | Код `3`, затем режим и путь в формате захвата |
| Чтение | Чтение с 0 после привязки | Ровно 4 байта знакового Int32, старший байт вперёд |
| Запись | Запись с 0 после привязки с правом записи | Ровно 4 байта нового значения, старший байт вперёд |
| Пересылка | Чтение с 4 и далее после привязки | Длина определяется чтением. Полный дескриптор начинается с 4 и оканчивается на EOF. |

Захват открывает исходный удалённый fid и собирает дескриптор из его Qid.
Приём копирует и проверяет дескриптор без обращения к владельцу.
[Парное открытие](module_ref_port_open_paired.ru.md) также допускает
дескрипторы экспорта местной стороны.
[Открытие с захватом](module_ref_port_open_owned.ru.md) позволяет выдавать
ссылки на местные экспорты с тем же Qid, что видит встречная сторона.
Первое чтение или запись значения
открывают точный экспорт и сверяют его Qid.
Если экспорт отозван или заменён, запрос отклоняется. Пересылка читает
сохранённый кадр.

Обычное встречное подключение к DisVM публикует область через `/.varref`
только для чтения. Гостевой адаптер DisVM выполняет команды порта через
независимый служебный fd на чтение и запись. Внешнее приложение на C может
использовать тот же интерфейс непосредственно через выданное подключение.
