# styxrpc_graph_update_fields

[English](graph_update_fields.md) · [Объявление](../include/styxrpc/graph.h#L76) · [Реализация](../src/graph.c)

Подключите `StyxRpc::rpc` и `styxrpc/graph.h`. Прочитайте одну запись UniBus
из разреженного списка проверенного [ответа](graph_read.ru.md). Передайте её
как `update` вместе с исходным типом `r[…]`. При успехе функция возвращает 1
и записывает в `fields` список выбранных развёрнутых типов, битовую маску и
закодированные дочерние записи. Неверное обновление даёт 0.

Представление дочерних записей заимствует память из обновления. Сохраняйте
буфер ответа, пока пользуетесь представлением. Кодек работает независимо от VM.
