# styxrpc_control_set_extension

[English](control_set_extension.md) · [API](../include/styxrpc/control.h#L51) · [Реализация](../src/control.c) · [Дерево управления](control_create.ru.md)

```c
void styxrpc_control_set_extension(StyxRpcControl *control,
    int (*command)(void *context, const char *bytes, size_t size));
```

Установите `command` в потоке владельца. NULL снимает расширение.
При NULL в `control` вызов ничего не меняет. SDK сначала обрабатывает
четыре штатных слова. Для остальных записей вызывает обработчик с исходным
контекстом управления и байтами команды без одного необязательного LF в
конце. Терминатор NUL не требуется. Байты заимствуются до возврата.
Возврат 1 подтверждает запись. Остальные ответы отклоняют её. Для каждой
команды открывайте отдельный fid записи со смещения ноль.

Приложение может добавить команды, например для выбора остановки
отладчика. Правила операций и состояние колбэка принадлежат приложению.
