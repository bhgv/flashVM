# styxrpc_named_send_until

[English](named_send_until.md) · [Named channels](named_channel.ru.md) · [Header](../include/styxrpc/named_channel.h)

Послать кадр именованного канала с отменой.

Подключите `styxrpc/named_channel.h`. Передайте открытый fid `file`,
полученный из `styxrpc_named_open`. Передайте непустой заимствованный буфер `bytes` и его длину `size` в байтах. Буфер должен оставаться действительным до возврата.

Опциональный колбэк `stop(state)` вызывается синхронно перед отправкой
запроса и между опросами ответа. Ненулевой результат отменяет местное
ожидание. Колбэк не должен обращаться к этому fid. `NULL` даёт обычное
блокирующее ожидание.

При `STYXRPC_IO_CANCELLED` закройте fid через `styxrpc_vfs_close`.
Если участники встретились до отмены, встречный эффект мог уже произойти.
Операцию нельзя повторять вслепую. Отмена не прерывает текущую транзакцию
Styx. Пока функция ожидает, другие fid могут обслуживаться между опросами.
Вызовы на одном fid должны выполняться последовательно.
