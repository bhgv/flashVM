# styxrpc_named_recv_until

[English](named_recv_until.md) · [Named channels](named_channel.ru.md) · [Header](../include/styxrpc/named_channel.h)

Принять кадр именованного канала с отменой.

Подключите `styxrpc/named_channel.h`. Передайте открытый fid `file`,
полученный из `styxrpc_named_open`. При успехе `bytes` получает собственный буфер для `free`, а `size` его длину. При ошибке оба выхода прежние.

Необязательный колбэк `stop(state)` работает в вызывающем потоке перед
отправкой и во время ожидания данных на мультиплексоре. Ненулевой результат
запрашивает отмену. Колбэк должен быстро завершаться и не обращаться к fid
операции. `NULL` даёт обычное блокирующее ожидание.

При `STYXRPC_IO_CANCELLED` закройте fid через `styxrpc_vfs_close`.
Если участники встретились до отмены, встречный эффект мог уже произойти.
Операцию нельзя повторять вслепую. Мультиплексор посылает `Tflush` по
тегу отправленного запроса. Другая сторона должна подтвердить flush в
срок сессии. На рабочей сессии запросы по другим fid могут выполняться
одновременно. Вызовы на одном fid выполняйте последовательно.
