# styxrpc_scalar_invoke

[English](scalar_invoke.md) · [Заголовок](../include/styxrpc/scalar_client.h) · [Реализация](../src/scalar_client.c)

Подключите `styxrpc/scalar_client.h` и цель `StyxRpc::launch` хостового SDK.

```c
StyxRpcOutcome styxrpc_scalar_invoke(struct StyxClient *session, const char *module,
    const char *name, uint32_t signature, int64_t argument, unsigned wait_ms, int64_t *result);
```

Передайте уже смонтированную сессию Styx, путь модуля относительно корня
монтирования и точное имя экспорта. `signature` принимает
`STYXRPC_INT_SIGNATURE` или `STYXRPC_BIG_SIGNATURE`. Значение `argument` должно
помещаться в выбранный знаковый тип. Функция заимствует аргументы. Она удерживает
один fid модуля для проверки `.interface` и поиска функции, затем владеет fid
функции до получения ответа. Используется та же проверка профиля, что и
в загрузчике DisVM. Этот API обслуживает экспорты без PID вызывающей стороны.
Модулю требуются права чтения и прохода, файлу функции — чтения, записи и исполнения.

| Результат | Значение |
| --- | --- |
| `STYXRPC_CALL_OK` | Ответ проверен, значение записано в `result`. |
| `STYXRPC_CALL_REMOTE_ERROR` | Получена запись с ошибкой удалённой функции. |
| `STYXRPC_CALL_NOT_SENT` | Попытки записать запрос функции не было. |
| `STYXRPC_CALL_UNCERTAIN` | Запрос начали передавать, проверенного результата нет. Функция могла выполниться. |

Ожидание готовности ответа ограничено `wait_ms` (1–60000 мс).
Операции Styx и clunk имеют собственные тайм-ауты сессии. Функция синхронна,
дописывает только остаток после подтверждённой короткой записи и не повторяет
вызов. Сессия должна жить до возврата из всех вызовов. Используйте выделенный
поток, если потоку событий или отрисовки нужно отвечать без задержки.
См. [C-клиент](../examples/client.c) и [публикацию модуля](scalar_module_init.ru.md).
