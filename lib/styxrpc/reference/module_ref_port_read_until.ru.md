# styxrpc_module_ref_port_read_until

[English](module_ref_port_read_until.md) · [Объявление](../include/styxrpc/module_ref_port.h#L77) · [Реализация](../src/module_ref_port.c#L168)

Прочитать знаковый Int32 или часть сохранённого кадра ссылки с колбэком остановки.

## Синтаксис

```c
#include <styxrpc/module_ref_port.h>

StyxRpcIoOutcome styxrpc_module_ref_port_read_until(StyxRpcModuleRefPort *port, uint64_t offset,
    void *bytes, size_t size, size_t *used, StyxRpcVfsStop stop, void *state);
```

## Доступность

Хостовый SDK C с библиотекой `StyxRpc::launch`. Нужна подключённая сессия и действительный порт. Нативная пара Linux64 проверена с DisVM и FlashVM.

## Параметры

| Имя | Описание |
| --- | --- |
| `port` | Заимствованный привязанный порт, действительный до возврата. |
| `offset` | Смещение в байтах. Ноль читает значение, от четырёх читается кадр описателя. Смещения 1–3 недопустимы. |
| `bytes` | Заимствованный изменяемый буфер на `size` байт. NULL допустим для нулевого чтения описателя. При отказе содержимое сохраняется. |
| `size` | Запрошенная длина в байтах. Для значения нужна длина 4. Чтение описателя может вернуть меньше байтов и остановиться в конце кадра. |
| `used` | Обязательный выход для числа байтов. Четыре при чтении значения, длина подтверждённого фрагмента или ноль в конце кадра. Ноль при отказе. |
| `stop` | Необязательный колбэк. Ненулевой результат запрашивает остановку. NULL использует обычные ожидания. |
| `state` | Заимствованный контекст колбэка до возврата. NULL допустим по контракту колбэка. |

## Результат

| Исход | Условие |
| --- | --- |
| `STYXRPC_IO_OK` | Выдано полное значение, часть описателя или конец кадра. |
| `STYXRPC_IO_NOT_OPEN` | Неверный порт, смещение, размер или другой аргумент. Исходный экспорт также мог стать недоступным или получить другой Qid. |
| `STYXRPC_IO_FAILED` | Сбой точной передачи, например короткий ответ или ошибка проверки метаданных. |
| `STYXRPC_IO_CANCELLED` | Вызывающий остановил ожидание до завершения. Значение не выдано. |
| `STYXRPC_IO_UNCERTAIN` | Достоверный ответ не получен. Содержимое буфера сохранено. |

## Поведение и время жизни

Для чтения значения порт при необходимости открывает экспорт по исходному описателю, читает четыре байта с нуля и копирует в `bytes`. Чтение кадра копирует сохранённые байты локально. Полный исходный ответ, полученный до `Rflush`, может успеть завершить чтение.

После отмены ожидающего удалённого доступа к значению или неподтверждённого исхода порт освобождает fid. Описатель и байты для пересылки остаются в порту. Следующее обращение сравнивает исходный полный Qid.path. Замена по тому же пути отклоняется.

Сериализуйте операции и закрытие порта. Колбэк остановки работает в вызывающем потоке и должен быстро возвращать управление. Мультиплексированный клиент может отменить ожидающий запрос по тегу. Последовательный клиент проверяет флаг между обменами. Для локальных колбэков порта SDK проверяет флаг на границах вызова. Отмена внутри них зависит от провайдера.

## Пример

Пример заимствует уже привязанный порт. Колбэк и срок ожидания даны в руководстве.

```c
unsigned char value[4];
size_t used;
StyxRpcIoOutcome status = styxrpc_module_ref_port_read_until(port, 0,
    value, sizeof(value), &used, deadline_reached, &deadline);
```
