# styxrpc_channel_import_element

[English](channel_import_element.md) · [libstyxrpc](../README.ru.md)

## Синтаксис

```c
#include <styxrpc/channel_call.h>
StyxRpcStatus styxrpc_channel_import_element(StyxRpcChannelCall *call, uint32_t via,
    const void *bytes, size_t size);
```

Вызывайте после успешного типизированного приёма, чтобы добавить вложенные ключи
из одного элемента. `call` — активный вызов на исходном встречном соединении
Styx. Выданный ключ приёма `via` определяет схему элемента. Передайте полный
буфер результата `bytes` и его размер в байтах `size`. Исходный запрос вызова
должен оставаться живым. Функция копирует ключи и типы и освобождает вызывающего
от необходимости удерживать буфер принятого элемента.

`STYXRPC_OK` добавляет разные ключи текущего вызова и объединяет псевдонимы
одного типа. `STYXRPC_INVALID` сохраняет прежние полномочия. Причины включают
некорректную запись, расхождение типов у псевдонимов, полномочия с другого
маршрута и заполнение таблицы `STYXRPC_CHANNEL_SLOTS`. Основанием для добавления
ключей служит подтверждённый приём на том же живом маршруте. При закрытии вызова
использование этих полномочий заканчивается.

Подключите `StyxRpc::rpc`. Функция выполняется синхронно без ввода-вывода.
Согласуйте доступ к записи одного вызова.
