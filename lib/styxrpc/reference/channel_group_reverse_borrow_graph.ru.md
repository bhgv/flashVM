# styxrpc_channel_group_reverse_borrow_graph

[English](channel_group_reverse_borrow_graph.md) · [libstyxrpc](../README.ru.md) · [Объявление](../include/styxrpc/channel_group.h#L51) · [Реализация](../src/channel_group.c#L277)

## Синтаксис

```c
#include <styxrpc/channel_group.h>
StyxRpcStatus styxrpc_channel_group_reverse_borrow_graph(StyxRpcChannelQueue *queues, size_t count,
    size_t root, StyxRpcChannelOutput *output);
```

Заимствует граф FIFO и rendezvous для одного встречного PID. Линкуйте `StyxRpc::serve`.

| Параметр | Контракт |
| --- | --- |
| `queues` | Непрерывный массив изменяемых дескрипторов. У каждого отдельный положительный 31-битный ключ, полная схема элемента в скобках и ёмкость от 0 до 8 слотов. Управляемые ссылки и гибридные дескрипторы находятся за пределами профиля. |
| `count` | От 1 до `STYXRPC_CHANNEL_SLOTS` дескрипторов. |
| `root` | Индекс с нуля. Ресурс сообщит вызывающему ключ и признак ёмкости этого канала. |
| `output` | Обязательный выход. При успехе владеет ресурсом через `release`. |

Для каждого FIFO выделите отдельные массивы байтов и длин. Задайте шаг от 1 до `STYXRPC_MANAGED_LIMIT` байт, голову меньше ёмкости и число элементов не больше ёмкости. Нулевая ёмкость создаёт rendezvous и требует нулевых курсоров. В каждом занятом слоте хранится полный кодированный элемент. Вложенные каналы представлены ключами текущей шины из этой группы либо nil. Ключ должен иметь точный заявленный тип элемента. На входе rendezvous допускает обычный маркер ключа, на выходе получает штатный признак rendezvous.

Возвращает `STYXRPC_OK` для подготовленного ресурса либо `STYXRPC_INVALID` при неверных параметрах, кадрах или ошибке выделения. При отказе дескрипторы, массивы и `output` сохраняют исходное состояние.

Оставьте дескрипторы и массивы в исключительном пользовании ресурса до `output.release(output.resource.context)`. Ресурс использует штатные смещения ответа после запроса. Сериализуйте колбэки и закройте все fid до освобождения. Зарегистрируйте ресурс через [выдачу PID](program_server_grant.ru.md) и сначала [отзовите](program_server_revoke.ru.md) его, чтобы закрыть fid. FIFO по значению используют массивы вызывающего напрямую. SDK нормализует и обрабатывает вложенные кадры в собственной памяти, затем возвращает занятые слоты и итоговые курсоры. Читайте оставшиеся элементы по возвращённой голове и числу элементов.

[Отдельная проверка на C](../tests/channel_group.c) отклоняет неизвестный дочерний ключ и проверяет сохранность возвращённого rendezvous. Для одной очереди по значению см. [заимствование встречной очереди](channel_group_reverse_borrow.ru.md).
