# styxrpc_server_io_cancelled

[English](server_io_cancelled.md) · [Установка отложенных колбэков](server_enable_deferred_io.ru.md)

## Синтаксис

```c
#include <styxrpc/serve.h>

int styxrpc_server_io_cancelled(void);
```

Хостовая сборка C99, цель `StyxRpc::serve`.

## Поведение

Аргументов нет. Возвращает `1`, если исходный запрос текущего отложенного
файлового колбэка снят при flush, закрытии fid или завершении сессии. До
снятия и вне такого колбэка, включая поток владельца, возвращает `0`.
Установленный флаг сохраняется до возврата колбэка. Запрос не выполняет
ввод-вывод и не выделяет память. Состояние заимствуется у текущего потока.

Проверяйте флаг между ограниченными ожиданиями внутри выбранного
`StyxRpcVfs.read` или `StyxRpcVfs.write`. Проверка не прерывает чужой
блокирующий вызов. После остановки выйдите из колбэка. Сервер удерживает
файловое состояние до возврата и затем закрывает его у владельца, если fid
снят. До обнаружения флага колбэк мог применить изменения.

## Пример

[Цикл провайдера](../examples/disvm/deferred_device.c) проверяет остановку
перед каждой ограниченной паузой, отмечает точный остановленный колбэк и
возвращается. Соседний запрос использует другой fid и продолжает получать
ответы. Запустите [парную проверку](../examples/disvm/DEFERRED_IO.ru.md).
