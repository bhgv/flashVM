# styxrpc_cell_set

[English](cell_set.md) · [Заголовок](../include/styxrpc/named_cell.h) · [Реализация](../src/named_channel_client.c) · [Ячейки](named_cell.ru.md)

Передайте собственный fid, заимствованный [полный кадр значения](cell_value.ru.md) и длину. `STYXRPC_IO_OK` подтверждает атомарную замену. Неверный кадр отвергается до отправки. При неопределённом исходе значение могло измениться. Проверьте его перед новой записью. Сериализуйте работу с fid и подключите `StyxRpc::launch`.

Операции I/O используют сроки запросов сессии.
