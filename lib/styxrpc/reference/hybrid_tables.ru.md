# Гибридные таблицы Dis в самостоятельных программах на C

[English](hybrid_tables.md) · [SDK](../README.ru.md) · [Графовый клиент](graph_invoke.ru.md) · [Графовый сервер](graph_module_init.ru.md)

Подключите `styxrpc/hybrid.h` и переносимую цель `StyxRpc::rpc`. Приложение владеет таблицами `StyxRpcHybrid` и обрабатывает их операции последовательно. SDK и DisVM используют общее хранилище C и общие алгоритмы упорядоченных снимков и патчей. Таблицы можно использовать без VM и подключения Styx.

1. [Откройте](hybrid_open.ru.md) и [заполните](hybrid_apply.ru.md) таблицу. Числовые индексы и ключи UTF-8 с длиной раздельны. Значения — знаковые 64-битные целые.
2. [Запишите упорядоченный снимок](hybrid_snapshot.ru.md). В графовом профиле используется тип `h`. При первом появлении ref содержит однобайтовый ID, за которым следует снимок. При повторных появлениях передаётся ID.
3. Для ответа вызовите [разницу графов](graph_diff.ru.md) с полными исходным и новым определениями. Она упакует [патч ключей](hybrid_diff.ru.md) под позиционным селектором или вложенным ID.
4. На стороне вызывающего найдите исходную таблицу по [индексу обновления](graph_update_index.ru.md). Первый байт полезной нагрузки — селектор, остальные образуют полный патч таблицы. [Подготовьте патч](hybrid_stage.ru.md) по текущему содержимому и проверьте другие изменения ответа. Публикуйте замену после успеха. [Закройте](hybrid_close.ru.md) каждую исходную или отброшенную таблицу, когда она больше не нужна.

[Чтение](hybrid_big_parse.ru.md) и [запись](hybrid_big_format.ru.md) десятичного представления сохраняют весь 64-битный знаковый диапазон. [Переносимая проверка на C](../tests/hybrid.c) охватывает графовые снимки, подготовку обновления, повреждённые патчи и граничные целые. Для живой таблицы во встречном VFS существует [`styxrpc_program_bigtable`](program_bigtable.ru.md).
