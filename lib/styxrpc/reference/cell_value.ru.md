# styxrpc_cell_value

[English](cell_value.md) · [Объявление](../include/styxrpc/named_cell.h#L30) · [Реализация](../src/named_cell_wire.c#L70) · [Ячейки](named_cell.ru.md)

```c
#include <styxrpc/named_cell.h>

int styxrpc_cell_value(const void *frame, size_t size);
```

Передайте доступный для чтения буфер и его длину в байтах с первым байтом
типа именованного сообщения. Функция возвращает единицу для [полного скаляра](cell_scalar.ru.md)
или кадра графа с допустимой сигнатурой FVMG, версией 1–9, заявленной длиной тела
и контрольной суммой IEEE CRC-32. Возвращает ноль для пустого или нулевого буфера,
кадра длиннее 65 536 байт, дескриптора или неверной оболочки. Содержимое
проверяет принимающая VM. Она определяет, можно ли восстановить значение.

Подключите `StyxRpc::rpc`. Проверка обходится без ввода-вывода и выделения памяти,
не меняет состояние и не удерживает буфер. Вызовите её перед созданием ячейки или
заменой значения, если кадр получен от другого компонента.
