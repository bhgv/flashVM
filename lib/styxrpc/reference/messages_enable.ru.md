# styxrpc_messages_enable

[English](messages_enable.md) · [Заголовок](../include/styxrpc/messages.h) · [Реализация](../src/serve.c)

Подключите `styxrpc/messages.h` и библиотеку `StyxRpc::serve`.

```c
StyxRpcStatus styxrpc_messages_enable(StyxRpcServer *server, const StyxRpcMessageSpec *spec);
```

Передайте существующий сервер `server` и регистрации `spec` до первого шага
диспетчера. SDK копирует описатели и имена. Контексты обработчиков и хуков
должны жить до уничтожения сервера. Любой хук может быть NULL.
`opened` выдаёт заимствованный порт для отправки. `closed` вызывается перед
освобождением порта, в том числе при разрыве связи. Диспетчер обслуживает
следующий запрос после возврата колбэка.

Результат `STYXRPC_OK` означает публикацию `.messages`. `STYXRPC_INVALID`
означает ошибочные регистрации, сбой выделения памяти, повторный или поздний
вызов либо конфликт в дереве. Зарезервируйте имя `.messages` в корне, Qid
`UINT64_MAX - 1` и одну позицию в корневом каталоге. Обработчики доступны всем
подключённым клиентам, которые могут открыть файл на чтение и запись.
