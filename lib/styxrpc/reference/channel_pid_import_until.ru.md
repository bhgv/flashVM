# styxrpc_channel_pid_import_until

[English](channel_pid_import_until.md) · [Объявление](../include/styxrpc/channel_route.h#L120) · [Реализация](../src/channel_pid.c#L89)

Допустить встречные каналы PID из одного типизированного элемента и сохранить их стабильные индексы.

## Синтаксис

```c
#include <styxrpc/channel_route.h>

StyxRpcStatus styxrpc_channel_pid_import_until(struct StyxClient *reverse, const char *shape,
    const void *bytes, size_t size, StyxRpcChannelRoutes *routes, StyxRpcCallStop stop, void *state);
```

## Доступность

Хостовый SDK C, библиотека `StyxRpc::launch`. Проверено на Linux64 на нативном DisVM.

## Параметры

| Имя | Описание |
| --- | --- |
| `reverse` | Заимствованный подключённый клиент Styx для исходного дерева процессов владельца. Сохраняйте подключение на время импорта и последующих обменов. |
| `shape` | Заимствованная схема одного значения с каналами в скобках и с завершающим NUL, например `(c[i])` или `((c[i]c[s]))`. Допустимы поля nil и выданные маршруты PID. Управляемые ссылки и гибридные дескрипторы выходят за рамки профиля. |
| `bytes` | Заимствованный полный кадр элемента UniBus, включая тег. |
| `size` | Длина кадра в байтах от одного до `STYXRPC_MANAGED_LIMIT`. |
| `routes` | Таблица вызывающего. Перед первым импортом заполните её нулями. Используйте только с тем же семейством результата и встречным подключением. |
| `stop` | Необязательный колбэк. Ненулевое значение запрашивает остановку. NULL оставляет обычное ожидание. |
| `state` | Заимствованный контекст `stop`, действительный до возврата. NULL допустим по контракту колбэка. |

## Результат

| Код | Условие |
| --- | --- |
| `STYXRPC_OK` | Вся таблица публикуется после успешной проверки всех маршрутов. |
| `STYXRPC_INVALID` | Неверный кадр, конфликт маршрута, переполнение, отказ владельца или сбой транспорта. |
| `STYXRPC_CANCELLED` | Остановка обнаружена до публикации. Таблица и индексы прежних маршрутов сохраняются. |

## Поведение

Для каждого отдельного PID SDK обходит путь `.prog/<pid>`, открывает `.pid` на чтение, сравнивает полную десятичную строку с переводом строки и проверяет доступность `.unibus` в том же каталоге. После проверки SDK освобождает временные fid. Для каждого PID сохраняется один корневой маршрут с выданным ключом, схемой и признаком рандеву. Повторная выдача того же маршрута использует прежний индекс.

Вызывающий связывает кадр с исходным результатом и сериализует обращения к таблице или аренде. Выполняйте импорт вне колбэков диспетчера встречных запросов. Колбэк остановки вызывается в том же потоке. Колбэк должен быстро возвращать управление и избегать повторного входа в сессию. Мультиплексирование позволяет прервать ожидающий запрос по тегу. При последовательном транспорте флаг проверяется между обменами. При отмене очистка временных fid может завершиться позже. После отказа или остановки номер прежнего маршрута можно использовать для нового обмена.

После импорта [обмен по PID](channel_pid_exchange_until.ru.md) использует допущенный корень и может открыть дочерние ключи той же шины. Владелец может отозвать маршрут после импорта.

## Пример

Создайте таблицу один раз для данного результата и подключения. Колбэк и срок даны в руководстве.

```c
StyxRpcChannelRoutes routes = {0};
StyxRpcStatus result = styxrpc_channel_pid_import_until(reverse, "(c[i])",
    frame, frame_size, &routes, deadline_reached, &deadline);
```
