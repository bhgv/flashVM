# styxrpc_module_channels_init

[English](module_channels_init.md) · [libstyxrpc](../README.ru.md)

## Синтаксис

```c
#include <styxrpc/module_channels.h>
int styxrpc_module_channels_init(StyxRpcModuleChannels *channels, StyxRpcModuleChannel *slots,
    size_t capacity, int (*entropy)(void *, void *, size_t), void *context);
```

Инициализируйте реестр одного смонтированного модуля на одном подключении Styx.

| Параметр | Назначение |
| --- | --- |
| `channels` | Объект реестра приложения. Его адрес должен оставаться постоянным. |
| `slots` | Массив на `capacity` выдач. Его адрес сохраняется до закрытия сервера. |
| `capacity` | Максимум одновременных выдач в слотах. Число положительное и соответствует выделенной памяти. |
| `entropy` | Колбэк заполняет все запрошенные байты криптографически стойкими случайными данными и возвращает 1. При отказе возвращает 0. |
| `context` | Необязательное состояние для колбэка. Оно живёт до последней публикации. |

Функция возвращает 1 после очистки слотов и настройки реестра. Возвращает 0,
если отсутствует реестр, массив или колбэк, ёмкость нулевая либо размер
массива переполняется. Инициализация выполняется без ввода-вывода, выделения
памяти и чтения случайных байтов. Вызывайте её до начала обслуживания.
Реестр и слоты должны оставаться на месте, пока не закрыты все fid.
Повторная инициализация начинает новое пространство токенов.
Дальнейшие операции выполняются на диспетчере-владельце.

Библиотека `StyxRpc::serve`.
