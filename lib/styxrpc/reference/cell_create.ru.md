# styxrpc_cell_create

[English](cell_create.md) · [Заголовок](../include/styxrpc/named_cell.h) · [Реализация](../src/named_channel_client.c) · [Ячейки](named_cell.ru.md)

Передайте подключённую сессию, полный скалярный кадр с длиной и буфер для жетона. При подтверждении функция выдаёт собственный fid на чтение и запись и заполняет жетон. При отказе или потере ответа возвращает NULL и сохраняет выходной буфер. Подключите `StyxRpc::launch` и освободите fid через [close](vfs_close.ru.md).

Операции I/O используют сроки запросов сессии.
