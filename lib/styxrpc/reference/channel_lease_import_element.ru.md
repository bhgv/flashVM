# styxrpc_channel_lease_import_element

[English](channel_lease_import_element.md) · [Объявление](../include/styxrpc/channel_client.h) · [Реализация](../src/channel_client.c) · [Сценарий аренд](channel_leases.ru.md)

Подключите `<styxrpc/channel_client.h>` и линкуйте `StyxRpc::launch`.

```c
StyxRpcStatus styxrpc_channel_lease_import_element(StyxRpcChannelLease *lease, size_t route_index,
    const void *bytes, size_t size);
```

| Аргумент | Назначение |
| --- | --- |
| `lease` | Активная аренда результата на сериализованном владельце приложения. |
| `route_index` | Индекс от нуля уже допущенного маршрута подтверждённого приёма. Его токен и схема определяют область новых ключей. |
| `bytes` | Полный типизированный элемент подтверждённого приёма. Обычно это `result.value` после [обмена по аренде](channel_lease_exchange.ru.md). Буфер заимствуется для проверки. |
| `size` | Точная длина элемента в байтах до `STYXRPC_MANAGED_LIMIT`. |

Возвращает `STYXRPC_OK`, добавляя проверенные ключи текущей шины в область исходного токена. SDK копирует точные типы и признаки ёмкости, сохраняет прежние индексы и объединяет совпадающие алиасы. Ошибка формата, отдельный PID или токен, несовпадение алиасов либо заполнение таблицы дают `STYXRPC_INVALID`, сохраняя прежнюю аренду. Общий предел всех допущенных маршрутов равен `STYXRPC_CHANNEL_SLOTS`.

Функция работает без сетевого ввода-вывода. Передавайте только данные успешно выбранного приёма на том же маршруте. Получить добавленные записи можно [по индексу](channel_lease_route.ru.md), а использовать их через [обмен по аренде](channel_lease_exchange.ru.md). Удерживайте аренду на весь срок использования вложенного ключа. Для заимствованного вызова используйте [импорт области вызова](channel_import_element.ru.md).
