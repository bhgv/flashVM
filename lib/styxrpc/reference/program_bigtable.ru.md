# styxrpc_program_bigtable

[English](program_bigtable.md) · [libstyxrpc](../README.ru.md)

## Синтаксис

```c
#include <styxrpc/bigtable.h>
int styxrpc_program_bigtable(StyxRpcPrograms *programs, uint32_t pid, const char *name,
    const StyxRpcBigTable *table);
```

Опубликуйте `.prog/<pid>/.var/<name>` во встречном дереве Styx. Передайте
инициализированный `programs` с зарегистрированным `pid`, уникальное имя ребёнка
`name` и `table` с функцией `apply`. Для чтения требуется шесть слотов, для чтения
и записи десять. Библиотека копирует имя. Описатель и контекст колбэка живут до
закрытия сервера и его fid. Отдельное дерево для каждого подключения даёт
независимый выбор ключа.

Откройте `.idx` на запись и передайте один ключ со смещения ноль. Числовой
ключ начинается байтом 0, далее идёт восьмибайтное знаковое число в сетевом
порядке. Строковый ключ начинается байтом 1, далее идут от 0 до 255 байтов
UTF-8. Допустимы нули внутри строки. При SELECT для отрицательного индекса
колбэк вычисляет позицию относительно плотной части и возвращает
канонический неотрицательный ключ. Держите этот fid открытым, пока работаете
с `.val`. Закрытие селектора отзывает зависимые fid. Запишите полное
восьмибайтное значение со смещения ноль или прочитайте его по частям.

| Файл | Содержимое |
| --- | --- |
| `.type` | Текст `table of big` и перевод строки |
| `.len` | Десятичная длина плотной части и перевод строки |
| `.count` | Десятичное число занятых позиций и ключей и перевод строки |
| `.ins` | Одна запись знаковой позиции и значения, по восемь байтов |
| `.push` | Одна запись восьмибайтного знакового значения |
| `.pop` | Первое непустое чтение извлекает последний плотный элемент и сохраняет восьмибайтное знаковое значение |
| `.add` | Одна запись типизированного ключа и восьмибайтного знакового значения |

Задайте `writable`, чтобы опубликовать четыре файла изменений и разрешить
запись в `.val`. Колбэк возвращает 1 при выполнении операции и 0 при отказе
без изменений. Он управляет хранилищем, отсутствующими ключами и атомарностью
записи. SELECT не изменяет таблицу и использует байты строки только в
текущей операции. Согласуйте диспетчер с другими нативными пользователями
хранилища.

Регистрация возвращает 1 при успехе. Ноль означает неверный аргумент, занятое
имя, неизвестный процесс или нехватку слотов. При ошибке узлы не публикуются.
Подключите `StyxRpc::serve`.
