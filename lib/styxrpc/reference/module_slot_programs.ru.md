# styxrpc_module_slot_programs

[English](module_slot_programs.md) ·
[Объявление](../include/styxrpc/module_slot.h) ·
[Реализация](../src/module_slot.c) · [Слот модуля](module_slot.ru.md)

Подключите `<styxrpc/module_slot.h>` и линкуйте с `StyxRpc::serve`.

```c
int styxrpc_module_slot_programs(StyxRpcModuleSlot *slot, StyxRpcPrograms *programs);
```

Подключите подготовленный [реестр программ](programs_init.ru.md) к
действующему `slot` до запуска диспетчера Styx. Приложение владеет
`programs` и его памятью. Храните их до закрытия сервера и слота.
Первое успешное подключение возвращает 1. Неверный аргумент или повторное
подключение возвращает 0 и сохраняет текущее дерево.

Клиент RPC может обратиться к `.prog/<pid>` напрямую. Чтение корневого
каталога пропускает этот служебный путь. Вложенные fid работают с
зарегистрированными ресурсами и переживают замену образа модуля.
Меняйте реестр только у владельца диспетчера между запросами, вне
колбэков ресурсов. Функция обходится без выделения памяти, ожидания
ввода-вывода и вызова колбэков.
