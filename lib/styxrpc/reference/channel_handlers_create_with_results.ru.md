# styxrpc_channel_handlers_create_with_results

[English](channel_handlers_create_with_results.md) · [Объявление](../include/styxrpc/channel_handlers.h) · [Очередь](../src/channel_handlers.c) · [Файлы Styx](../src/channel_handlers_files.c) · [Сценарий](channel_handler_modules.ru.md)

Подключите `<styxrpc/channel_handlers.h>` и линкуйте хостовую цель C99 `StyxRpc::serve` с поддержкой потоков POSIX.

```c
StyxRpcChannelHandlers *styxrpc_channel_handlers_create_with_results(const char *name,
    const StyxRpcChannelFunction *functions, size_t count, const StyxRpcChannelExport *results,
    size_t result_count, StyxRpcModuleChannels *registry);
```

| Параметр | Контракт |
| --- | --- |
| `name` | Обязательное имя модуля внутри `mounted`. Непустой компонент длиной до 255 байт без косых черт и специальных имён `.` и `..`. |
| `functions`, `count` | [Функции с копируемым результатом](channel_handlers_create.ru.md) и их количество. Для пропуска передайте NULL и ноль. |
| `results`, `result_count` | Функции с каналами в результате и их количество. Описатель содержит точное компилированное имя, сигнатуру, схему, колбэк `begin` и его контекст. Аргументы могут включать заимствованные каналы. Элементы аргументов могут содержать каналы текущей шины. Канал результата может передавать вложенные ключи того же [ресурса группы](channel_group_output.ru.md). Для пропуска передайте NULL и ноль. |
| `registry` | [Готовый реестр аренд](module_channels_init.ru.md), обязателен при положительном `result_count`. Выделите слоты для одновременных результатов. Реестр и колбэк энтропии использует только диспетчер. |

Общее число экспортов от 1 до `STYXRPC_MAX_EXPORTS`. Имена уникальны в обоих массивах. Возвращает собственный модуль либо NULL при неверных описателях, нехватке памяти или ресурсов синхронизации. Модуль заимствует массивы, имена, контексты и реестр до завершения.

Обслуживайте `styxrpc_channel_handlers_tree` одним диспетчером прямой сессии. Вызывайте [step](channel_handlers_step.ru.md) у владельца колбэков. Колбэк `begin` передаёт в `StyxRpcChannelOutput` ресурс, положительный ключ, признак ёмкости и необязательный колбэк освобождения. Нулевой ключ отправляет канал nil. Ресурс должен работать после возврата из колбэка. Операции ресурса и отзыв выполняет диспетчер. Колбэк освобождения может выполняться у владельца либо у диспетчера и освобождает переданный ресурс один раз, в том числе после ошибки или отказа от вызова.

Диспетчер регистрирует токен при первом чтении ненулевой длины со смещения ноль после выполнения колбэка. Токен выдаётся в проверенном ответе и принимается на `.unibus`. Clunk выдавшего fid отзывает его операции до освобождения ресурса. Если от вызова отказались до публикации, токен не расходуется. При ошибке публикации диспетчер освобождает ресурс и возвращает удалённую ошибку. Завершённые операции над аргументами остаются видны вызывающему.

[Самостоятельный сценарий C](../tests/module_channels.c) · [Остановка](channel_handlers_stop.ru.md) · [Уничтожение](channel_handlers_destroy.ru.md)

Дескриптор с арендой результата может принять копируемые графовые аргументы и заимствованные каналы в одном вызове. Поля обновлений `StyxRpcChannelOutput` подчиняются [правилам владения](channel_module_init.ru.md). Для описателей с копируемым результатом действует их штатный API.

Составной ответ передаётся по [контракту результата](channel_module_init.ru.md#составной-ответ).
