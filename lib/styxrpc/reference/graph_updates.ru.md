# Позиционные изменения графа

[English](graph_updates.md) · [Объявления](../include/styxrpc/graph.h#L60) · [Реализация](../src/graph.c)

Переносимый кодек графа входит в `StyxRpc::rpc`. Возьмите аргументы из [`styxrpc_graph_arguments`](graph_arguments.ru.md), список изменений из [`styxrpc_graph_read`](graph_read.ru.md) или [хостового клиента](graph_invoke.ru.md). Читайте отдельные элементы списка как S-записи UniBus.

| Функция | Вход и выход |
| --- | --- |
| [`styxrpc_graph_update_index`](graph_update_index.ru.md) | Разрешает проверенную запись изменения в исходный ID с нуля. `originals` задаёт число существующих ID. |
| [`styxrpc_graph_update_fields`](graph_update_fields.ru.md) | По исходному типу `r[…]` и проверенной записи возвращает битовую маску, развёрнутые типы выбранных полей и заимствованные дочерние записи. |
| [`styxrpc_graph_diff`](graph_diff.ru.md) | По исходному ID, его типу и полным записям ref до и после кодирует разреженное изменение. Нужны отдельные рабочий и выходной буферы. При совпадении возвращает успех с `used=0`. |

Все три функции возвращают 1 при успехе и 0 при неверном входе или нехватке места. Функции работают над записями и не зависят от владельца VM или её кучи. Память исходных записей принадлежит вызывающему и сохраняется, пока используются заимствованные представления.
