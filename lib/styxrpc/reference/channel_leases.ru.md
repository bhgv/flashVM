# Аренда каналов UniBus в хостовом SDK

[English](channel_leases.md) · [SDK](../README.ru.md) · [Исполняемый клиент C](../examples/disvm/routed_client.c)

Используйте [контекстный клиент](channel_invoke.ru.md), когда функция Dis возвращает живой канал. SDK проверяет кадр и отдельные маршруты, затем возвращает собственную ссылку. Fid модуля определяет путь операций, а fid функции владеет удалённым токеном. Каждый локальный пользователь удерживает свою [ссылку](channel_lease_retain.ru.md) и [освобождает](channel_lease_release.ru.md) её после использования.

Используйте [обмен с арендой](channel_lease_exchange.ru.md) для маршрутов исходного результата. Для полномочий, пришедших внутри последующих сообщений, используйте [парсер элементов](channel_element_routes.ru.md) и [маршрутизированный обмен](channel_route_exchange.ru.md). Удерживайте выдавшую аренду и применяйте политику делегирования своего приложения.

Программа на C может обслуживать контекстные фабрики через [инициализацию модуля](channel_module_init.ru.md). Колбэк возвращает ресурс канала. Библиотека проверяет полномочия на шине модуля и отзывает токен при clunk функции. Приложение задаёт память и операции. Переносимый [планировщик](scheduler_init.ru.md) поддерживает ограниченный FIFO и синхронную встречу отправителя и получателя.
