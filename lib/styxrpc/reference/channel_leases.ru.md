# Аренда каналов UniBus в хостовом SDK

[English](channel_leases.md) · [SDK](../README.ru.md) · [Исполняемый клиент C](../examples/disvm/routed_client.c)

Используйте [контекстный клиент](channel_invoke.ru.md), когда функция Dis возвращает живой канал. SDK проверяет кадр и отдельные маршруты, затем возвращает собственную ссылку. Fid модуля определяет путь операций, а fid функции владеет удалённым токеном. Каждый локальный пользователь удерживает свою [ссылку](channel_lease_retain.ru.md) и [освобождает](channel_lease_release.ru.md) её после использования.

Используйте [обмен с арендой](channel_lease_exchange.ru.md) для маршрутов исходного результата. После подтверждённого приёма [добавьте ключи текущей шины](channel_lease_import_element.ru.md) и найдите их [индексы](channel_lease_route.ru.md). У ключей общий токен и выдавший fid. Вложенный ключ работает, пока вызывающий удерживает аренду. Для отдельно адресованных полномочий используйте [парсер элементов](channel_element_routes.ru.md) и [маршрутизированный обмен](channel_route_exchange.ru.md) с политикой делегирования приложения. Если приложение проверило токен модуля для конкретного живого результата, [добавьте его в аренду](channel_lease_admit_module.ru.md), чтобы сохранить точный удерживаемый модуль.

Для полного встречного сообщения, доставленного для этого результата, используйте [импорт сообщения](channel_lease_import_message.ru.md). Он подтверждает каждый токен на удерживаемом модуле и дописывает маршруты после успеха всех проверок.

[Встречная очередь](channel_mailbox_create.ru.md) создаёт два отдельных ограниченных FIFO для партнёра и владельца под одним PID. Диспетчер проверяет типизированные кадры. Владелец может извлечь кадр и импортировать полномочия модулей под удерживаемой арендой.

[Очередь результата модуля](channel_mailbox_result_create.ru.md) принимает встречные PID клиента. Владелец [импортирует подтверждённые PID](channel_pid_import.ru.md) и выполняет маршрутизированный обмен на том же подключении. Clunk отзывает ресурс, а владелец отдельно освобождает свой дескриптор.

Программа на C может обслуживать контекстные фабрики через [инициализацию модуля](channel_module_init.ru.md). Колбэк возвращает ресурс канала. Библиотека проверяет полномочия на шине модуля и отзывает токен при clunk функции. Приложение задаёт память и операции либо использует [копируемый ресурс группы](channel_group_output.ru.md) для вложенных очередей с начальными значениями. Переносимый [планировщик](scheduler_init.ru.md) поддерживает ограниченный FIFO и синхронную встречу отправителя и получателя.
