# styxrpc_channel_lease_import_message_until

[English](channel_lease_import_message_until.md) · [Объявление](../include/styxrpc/channel_client.h#L92) · [Реализация](../src/channel_client.c#L345)

Проверить делегированные токены и допустить их маршруты на удерживаемом модуле результата.

## Синтаксис

```c
#include <styxrpc/channel_client.h>

StyxRpcStatus styxrpc_channel_lease_import_message_until(StyxRpcChannelLease *lease, const char *shape,
    const void *bytes, size_t size, StyxRpcCallStop stop, void *state);
```

## Доступность

Хостовый SDK C, библиотека `StyxRpc::launch`. Проверено на Linux64 на нативном DisVM.

## Параметры

| Имя | Описание |
| --- | --- |
| `lease` | Заимствованная действующая аренда. Сохраняйте собственную ссылку на время импорта и последующего использования маршрутов. |
| `shape` | Заимствованная схема одного значения с каналами в скобках и с завершающим NUL, например `(c[c[i]])`. Допустимы поля nil и маршруты модуля. Управляемые ссылки и гибридные дескрипторы выходят за рамки профиля. |
| `bytes` | Заимствованный полный кадр элемента UniBus, доставленный семейству результата. |
| `size` | Длина кадра в байтах от одного до `STYXRPC_MANAGED_LIMIT`. |
| `stop` | Необязательный колбэк. Ненулевое значение запрашивает остановку. NULL оставляет обычное ожидание. |
| `state` | Заимствованный контекст `stop`, действительный до возврата. NULL допустим по контракту колбэка. |

## Результат

| Код | Условие |
| --- | --- |
| `STYXRPC_OK` | Вся таблица публикуется после успешной проверки всех маршрутов. |
| `STYXRPC_INVALID` | Неверный кадр, конфликт маршрута, переполнение, отказ владельца или сбой транспорта. |
| `STYXRPC_CANCELLED` | Остановка обнаружена до публикации. Таблица и индексы прежних маршрутов сохраняются. |

## Поведение

Для каждого отдельного токена SDK обходит `.unibus` относительно модуля, удерживаемого арендой, открывает временный fid на чтение и запись, записывает весь 16-байтовый токен со смещения ноль и закрывает fid. За проверенным токеном сохраняются выданный ключ, схема элемента и признак рандеву. На каждом временном fid допуск выполняет только запись токена.

Вызывающий связывает кадр с исходным результатом и сериализует обращения к таблице или аренде. Выполняйте импорт вне колбэков диспетчера встречных запросов. Колбэк остановки вызывается в том же потоке. Колбэк должен быстро возвращать управление и избегать повторного входа в сессию. Мультиплексирование позволяет прервать ожидающий запрос по тегу. При последовательном транспорте флаг проверяется между обменами. При отмене очистка временных fid может завершиться позже. После отказа или остановки номер прежнего маршрута можно использовать для нового обмена.

Допущенные полномочия доступны через [маршрут аренды](channel_lease_route.ru.md). [Обмен по аренде](channel_lease_exchange_until.ru.md) выполняет выбор ветвей на отдельном fid. Владелец может отозвать токен при clunk выдавшего его результата.

## Пример

Передайте кадр, который хост связал с исходным результатом. Колбэк и срок даны в руководстве.

```c
StyxRpcStatus result = styxrpc_channel_lease_import_message_until(lease,
    "(c[c[i]])", frame, frame_size, deadline_reached, &deadline);
```
