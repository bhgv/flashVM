# styxrpc_server_step_for

[English](server_step_for.md) · [Заголовок](../include/styxrpc/serve.h) · [Исходник](../src/serve.c) · [Блокирующий шаг](server_step.ru.md)

Подключите `styxrpc/serve.h` и `StyxRpc::serve`.

```c
int styxrpc_server_step_for(StyxRpcServer *server, int timeout_ms);
```

Передайте живой сервер и монотонный бюджет ожидания в миллисекундах. `-1` ждёт бессрочно, ноль обрабатывает готовый ввод-вывод без ожидания, положительное число задаёт общий бюджет ожидания в том числе для неполных кадров. Вызов использует штатный диспетчер с накопленными запросами и ответами. Истечение срока, готовность и пробуждение возвращают 1. Разрыв, ошибка транспорта или недопустимый аргумент возвращают 0. Время колбэков учитывается отдельно. Вызывает только поток владельца. Цикл приложения может передать ближайший срок и выполнить работу таймера перед следующим шагом.

Для встречного обслуживания во время синхронного вызова см. [styxrpc_server_program_step_for](server_program_step_for.ru.md).
