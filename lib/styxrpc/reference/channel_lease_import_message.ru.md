# styxrpc_channel_lease_import_message

[English](channel_lease_import_message.md) · [Сценарий аренд](channel_leases.ru.md) · [Объявление](../include/styxrpc/channel_client.h#L84) · [Реализация](../src/channel_client.c#L329)

```c
#include <styxrpc/channel_client.h>
StyxRpcStatus styxrpc_channel_lease_import_message(StyxRpcChannelLease *lease,
    const char *shape, const void *bytes, size_t size);
```

Линкуйте `StyxRpc::launch`. В потоке-владельце `lease` передайте типизированный элемент со встречного ресурса, который приложение связало с этим семейством результата. Параметр `shape` задаёт схему элемента с завершающим NUL, например `(c[c[i]])`. Передайте полный кадр UniBus в `bytes` и его длину в байтах в `size` до `STYXRPC_MANAGED_LIMIT`. Кадр и схема заимствуются на время вызова. Допускаются полномочия модулей и ссылки nil. Управляемые ссылки и гибридные дескрипторы находятся за пределами профиля.

SDK проверяет целый кадр и резервирует индексы во временной таблице. Для каждого отдельного токена он открывает временный fid чтения и записи по пути `.unibus` от удерживаемого модуля, записывает полный токен со смещения ноль и закрывает fid через clunk. Это подтверждает токен на модуле без выполнения операции канала. Ключ, тип и признак rendezvous берутся из типизированного сообщения. Вызывающий отвечает за привязку встречного ресурса к исходному результату.

`STYXRPC_OK` устанавливает подготовленную таблицу. Найдите индексы через [маршрут аренды](channel_lease_route.ru.md) и используйте [обмен по аренде](channel_lease_exchange.ru.md). `STYXRPC_INVALID` сохраняет прежнюю таблицу при неверном кадре, несовместимых полномочиях, исчерпании слотов или отказе проверки на транспорте. Каждая операция Styx использует таймаут монтирования клиента. Вызывайте вне колбэков встречного диспетчера и удерживайте исходную аренду до возврата. Партнёр может впоследствии отозвать токен, поэтому операции повторно подтверждают его на своих fid.
