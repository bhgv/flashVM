# styxrpc_named_peer_read_ref_scope

`StyxRpc::serve`

```c
int styxrpc_named_peer_read_ref_scope(struct StyxClient *client, void *scope);
```

## Контракт

В паре FlashVM передайте подключение к службе имён с `STYXRPC_MODULE_REF_ATTACH`. В смешанной паре передайте обычное встречное подключение к DisVM. Вызывающий выделяет 16-байтовый выходной буфер `scope`. Функция находит служебный файл, проверяет заявленную длину и читает полное содержимое. Она закрывает временный fid при любом результате.

Успех копирует область и возвращает 1. Отсутствие поддержки, неверные аргументы, неполная передача или несовместимые метаданные дают 0 и сохраняют результат. Вызов блокируется в пределах сроков запросов клиента. Сохраняйте подключение до завершения. Передайте область в [кодек дескриптора](module_ref_decode.ru.md).
