# Общие ячейки значений именованного канала

[English](named_cell.md) · [Заголовок](../include/styxrpc/named_cell.h) · [Каналы](named_channel.ru.md) · [FlashVM](../../../flashVM/doc/STYX_RPC_NAMED_SEND.ru.md)

Ячейка принадлежит реестру одной подключённой сессии. Владелец использует
системную энтропию и серийный номер для её идентификации. Каждый открытый
fid удерживает аренду ячейки. Именованный канал удерживает аренду во время
передачи дескриптора и после приёма кадра до следующего запроса или clunk.
Получатель должен открыть собственную аренду до следующей операции
канала. Последнее освобождение отзывает жетон.

Ячейка принимает переносимые кадры чисел, строк с длиной, Boolean, null,
undefined и снимки графа FlashVM в формате обычного именованного сообщения.
Запись атомарно заменяет кадр целиком. Последовательные чтение и запись
выполняются двумя операциями. Вызовы на одном fid выполняются последовательно.
При присваивании тип может измениться. Чтение графа возвращает снимок.

| Вызов C | Действие |
| --- | --- |
| [`styxrpc_cell_create`](cell_create.ru.md) | Создать ячейку и получить первую аренду и жетон. |
| [`styxrpc_cell_attach`](cell_attach.ru.md) | Открыть аренду по полученному жетону. |
| [`styxrpc_cell_get`](cell_get.ru.md) | Прочитать полный кадр значения. |
| [`styxrpc_cell_set`](cell_set.ru.md) | Заменить полный кадр значения. |

Закрывайте аренды через [`styxrpc_vfs_close`](vfs_close.ru.md). Провайдер
включает ячейки через [`styxrpc_named_cells_enable`](named_cells_enable.ru.md)
до открытия участников. [Проверка кадра](cell_value.ru.md) включает оболочку и контрольную сумму
снимка. Тело графа проверяет и декодирует принимающая VM.

[Сервис `/.channels`](named_channel.ru.md) добавляет операции 4–7. Создание
принимает кадр значения и возвращает жетон длиной 24 байта. Получение
аренды принимает этот жетон и подтверждается после приёма всего запроса.
Чтение имеет пустое тело и возвращает текущий кадр значения. Запись принимает
кадр значения и подтверждает замену. Для ячейки используется отдельный
fid Styx на чтение и запись. Ссылка передаётся тегом 8 и 24 байтами жетона.

В [Limbo](../../../disVM/module/styxnamed.m) `share(frame)` создаёт ячейку,
а `adopt(frame)` открывает аренду по полученному дескриптору. Методы
`cell.get()` и `cell.set(value)` читают и меняют общий кадр значения.
`cell.payload()` возвращает дескриптор для пересылки, а `cell.close()`
снимает аренду. Кадры могут содержать скаляры и снимки графов, а сам объект
Limbo имеет тип `ref Cell`.
