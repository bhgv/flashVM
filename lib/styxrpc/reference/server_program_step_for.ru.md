# styxrpc_server_program_step_for

[English](server_program_step_for.md) · [Объявление](../include/styxrpc/serve.h) ·
[Реализация](../src/serve_program_wait.inc)

```c
#include <styxrpc/serve.h>

int styxrpc_server_program_step_for(StyxRpcServer *server, int timeout_ms);
```

Выполняет один такт встречного Styx, пока владелец приложения ждёт
синхронный вызов. Передайте заимствованный сервер слота с
зарегистрированным нативным деревом программ. Его ресурсы должны быть
доступны во время паузы приложения. `timeout_ms` задаёт неотрицательное
время ожидания готовности транспорта в миллисекундах. Ноль выполняет
доступную работу без этого ожидания.

Во время такта доступны обход и операции нативного дерева `.prog`.
Обычные файловые операции за его пределами получают отказ. Колбэки
закрытия других fid откладываются до обычного такта либо уничтожения
сервера. Служебная очистка транспорта продолжает выполняться.

Единица означает, что диспетчер может продолжать работу, в том числе
после истечения ожидания готовности. Ноль означает обрыв, неверные
аргументы, отсутствие нативного дерева программ либо вызов из другого
такта диспетчера. Сервер остаётся во владении вызывающего, скрипт не
запускается. Вызывайте функцию из потока обычного диспетчера без
параллельных операций с сервером из других потоков.

Пока идёт нативный обмен, между проверками его завершения можно вызывать
`styxrpc_server_program_step_for(server, 5)`. Дождитесь потока обмена
перед возвратом в приложение. Затем продолжайте
[обычное обслуживание сервера](server_step_for.ru.md).
