# styxrpc_vfs_service_name

[English](vfs_service_name.md) · [Заголовок](../include/styxrpc/vfs_client.h) · [Исходник](../src/named_channel_path.c)

Подключите `StyxRpc::rpc`. Передайте компонент пути и его длину в байтах.
Диапазон должен оставаться доступным до возврата. Точное служебное имя
возвращает единицу, прочие — ноль. Вызов не выполняет I/O и допустим в
любом нативном потоке. Обычное открытие дополнительно проверяет
метаданные служебных узлов с произвольными именами.
