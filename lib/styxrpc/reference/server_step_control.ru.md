# styxrpc_server_step_control

[English](server_step_control.md) · [API](../include/styxrpc/control.h#L59) · [Реализация](../src/serve_control.inc) · [Дерево управления](control_create.ru.md)

```c
int styxrpc_server_step_control(StyxRpcServer *server);
```

Обработайте цикл в потоке владельца сервера для дерева управления
или слота модуля. Вызывайте между обычными шагами, например пока
активация ожидает команды отладчика. До возврата открытие, чтение и
запись доступны только для `.state`. Поиск имён, stat и штатное
закрытие fid продолжают работать. Используйте колбэки и очистку,
допустимые при приостановленной активации.

Шаг ждёт работу транспорта и возвращает 1 для продолжения. При
обрыве связи, ошибке, неподдерживаемом дереве, NULL или попытке
повторного входа в тот же сервер возвращает 0. Вызов заимствует
`server` и использует уже выданный транспорт.
