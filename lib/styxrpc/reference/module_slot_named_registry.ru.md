# styxrpc_module_slot_named_registry

[English](module_slot_named_registry.md) · [Заголовок](../include/styxrpc/module_slot.h#L39) · [Реализация](../src/module_slot_named.c) · [Слот модуля](module_slot.ru.md)

```c
#include <styxrpc/module_slot.h>

StyxRpcNamedRegistry *styxrpc_module_slot_named_registry(StyxRpcModuleSlot *slot);
```

Создать свой реестр с заимствованием живого `slot`. При NULL или нехватке
памяти результат NULL. Реестр принимает канонические абсолютные пути
в живом дереве колбэков. Свободные имена каналов допустимы в корне и
существующих каталогах с правом прохода. Проверяются обычные узлы,
служебные пути и дерево образа под `mounted`. Резерв виден только
службе каналов. Публикация конфликтующего колбэка вернёт INVALID, пока не
закроется последний участник. Замена каталога запрещает новые подключения
к старому резерву.

Используйте реестр с [named_peer_host](named_peer_host.ru.md) либо
[API именованных участников](named_channel.ru.md). Проверки метаданных
синхронизированы с публикацией и не входят в гостевой код. Открытые
участники сохраняют дескрипторы при изменении пространства имён.
Остановите диспетчеры, закройте участников и уничтожьте реестр перед
освобождением слота. Линковать с `StyxRpc::serve`.
