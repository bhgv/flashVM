# styxrpc_vfs_dir_next_until

[English](vfs_dir_next_until.md) · [Обычный вызов](vfs_directory.ru.md) · [Общий контракт](../VFS_CONTROL.ru.md)

## Синтаксис

```c
#include <styxrpc/vfs_client.h>

StyxRpcIoOutcome styxrpc_vfs_dir_next_until(StyxRpcVfsDir *dir, StyxRpcVfsVisitor visit, void *state, int *found,
    StyxRpcVfsStop stop, void *stop_state);
```

Хостовая сборка C99, цель `StyxRpc::launch`.

Продвинуться до одной видимой записи либо EOF. Буфер декодируется целыми записями. Отмена завершает точный fid, после чего перемотка отклоняется. Закройте память курсора и откройте новый для продолжения.

## Параметры

| Параметр | Значение |
| --- | --- |
| `dir` | Заимствованный курсор с сериализацией у вызывающего. Память курсора остаётся у вызывающего при любом исходе. |
| `visit` | Необязательный обработчик одной видимой записи. Имя и метаданные заимствованы. Верните 1 для принятия. |
| `state` | Непрозрачный аргумент, заимствованный visit на время вызова. |
| `found` | Выходной флаг. Ноль при EOF или отмене, единица для выданной записи. |
| `stop` | Необязательный короткий нативный колбэк в потоке вызова. Ненулевой результат останавливает ожидание. NULL сохраняет обычный режим. |
| `stop_state` | Непрозрачный аргумент stop, заимствованный до возврата. |

## Результат

Коды ниже используют префикс `STYXRPC_IO_`. `OK` подтверждает результат. `CANCELLED` означает остановку ожидания колбэком. При включённом мультиплексоре посланный запрос завершается через `Tflush`, когда отмена выигрывает. Для последовательного транспорта колбэк проверяется перед этапом обмена. Подтверждённый исход имеет приоритет над отменой.

Неверный курсор даёт `NOT_OPEN`. Неверная запись или отказ обработчика дают `FAILED`. Для неподтверждённой записи обработчик не вызывается.

## Пример

Используйте подключённый session или ранее открытый дескриптор и функцию stop, которая читает флаг остановки вашего потока.

```c
int found;
StyxRpcIoOutcome status = styxrpc_vfs_dir_next_until(dir, NULL, NULL, &found, stop, state);
if (status == STYXRPC_IO_CANCELLED)
{
    styxrpc_vfs_dir_close(dir, 1);
}
```

Этот вызов проверяет [тест протокола](../tests/vfs_control_wire.c). Запустите его через `ctest --test-dir build-styxrpc -R styxrpc-vfs-control-wire --output-on-failure`. Он проверяет подтверждения, отмену и работу соседнего fid.
