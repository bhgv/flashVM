## Описание

fvm_sadapt_feedback_read: выбранные host решения адаптации связи и гистерезис.

### Сохранённый контракт implementation/header

Compact tag-zero report codec, no padding. Unknown subservice/command UNKNOWN; bad metadata
INVALID, checksum/prefix errors forwarded. Outputs atomic; read consumes one record only.

## Возвращаемое значение

`FVM_SResult`; прямые константы результата тела: FVM_S_INVALID, FVM_S_OK, FVM_S_UNKNOWN. Пересылаемый результат сохраняет статус вызываемого API.

## Ошибки и владение

Соблюдать точный контракт выше: overlap input/output, capacity, отмену и правила освобождения. Протокольное подтверждение, результат native queue и завершённый удалённый эффект — разные результаты. Уведомление не даёт прав, неопределённая запись не повторяется автоматически.

Unibus::wire; C89, no OS/allocator/threads
