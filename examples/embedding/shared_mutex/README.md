# embedding/shared_mutex

Использует установленные расширения mutex/channel в нескольких worker-контекстах. Демонстрирует разделяемую блокировку и обмен сериализованными значениями при раздельном владении обычными объектами.

## Реализация и запуск

Пример C/C++ собирается с `FVM_BUILD_EXAMPLES=ON`. Из корня репозитория:

```sh
cmake -S . -B build-examples -DFVM_DEFS_FILE=cmake/profiles/minimal.defs -DFVM_BUILD_EXAMPLES=ON
cmake --build build-examples --target flashvm_examples_embedding_shared_mutex_main --parallel
./build-examples/flashvm_examples_embedding_shared_mutex_main
```

Операции зависят от выбранного DEFS-профиля; OS_PORTS, JIT, графика и codecs
не включаются наличием этого README. Исходники ниже показывают порядок API-вызовов
и освобождения ресурсов.
