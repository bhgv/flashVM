# embedding/standard_boolean

Устанавливает стандартные объекты и сравнивает вызов Boolean как функции и конструктора. Демонстрирует преобразование примитива, boxed-объект, методы и защиту удерживаемых объектов от GC.

## Реализация и запуск

Пример C/C++ собирается с `FVM_BUILD_EXAMPLES=ON`. Из корня репозитория:

```sh
cmake -S . -B build-examples -DFVM_DEFS_FILE=cmake/profiles/minimal.defs -DFVM_BUILD_EXAMPLES=ON
cmake --build build-examples --target flashvm_examples_embedding_standard_boolean_main --parallel
./build-examples/flashvm_examples_embedding_standard_boolean_main
```

Операции зависят от выбранного DEFS-профиля; OS_PORTS, JIT, графика и codecs
не включаются наличием этого README. Исходники ниже показывают порядок API-вызовов
и освобождения ресурсов.
