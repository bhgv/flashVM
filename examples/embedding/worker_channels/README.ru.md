# Обмен сообщениями между потоком и приложением (C89)

`main.c` запускает независимый контекст FlashVM в системном потоке. Приложение передаёт копию UTF-8 строки по одному каналу, поток возвращает её длину в байтах по другому каналу, а `join` получает итоговое значение функции. Два канала обеспечивают двунаправленный обмен без совместного использования Flash-объектов.

Соберите проект с `-DFVM_BUILD_EXAMPLES=ON`, запустите `flashvm_examples_embedding_worker_channels_main`. Указатели каналов передаются через `userdata` C-обработчика, а не через значение AVM1. Закрытие канала будит ожидающего получателя; перед уничтожением каналов нужно дождаться завершения потока.

Синтаксис ActionScript `thread.run`, `<...>` и `<-` ещё не реализован.
