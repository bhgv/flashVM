# Встраивание C89: трассирующий GC

Пример создаёт объект, удерживает его через `fvm_gc_pin`, выполняет полный цикл сборки, снимает удержание и освобождает объект при следующей сборке. Указатель `FVM_Object *` заимствованный: нельзя обращаться к нему после освобождения сборщиком. Глобальный объект VM всегда является корнем.

Сборка CMake с `FVM_BUILD_EXAMPLES=ON`; запуск `flashvm_example_gc`.
