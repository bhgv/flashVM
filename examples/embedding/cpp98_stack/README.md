# embedding/cpp98_stack

Создаёт flashvm::Stack в области видимости C++98, помещает число, читает его по отрицательному индексу и удаляет. Показывает RAII поверх C ABI и необходимость завершить жизнь стека до уничтожения контекста.

## Реализация и запуск

Пример C/C++ собирается с `FVM_BUILD_EXAMPLES=ON`. Из корня репозитория:

```sh
cmake -S . -B build-examples -DFVM_DEFS_FILE=cmake/profiles/minimal.defs -DFVM_BUILD_EXAMPLES=ON
cmake --build build-examples --target flashvm_examples_embedding_cpp98_stack_main --parallel
./build-examples/flashvm_examples_embedding_cpp98_stack_main
```

Операции зависят от выбранного DEFS-профиля; OS_PORTS, JIT, графика и codecs
не включаются наличием этого README. Исходники ниже показывают порядок API-вызовов
и освобождения ресурсов.
