# Peephole FIR → FIR

[English](README.md). Реализация: [peephole.c](peephole.c).

`fir1 opt INPUT OUTPUT` проверяет модуль до и после преобразований. Повторяет:

1. Свёртку i32 add/sub/mul и сравнений известных целых констант.
2. Замену i32 x+0 и x-0 значением x.
3. Распространение copy без повторного вычисления исходного выражения.
4. Удаление неиспользуемых констант и типизированной арифметики/сравнений.

Вычисления компилятора используют unsigned, задавая модуль 2^32 без знакового
переполнения C. Использования — индексы символов, не текстовые замены. Проход
повторяется до стабилизации. Сворачиваются константные if, удаляются недостижимые блоки и циклы;
CSE работает в одном блоке. Перемещения загрузок и inlining пока нет.
Динамические сложение/преобразование, trace и эффекты каналов сохраняются даже
при неиспользуемом результате. Преобразований и свёртки f64 нет: сохраняются
отрицательный ноль и поведение runtime FP.

```text
// До
%a: i32 = const.i32 6
%b: i32 = const.i32 7
%c: i32 = i32.mul.wrap %a, %b
trace %c
// После: неиспользуемые a/b удалены
%c: i32 = const.i32 42
trace %c
```

Исходные комментарии заменяются заметками о строках входа. Это проход IR,
независимый от будущего peephole инструкций AVM1.
[Формат и эффекты](../doc/FORMAT.ru.md), [тесты](../doc/TESTING.ru.md).

Локальная CMake-сборка: можно конфигурировать эту папку с теми же параметрами
COCOR_ROOT и COCOR_EXECUTABLE; executable находятся в `v1/` каталога сборки.

## 0.2.1

`effects.c` задаёт шесть признаков побочных эффектов; неизвестные операции
получают все признаки. DCE проверяет эту таблицу, а не порядок enum.
Константный `if` превращается в `jump`, недостижимые блоки (включая циклы)
удаляются с перенумерацией меток. Эффекты удаляются только на доказанно
неисполняемом пути. CSE повторно использует одинаковые арифметические операции
в одном блоке без перестановки операндов; f64 не сворачивается в константы.
Динамические преобразования, каналы и trace остаются даже без пользователей.
