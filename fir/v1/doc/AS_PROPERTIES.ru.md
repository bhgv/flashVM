# Динамические AS-значения и запись свойств в FIR

[English](AS_PROPERTIES.md) · [Профиль AS2](../../../compiler/as2/view/README.ru.md) ·
[Формат](FORMAT.ru.md) · [Грамматика](../compiler/fir1.atg) · [Backend AVM1](../compiler/object.c)

Три операции FIR дают первый путь к UI-объектам без передачи адресов и раскладок
кучи Dis. `any` здесь содержит значение AVM1, в том числе ссылку на объект,
владельцем которого остаётся FlashVM. Это не адрес чужой кучи и не готовый RPC-прокси.

| Операция | Вход/результат | Смысл |
| --- | --- | --- |
| `%x: any = as.global_get "name"` | без SSA-входов → any | Прочитать глобальное AS-значение. |
| `as.global_set "name", %x` | scalar → void | Записать глобальное AS-значение. |
| `as.member_set %owner, "key", %x` | any, scalar → void | Записать именованное свойство захваченного объекта. |

Scalar — i32/f64/bool/string/any; channel и таблицы/ячейки Dis исключены. Ключ
следует существующему ограниченному UTF-8-контракту строк FIR. Верификатор проверяет
арность, типы, строки и доминирование SSA. Печать сохраняет ключи и операнды для
повторного разбора и оптимизации.

Все три операции консервативно имеют все биты эффектов: чтение/запись памяти,
выделение, исключение, вызов пользователя и приостановку. Оптимизатор не удаляет,
не объединяет и не переносит чтение через неизвестную запись/callback. Ошибки
преобразования или свойства остаются ошибками VM, не фиктивным успехом.

Backend AVM1 использует GetVariable, SetVariable и SetMember. SSA-значения хранятся
по прежней схеме с префиксом модуля. Это backend инициализаторов, не реентерабельное
понижение AS-функций: исполнение представлений сериализуется владельцем контекста.
SWL допускает выдаваемую запись SetMember и сохраняет проверки длин команд/целей
переходов. SWO остаётся объектом, SWF создаёт только линкер. Контейнеры и опкоды Dis
не изменяются.

Backend Dis явно отвергает эти операции до появления типизированного интерфейса
к чужим AS-объектам. Неподдержанная цель не перезаписывает прежний успешный продукт.
Создания объектов, чтения свойств, вызовов методов, классов, замыканий и сетевых
прокси эти три операции не реализуют.

`ide/as/editor-view.as` проходит проверки, оптимизатор, SWO и SWL. Runtime-тест
загружает связанный SWF, а не байткод, созданный фронтендом в обход FIR. Отдельный
тест FIR проверяет порядок эффектов, печать/разбор, неверные типы и сохранение
прежнего файла при отказе цели.

Global names must be nonempty; the backend-reserved `__fir1$` prefix is rejected to protect SSA storage. / Глобальные имена непустые; префикс `__fir1$` зарезервирован для SSA.
