# Динамические AS-значения, доступ к свойствам и вызов методов в FIR

[English](AS_PROPERTIES.md) · [Профиль AS2](../../../compiler/as2/view/README.ru.md) ·
[Формат](FORMAT.ru.md) · [Грамматика](../compiler/fir1.atg) · [Backend AVM1](../compiler/object.c)

Эти операции FIR дают доступ к UI-объектам без передачи адресов и раскладок
кучи Dis. `any` здесь содержит значение AVM1, в том числе ссылку на объект,
владельцем которого остаётся FlashVM. Это не адрес чужой кучи и не готовый RPC-прокси.

| Операция | Вход/результат | Смысл |
| --- | --- | --- |
| `%x: any = as.global_get "name"` | без SSA-входов → any | Прочитать глобальное AS-значение. |
| `as.global_set "name", %x` | scalar → void | Записать глобальное AS-значение. |
| `%x: any = as.member_get %owner, %key` | any, scalar → any | Прочитать свойство по вычисленному ключу. |
| `as.member_put %owner, %pair` | any, список из двух → void | Записать свойство. В список `as.arg` добавить сначала ключ, затем значение. |
| `as.member_set %owner, "key", %x` | any, scalar → void | Записать именованное свойство захваченного объекта. |
| `%result: any = as.member_call %owner, "key"[, %arg]` | any, необязательный scalar → any | Вызвать именованный метод захваченного объекта и вернуть результат. |
| `%args: as.args = as.arg %value[, %previous]` | scalar, необязательный список → список | Дополнить список FIR одним захваченным аргументом. |
| `%result: any = as.member_call_args %owner, "key", %args` | any, список → any | Вызвать метод с аргументами в порядке исходника. |

Scalar — i32/f64/bool/string/any. Строковые литералы ключей используют
ограниченный формат UTF-8 FIR. Вычисленные ключи обрабатываются по обычным
правилам доступа к членам AVM1. Верификатор проверяет
арность, типы, строки и доминирование SSA. Печать сохраняет ключи и операнды для
повторного разбора и оптимизации.

Список из максимум восьми аргументов существует только в FIR. Связи SSA
сохраняют порядок вычисления, а backend загружает значения в нужном порядке
стека AVM1. Копирование или преобразование списка в значение AS недоступно.
Остальные операции консервативно имеют все биты эффектов: чтение/запись памяти,
выделение, исключение, вызов пользователя и приостановку. Оптимизатор не удаляет,
не объединяет и не переносит чтение через неизвестную запись/callback. Вызов
сохраняется и при неиспользуемом результате. Ошибки
преобразования или свойства остаются ошибками VM, не фиктивным успехом.

Backend AVM1 использует GetVariable, SetVariable, GetMember, SetMember и CallMethod. SSA-значения хранятся
по прежней схеме с префиксом модуля. Это backend инициализаторов, не реентерабельное
понижение AS-функций: исполнение представлений сериализуется владельцем контекста.
SWL допускает GetMember, SetMember и CallMethod и сохраняет проверки длин команд и целей
переходов. SWO остаётся объектом, SWF создаёт только линкер. Контейнеры и опкоды Dis
не изменяются.

Backend Dis явно отвергает эти операции до появления типизированного интерфейса
к чужим AS-объектам. Неподдержанная цель не перезаписывает прежний успешный продукт.
Создание объектов, классы,
замыкания и сетевые прокси выходят за пределы этого набора операций.

`ide/as/editor-view.as` проходит проверки, оптимизатор, SWO и SWL. Runtime-тест
загружает связанный SWF, а не байткод, созданный фронтендом в обход FIR. Отдельный
тест FIR проверяет порядок эффектов, печать/разбор, неверные типы и сохранение
прежнего файла при отказе цели.

Глобальные имена и имена методов должны быть непустыми. Префикс `__fir1$`
глобальных имён защищает хранилище SSA.
