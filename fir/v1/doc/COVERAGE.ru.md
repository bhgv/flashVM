# Покрытие и ограничения

[English](COVERAGE.md).

| Компонент | Реализовано | Пока отсутствует |
| --- | --- | --- |
| Читатель FIR | Coco/R, UTF-8, комментарии, точная версия | Будущие версии, бинарный формат |
| Проверка | SSA, доминирование, типы, метки, достижимость, терминаторы | Межпроцедурный анализ |
| Учебные AS1/AS2/AS3 | Один или несколько `trace(expression);`; литералы, скобки, +, -, * | Строки, классы, свойства, полная семантика |
| Учебный Limbo | Точно `implement Name; Name: module { value: fn(): int; }; value(): int { return expression; }` | Общие модули, исходные операторы каналов, процедуры, import |
| Выражения | Десятичные числа; минус перед литералом; * раньше +/-, левая ассоциативность | Деление, минус перед группой |
| Каналы FIR | Create/send/receive/close через существующее расширение | Преобразование исходных каналов Limbo, alt, spawn, ёмкость, типизированные графы |
| Backend | FWS8, один trace-only кадр, DoAction AVM1 | ABC/AVM2, графика, linker/import, исключения |

AS-адаптеры используют f64; Limbo — целые написания литералов в диапазоне i32 и wrap-арифметику.
Обвязка Limbo выводит value(), не реализуя ABI загрузчика Inferno. Пределы
source-адаптера: 64 KiB, 1000 значений, 64 вложенные группы. Неизвестный синтаксис
отклоняется; неподдержанная инструкция не пропускается молча.

AS3 здесь — ограниченный арифметический профиль совместимости для AVM1.
Для общего AS3 нужен отдельный AVM2/ABC backend. Существующие
[фронтенды](../../../compiler/README.ru.md) независимы, распознают существенно
больше синтаксиса и не заменяются учебными адаптерами. Отдельный
[linker](../../../linker/README.ru.md) остаётся границей будущей многомодульной
сборки; текущий emitter работает с одним самодостаточным модулем. Будущие
операции и типы FIR должны сохранять семантику языков до экспорта LLVM.

## Обновление 0.2.0

Числовые адаптеры поддерживают объявления с обязательной инициализацией (`var x = 1;` в AS, `x: int = 1;` в теле Limbo), присваивания и чтение переменных. AS2/AS3 допускают только аннотацию `:Number`; AS1 отвергает аннотации. Область имён одна на программу, максимум 256 имён. Повторное объявление, чтение до инициализации и неявные глобальные переменные запрещены. Это ограниченный профиль, без AS hoisting и вложенных областей. AS поддерживает десятичную экспоненту; Limbo требует целочисленное написание. Семантика находится в `compiler/lower.c`, грамматика — в `compiler/src1.atg`.
