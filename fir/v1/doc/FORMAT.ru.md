# Формат FIR 1.0

[English](FORMAT.md). Здесь описано реализованное подмножество. Возможности из
предыдущего архитектурного предложения не считаются автоматически реализованными.
Основная грамматика: [fir1.atg](../compiler/fir1.atg).

## Версия, кодировка, комментарии

Первая физическая строка — точно `FIR 1.0`, затем LF или CRLF. Перед ней нет BOM,
пустых строк и комментариев. Расширение `.fir`; каталог `v1` обозначает основное
семейство, `1.0` в заголовке — точную грамматику. Неизвестная версия отклоняется
до разбора. Поддержка новой грамматики требует явного изменения читателя, даже
при увеличении младшего номера. Версия реализации 0.1.0 и версия FlashVM независимы.

UTF-8 проверяется во всём файле, включая комментарии; NUL и неверные последовательности
запрещены. `//` — до конца строки/файла. `/* ... */` — ненестинговый комментарий
с обязательным закрытием. В строках разделители комментариев являются текстом.
Escape: `\n`, `\r`, `\t`, `\"`, `\\`. Физический перевод строки и NUL внутри
строки запрещены; Unicode escape пока нет. Print/opt сохраняют смысл, но не исходные
комментарии: вместо них печатаются номера строк входного FIR. Полные source maps
и записи исходных переменных для отладчика ещё не реализованы.

## Модуль и управление

```text
FIR 1.0
module @decision
func @main() -> void {
^entry:
    %a: i32 = const.i32 6
    %b: i32 = const.i32 7
    %test: bool = i32.lt.signed %a, %b
    if %test, ^yes, ^no // первый адрес — true, второй — false
^yes:
    trace %a
    jump ^end
^no:
    trace %b
    jump ^end
^end:
    return
}
```

Реализована ровно одна `@main() -> void` без параметров. Первый записанный блок —
входной. У каждого блока уникальная метка и терминатор `if`, `jump` или `return`.
После терминатора инструкции до следующей метки запрещены. Все блоки достижимы.
`if` принимает bool и ровно два адреса. Обратные переходы возможны, но параметров
блоков, phi, изменяемых ячеек и вызовов функций пока нет, поэтому общие циклы
с изменяемой переменной выразить ещё нельзя.

`%` обозначает значение, `^` — блок, `@` — модуль/функцию. Имя начинается с
латинской буквы или `_`; далее допустимы также цифры и точки. Регистр важен.
Значение определяется один раз. Определение доминирует над каждым использованием;
в одном блоке оно должно предшествовать использованию. Ссылки на следующие метки разрешены.

## Реализованные операции

| Операция | Вход → результат | Смысл |
| --- | --- | --- |
| `const.i32 N` | → i32 | Десятичное целое от -2147483648 до 2147483647 |
| `const.f64 N` | → f64 | Конечный десятичный литерал; дробь и экспонента допустимы |
| `const.bool true/false` | → bool | Логическое значение |
| `const.string "text"` | → string | UTF-8 с описанными escape |
| `copy %a` | T → T | То же значение, включая идентичность обёртки канала |
| `i32.add.wrap %a, %b` | i32,i32 → i32 | Сложение по модулю 2^32, знаковый результат |
| `i32.sub.wrap %a, %b` | i32,i32 → i32 | Вычитание по модулю 2^32 |
| `i32.mul.wrap %a, %b` | i32,i32 → i32 | Точные младшие 32 бита произведения |
| `i32.lt.signed %a, %b` | i32,i32 → bool | Знаковое сравнение |
| `i32.eq %a, %b` | i32,i32 → bool | Равенство |
| `f64.add/sub/mul %a, %b` | f64,f64 → f64 | Три отдельные операции строгой вещественной арифметики |
| `as.add %a, %b` | scalar,scalar → any | Преобразования/конкатенация AVM1 Add2, SWF8 |
| `as.to_number %a` | scalar → f64 | AVM1 ToNumber, SWF8 |
| `trace %a` | scalar → void | ActionTrace: преобразование в строку, передача sink хоста |
| `if %c, ^yes, ^no` | bool → void | Два явных исхода |
| `jump ^block` | → void | Безусловный переход |
| `return` | → void | Завершение текущего блока top-level actions |

Результат записывается `%name: type = operation`. Scalar — i32/f64/bool/string/any,
исключая channel. Any пока создаётся динамическим сложением или receive; создания
произвольных объектов нет. Константы f64 конечны, но вычисления могут дать infinity,
NaN и отрицательный ноль. Fast-math не используется. Разбор чисел работает в
исходной C locale исполняемого файла.

## Уже существующее расширение каналов FlashVM

После `module` укажите `requires flashvm.channels`.

| Операция | Вход → результат | Вызов существующего API |
| --- | --- | --- |
| `limbo.chan_create` | → channel | `channel.create()`, неограниченная очередь |
| `limbo.chan_send %ch, %value` | channel,scalar → void | `ch.send(value)`, успешный true отбрасывается |
| `limbo.chan_receive %ch` | channel → any | `ch.receive()`, может блокироваться |
| `limbo.chan_close %ch` | channel → void | `ch.close()`, результат отбрасывается |

[Пример](../examples/channels/main.fir). Перед выполнением хост вызывает
`fvm_extensions_install(context)`. Генератор использует AVM1 CallMethod и готовое
расширение; новых opcode VM нет. Ошибки распространяются через выполнение AVM1.
Close не уничтожает канал; ссылками обёртки управляет VM. Настройка ёмкости,
типизированный receive, alt/select, spawn и графовые типы FIR пока не реализованы.
Наличие каналов в VM не означает готовность всех преобразований языка Limbo.
[API расширения](../../../flashVM/doc/ACTIONSCRIPT_EXTENSIONS.ru.md),
[ёмкость очередей](../../../flashVM/doc/CHANNEL_CAPACITY.ru.md).
В обычном проигрывателе без расширения этот профиль не работает.

## Эффекты и оптимизации

Порядок инструкций в блоке — порядок выполнения. Константы, copy и типизированная
арифметика/сравнения полны и не имеют наблюдаемых побочных эффектов в модели FIR.
Payload NaN и флаги исключений host FPU не являются наблюдаемым состоянием FIR.
Динамические сложение/преобразование, trace и каналы консервативно сохраняются.
Каналы могут выделять память, менять очередь, блокировать поток или завершаться
ошибкой. Проход не переставляет их через другие эффекты. Обработчики исключений,
invoke и явные токены эффектов ещё не входят в 1.0. Неизвестные операции запрещены.

## Представление и пределы

[Структуры C99](../include/fir.h) содержат индексы, без приватных указателей VM.
[Builder](../src/builder.c) проверяет границы каждого добавления. Пределы: вход
2 MiB; 4096 инструкций/значений; 256 блоков; написание токена не длиннее 255 байтов,
включая кавычки и escape строки. Буферы backend — по 2 MiB. Смещение AVM1-перехода
знаковое 16-битное; слишком дальний переход отклоняется. Trampoline пока нет.

Сгенерированный парсер имеет глобальное состояние: один вход на процесс,
параллельных вызовов разбора нет. C99 API внутренний, стабильный embedding ABI
и двоичный файловый формат не обещаны. Формат обмена — текст. Ошибки синтаксиса,
типов, доминирования и диапазона backend не перезаписывают прежний результат.
Ошибка записи ОС всё ещё может оставить частичный выходной файл.
