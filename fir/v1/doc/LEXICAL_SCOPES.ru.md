# Лексические блоки численного Limbo, FIR tools 0.5.3

[English](LEXICAL_SCOPES.md) · [Профиль](SOURCE_SYNTAX.md) ·
[Полностью комментированный пример](../examples/limbo/scopes.b)

Исполняемый адаптер Limbo→FIR принимает вложенные `{ ... }`. Объявления принадлежат
блоку: локальное имя затеняет внешнее, а инициализатор читает прежнюю внешнюю
привязку. Повторное инициализированное объявление в том же блоке отклоняется.
При выходе локальные имена исчезают. Присваивание меняет ближайшую видимую
инициализированную переменную; изменение внешней переменной сохраняется.
Профили AS сохраняют плоские привязки; фигурные блоки к ним не добавлены.

Каждый блок выполняется один раз по порядку исходника. Таблица привязок выбирает
текущие SSA-значения, поэтому расширение FIR phi/mutable slots не требуется.
Ветвления, циклы, ранний return, функции, каналы и полноценные Limbo-модули пока
не реализованы. Return остаётся последним оператором численного value(). Правило
затенения этого профиля не заявляет полную совместимость языка.

Блоки, скобки и общие унарные операторы разделяют бюджет вложенности 64.
Завершённые локальные привязки занимают слоты до конца компиляции: всего 256,
включая затенения и обращения. Также сохраняются пределы 1000 SSA и 64 КиБ.
Лишняя открывающая фигурная скобка потребляется с ошибкой без рекурсивного спуска,
чтобы recovery не зацикливался на том же токене. Новый разбор сбрасывает глубину,
в том числе после незавершённого вложенного выражения в C embedding API.

## Запуск

Соберите инструменты по [pipeline](PIPELINE.md), затем из корня workspace:

```sh
# Компиляция подробного примера через авторитетную Coco/R-грамматику.
build/fir1/fir1_source limbo --input fir/v1/examples/limbo/scopes.b scopes.fir
# Проверка типов и dominance перед оптимизацией.
build/fir1/fir1 check scopes.fir
# Свёртка арифметики до const.i32 48 и trace.
build/fir1/fir1 opt scopes.fir scopes.opt.fir
# Отдельный object и линковка независимым SWL.
build/fir1/fir1 object scopes.opt.fir scopes.swo
build/swl/swl link scopes.swf scopes.swo
```

Если системный temp недоступен, задайте доступный TMPDIR. Ожидаемый trace — `48`
и перевод строки. Получение FIR не доказывает исполнение SWF: для приёмки нужен
явный runner. CTest `fir1_source_scopes` проверяет восемь успешных lowering/opt
случаев и девять ошибок с сохранением прежнего результата. Embedding-тест также
проверяет восстановление после незавершённых скобок в одном процессе.
