# Пример C99-клиента диагностики

[English](README.md) · [Контракт](../../doc/SOURCE_DIAGNOSTICS.ru.md)

[main.c](main.c) — полностью комментированный host-клиент независимого FIR API.
Он создаёт ошибочный текст `/*中*/\ttrace(missing);` с явными UTF-8 байтами,
вызывает `fir_source_ex` и проверяет semantic-ошибку, диапазон и отсутствие
записанного FIR. Здесь ожидаемая ошибка компиляции означает успех демонстрации;
неверный SWF не создаётся и не исполняется.

Из корня, с подготовленным внешним Coco/R:

```sh
./build-workspace.sh --projects fir --tests
TMPDIR="$PWD/build/workspace/tmp" build/workspace/fir/fir1_diagnostic_example
```

Ожидается сообщение `read before initialized declaration`, диапазон [14,21),
строка 1, байтовая колонка 15 и `PASS source diagnostic example`.
`main` владеет обоими потоками и закрывает их на всех путях. Диагностика содержит
копии скаляров, не указатели на исходник. Из-за трёхбайтового символа и табуляции
байтовое смещение 14 нужно преобразовать в символьное 12 перед навигацией.
При асинхронной обработке нужны digest исходного снимка и захваченная ревизия:
корректная позиция сама по себе не означает актуальность позднего результата.
[Host IDE](../../../../ide/README.ru.md) умеет проверять такую JSON-запись.
Это нативный инструмент сборки, не runtime развёртываемой IDE.
