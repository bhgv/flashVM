# Пример условий IF для C

Русская версия [README.md](README.md). Оригинал сохранён.

[choices.atg](choices.atg) показывает альтернативы с IF, необязательную часть,
ограниченное повторение и точный литерал UTF-8. Каждая строка исходника
прокомментирована. Генерируется C-код, не требующий среды исполнения C++.

Из корня репозитория, в POSIX-оболочке с компилятором C:

```sh
make -C sources -f unix.mk
cd samples/resolvers
CRFRAMES=../../frames ../../cocor choices.atg
cc -o choices choice.c choicep.c choices.c
./choices input.txt
```

Ожидаемый вывод:

```text
guarded branch
z count: 2
```

Первая альтернатива использует IF, хотя обе ветви начинаются с `x`. Чтобы
проверить запасную ветвь, замените `count == 0` на `count != 0`. Необязательная
часть использует `Sym` для проверки предпросмотра. Цикл проверяет и токен,
и счётчик; в каждой итерации потребляет вход и меняет счётчик. Он останавливается
перед третьим `z`, который затем вызовет синтаксическую ошибку вместо ожидаемого
токена `中文`. Генератор не доказывает завершение цикла и не проверяет типы
выражений C.

| Конструкция/API | Назначение | Документация |
| --- | --- | --- |
| `IF(expression)` | Заменить предсказание при выборе ветви, опции или итерации | [Семантика IF](../../docs/RESOLVERS_UTF8-ru.md#if-resolvers) |
| `Sym`, генерируемые `xSym`, `ySym`, `zSym` | Проверить токен предпросмотра без потребления | [Предпросмотр и потребление входа](../../docs/RESOLVERS_UTF8-ru.md#lookahead-and-consumption) |
| `(. ... .)` | Выполнить C-код после сопоставления входа | [Реализация и исходники](../../docs/RESOLVERS_UTF8-ru.md#implementation-and-source-links) |
| UTF-8 `"中文"` | Сопоставить точную последовательность байтов | [Гарантии UTF-8](../../docs/RESOLVERS_UTF8-ru.md#utf-8-contract) |

IF выбирает ветвь, но сам не читает токен. В `[]` условие проверяется один раз,
в `{}` — перед каждой итерацией. При ложном условии вход остаётся нетронутым.
Ветвь после `|`, не защищённая IF, по-прежнему проверяет FIRST/FOLLOW,
поэтому её нельзя считать безусловным C `else`. Подробности и ограничения
описаны в [руководстве](../../docs/RESOLVERS_UTF8-ru.md).
