# Инструменты оформления исходников

[English](README.md). Эти необязательные инструменты хоста не требуются для
сборки или выполнения отделённых компиляторов, FIR и VM.

[atg_format.py](atg_format.py) оформляет шесть текущих Coco/R C-грамматик.
Строки, комментарии, C-действия и атрибуты выделяются отдельно; порядок команд
парсера и C-токенов сохраняется. Это форматирование, а не генератор/верификатор:
после правок нужны настоящий Coco/R и тесты компонентов. Разбор атрибутов
рассчитан на используемые здесь C99-аргументы, не произвольные C++ templates.

Правила: четыре пробела на вложенность групп; завершающая точка отдельно и
пустая строка после неё; C-действия с колонки 73, последними в физической строке.
Продолжение команд парсера переносится на следующую строку. Многострочный C-блок
имеет выровненные открывающий и закрывающий маркеры. Особое действие pragma
сохраняется ПОСЛЕ завершающей точки: таков порядок Coco/R. Точки в литералах и
C-коде не являются концом правила.

Из корня репозитория:

```sh
python3 tools/atg_format.py --check compiler/*/frontend/*.atg fir/v1/compiler/*.atg
python3 tools/test_atg_format.py
python3 tools/atg_format.py --clang-format /host/path/clang-format \
  compiler/*/frontend/*.atg fir/v1/compiler/*.atg
```

Без --check явно перечисленные файлы перезаписываются. Проверка --check ничего
не меняет и требует только Python 3. Перед записью сверяется порядок токенов.
Необязательный clang-format должен исполняться на ХОСТЕ, не целевой платформе.
Семь тестов проверяют порядок действий, литералы/комментарии с похожими маркерами,
pragma, отступы, повторяемость и повреждённые группы/блоки. Потоки токенов всех
шести грамматик, включая прелюдию и C-действия, сверены с предыдущей версией;
после генерации прошли 16 CTest фронтендов и 3 CTest FIR.

[test_portable_headers.py](test_portable_headers.py) проверяет совместное
подключение публичных C99 API и диагностику неподдерживаемых byte/int/double ABI.
Запуск: python3 tools/test_portable_headers.py --cc /host/path/cc. Требуется
компилятор с синтаксисом GCC/Clang; проверка не исполняет полученный код.
