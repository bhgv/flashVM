# Inferno mk из исходников

[English](README.md) · [Манифест](UPSTREAM.json) · [Пути сборки](../../BUILD-NATIVE.ru.md)

Выбранные исходники bhgv/Inferno-OS-bhgv, experiment; точная ревизия находится
в [манифесте](UPSTREAM.json). В нём 83 файла: POSIX/sh версия mk,
реально используемые части lib9/BIO/regexp, заголовки и лицензии. По карте нативной
линковки выборка сокращена до 58 единиц трансляции. ОС, GUI, службы, остальные
утилиты и готовые бинарники не импортируются. C-код, исходные mkfile и лицензии
upstream сохраняются побайтово. Адаптация размещена отдельно: lib9-обёртка исключает
ARM-only inline caller-address, добавляет нативные объявления времени; host/support.c
обеспечивает диагностику. ARM-код на Linux AMD64 не исполняется.

Первичная сборка без CMake, make и готового mk:

```sh
sh tools/mk/bootstrap.sh build/mk
build/mk/mk -f mkfile compilers linker
```

Одной командой: `./build-workspace.sh --backend mk --projects compilers,linker`.
Настоящий mk разбирает корневой mkfile. Рецепты вызывают tools/build-native.sh,
который компилирует напрямую через CC/ar. Собственный tools/mk/mkfile позволяет
пересобрать mk из его папки. CC/AR — пути исполняемых файлов; CPPFLAGS/CFLAGS/LDFLAGS —
списки опций через пробел. Для сложного цитирования аргументов используйте обёртку
компилятора. Проверены пути с пробелами. Bootstrap всегда пересобирает; путь CMake
остаётся инкрементальным. Предупреждения upstream не скрываются.

Тест: `python3 tools/mk/tests/smoke.py build/mk/mk`. Проверяются настоящие рецепты,
шаблонные правила, отсутствие ненужной пересборки и ошибки дочернего процесса.
При равных секундах timestamp upstream mk может пересобирать цель; тест задаёт
входу более старое время без sleep. Проверенный хост — Linux AMD64/glibc.
Физические Android, BSD, ARM64 и RISC-V этими тестами не проверены.


Присваивания в командной строке используют mkstemp и ограниченный полный путь
в заданном TMPDIR, включая каталоги с пробелами. После разбора временный файл
удаляется. Недоступный/слишком длинный путь даёт явный отказ. Проверка:
`python3 tools/mk/upstream/utils/tests/mk-tempdir.py build/mk/mk`.
