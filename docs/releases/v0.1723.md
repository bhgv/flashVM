## Source and diagnostic work

The imported scalar compiler can emit private instruction/source traces without
changing executable bytes. Offline source maps bind the exact complete image,
decoded Dis PCs/opcodes and explicit source endpoints. Lookup validates those
identities; a complete experimental console reports original Dis fault PCs.
The JSON remains optional private tooling, not a VM input or new mandatory debug
section. File names are diagnostic values, not instructions to load source files.

Reverse fix: the location reader formerly checked file size and then read the
whole file, allowing growth to bypass the documented materialized-input bound.
It now reads a single opened stream with limit+1. The new independent virtual
growth test checks exact limits, EOF and stream closure without timing races.
The correction and test are published in Inferno and imported byte-for-byte.
Two CTest cases exercise bounded reads and real compiler map/lookup contracts;
the latter has explicit compiler/Linux-host input.

Our Coco/R frontend tree retains half-open original UTF-8 byte spans. Existing
scanner diagnostic columns expand tabs over bytes; interface-binding columns
count bytes. Neither is silently relabelled as Unicode. New frontend0.11.0
`limbo_source_position` resolves exact byte boundaries to one-based physical
lines and Unicode scalar columns. Tabs count one; CRLF/CR/LF each end one line.
It validates the entire borrowed snapshot and preserves output on refusal.
EOF is valid; NUL, invalid UTF-8 and interior scalar/CRLF offsets refuse.
The pure C99 API allocates nothing, uses no parser globals and is reentrant.

[English API contract](../../compiler/limbo/frontend/SOURCE-POSITIONS.md) ·

The SDK ships the header/library/example, and the offline Dis64 tool is packaged
as development tooling. No Python dependency is introduced into deployed VM code.

FLASHVM-0051 accepts decoded PCs, existing np0 entry, files/one-based lines and
explicit unknown locations. It proposes Unicode scalar columns with original
half-open byte anchors, separately recording logical #line remapping. Column/
registry changes still require explicit agreement; no shared IDs are assigned.
Default execution_supported=false, file CALL/MCALL and managed native calls stay
closed. The source-position API does not change legacy diagnostic output.
