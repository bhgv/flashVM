# v0.1552: Dis viewport, scrolling and revision-bound glyph interaction

The graphical editor now displays a Dis-selected logical-line window instead
of permanently previewing the document prefix. Ideviewport bounds each Unicode
window to 4096 UTF-8 bytes, follows page/navigation destinations and reveals long
line suffixes. Wheel scroll preserves the document cursor/history. Native
horizontal following uses actual FlashVM TextField pixel observations.

Each complete view has a monotonic ticket independent of its content revision.
Actual glyph hits become typed value requests; Dis checks ticket/revision/bounds
before applying click/Shift/drag policy. Old hits after scrolling are rejected.
Unstarted drag updates do not move selection, and focus loss releases gestures.
The renderer retains actual layout geometry and conservatively culls offscreen
contours before bounded raster calls without distorting retained control points.

Real graphical checks cover non-BMP drag replacement, scrolling without moving
the caret, stale hits, page reveal, source tails and long lines in interpreter/
JIT modes and SDL dummy upload. Independent real Dis viewport tests check logical
bounds, clamped deltas and exact UTF-8 budgets. Modules and public policy clients
must be rebuilt. Physical display/mouse, full bidi/grapheme/resize behavior,
syntax and completion widgets remain open.
