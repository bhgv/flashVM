node carrying an obsolete tail. Eight preparations bound repeated callback writes;

one consuming destructor raises. The body error wins; after a successful body,
the first cleanup error wins. No consumed release is retried. An error after commit
does not undo commit. Deferred last-owner queue ownership remains rooted until
joined Fast; tests do not confuse pending retirement with immediate reclamation.

stale writes, alias plus stale source preservation, and primary plus secondary
