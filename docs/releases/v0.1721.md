## Compiler and runtime changes

The temporary source-built Limbo now links `dis64.c` and the selected shared
header-only codecs. Its opt-in scalar backend emits the existing five sections,
checks the complete image before publication, rebases direct locals and moves
scratch aliases into a separate aligned frame tail. The ordinary Dis path is
unchanged. Our Coco/R Limbo → FIR compiler remains primary; this does not replace
its parser or claim a new general FIR → Dis64 backend.

The private field witness identifies exact declared ordinal/kind/width and binds
it to generated callable, retained Module/Type, current instance and activation
lease. Acceptance is limited to synchronous trusted C calls. Generated tables
and constructor pairing must remain immutable/trusted. This is not detached
process ownership or arbitrary bytecode-local metadata.

Optional `DVM_NATIVE64_LIMBO_EXECUTABLE` enables six explicit CTest cases without
hidden sibling build dependencies: a 64-layout external-reader test plus normal
field validation and four semantic contract-removal controls. Runtime defaults
remain unchanged: `execution_supported=false`, shared43-op np0, no file-native
CALL/MCALL, no managed native graphs or full shell.

## Reverse contribution and examples

`utils/tests/dis64-external-reader.py`, now published in Inferno and imported
byte-for-byte, generates64 layouts crossing zero..seven Big and WORD locals
kept live around scratch-using expressions. Independent native Inferno and
FlashVM bootstrap products must agree byte-for-byte. Our actual reader must
admit and exactly rewrite them without claiming general execution. Ordinary
Dis products must remain identical;64 managed-map mutations must refuse without
overwriting the destination. Optional whole-emulator execution checks actual
results and late scheduler retirement for JIT0/1, including wrong-answer errors.

The new [commented example](../../examples/firststeps/tools/limbo-scalar/loop.b)
and [bilingual README](../../examples/firststeps/tools/limbo-scalar/README.md)
ship in the bootstrap and Dis inspector packages. They check4097 iterations,
a Big sum and a preserved live Big local. The installed example can be compiled
and inspected without consulting a source checkout.
