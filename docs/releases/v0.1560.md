# v0.1560: bounded channel-owned window resize

The SDL editor window now resizes through Dis-admitted canvas proposals.
Pixel buffers/textures, TextFields, captures, hit testing, footer and zoom/page
geometry follow a bounded 240..2048 by 160..2048 canvas. Source/history/saved
state and active input fields remain owned by Dis. View identity rejects old
geometry; Canvas/Style/Panel/Viewport/snapshot revisions are checked together.
Runtime component version is now 0.5.0; host and controller must be shipped as a
matching pair. No fvd1, Dis container or heap ABI change is introduced.

[English contract](../../ide/dis/RESIZE.md) ·
[Русское руководство](../../ide/dis/RESIZE.ru.md).

Four real regression variants pass: interpreter/JIT, with replay and real SDL
texture uploads under the dummy video driver. Tests inspect actual resized
rasters, independently scanned caret/ink agreement, derived mouse coordinates,
minimum/maximum bounds, stale/malformed requests, PageUp/reveal, zoom and a retained
Find field. Device/window-manager/high-DPI acceptance remains separate.
