# v0.1760 — rooted managed owners and native Fast handoff

Runtime 0.63.0 captures one distinct managed strong reference plus external root
behind an opaque native ticket. Native scope aliases can retain/transfer/release
it outside heap admission. Last native drop allocates nothing, touches no managed
payload and wakes Fast; only the stopped-world collecting owner removes the root
and invokes retained destroy. A producer pin covers wake/worker lifetime even
when another thread's nonfinal drop overlaps final ticket reclamation.

Capture/borrow require matching acknowledged ACTIVE admission, real hosted error
environment, no guards and no native unwind. Shutdown refuses live native owners
or producer callbacks; pending tickets remain rooted until drained. Public native
extension headers, exact protocol and a commented real-runtime example ship in SDK.

The probe uses actual String/root/Cycles/Fast paths: eight native receivers,
32 real cycle passes, content validation after reentry, native error cleanup and
exact captured=2/released=2 retirement. A root-removal control must observe actual
collector reclamation and fail by semantic predicate before reclaimed payload
access. Separate real-world role sentinels test refusal, not a simulated heap.

No managed Heap/Type/Jit/wire layout change, compiler escape analysis, automatic
ownership conversion of all Dis variables or parallel managed admission occurs.
Current arenas remain address-stable; this is not a future moving-GC pin. See
[protocol and limitations](../../disVM/runtime/MANAGED-OWNERS.md).

Validation on native Linux x64: 18 affected runtime tests passed, including real
cycle GC in both executables; final root/role gates passed after admission fixes.
Actual root-removal and forced producer-overlap/pin-removal controls pass with
adapter/wrapper UBSan. The joined forced overlap, full root probe, role fixture
and helper-RC workload pass instrumented Debug interpreter TSan. Fatal negative
controls are not a TSan pass: the attempted pin-removal run reported unjoined
threads and is excluded. No sanitizer race checks were disabled. SDK C89/C++98
headers and native source example compile; vendor manifests remain unchanged.

The optional control driver also relinks production refcount.c with the forced
registry fallback: real root/ticket controls pass adapter UBSan and joined
producer overlap passes interpreter TSan for that backend too. This differs
from locked world polling and does not claim atomic conversion of all C/JIT paths.
