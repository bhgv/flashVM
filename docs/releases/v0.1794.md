# v0.1794 — fifteen guarded binary integer operations

Runtime0.96 extends explicit --gc-worker --guarded-copies to ADD/SUB/AND/OR/XOR
for BYTE, native WORD and LONG. Separate admission/computation modules claim two
inputs and the output together, capture both before any store, then compute and
publish before unlocking. Unsigned WORD/LONG arithmetic preserves modular wrap;
BYTE promotions fit int. No allocation, VM callback, FP or ownership effect occurs
under these guards. Default operation bodies/emission remain intact.
