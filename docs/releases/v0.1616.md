# v0.1611–v0.1616: live document projections, responsive windows and line numbers

[Workspace](../../README.md) · [Window/gutter guide](../../ide/dis/WINDOWS-GUTTER.md) ·
[Русский](../../ide/dis/WINDOWS-GUTTER.ru.md) · [Live projection contract](../../ide/dis/LIVE-PROJECTIONS.md)

Six FlashVM commits deliver the live document projection adapter, console watch
operations, a rendered read-only inspector, native window lifecycle repair,
dirty-close confirmation and a hideable measured line-number strip. One owning
Inferno commit fixes numeric string conversion exposed by the live inspector.

## User-visible changes

- Close recognizes per-window SDL_WINDOWEVENT_CLOSE as well as SDL_QUIT. Resize,
  size-changed, maximize and restore notifications reach the checked Dis path;
  expose repaints cached state and redundant native size requests are avoided.
- Unsaved close visibly offers S save, D discard, Esc cancel. Untitled source
  uses Save As before close. Failed output and cancelled Save As keep the document.
- Line numbers are shown on the left by default. Ctrl+L hides/shows them;
  `--line-numbers 0|1` controls startup preference. Width, font baselines, text
  offset, caret, selection, horizontal reveal and mouse hits share real geometry.
- Ctrl+I shows actual document length/revision/saved/dirty through a channel
  projection. It is read-only and closes with Esc or Ctrl+I.
- Console `watch`, `watchtable`, `setref` and `callref` use the actual document
  owner. Mutations require an observed revision and bound history methods run
  at that same owner. Adapter Release leaves the document alive.
- Packages include matching interfaces/modules/source and linked EN/RU guides;
  both headless and graphical relocated SDK examples execute successfully.

Default font remains the bundled OFL Noto Sans Mono at size 11. The native host
and Limbo modules must be rebuilt together for the added Idehost preference and
view records. Native runtime reports its CMake version (0.13.0); IDE modules are
0.10.0. Existing canvas resource bounds remain documented in the window guide.

## Bidirectional Inferno synchronization

Imported `1d8a664` adds checked string-comparison spans and AMD64/ARM64 upper-owner
windows. `ba3b4f9` fixes RV64 string windows and scalar-list address overflow.
The selected experiment head is now
[c0fe524f1653267d947ebf805c0b89ff35974c3c](https://github.com/bhgv/Inferno-OS-bhgv/commit/c0fe524f1653267d947ebf805c0b89ff35974c3c),
our returned numeric-format ownership repair, applied after both upstream changes.
Both selected snapshots verify byte-for-byte.

The actual inspector emitted `cvtlc 8(tmp), tmp`: a temporary still retained a
Value ADT containing the source big. C conversion presumed that old owner was a
String, producing an invalid heap rejection. The fix captures input before any
release and reuses only exact Tstring storage; a generic old owner remains alive
until replacement allocation/publication succeeds. AMD64/ARM64 leaves check Type
before any String access and decline write-free to C when needed. Private emission
capacity is 80 words; the Dis container/instruction ABI is unchanged.

Owning native fixtures exercise shared/unique foreign owners, embedded scalar
sources, allocation failure and unchanged register/owner state in both WORD
models. Emulation includes wrong-Type cases, exact sizing/publication, complete
memory images, upper-address spans and FP state. The graphical panel now runs
that coalesced-temporary expression directly, without an IDE-only workaround.

SDL tests use a real dummy-driver window/event queue and actual renderer uploads.
They do not claim a physical desktop/touch test. ARM64/RV64 instruction emulation
and foreign compilation are distinguished from physical native-machine execution.
The tested full runtime remains Linux AMD64 NC64.

This is a live document inspector, not yet a general debugger-local object tree.
Network RPC, authenticated export/GC, generic any/FIR lowering and arbitrary
FlashVM heap reflection remain separate work. General Limbo ADT/channel modules
currently compile with the matching source-built bootstrap.
