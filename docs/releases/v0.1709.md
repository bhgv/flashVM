# v0.1709 — Restore pooled chrome and compact desktop command bubbles

IDE 0.7.2 fixes the intermittent transparent window/control background. A hidden
scene slot clears its MovieClip graphics while retaining the managed object for
reuse. Previously its chrome cache survived that clear, so reopening an identical
control skipped painting. Retirement now invalidates the cache before clearing;
reappearance runs its AS view again. The next cache key also distinguishes popup
role and thumbnail preview scale. A render failure cannot keep a valid old key.
Position-only changes retain graphics reuse; no global redraw or frame wait was
added.

The right shelf shrinks from 104 to 60 pixels. Its common 44×27 controls sit six
pixels from the outer edge. Files/Edit/Search/View open rounded compact bubbles
immediately to the left, with a triangular pointer toward the invoking button.
Their buttons execute the same AS appearance as shelf buttons. Search uses only
the two occupied columns; the other grids use three columns, or four on shorter
canvases. Readable numbered recent-path labels are below the Files grid. Gaps,
empty cells and the legend cannot execute a command.

Palette-only commands leave the main shelf. The explicitly requested frequent
Save, Undo, Redo and Find exceptions remain. Build, Debug and Help are direct
commands; Help toggles its owned pane. View contains All, Max/Norm, MDI, SDI and
Close. New graphics are under Files → SVG. Maximize, reveal, Show All, source hit
admission and wheel routing use the actual narrower shelf boundary.

Layout, command mapping and hit admission remain Limbo-owned. The separate
`idetoolpalette` module owns popup geometry; new `tool-palette.as` and
`tool-pointer.as` own their visuals. AS resources use the real Coco/R → FIR → SWO
→ linked SWF pipeline and run through FlashVM. C invalidates graphics and reads
rail extents from the complete copied scene; it does not define a second toolbar
layout. No shared Dis64 format or external module ABI changes.

The installer includes the new Dis module and its source, plus both AS views.
English/Russian control contracts, vector entry points and workspace instructions
are linked from the IDE documentation; the runtime Help text names the new menus.
See [desktop controls](../../ide/dis/DESKTOP-CONTROLS.md) /
[контролы](../../ide/dis/DESKTOP-CONTROLS.ru.md).
