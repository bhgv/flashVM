# FlashVM v0.1722 — object/node tools and scale damage repair

The vector pane adds two independent arrow tools at the top of its left toolbar:
Objects (V) and Nodes (N). Each existing Shape is one selectable figure, including
primitive paths, connected Lines, fitted Brush unions, Pen and imported compound
paths. Colours remain on the right.

Objects picks the topmost touched stroke/filled interior. Drag translates it;
four corner handles scale around the opposite corner and the upper handle rotates
around the figure centre. Nodes picks one contour, highlights it and displays
endpoint/control squares and quadratic guides. Click selects a handle, Ctrl-click
toggles additive selection, empty-canvas drag selects a rectangular group, and
dragging selected handles moves the group. Picking a different contour retires
the old node selection. Existing curves remain quadratic.

`idevectoredit.b` owns the algorithm and immutable gesture baseline in Limbo.
Pointer updates derive from the original snapshot; release creates one Undo item,
Cancel restores it, and returning to the origin creates no edit. SVG/history
contain source figures only, never selection overlays. Pending ink fitting is
settled before a portable edit starts. Editing arrows bypass native stamp capture;
render workers receive copied immutable geometry through existing channels.
Private commands 18/19 and tool values 6/7 require rebuilding matching native and
Dis products; no shared SWF/Dis64 format ID changes. IDE version is 0.7.9.

Retained raster preparation now treats width/height changes as transformed ink,
invalidating both old and new extents. A changed linear affine transform marks
the root for recomposition from cached images. Translation-only gestures retain
bounded tile damage. The regression shrinks/re-expands a card at an unchanged
matrix and compares incremental pixels byte-for-byte with a fresh render; zoom
and rotation continue to reuse local images. This addresses stale strips left
by old card/control geometry during desktop scale changes.

Validation covers model move/scale/rotation, Ctrl groups, marquee, separate
quadratic controls, immutable source, Undo/Cancel and real mouse toolbar/SVG
routing in interpreter and JIT. Existing drawing, native ink, control-cache,
workspace and atlas regressions remain passing. The installed SDK includes the
new helper and bilingual guides and is exercised through its actual executable.

The presentation overlay retains a 4096-command budget. Very dense paths show a
bounded initial set of handles while the complete contour stays intact and all
nodes participate in marquee picking. This first implementation has no node
insert/delete/join/split commands or multi-object selection. Transforms leaving
the bounded 1000×600 canvas are refused. Physical desktop latency was not measured.
