## Visible editor behaviour

Desktop/menu **8** now displays Limbo/AS keyword, numeric, string and comment
colours. Untitled/.b selects Limbo; .as/.as1/.as2/.as3 selects AS. Recognition
comes from the Coco/R-generated lexical service introduced in v0.1692.
One active scan plus only the newest pending snapshot bounds obsolete work.
Revision/profile/ticket mismatches cannot publish old colours into new text.
The same immutable catalog can serve lexical context/search consumers; semantic
scopes, typed completion and full compiler parsing remain separate work.

The pane projects colours only into its bounded current viewport. The app gets a
fresh owner snapshot before sending a copied palette through the typed channel.
Late completion is paint-only: it keeps the completed geometry/input ticket,
does not acknowledge pending input, move windows, change caret/selection, edit
source, touch Undo or mark the document dirty. It is independent of the legacy
Flash timeline. A burst of26 queued characters is checked while completions
compete with input; exact text order and the final revision palette survive.

Only explicit `startnotified` with a buffered readiness channel and positive pane
ID enables automatic analysis. Plain library `start` keeps its previous owner
behaviour without unexpected scans. This matters for large clipboard/service
clients with bounded instruction budgets. Unknown suffixes, missing optional
scanners and over-budget results remain editable plain text. Shutdown can drain
an active bounded scan; no OS-thread-parallel Dis/GC claim is made.

## Shared TextField geometry and rendering

New C89 `fvm_textfield_path_ranges` exports detached selected glyph contours from
one cached whole-field layout. It accepts sorted scalar-aligned UTF-8 byte ranges
and selects glyphs by shaping-cluster start, preserving whole-field advances,
kerning, wrapping, alignment and scroll. It never reshapes each coloured token.
Empty ranges, quotas and malformed UTF-8 boundaries have explicit contracts.
Uniform underline is excluded from range exports; the old full export is unchanged.
This is a native colour presentation extension, not full AS range TextFormat,
mixed-font or HTML implementation.

Native code batches palette contours, draws selection first and caret last,
and copies commands into the existing immutable dirty-tile raster jobs. Thumbnail
and drag caches include colours. The native receiver validates current view,
live editor item, scalar extent, classes and quota; source revision authority
stays with Limbo. Local UI code65575 does not allocate a Dis64 extension ID.
Captions replace control/line separators only for presentation, preserving the
actual file path and the caption/body delimiter. A legal POSIX newline filename
is covered by the real UI test.
