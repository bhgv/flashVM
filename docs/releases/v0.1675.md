# v0.1675 — Каретка и выделение в настоящем MovieClip-столе

[Подробное руководство](../../ide/DESKTOP-POINTER.ru.md) ·
[English](../../ide/DESKTOP-POINTER.md) · [Предыдущая серия](v0.1674.md)

В редакторах desktop-ide.dis теперь работают клик для установки каретки,
Shift-клик и выделение перетаскиванием внутри тела окна. Подсветка — настоящий
MovieClip под текстом; клавиатурное выделение и миниатюры используют те же значения.
Ввод заменяет полный выбранный исходник через Ideinput/Idecore, а не обрезанный
viewport. Undo остаётся одной операцией изменения текста. Активация другого тела
не перемещает стол; заголовки, пустое место, Close/Cancel сохраняют прежние роли.

![Реальное выделение и сборка](../../ide/assets/desktop-v0.1675.png)

FlashVM измеряет реальную матрицу клипа и глифы по общему пути font/wrap/tab с
кареткой и подсветкой. Затем Limbo layout отдельно проверяет окно/ticket/перекрытие,
а владелец документа — полную Unicode-позицию и точную source revision. Родной
anchor остаётся приватным; наружу уходит только обрезанная видимая граница.
Stale, повреждённые метаданные, потеря фокуса, другой ввод, выход из тела и modal
отменяют продолжение. Позднее отпускание не оживляет жест.

Исправлен AS-порядок настройки TextField: multiline/wrap/размеры задаются до текста.
Табуляция требует немедленного измерения, поэтому прежнее присваивание текста до
multiline вызывало UNSUPPORTED. Изменён обычный исходник AS, пересобранный Coco/R →
FIR → peepholes → SWO → SWL → SWF8. Новый парсер/контейнер не добавлен.

Добавлен [полностью комментированный пример](../../ide/dis/examples/desktop-pointer/README.ru.md):
настоящий владелец выделяет π/😀, заменяет их, отвергает устаревшую revision и
подтверждает Shutdown. Он не изображает геометрию/GUI и не читает/не пишет файлы.
Согласованные `.m`/`.dis` и native runtime нужно устанавливать вместе: Item теперь
содержит девять слов, предложение указателя — четыре. Runtime 0.38.0.

Inferno experiment: `b27a8513e5cbae9768bf7d95d1fe25bb967a4c4b`.
Импортированы проверки циклов и повреждённых хвостов до добавления/отмены ожидания,
FIFO head/successor и empty-head readiness/JIT guards. Dis 799 + bootstrap 277,
956 уникальных исходников побайтово сверены с Git blob и SHA-256. Нового общего
дефекта для обратной отправки не найдено; прошлые исходящие правки сохранены там.
UI-исправления остаются здесь, upstream-снимки не адаптируются на месте.

Финальная приёмка: **core 214/214**, **runtime 245/245** целиком после
AS-исправления. Установленные editor/runtime SDK, compiler-OFF и восстановленные
только из Git владельцы/примеры проходят interpreter и JIT. Отдельно проверяются настоящий raster выделения, сохранённые исходники, Unicode/CRLF,
wrap/tab, один Undo, полный Ctrl+A за пределами viewport, Shift/drag, независимый
фокус, перемещённое окно и stale/malformed/cancel. Оба SDK проверяют настоящие
графические точки входа, исходные файлы и C99-перелинковку. Текст/шрифт берётся
из установленного пакета, не из путей рабочего дерева.

Первый вариант не захватывает drag через другие окна и не делает autoscroll за
границами тела. Clipboard, сохранение сессии, resize окон, графические документы,
панели экспорта и подключённые Run/Debug в этой оболочке ещё интегрируются.
MovieClip-измерение и рисование идут на владельце FlashVM; worker получает только
пиксели. Кооперативные процессы Limbo не объявляются параллельными нативными VM.
Физический touch и прочие CPU/OS не выводятся из headless AMD64 replay.
