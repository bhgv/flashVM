# v0.1549: refreshed Dis/JIT and executable selected Inferno modules

The selected Inferno experiment snapshot advances from 96935b0 through dad4b09,
including six upstream commits. Both Dis and temporary compiler provenance are
refreshed; imported files retain exact hashes/notices. Updates include numeric
native table dispatch, owner marking/copies, typed-record copies, module-table
checks, head lifetimes, Sys pctl/directory packing and Srv result/error ownership.
The source selection remains a bounded interpreter/tools/library closure, not an OS.

The real NC64 runner registers $Srv, $Math and $Loader and packages eight selected
Limbo libraries: Bufio, String, Arg, Readdir, Debug, Dis, Styx and Styxservers.
The root menu adds launch 7 for the heavily commented real Dis module tutorial;
installed run-checks includes it. Canonical selected /dis/lib paths resolve to
package siblings without changing ordinary Sys file paths or caller cwd. The
installer ships symbols, interfaces, prepared sources and linked status/tutorial
guides. The library project also builds independently with explicit compiler and
source closure, in either classic or NC64 mode.

Srv retains production owner rollback/GC roots, calls a shared real native resolver
and uses a native lock. Service-port validation prevents getaddrinfo from wrapping
65536 to zero, including signed/whitespace bypasses. Math retains checked binding
and vector code with matching generated frames; scalar functions use host libm.
Module-local primitive array descriptors are admitted by the NC64 adapter. Loader
returns actual instructions, descriptors and links; Sys descriptor initialization
is idempotent across registration. Sys fprint reports actual formatted FD writes.

New upstream numeric native leaves use classic fixed-width tables. NC64 explicitly
declines those leaves and uses separate checked native-cell C adapters. Tests
execute sparse int, big and dense tables, verify all three opcodes actually occur
in compiler output, and exercise unaligned fields/high-bit PC rejection separately.
Core tests still exercise the upstream native classic table/owner/mapped-copy paths.

Transfer uncovered additional bugs. Legacy dtoa used native long for 32-bit limbs,
accessing beyond double storage on LP64; its signed limb-packing shift was also
undefined. Both compiler build routes now derive 32-bit limbs and unsigned packing.
Both Styx decoders could trim away a claimed sub-header frame then index outside
it; prepared views reject those sizes first. NC64 Styx additionally preserves
signed wire int32 semantics for NOFID and Qid versions. Separate source patches
for dtoa and the portable Styx guard are retained without editing imported bytes.
The checked upstream revision still contained those defects.

Validation: 64 core CTest entries and 39 real-runtime/IDE/port entries pass.
The module tutorial and 134 independently checked binary64 constants run in both
interpreter/JIT modes and under UBSan, including actual compiler preparation.
Port/table fixtures also pass UBSan; the resolver compiles as C89. Nineteen menu,
four graphical-package selector and five preflight checks pass. Detached library
builds in a path with spaces produce eight classic and eight NC64 .dis/.sbl pairs.
Direct compiler/bootstrap products and Math scaffolds build. Installed package
relocation and the normal check launcher are verified. Our Coco/R Limbo parser
accepts the tutorial. Graphics library build acceptance does not establish physical
window/audio/video behavior or other runtime platforms.

[Module-by-module coverage and limitations](../../disVM/libraries/README.md)
is authoritative. Debug initialization is not a /prog device or working source
debugger. Dis's classic object parser is not declared NC64-compatible. Readdir
still needs Sys.dirread for enumeration, Styxservers needs process/transport/
namespace services for live serving, and full Math/Loader conformance is open.
The runtime remains Linux AMD64 NC64 with one native owner; synchronous DNS may
block it. No full Inferno VFS/Styx, parallel VM/GC or graphical IDE claim is made.
