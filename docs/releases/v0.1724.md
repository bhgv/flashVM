# FlashVM v0.1724 — brush splines, page viewport and Sys.millisec

The vector editor adds post-release relative brush fitting and an independent
canvas camera. The native Dis runtime also implements the existing Sys.millisec
service without a GUI or Flash frame dependency. IDE version:0.7.10.

## Brush fitting

The private Limbo worker compares both coordinate deltas strictly against1/40
of the complete filled figure's corresponding extent, including compound loops.
Dense bounded runs become two-piece quadratic splines with two controls and a
common tangent at the middle knot, unless a control needs canvas clamping.
Endpoints and the middle knot are interpolated; other close samples are fitted.
Run-span limits prevent a chain of short edges collapsing a whole closed path.
Sparse corners/holes and explicit Close commands remain in the existing model.

`idevectorbrushfit.b` is separate from native raw ink capture and the UI owner.
`brushfit` is a bounded pure model/worker helper. The Nodes arrow exposes both
controls; nearest-handle picking fixes overlap ambiguity for dense controls.
Existing Ctrl/marquee groups, immutable transactions, Undo/Cancel and SVG Q apply.
No cubic command or shared file format is invented.

## Canvas viewport

The new magnifier below the two selection arrows toggles viewport mode. Wheel or
two-finger pinch over the page zooms around the pointed logical focus. Left-drag
frames a rectangle; release fits and centres it. Native double-click/double-tap on
the magnifier sends an owner reset to the initial1:1 camera. Dis does not depend
on wall-clock callbacks or frame playback to recognize the gesture. Exiting mode
restores the previous tool and retains magnification for drawing/editing.

`idevectorviewport.b` owns25..1600% zoom and logical centre. Camera state and
rubber-band overlays do not enter SVG, history or source revisions. 100% means
the original fitted-page camera, not a physical-DPI promise. All paint, native
stamp/XOR preview and inverse pointer paths use the same copied camera. The
fixed viewport clips geometry independently of toolbar/title controls.

Default wire bytes remain unchanged. Nondefault camera metadata uses private
bit0x10000 and three bounded words before geometry. Unknown flags, short data
and invalid zoom/centres refuse before publication. Private command20 toggles,
21/22 step and23 resets; pointer12 classifies native double magnifier activation.
These are matched IDE/native interfaces, not SWF/Dis64 registry assignments.

## Sys.millisec

`runtime/clock_sys.c` captures the real generated Sys frame, then reads the
independent `host/clock_port.c` monotonic port. Arbitrary epoch, host-dependent
resolution/suspend behavior and native WORD wrapping follow the clock contract;
use elapsed differences, never calendar time. No allocation, callback, scheduler
wait, SDL or Flash context is required. OS failure raises a normal VM error
without a fabricated result.

Linux/Android use CLOCK_MONOTONIC; macOS mach_absolute_time; Windows GetTickCount64.
Only native Linux x64 is executed in this series. The generic C99 header and
source reference, commented Limbo probe and compiled example ship in the SDK.
No Sys signature or native-file-call permission changes.

## Validation

The final18-case set passes model fitting, spline-handle editing, camera-only
marquee/focus/reset, object/node routing, native brush/primitive capture, actual
SDL double-tap, retained raster and Sys clock checks. The broader drawing/tool
suite also ran; two caption fixtures initially detected an unconditional suffix
and passed after default captions were preserved.

Actual desktop replays in both interpreter/JIT cover wheel, pinch, fitted
selection, pixel clipping, double reset and byte-identical saved SVG. The native
clock test executes10000 ordered samples and a real20ms wait; the Sys probe makes
2001 actual calls in each mode without GUI. Installed SDK probes and viewport
replay use the shipped executables. These are conformance checks, not measured
physical touch latency/FPS or acceptance of unexecuted clock ports.
