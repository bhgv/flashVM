# v0.1706 — Brush areas, Pen centerlines and deferred geometry

Кисть и перо разделены: **B** рисует заполненный след круглого наконечника,
**P** — осевую линию с обводкой. Сглаживание выполняется после отпускания,
в отдельном процессе Limbo. Периодическое сглаживание во время жеста пока
не включено. Последняя нижняя кнопка палитры теперь выбирает перо.

Brush paints a filled nib boundary; Pen smooths a stroked centerline. Raw input
is preserved while moving. The old63-sample decimation, per-move quadratic
fitting, captured-motion coalescing and raster wait for captured continuations
have been removed. The capture maps against its pane's composed matrix and
clamps to the page; leaving the page does not discard the whole stroke.

The portable Limbo worker receives immutable shapes. One active job and one
latest queued snapshot bound memory/latency; only the current revision publishes.
Save drains current work. Ordinary input does not wait. Exceptions and contour
limits retain raw ink, and a sample-capacity event commits retained raw ink as
one Undo unit instead of canceling it. Dis scheduling remains separate from
Flash frame clocks; this does not introduce parallel native VM/GC execution.

Brush geometry uses a1000×600 packed coverage grid, circular sweep, visible
same-colour connected union, winding-preserving boundary tracing and polygonal
approximation. Holes survive as compound SVG subpaths. Different-colour overlays
are respected. Precision is quantized to logical cells; this is not an exact
analytic Boolean library. Canonical masks and all history snapshots are immutable.
Plain Limbo scalar storage is explicitly zeroed; doubling array copies avoid
per-cell interpreted initialization and prevent old allocation bits leaking into
new masks. The copied wire encoder also writes a single sized byte buffer.

Budgets:32 shapes,4096 commands/path,16384 commands/document,1 MiB complete SVG
input. There is no lossy live decimation. Quota/failure behavior and imported-curve
subdivision are documented in the [English guide](../../ide/VECTOR-EDITOR.md) and
[русском руководстве](../../ide/VECTOR-EDITOR.ru.md).

Validation exercises both interpreter and native JIT dispatch: raw samples,
release-time Pen curves, Brush fill and holes, compound SVG roundtrip, connected
union across queued gestures, different colours, immutable Undo, capacity
retention, actual SDL FIFO ordering and real MovieClip pixels/Save/Open. Native
input policy tests run without a display; UI replay is not physical-device or
input-latency certification. No Dis64 format IDs or upstream Inferno files change.

Acceptance on the Linux x86-64 development host: the runtime matrix covered348
cases; all14 affected cases passed on the final tree, including both MDI dispatch
modes. A freshly installed SDK relocated to a path containing spaces passed the
actual mouse-toolbar Brush/Pen/figure, captured off-page release, SVG Save/Open,
Undo/Redo and raster checks with native JIT dispatch. The other334 cases passed
in the broad runtime run. No physical touch/arm64/riscv64 latency claim is made.
