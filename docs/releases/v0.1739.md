# v0.1739 — FIFO exclusive heap-mutator turns

Runtime 0.47.0 uses an explicit serialized native world for its GC-worker heap.
Multiple native owners can register stable roots, but only the oldest admitted
owner may mutate the heap. Leaving for audited native I/O makes the next ticket
eligible. A returning owner cannot bypass an already queued peer. Collection
keeps priority over admission and observes both active/parked and inactive roots.
No mutex is added to the ordinary no-request instruction fast-poll.

The public create_serial/admission API, runtime diagnostics and fixture contracts
are documented. The existing parallel-admission constructor retains its original
behavior and requires caller synchronization for shared mutation.

Two actual OS owners execute retained addw against one plain shared operand.
They prove FIFO under deterministic contention, peer progress during a native
wait, 20000 stress reentries, exact arithmetic, 201 stable-root scans and complete
TLS/registration teardown. Atomic/locked, no-atomics fallback and strict UBSan
runs pass. The focused native TSan run also passes without a race report
(executable-name lookup warns, limiting symbolization). This is not whole-VM
TSan coverage. Removing the production exclusive-active condition triggers the
expected immediate semantic failure. Existing two-active-owner reference/GC
worker fixtures remain separate and pass unchanged.

Sixteen runtime gates pass, including real GC, native read/write/print/wait,
file services and UI ownership. This is admission infrastructure connected to
production, not completed parallel managed spawn. The current managed scheduler
still has one executor; per-owner call state, runnable lists, module caches and
channels need migration before another can be enabled. Concurrent graph marking
and cancellation of a queued owner are not admitted.

Inferno experiment was checked through e5fa611. Dis64 code remains at the tested
0069 checkpoint; both snapshot manifests retain a1d8cd9. No wire/calling ABI or
registry ID changes in this series.
