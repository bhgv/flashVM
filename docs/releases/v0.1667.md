# v0.1667 — Grouped typed conditions, compiler accounting and portable IDE fixtures

[Contract EN](../../fir/v1/doc/GROUPED_CONDITIONS.md) / [RU](../../fir/v1/doc/GROUPED_CONDITIONS.ru.md) · [Real tutorial](../../fir/v1/examples/dis/grouped-conditions.b) · [Int tutorial](../../fir/v1/examples/dis/grouped-int.b) · [Inferno synchronization](../../disVM/SYNC.md)

FIR **0.56.0**, source CLI **0.23.0**. Homogeneous Limbo int/real expressions
now share one authoritative Coco/R precedence hierarchy. Arithmetic and boolean
parentheses compose normally; repeated unary negation and bool-predicate equality
work without a separate grouping classifier. Equality/ordering/bit precedence
matches the corresponding native Limbo operators. Existing explicit !(...) and
arithmetic-only inputs remain accepted.

Numeric producers now record static SSA kinds. Arithmetic, signs, complement,
shifts, identity alias casts, numeric bindings and returns reject intermediate
bools before publication. Conditions still require normalized bools, and bool
ordering/mixed equality reject. Once SSA allocation fails, condition validation
does not index an exhausted type catalog. Negative fixtures require one structured
compiler diagnostic: a sanitizer abort cannot count as correct rejection.

Source order, lazy RHS errors, IEEE NaN/signed-zero behavior and existing depth/
SSA/block budgets are retained. FIRDBG1 preserves exact relation/logical/unary
UTF-8 origins. No opcode, frame/GC layout, container format, dynamic AS coercion
or shared heap pointer is introduced. New examples comment every nonblank source
line and ship with detailed linked EN/RU guides. Relocated C99 SDK checks compare
CLI/library Dis and execute the new real tutorial alongside prior examples.

Inferno experiment **11e277299395ec75ea331c6ed1f93016b9c059c2** advances both exact
snapshots: **744 Dis / 262 bootstrap files**. Checked declaration use counts and
temporary holds now cover all remaining compiler producers; the new lifetime/
source-audit fixture is imported and registered. Existing helper-dependent fixtures
are synchronized. No additional shared defect required an outbound patch; our
compiler/IDE-specific changes remain in FlashVM, and experiment is unchanged here.

Relocated IDE acceptance exposed a transient staging sibling next to its sparse
4-GiB fixture: exact directory enumeration saw one unexpected entry. The driver
now creates that sparse stat fixture outside the directory whose complete 73
entries are checked as 32/32/9 batches. No names are filtered and no retries or
sleeps hide extra entries. Unicode, controls, exact large metadata, cursor/value
ownership, quota and both execution modes remain checked. Shipped Limbo tutorial
and detailed EN/RU READMEs use the same isolated fixture contract.

## По-русски

Добавлены обычная группировка условий, повторное ! и равенство bool-предикатов.
Общая Coco/R-грамматика сохраняет приоритеты Limbo, порядок и ленивость вычислений.
Числовые переменные, return, арифметика, сдвиги и alias-casts проверяют статический
тип и не принимают промежуточный bool. Защищён выход после исчерпания SSA-бюджета;
отрицательные проверки требуют корректный JSON diagnostic, а не просто ненулевой
код процесса. Позиции каждого ! и ленивого оператора проверены после Unicode-префикса.

Синхронизированы проверяемые refs/tref компилятора Inferno и новые fixtures.
Пример браузера IDE отделяет sparse-stat от строгого перечисления каталога:
реальный сбой перенесённого SDK устранён без фильтрации записей и ослабления
контракта. Два новых примера и подробные руководства связаны с общей документацией
и входят в установленные SDK. Полные языки, self-hosted сборка всей IDE, итоговые
карты Dis/SWF/JIT PC и панели Build/Run/Debug остаются дальнейшими этапами.
