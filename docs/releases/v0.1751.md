# v0.1751 — metadata and directory waits outside the managed heap

Runtime0.55.0 adds audited native waits for Sys.stat, Sys.fstat and Sys.dirread.
Path stat snapshots validated UTF-8 into native storage; file/directory fstat
pins the mapped FD and captures its native handle. Both use copied native
metadata, building VM records/strings only after heap reentry. Path staging is
freed for success/error returns; FD pins retire before VM publication.

Directory slots now allocate the same native FIFO as ordinary files. Directory
metadata, batch read and abort participate in it; close refuses pending gates.
A batch read pins FD, reserves while ACTIVE, releases the native lease, reads a
bounded native batch, finishes its gate BEFORE reentry and then builds mapped
records under the heap gate. Native storage is freed on success/EOF/protected
publication failure. Abort retains its active error-cleanup boundary. Native
operation order does not imply whole-directory snapshot/transaction or VM
publication order; completed concurrent batches cannot be rolled back.

NATIVEMETADATA reports path/descriptor attempts, actual lease releases, pins,
native PATH staging/peak and directory batch attempts. Batch memory is owned by
the port separately. Open/create/close, private loader work and protected
native64holds/gchalt remain synchronous. The stable default still uses one
managed executor; worker GC and1..8 executors remain opt-in. No forced native
cancellation or parallel managed heap writes are introduced.

The commented metadata-overlap Limbo example and private Linux/glibc interposer
pause real stat64/fstat64/readdir64 calls in inherited OS-pipe barriers. The
driver sends stdin tokens only AFTER observing each pause; an unrelated actor
must convert another UTF-8 path, compute and print BEFORE release. It verifies
two simultaneously live path snapshots and normal pin/staging/gate retirement.
Two directory actors also consume65 distinct names exactly once through one FD,
across32-entry native batches. Console/editor C/JIT4/8-owner cases pass. These
are controlled blocking checks, not measured slow-filesystem performance.
