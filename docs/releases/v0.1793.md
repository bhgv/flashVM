# v0.1793 — jointly guarded integer conversions

Runtime0.95 extends explicit --gc-worker --guarded-copies to six integer
conversions: CVTBW/WB/WS/SW/WL/LW. Separate admission and value modules validate
both spans, claim their ordered byte union, capture input and publish output
before unlocking. Identical/partially overlapping and unaligned cells are supported.
No allocation, managed ownership change, VM callback or FP computation is added
under guards. Default bodies/emission and host C narrowing semantics are retained.

[Commented Limbo example](../../disVM/examples/guarded-integer/README.md).
[Parallel heap status](../../disVM/runtime/HEAP-PARALLELISM-STATUS.ru.md).

29 affected CTests pass in 193.96 seconds. The actual six-op C fixture checks 23400
values/overlaps with full result/canary comparisons, geometric/held-guard refusals,
unchanged guard failure and real protected opcode errors. Two omission controls
must stop at the precise semantic failure. The compiled Limbo guest proves four
real x64 conversion tails through cache/unmap/error/return-PC and negative emitter
controls; native SHORT C coverage is not a guest SHORT-tail proof. Both new suites
pass TSan positives. Generated machine code is uninstrumented; no new physical
ARM64/RV64, hosted UBSan or general parallel-managed acceptance is claimed.

The old MOV-tail observer now filters only its own five operations, so new
conversion entries cannot masquerade as MOVM coverage. Three affected tail suites
pass again after this correction in 54.91 seconds. Installed source/test closure
and ordinary C/guarded C/guarded JIT example profiles pass. Vendor sources remain
byte-identical: 1096 DisVM and 312 bootstrap files at ba26acc.

[INT-095 cost ledger](../../disVM/runtime/PERFORMANCE-COSTS.md): median of three
local startup-inclusive runs after warmup, same image/binary, 20000 iterations:
C 0.174222527→0.191245283 seconds (+9.77%); JIT 0.126487650→0.167297898 (+32.26%).
This is whole guarded-profile overhead, including other copy operations. Do not
attribute the total to a single instruction or sum unrelated workload percentages.
No guard/root safety was removed for the measurement.

NativeWorld still serializes general managed execution. Remaining major gates:
list construction, other arithmetic/reference writers, channel/scheduler ownership,
root/graph/GC epochs and executable/frame/module lifetimes, then compiler-proven
local/shared paths. The six converted writers are a bounded prerequisite, not
completion of parallel managed execution. Dis64 IDs/layout/default admission and
immutable named launch/cache agreements are unchanged; no upstream implementation
or Draw import. Inferno correspondence continues in FLASHVM-0111.
