# v0.1788 — preallocated atomic root groups

Runtime0.90 adds a reserved native root group: create metadata before access
locks, publish all occurrences together, clear exactly that group, then destroy
an inactive reservation. Publication/clear never allocate or invoke callbacks;
registry mutex acquisition may wait. Ordinary root removal cannot steal group
entries. Empty publication is active and blocks premature destruction.

This is the root-retirement prerequisite for reference-rich mapped copies.
MOVMP/HEADMP are not yet converted. It does not remove NativeWorld, acquire
strong owners, validate arbitrary pointers or introduce concurrent GC epochs.
No Heap/native VM or Dis64 serialized layout/IDs/default admission changes.
