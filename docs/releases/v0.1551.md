# v0.1551: published Inferno fix and Dis logical-line navigation

Both Inferno selections now pin public experiment cc9c3199, including the
compiler-local byte-descriptor fix. Preparation no longer nests a second local
guard. The original published WORD32/native string/UTF regression is selected
and executed without rewriting production C. Historical patch provenance stays
explicit. The user's renewed standing authorization for non-force publication
and two-way upstream synchronization is recorded in the owning instructions.

The Dis input controller adds preferred Unicode columns across short lines,
Up/Down, bounded PageUp/PageDown, Ctrl+Home/End and Shift selections. CR before
LF/EOF is excluded from navigation destinations without changing source bytes.
Edits, horizontal moves and external revisions reset the vertical goal. SDL maps
real native key transitions; it does not implement document movement.

The new real-channel regression passes in interpreter and JIT modes, including
Unicode/non-BMP text, paging, CRLF, selections, unchanged revisions and stale
external edits. The upstream descriptor regression, existing bridge applications
and idempotent source generation also pass. All State clients must be rebuilt.
Full visual-wrap/bidi/grapheme editing is not claimed.
