FIR **0.57.0**, source compiler **0.24.0**, structural frontend **0.1.5**.
Homogeneous Limbo int and real functions now support nonterminal if/else joins,
optional else, else-if, while, innermost break/continue, lexical shadowing and
early return. Locals crossing control-flow edges use exact typed storage.
Coco/R remains authoritative for both source and FIR parsers. Separate numeric
and table statement FIRST sets also fix non-progress on unsupported numeric for:
it now produces a located structured diagnostic.

Two private types, i32.slot and f64.slot, and six append-only local/store/load
operations carry mutable numeric locals. Construction initializes zero/+0;
loads capture values independently of later stores. Verification enforces exact
types, dominance and non-escape. Effects and peephole forwarding preserve barriers.
Scalar and hosted Dis, AVM1 SWO/SWF and the C99 reference executor implement the
same operations. Hosted pointer maps exclude numeric cells. No new native Dis
opcode or cross-VM shared pointer is introduced.

Four fully commented tutorials demonstrate int/real control flow and raw FIR
cells, with detailed linked English/Russian contracts and relocated SDK coverage.
Debug checks preserve UTF-8 byte origins through while and loop transfers.
NaN, signed zero, int wraparound, independent cells, early returns, nested loops,
forged signatures and staged-output preservation have executable checks.

**36d5228f5e46a594a8b983429e16fb69eb07a7e9**: **752 Dis / 270 bootstrap files**.
This imports checked lexical-scope indices and label growth, iterative global

required publishing an Inferno patch in this series. This tested pin is fixed.

## По-русски

Числовой Limbo больше не ограничивается завершающим if: доступны продолжение после
ветвления, while, break/continue, ранний return и области видимости. Изменяемые
int/real представлены приватными типизированными ячейками FIR с проверкой типов,
эффектами оптимизатора и исполнением в Dis и SWF. Исправлено зависание диагностики
неподдерживаемого числового for. Добавлены четыре подробно комментированных примера,
связанные руководства и проверки переносимых SDK. Синхронизированы защиты scope/
labels и итеративное связывание глобальных деклараций из Inferno experiment.

The profiles remain bounded: numeric for, full function-call ABI, full AS/Limbo
languages, complete self-hosted IDE and final cross-backend debugger PC maps are
future work. Constant-true loops are conservatively considered possibly empty
when proving a function returns. Optional foreign CPU emulation is unavailable;
physical ARM64/RV64 acceptance and complete Inferno boot are not claimed.
