# FlashVM v0.1728 — finer brush fitting and superseded-job cancellation

IDE0.7.13. [Contract EN](../../ide/VECTOR-CANCELLATION.md) ·
[Описание RU](../../ide/VECTOR-CANCELLATION.ru.md).

The per-axis cubic sample budget is now complete figure width/100 and height/100,
replacing1/40. Removed the fixed0.75-unit preliminary simplification so small
figures are checked against their original traced samples. The reverse sampled
check uses a monotonic chord cursor and nearby edges; rejection is conservative
and avoids rescanning every source edge for each reverse sample.

Ordered raw input acquisition is separated from replaceable fitting. A new job
cancels the old computation and discards pending old results. It refits the latest
complete raw snapshot, retaining all strokes/history. Cooperative checkpoints
cover union, tracing, curve fitting and serialization; cancelled replies cannot
publish or contaminate carried raw state. Each child has a private document and
one monotonic cancellation capsule. Shutdown drains child replies. No native GUI
pointer or raster mutation crosses this boundary.

The pane sends new jobs directly rather than waiting for a fitting FIFO. Native
and portable source/history safety, Save/Undo synchronization, token publication
fences and stale-revision checks remain. Rebuild all matching Dis modules because
private Document/Done layouts changed. No SWF/Dis64 file format is changed.

Tests exercise real in-flight cancellation, superseded publication, complete
input/history retention, overlapping native token handoff, interpreter/JIT and
an independent per-axis wavy-contour oracle. Finite reverse sampling is not a
continuous Hausdorff-distance proof. Cancellation is cooperative, checkpoint-bound,
not a fixed wall-clock latency guarantee.


The independent wavy-contour oracle passes with1/100 and rejects an isolated
matching-ABI control differing only by restoring the old1/40 factor. Pre/in-flight
cancellation and latest-only publication pass in interpreter/JIT; native handoff
checks now use real token-bearing Begin events so later strokes overlap fitting.


Validation:12 affected interpreter/JIT tests passed across final runs: geometry
accuracy/model, pane protocol, native token handoff/history, cancellation supervisor,
viewport and dense selection. The installed SDK passed latest-only cancellation
and rebuilt its shipped vector model/worker sources with its matching compiler.
