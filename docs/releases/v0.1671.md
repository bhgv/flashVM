# v0.1671 — Сборка и диагностика в редакторе, общий fetch отладчика Inferno

Графический редактор получил настоящую F7-сборку и F8-переход к ошибке. Политика
остаётся на Dis-каналах, компиляторы вызываются библиотечно, FlashVM отображает
копируемые значения. Новые артефакты сохраняются в памяти с привязкой к ревизии.

## Изменения серии

- Новый переносимый Idebuildpanel соединяет существующий документ с частными
  workspace/worker, повторно проверяет ревизию после компиляции, выдаёт копии
  артефакта и исходного FIRDBG1, переводит диапазон диагностики через Utf8Span.
- F7 выбирает язык по явному расширению .b/.as/.as1/.as2/.as3 и запрашивает
  оптимизированный Dis для Limbo либо SWF 8 для AS. Неизвестный язык не угадывается.
  F8 выделяет оригинальный диапазон в символьных координатах. Escape закрывает
  текстовый результат. Все три пути завершения редактора закрывают частные сервисы.
- Ошибка новой сборки той же ревизии сохраняет предыдущий успешный бинарник с его
  собственными language/target. Правка исходника закрывает доступ к старому
  артефакту и старой диагностике. Успешная нативная компиляция после конкурентной
  правки не публикуется даже в памяти.
- Пакеты с отключённым Fircompiler сохраняют переносимый модуль панели и явно
  сообщают об отсутствии компилятора. ON→OFF удаляет принадлежащие установщику
  исполняемые примеры/приёмку и архив библиотеки. Документ редактора не принадлежит
  панели и остаётся работоспособным после её завершения.
- Новый построчно комментированный пример build-panel демонстрирует полный цикл
  Build/Artifact/Shutdown без файлов и запуска результата. Добавлены подробные
  EN/RU README и единый контракт BUILD-PANEL с локальными ссылками SDK.

## Синхронизация Inferno в обе стороны

Закреплён experiment **51d18eaea7fb1aa724fcbb5e0aaa92f7c1d1a4fa**, поверх ранее
отправленного исправления Math 34d019f. Импортированы общий include/vmfetch.h,
обычный executor, emu/os debugger/coverage и benchmark guards вместе с настоящими
production-decoder тестами. Снимок Dis содержит **787 файлов**, bootstrap **277**.
Все **944 уникальных выбранных исходника** совпадают с Git-объектами Inferno
побайтно и подтверждены SHA-256 обоих manifests.

Host-адаптация преобразует активные регистры общего заголовка в TLS, сохраняя
проверенную выборку до GC safepoint и учёта инструкций. Код запуска использует
захваченные opcode/callback; изменения include отслеживаются CMake. Генерация
повторяется побайтно и проверяет реальный каталог компилируемых исходников.

Обратная сверка не выявила нового общего дефекта для отправки. Исправление Math
из предыдущей серии уже присутствует в публичном experiment; новых приватных
расхождений общего исходника нет. Политика графического редактора и NC64 host
адаптации остаются в flashVM. Пустой или искусственный коммит в Inferno не создаётся.

| Provenance и Git diff | Оба manifests; 944 уникальных исходника без расхождений; diff --check |

Интерфейсы и шесть модулей панели дополнительно восстановлены только из Git-объектов,
пересобраны и исполнены в обоих режимах: пример и приёмка проходят без нетрекнутых
исходников. Финальные графические проверки также включают неверный pressed-флаг
и ограничение текста до 256 Unicode-скаляров под 1024-байтовый канал.

Проверка конкурентной правки не зависит от таймеров: обычный прокси канала
документа вносит реальную правку перед второй проверкой снимка, после успешного
вызова компилятора. Ошибочные/успешные результаты проходят действительные VM,
каналы, библиотеки и FlashVM renderer. Python используется только на машине
разработчика. Санитайзеры исполняются на native AMD64; проверка не означает полный
запуск Inferno или физический ARM64/RV64. LeakSanitizer task enumeration в окружении
недоступен; покрытие LSan не заявляется.

## Ограничения

Компиляция синхронно блокирует единственного владельца VM. Отмена, фоновая
отзывчивая сборка, экспорт бинарника, Run/Debug controls и полное подключение Dis
отладчика пока отсутствуют. Панель показывает ограниченный текст; сервис хранит
полную диагностику. Языки представлены реализованными подмножествами Coco/R;
вся IDE ещё собирается закреплённым bootstrap. AS3 не создаёт AVM2. FIRDBG1
сохраняет исходные позиции, но не является картой итоговых/native PC. Результат
не записывается, не загружается и не исполняется автоматически. Проверки rendering
replay не подменяют испытание физического окна/touch.
