FIR **0.52.0**, source CLI **0.19.0**, SWL **0.3.12**. Three append-only pure FIR primitives provide exact i32.and/or/xor, with strict verifier signatures, uint32 constant folding, C99 reference execution, scalar/hosted Dis lowering and standard AVM1 object emission. The linker accepts BitXor and preserves its bytes. No old opcode ID, Dis instruction, container version or native module ABI changes.

Homogeneous Limbo int gains &, |, ^, ~, checked shifts and compound updates through authoritative Coco/R productions. The typed big/table profile's int binary bit operations now emit one pure instruction instead of a four-operation widening sandwich. Checked operand effects remain observable. Shift counts use the existing strict 0..31 contract and live SWF rejection. Numeric conditions require grouped bit operands; real/AS source coercions are not introduced. Compound read/write debug sites retain the target while arithmetic points at the actual operator token.

Two line-commented examples and bilingual instructions are shipped with the SDK. Tests cover endpoints, raw/optimized execution, both Dis emitters, actual SWF trace, C99 effect/type contracts, resource/kind boundaries, branch captures and debug spans. Relocated SDK acceptance also relinks a fresh C99 client for these examples.

Incoming Inferno a42ca20 fixes Bio and fd formatter state/geometry, short-write suffix retention and native long write widths. Both snapshots finally pin e72c8da (703 Dis / 231 bootstrap files), also importing e438394 Bio refill windows/native reply-width guards and e72c8da allocated formatter ownership/geometric growth. The real formatter fixture is part of bootstrap acceptance; prior reverse corrections remain in upstream history.

## По-русски

Добавлены три чистых signed32-примитива FIR. Они проходят через verifier, оптимизатор, эталонный C99-исполнитель, оба Dis-бэкенда и SWF-объекты. Линкер принимает стандартный BitXor. Однородный int Limbo получил битовые операторы, дополнение, проверяемые сдвиги и составные присваивания. Для типизированного int убраны лишние расширения/сужение; эффекты получения операндов сохраняются.

Из Inferno перенесены проверки форматированного вывода Bio/дескрипторов. Добавлены полностью прокомментированные примеры, русские/английские инструкции и проверки перенесённых SDK. Новые примитивы не означают полную реализацию AS/Limbo, ABC или нового ABI Dis.
