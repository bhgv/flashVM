# v0.1645 — text expressions, exact int bits and emitter fixture ABI

## Русский

Компилятор **0.28.0** расширяет Coco/R big/table-профиль Limbo:
конкатенация `+`, строковое `+=`, равенство `==`/`!=`, побитовые int
`& | ^ ~` и составные `&= |= ^=`. Это позволяет собирать подписи IDE и
сравнивать `typeof` непосредственно в исходном коде. Смешанные типы требуют
явных cast; строковое упорядочивание и int-сдвиги пока не поддержаны.
Однородный int-профиль и AS-профили в этой серии не расширяются.

Две операции FIR string.concat/string.eq дописаны без изменения прежних ID.
Конкатенация сохраняет эффекты чтения/выделения/ошибки, поэтому не удаляется
при неиспользуемом результате. Равенство констант сворачивается в bool.
Эталонный исполнитель отдельно владеет выделенными строками, а алиасы и срезы
заимствуют их. Dis использует существующие ADDC/BEQC и карты корней кадра.
Побитовые int точно расширяются в big, исполняются существующими операциями
и нормализуются обратно до signed32; float-преобразований нет.

Новых внешних коммитов Inferno после 6945acaf на начало серии не было.
Расширенные проверки выявили отсутствующее поле channeltransferentry в Python
LeafLayout: строгая проверка ABI блокировала три теста до генерации кода.
Исправление [5b9bdcf](https://github.com/bhgv/Inferno-OS-bhgv/commit/5b9bdcfd188cd16846f8935b5c7d9074dcc89ee5)
опубликовано в experiment и импортировано обратно. Проверки размеров/смещений
сохранены. Итоговые снимки: 554 core/reference + 174 bootstrap файла.
Расширения языка остаются в FlashVM.

## English

The compiler now builds ordered Unicode labels, compares string contents and
preserves int32 bit patterns through the source/FIR/Dis pipeline. The public C99
verifier rejects forged operands/results before either backend publishes bytes.
An allocation registry frees reference concatenations exactly once despite copies
and non-terminated slices. Constant equality folds; allocating concatenation
retains its observable failure. [Contract](../../fir/v1/doc/TEXT_BITS.md).

The new tutorial demonstrates an editor-style status label, explicit conversion,
bit-mask updates, immutable aliases, Unicode scalar bounds and lazy conditions.
Relocated headless/editor SDK checks relink fresh source/FIR C99 clients and
execute the tutorial before/after optimization in both actual VM modes.

The upstream reverse patch repairs the checked ctypes emitter record only; it
adds no native fast path. AMD64/ARM64 availability remains 166/173, with partial
operand coverage. Existing native kernels and C fallbacks remain authoritative.
