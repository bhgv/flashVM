# v0.1638 — compiler, FIR and IDE application

## English

Compiler 0.21 adds `countof`, membership `in` and `delete` to the Coco/R Limbo grammar, FIR verification, reference execution, effect analysis and hosted Dis lowering. `len` remains the contiguous numeric prefix; `countof` counts all entries. Membership distinguishes a stored zero from absence. Deletion preserves snapshot key identity and never compacts numeric indices. Bool conditions and explicit scalar conversions work through both backends. Existing FIR operation IDs and old Bigtable imports remain stable.

See the [detailed contract](../../fir/v1/doc/TABLE_MUTATION.md), [commented tutorial](../../fir/v1/examples/tables/mutation.b) and [tutorial README](../../fir/v1/examples/tables/README.md). CLI and C99 library entry points share the implementation.

Runtime 0.24 provides `ide.dis`, which loads the graphical Limbo controller on our DisVM and uses typed channels for FlashVM rendering. The installed graphical package starts with `sh out/disvm-editor/run-ide.sh --new example.b`; its console entry is `run-ide-console.sh`. See the [application guide](../../ide/dis/app/README.md). Editing, Unicode cursor/selection, file operations, zoom and line numbers are exercised. Build/Run/Debug GUI panels and full debugger attachment remain unfinished. The controller is built with the matching source-built Limbo bootstrap; the bounded Coco/R compiler cannot yet compile the entire controller.

Inferno experiment synchronization includes our published integer branch/JMP repair `2664a10`, incoming independent branch checkpoints `e14f034` and numeric guards/CVTFX scale improvements `02b7b7f`. The pin is `02b7b7f96183d30f6c75b7415197ecc986e5d411`: 531 exact core/reference files and 174 bootstrap files. Language extensions remain in FlashVM. AMD64/ARM64 availability remains 164/173 with partial operand coverage; ARM64 instruction emulation is not hardware or full OS boot evidence.

Validation before the final incoming refresh: FIR 25/25, optional-table-core-disabled 23/23, focused UBSan 4/4, runtime 125/125, relocated headless and graphical SDK clients and actual installed launchers, 21 build-menu tests and 5 packaging tests. Native branch checks cover 9,392 C cases and 160,736 emulated cases; 57 parent-version probes demonstrate the repaired failures. The previous core suite passed 191/191 plus the newly registered native checkpoint separately.

The million-character interpreter replace-all scenario measured 55.277 seconds against the previous 50-second child timeout. Only this scenario now receives 90 seconds (100 seconds outer CTest); its data and correctness assertions are unchanged. The final runtime suite passed it in 54.72 seconds. SDL dummy replay does not prove physical window/touch behavior.

## Русский

Компилятор 0.21 реализует `countof`, проверку наличия `in` и `delete` по всей цепочке Coco/R → FIR → оптимизация → эталонное исполнение / Dis. `len` считает непрерывную числовую часть, `countof` — все элементы. Нулевое значение отличается от отсутствующего ключа. Удаление не сдвигает индексы и сохраняет идентичность ключей снимка. Добавлены булевы условия и явные преобразования; старые номера FIR и импорты Bigtable сохранены.

[Подробная семантика](../../fir/v1/doc/TABLE_MUTATION.ru.md), [полностью комментированный пример](../../fir/v1/examples/tables/mutation.b), [русский README](../../fir/v1/examples/tables/README.ru.md).

Runtime 0.24 запускает `ide.dis` на нашем DisVM; графический контроллер связывается с FlashVM типизированными каналами. Команда для установленного графического пакета: `sh out/disvm-editor/run-ide.sh --new example.b`. Консольный запуск сохранён как `run-ide-console.sh`. [Руководство приложения](../../ide/dis/app/README.ru.md). Панели Build/Run/Debug и полное подключение отладчика ещё не завершены. Полный контроллер пока собирается исходным Limbo bootstrap, а не ограниченным профилем нашего Coco/R-компилятора.

Синхронизация Inferno включает опубликованное обратно исправление переходов/JMP и два новых входящих коммита до `02b7b7f`: дополнительные проверки переходов, девяти числовых команд и масштабов CVTFX. Расширения языка в Inferno не переносились. Возможности native JIT остаются 164/173; проверки ARM64 проведены эмуляцией инструкций.

До последнего обновления снимка пройдены FIR 25/25, сборка без optional table core 23/23, UBSan 4/4 и runtime 125/125; проверены перемещённые SDK, C99 API, установленные графические launcher-скрипты и документация примеров. Для большого replace-all увеличен только лимит времени: измеренное корректное исполнение 55.277 с превышало прежние 50 с. Новый лимит — 90 с, внешнего CTest — 100 с; данные и проверки результата сохранены. Проверка SDL dummy не заменяет проверку настоящего окна и сенсорного экрана.
