# v0.1633 — acyclic table CFG and bidirectional string/JIT synchronization

FIR compiler 0.19.0 and hosted runtime 0.22.0 now execute big-result source
if/else with live tables, snapshots, retained keys, strings and captured locations.
The same verified acyclic graph works through direct NC64 Dis and the independent
C reference library. The source grammar is unchanged; the existing Coco/R
terminal-decision syntax now reaches the table-capable backend.

New public fir_acyclic verifies IR and performs a bounded, deduplicated topological
walk without mutation/allocation. Cyclic table graphs fail before output/owner
allocation. General FIR and the pointer-free scalar backend still admit cycles
under the existing runtime instruction budget. DAG execution visits each owner
producing instruction at most once, preserving bounded reference registries.

Two private emission passes measure final instruction PCs and resolve forward/
backward branches across native-call expansions and variable-width operands.
Their instruction counts must agree. Import loading happens once; owner maps
retain all potential heap cells while unselected cells remain H. Bool/range/index
cells stay scalar. Native calls, casts and faults execute only on the selected
path. Static capture flags remain separate from values; reference output is
chronological and staged until successful return.
