# v0.1664 — Direct typed predicates through FIR, Dis and SWF

[Contract EN](../../fir/v1/doc/TYPED_PREDICATES.md) / [RU](../../fir/v1/doc/TYPED_PREDICATES.ru.md) · [Limbo tutorial](../../fir/v1/examples/dis/typed-predicates.b) · [FIR/SWF tutorial](../../fir/v1/examples/dis/booleans.fir) · [Synchronization](../../disVM/SYNC.md)

FIR **0.53.0**, source CLI **0.20.0**, SWL **0.3.13**. Typed Limbo int comparisons now use existing signed32 comparisons directly. Bool equality and negation use two append-only pure FIR operations, bool.eq and bool.not, with strict verifier signatures and normalized results. All six numeric relations, inferred bool values, lazy logical joins and source operator provenance retain their contracts. Big/string comparisons retain their existing semantics. No Dis opcode, native ABI, frame/GC layout or textual FIR version changes. Structural frontend 0.1.3 admits a separated // comment after the physical FIR 1.0 header, retaining LF/CRLF and rejecting BOM, leading comments and bare trailing spaces. This aligns line-commented tutorials with the executable reader; Coco/R still parses the complete input.

The optimizer folds bool constants, removes double negation, simplifies equality with normalized constants and self-equality, and reuses identical pure predicates within one block. Checked producer failures remain observable when a predicate is unused. Scalar and hosted Dis emission use existing BEQW/BLTW/XORW; SWO output uses standard AVM1 Equals2/Not. The independent linker validates Not and preserves its action bytes. This does not introduce AS implicit coercions or table-backed SWF execution.

Two new examples comment every nonblank source line. Detailed English/Russian guides explain types, evaluation order, optimization, GC ownership, debug positions and exact commands/results. SDKs now ship the current coverage guide too. Relocated acceptance compiles the table-backed Limbo tutorial through CLI and freshly linked C99 libraries, compares Dis bytes and runs raw/optimized output with actual interpreter/native dispatch.

Inferno baca741 replaces recursive AST diagnostic printing with a private ordered action stack and bounded output. The additional 4f54d7f commit bounds descriptor mapping and zero-initialization Type traversal with checked work stacks. Both snapshots finally pin **4f54d7f1569b8b596ce01f036e683f7866c8aeb5**: **703 Dis / 239 bootstrap files**. Pointer-map, zero-initialization and rejection fixtures cover slot widths 4 and 8; the existing descriptor-map oracle is registered too. New upstream oracle/reference fixtures check shallow output order, quoting, deep expressions and debug dumps under sanitizers. Prior outbound corrections remain ancestors; review found no additional shared defect for an outbound patch. FlashVM-specific table/any/projection and FIR extensions remain here.

## По-русски

Сравнения типизированного int больше не расширяют операнды в big. Для отрицания и равенства bool добавлены две чистые операции FIR с точными типами; Dis использует существующие инструкции. Оптимизатор упрощает двойное отрицание, сравнения с константой и самим собой, сохраняя ошибки вычисления аргументов. SWF проходит обычную цепочку FIR → SWO → линкер; Not принимается и проверяется отдельно.

Добавлены два построчно прокомментированных примера и подробное руководство на русском и английском. Установленные SDK проверяют CLI, C99 API, исходный и оптимизированный Dis, оба режима исполнения и освобождение временных владельцев. Страница текущего покрытия входит в SDK и связана с новыми руководствами.

Из Inferno перенесены безопасная печать глубоких AST и обходы Type для карт указателей/нулевой инициализации через явные стеки. Проверки охватывают размеры ячеек 4 и 8 байт. Снимки проверены по хешам; прежние обратные исправления сохранены в Inferno. Нового общего дефекта для обратного исправления в этой серии не найдено. Аппаратная проверка ARM64, полная ABI-миграция и полнота IDE остаются отдельными задачами.
