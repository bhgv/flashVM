## What now executes

`asincviews.dis` is an ordinary source-built Limbo service on our DisVM. Owner0
and up to8 nonreused task IDs hold16 captured immutable-string bindings. Each
view shares immutable cells until a local write replaces one. BeforeFrame sends
only task-local dirty versions to the owner; AfterFrame sends owner versions to
clean task views. Received versions are not new writes and do not echo. Task
writes during frame computation survive when the frame changes another binding.

Remote subscriptions create copied events with original source, binding, version
and old/new values. Snapshot provides detached per-task arrays. A bounded queue
refuses a complete phase transaction before overflow; draining then retrying
publishes exactly once. Conflicting writers explicitly refuse without choosing
an undocumented winner. Explicit Discard permits caller-directed resolution.
Retire releases view roots/subscriptions and prevents ID reuse.
