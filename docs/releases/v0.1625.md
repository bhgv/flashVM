# v0.1625 — payload-list JIT and compiler synchronization

Inferno experiment advances from b9a569efc622c8f72a34e5e76c0089feb5a57700 to
b2da16226dfc5bc0e0c754ae5d95fcde6cc1afb9: three upstream commits, including
AMD64/ARM64 ICONSM/ICONSP, strict nil heap-prefix guards, bounded compiler source
history and corrected fixed/cast regressions. Both manifests preserve exact blobs:
446 selected core/reference files and 174 temporary bootstrap files.

Raw payload constructors stage old destination ownership across allocation before
copying/publishing; pointer constructors retain current owner/descriptor state and
mark using live GC values after the allocator returns. Native raw copies are
bounded to 256 bytes, with checked interpreter fallback for larger inputs.
RV64 availability is unchanged. No new table-language feature was sent upstream.

Seven new registered drivers cover payload layouts, actual AMD64 generated code,
AMD64/ARM64 instruction emulation, bounded source history, fixed opcode selection,
cast folding and string folding. Source dependencies used by extracted compiler
regressions are selected explicitly rather than depending on an external checkout.

WORD32/WORD64 fixture layouts and ARM64 emulation are separate from physical
hardware execution. Our Coco/R compiler and its direct typed-table Dis emitter
remain independent from the temporary upstream compiler. Table CFG, key sequence
indexing, typeof/any and source-to-Dis debug maps remain future work.

## Local acceptance

- Core: all 158 current test names passed (155-test full run plus four compiler
  drivers, with one shared history test).
- Full runtime/IDE suite: 113/113, rebuilt against the new core and bootstrap.
- Our FIR/Coco/R compiler and optimizer suite: 21/21.
- New payload drivers: 3/3; compiler/history drivers: 4/4.
- Both provenance manifests and whitespace checks passed.

The first FIR invocation lacked a writable TMPDIR and failed to create temporary
outputs. Repeating the suite with an explicit workspace TMPDIR passed all 21
checks. Initial new compiler fixtures also exposed missing selected source
inputs; the manifest now includes those exact upstream dependencies.
