Runtime 0.46.0 moves Sys.print/fprint out of the coordinator into formatted_sys.c.
Formatting stays on the active Dis owner; only completed bounded native bytes
reach OS I/O after releasing heap ownership. FD roots retain file handles; saved
native frames retain managed format/variadic owners. Reentry precedes result
publication and root retirement. Read-only/zero-byte/short-write contracts remain.

A real restricted stdout pipe exercises backpressure for both output builtins.
Every UTF-8 stdout/file byte is checked independently. Cycles, nested caller data
and a channel-blocked process's locals survive GC during released intervals.
Console/UI each run 12 normal and 2 post-output managed-error cases. Existing
native input/output/wait/cycle, filesystem/file-window and UI ownership gates
pass. The native-wait fixture now expects seven releases: six sleep calls and
its final print. These are distinct audited boundaries, not a generic unlock.

parameters through existing scalar operations. Source words are snapshotted
