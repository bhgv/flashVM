# v0.1660 — JIT GC guards and bounded shared inline graphs

[Bidirectional synchronization](../../disVM/SYNC.md) · [Owner tutorial EN](../../fir/v1/examples/type-aliases/README.md) / [RU](../../fir/v1/examples/type-aliases/README.ru.md) · [Commented source](../../fir/v1/examples/type-aliases/gc-owners.b)

Runtime **0.32.1** imports AMD64/ARM64 owner-GC preflight and builtin identity corrections from Inferno. Heap reference/color fields must be complete and disjoint; mutator/propagation cells must be aligned, disjoint and nonwrapping. Invalid builtin String/Array sentinels decline emission before caller output is published. These are numeric layout guards, not proof of mapping ownership.

Source-built Limbo imports bounded inline traversal and cycle refusal. Our confirmed reverse correction c1494cd adds query-local success caching for shared candidate DAGs: a 256-candidate diamond no longer expands exponentially. Deep AST/chain/cycle tests, small recursive oracles and shared-candidate retry/cleanup checks retain the prior boolean result and restore all temporary declaration state. Ordinary AST child DAGs are not memoized; allocator failures remain fatal.

Both snapshots pin c1494cd with 703 Dis / 219 bootstrap files and exact hashes. Flash extensions stay local. The new line-commented owner tutorial runs our existing Coco/R alias/cast frontend, FIR optimizer and Dis backend through string/key/table ownership churn. Its tests inspect raw/optimized execution, selected return flags, real dispatch counters, repeated GC and final host-owner counts in both VM modes and relocated SDKs. FIR stays 0.50.0: this release adds acceptance coverage without introducing a new FIR operation or source-language feature.

## По-русски

Приняты проверки GC-разметки и встроенных типов для JIT x64/ARM64. Принят обход зависимостей inlining без глубокой рекурсии; обнаруженное экспоненциальное повторение общих подграфов исправлено и отправлено обратно в Inferno. Кэш успешных проверок живёт только один запрос, все временные флаги восстанавливаются.

Добавлен построчно комментированный пример владельцев: удалённый ключ сохраняется в снимке, строки создаются и преобразуются на каждом проходе цикла, записи таблицы копируются и удаляются. Проверяются результат, GC, диспетчеризация и освобождение владельцев. Документация и команды запуска доступны на русском и английском. Испытания эмиттера ARM64 не заменяют запуск на физическом ARM64-устройстве.
