# v0.1790 — rooted guarded HEADMP

Runtime0.92 extends `--gc-worker --guarded-copies` to mapped list-head projection.
The new list_hold module prepares metadata before guards, captures/retains its
source node under the source-slot guard and publishes an actual external root.
The shared_head module reuses original index/Type validation, checks allocation
extent and equivalent pointer maps, then uses the existing mapped replacement.
Temporary list ownership/rooting is finished on success and error, preserving the
first body error across consuming-release errors. Default HEADMP stays unchanged.

[Contract and limits](../../disVM/runtime/SHARED-HEAD.md).
[Commented Limbo example](../../disVM/examples/guarded-list-head/README.md).

22 affected console/editor regression tests pass. After zero-tail map compatibility
was added, final affected head/tail checks pass again. Actual C/JIT/both-poll tests
cover seven preparation refusals, failed-mark rollback, original descriptor errors,
raw/empty/nil behavior, map/physical-extent refusal, source-slot/output alias and
consuming callbacks which remove the original list owner/root. The temporary hold
alone survives 32 genuine native Cycles passes, REG changes and combined errors;
final Fast restores List/String/Type baselines. Seven actual-boundary controls stop
at semantic exit 10 before unsafe continuation. Guarded tail cache/error controls
and NULL/foreign/held-guard refusal also pass. Final actual head/tail positives
pass TSan; emitted bytes remain uninstrumented. Installed source suites/examples
and retained 1096 engine/312 bootstrap pins verify. No new hosted-head UBSan,
physical ARM64/RV64 or parallel managed execution acceptance is inferred.

Local whole-profile 20000-head comparison, startup plus warmup/median three:
C 0.106s default/0.144s guarded (~36% extra); JIT 0.099s/0.152s (~54% extra).
Not isolated-op/whole-IDE/cross-target/statistical evidence or a speedup. Mapped
HEADMP currently prepares up to seven native blocks; reuse/locality are future
optimization work. The experimental path remains opt-in.

Other list/reference/arithmetic writers, channels/scheduler, shared root/graph/GC
epochs and code/frame/module lifetime still need conversion. NativeWorld remains
required. Dis64 wire/IDs/layout, ordinary LEA, default file-call admission and
Inferno named launch/cache agreement are unchanged. No Draw source is imported.
