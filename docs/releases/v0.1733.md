# v0.1733 — production cycle GC on a native owner

Runtime0.41.0 adds opt-in `--gc-worker` to console and graphical hosts;
`--gc-inline` retains the default reference. This invokes the retained collector
against the actual managed heap, not a fixture or alternate heap algorithm.

A separate collector extended-up/REG/error owner requests native_world stops.
The parked mutator's complete-instruction registers are copied to Prog.R before
root scanning. Requests coalesce; each real rungc call keeps the existing adaptive
budget. Idle graphical turns poll too. Managed normal/error returns drain/join,
detach roots and then retire TLS. Final diagnostics follow collector join.

The shipped Limbo example creates12,000 unreachable cycles while checking a live
cycle. Interpreter/JIT tests use three scheduler quanta, require actual cycle
reclamation/epochs/root snapshots, and verify instruction-limit error joins for
console and UI hosts. Eager RC remains on the mutator. Blocking native Sys
release/reentry, parallel shared-heap spawn and module/JIT synchronization remain
open. Native Linux x64 evidence does not imply ARM64/RV64/device acceptance.
