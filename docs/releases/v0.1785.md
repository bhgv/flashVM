# v0.1785 — canonical object guards and rooted ticket lifetime

Runtime0.87 adds a native canonical guard registry and binds every managed ticket
to a lease keyed by its real referent. Separate captures share one guard; different
objects stay distinct even under hash collisions. One shared parking domain serves
dynamically allocated nodes. Capture refusal rolls back the lease; Fast releases
it before removing the managed root/reference. Final session shutdown requires an
empty registry. Heap/Type headers, vendor pins and Dis64 file ABI are unchanged.
