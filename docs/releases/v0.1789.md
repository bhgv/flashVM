# v0.1789 — guarded mapped MOVMP and rooted retirement

Runtime0.91 extends the explicit `--gc-worker --guarded-copies` profile to MOVMP.
It prepares native snapshot/root metadata before locks, retains incoming pointers
and publishes a complete replacement under shared range protection, then unlocks
and retires displaced owners. Remaining old references stay rooted across actual
GC/callbacks. Indexed root-group withdrawal avoids exposing already consumed
headers to GC. Consumed-owner callback errors drain remaining owners, clean native
metadata and propagate the first error without retrying a completed replacement.
