# v0.1554: bundled Noto, default size 11 and channel-owned wheel/pinch scaling

Unmodified Noto Sans Mono is now included with original OFL 1.1 notices and exact
source provenance. Direct builds and installed packages put it beside the entry
Dis module. The editor and launch menu no longer require or ask for a font path.
Optional explicit overrides remain. The default size is 11 pixels.

Ctrl+wheel and SDL two-finger pinch use one revision/view-ticket-bound zoom
pipeline. Native code measures a proposal without changing the view. Dis clamps
size to 6..48, admits actual row geometry and publishes Style with the next
viewport/snapshot. Both TextFields and glyph hit geometry use the same admitted
face size. Panel height, page size and visible logical-line count follow actual
metrics; an offscreen trailing line is no longer counted as visible. Zoom also
works inside Dis-owned search/path fields without editing their document.

SDL_MULTIGESTURE handling has no Android-only condition, so desktop touch-capable
frontends can use it too. Finger changes/focus loss reset accumulation and touch
mouse synthesis is ignored to avoid duplicate gestures. Physical Windows/macOS/
Linux touch devices and full runtime ports remain separate acceptance work; the
current executable acceptance is Linux AMD64.

Zoom testing exposed a wider NC64 codec defect: signed int32 first/second wire
fields were decoded as positive wide ints. Explicit sign extension now preserves
negative pinch and upward scroll values. Encoding also rejects values outside
wire width rather than silently truncating them. Unsigned operation/flag bit
patterns and the header layout remain unchanged. Independent real Dis tests
cover signed boundary pairs, Unicode and NC64 overflow rejection.

This completes the four-commit editor series following v0.1550:

- v0.1551: published Inferno descriptor fix, original regressions, preferred-column
  vertical/page navigation and renewed standing synchronization authorization.
- v0.1552: Dis-owned Unicode viewports, scrolling, glyph proposals, drag and stale
  ticket rejection, with exact retained-contour culling before bounded raster APIs.
- v0.1553: reusable file/search libraries and Dis-owned Find/F3, two-field ReplaceAll,
  Open and Save As panels with dirty/NUL/I/O/destination guards.
- v0.1554: packaged Noto/11, bounded Ctrl-wheel/pinch scaling, actual font geometry
  and the signed wire correction.

Validation and limitations are linked in the current tutorial and zoom contract.
The checks execute actual Dis bytecode/channels/GC and FlashVM glyph/raster output;
no Node/Python implementation is substituted for the application runtime.
Syntax colors, popup completion, AS-worker execution, compiler/debugger UI,
full bidi/grapheme/resize behavior and multiple native owners remain open.
Source writes are checked overwrite, not atomic replacement. Font glyph coverage
is finite and does not alter Unicode source/saved bytes.
