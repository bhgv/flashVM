Our Limbo interface compiler/library is now **0.10.0**. Coco/R emits exact
TypeIdentifier spans; the immutable binding API follows outer aliases through
lexical scopes, supports forward references and UTF-8 names, detects cycles,
bounds chains and reports byte-accurate diagnostics. It does not reparse source.
Native classic32/NC64 C interfaces accept scalar aliases and emit canonical
primitive frames, structural signatures and GC maps, without alias C typedefs.
The fully line-commented .m tutorial uses aliases and executes in both Dis modes.

This is interface/type binding, not a complete typed body AST or FIR lowering.
Composite inner types, qualified/generic imports and composite native ABI remain
open. The native profile still requires a single top-level module; nested scopes
are a separate library-query capability. The underlying parser stays serialized.

Incoming Inferno commits 275bc64 and 3ba10d2 cover dial bounds/relative clone paths
and file2chan frame/owner capture. While preparing the reverse fix, experiment
advanced; our commit was reapplied on that new parent before non-force publication.
Published reverse correction:
[0ac9d293](https://github.com/bhgv/Inferno-OS-bhgv/commit/0ac9d293660a718cb3dbc3472e9c40d6b31cca8e).
Native control commands now require an exact write count. Partial/zero/oversized
results fail, negative native errors remain intact, opened handles close and no
data connection/control ownership is published after an incomplete command.
Command tails are not retried as independent commands.

The selected 683-file snapshot includes the complete new source fixtures and
matches that public commit. Native Sys network/file2chan service admission in our
NC64 host is still separate work; imported source is not claimed as an enabled
host service. Flash any/table/projection extensions were not exported upstream.

## Проверки / Validation

- 19 own Limbo checks: scope/UTF-8/comments/forward chains, cycles, exact diagnostic
  coordinates, 256/257-edge limits, output retention and allocation recovery.
- Independent MD5/layout calculations and actual Inferno classic32/NC64 oracles:
  aliased and primitive C headers are byte-identical; metadata matches both compilers.
- Native tutorial, AS-view and uncaptured asynchronous editor: five runtime checks.
  Tutorial big arithmetic, string GC, exceptions and typed calls remain executable.
- Resolver/semantic fixture ASan/UBSan; underlying static parser libraries in that
  focused harness are not rebuilt with sanitizers. LSan process discovery disabled.
- Dial full-port fixtures pass ASan and UBSan in both emu/os: 16418 predicates per
  port/profile. New write family fails on parent source before the correction.
- Five selected Dis checks: dial, file2chan ordinary/capture and existing JIT/ARM64
  compiler coverage. Bounded file2chan frame shifts are not exhaustive combinations
  or physical ARM64/network-device acceptance.

The SDK ships resolve.h and linked RU/EN guides. No full SWF compatibility stage,
complete compiler, tiled renderer or new JIT backend is declared complete.
