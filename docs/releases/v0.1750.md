# v0.1750 — native file FIFO and ordinary file waits outside the heap

Runtime0.54.0 removes global heap retention from audited ordinary-file
read/readn/write/fprint/seek. A new native per-file FIFO protects cursor/error
state. Reserve in the ACTIVE turn, root the FD, release the native heap lease,
wait/use the file, finish its ticket BEFORE reentering the heap. No managed
pointer is followed outside the heap. The short native gate mutex is not held
during I/O, so other owners can reserve without waiting for disk work.

Gate completion requires the exact ticket and native context; foreign/duplicate
completion refuses. Busy/reserved gates cannot retire. All runtime file cursor/
metadata access uses the same gate. Private loader and metadata callbacks retain
their synchronous boundary; open/create/close/directories and zero-write checks
are not made resumable. Protected native64holds/gchalt and cooperative native
shutdown restrictions remain. One shared heap still has exclusive mutation.

`Sys_seek` now lives in its own captured-frame/rooted native adapter. Full big
results, offset/origin validation and refused-seek cursor preservation remain.
`NATIVEFILES` reports lifetime, operations/contention and pending tickets. The
legacy pool `serialized_files` field counts per-file FIFO calls, not global heap
retention. Installed packages include the adapters and commented examples.

The actual native FIFO fixture reverse-starts eight OS owners, verifies FIFO,
foreign/duplicate completion and busy/reserved retirement. Three active private
removal controls must fail semantically. Optimized UBSan and focused native TSan
pass; this is not whole-VM race proof. The shared-file Limbo example now tests
relative seek, rewind/readback and negative-seek refusal in addition to exact
shared write/fprint/readn bytes and native lease/gate retirement counters.

The new file-overlap example and test-only fwrite interposer hold the first
ordinary write at a native OS-pipe barrier. A second writer waits on the SAME
file FIFO while an unrelated actor computes/prints BEFORE the barrier releases.
After release, byte-exact readback, gate contention and retirement are checked
at4/8 executors in interpreter/JIT. This is controlled blocking evidence, not
an actual slow-disk benchmark; existing real stdout backpressure tests remain.

Inferno0078 numeric-initialization code is reviewed and replayed in its owning
repository:2029 raw CFG/signature cases (1328 accepted/701 refused),13 active
controls, optimized nonrecovering UBSan. Exact seed kinds/spans, all reads before
writes, initialized-set intersection, loss-triggered requeue and deterministic
resource bounds are appropriate conditional proof layers. Canonical callable/
compiler binding and actual callee return guarantees remain required. No shared
Dis64 format IDs or file-call activation change; selected snapshots remain at
ba26accb,1096 runtime/312 bootstrap files. Peer cross-target results are separate
from this series' native Linux x64 pool tests.
