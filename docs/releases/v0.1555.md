# v0.1555: fresh Inferno decimal/store JIT paths and final editor-series acceptance

The active Inferno experiment branch advanced during editor development. Both
selected manifests now pin public `fa3b7abfc56980907d05d266516acef68954557d`,
including cd501233 and fa3b7abf after the published descriptor fix cc9c3199.
Imported files remain byte-for-byte and manifest integrity passes.

The refresh adds guarded AMD64/ARM64 short decimal CVTCW/CVTCL paths, existing
unique-owner string-character INSC stores and their logical-capacity checks.
C string/UTF paths now reject invalid backing H spans and inconsistent string
capacity before scanning or terminating storage. The private leaf layout gains
its explicit String.max offset; fixture declarations are refreshed together.
NC64 retains its own explicitly separated ABI and checked table adaptations.

Selected production-source native C/JIT regressions are registered under UBSan.
Optional capstone/unicorn tests execute actual staged AMD64/ARM64 instructions
with independent memory/write oracles. `DVM_EMULATOR_PYTHONPATH` supplies an
explicit test-only dependency directory; absence never creates a production
runtime dependency or a fake successful emulation test. Physical ARM64/RV64
execution and a complete multi-platform VM/GC/frame port are not claimed.

Final checks at this exact source snapshot:

- All 66 ordinary selected core checks pass; both newly registered instruction
  emulation checks pass separately, covering all 68 registered core entries.
- All 52 real runtime/editor/port checks pass in one run after the refresh.
- All 50 checks in the separately compiled UBSan runtime/editor build pass.
- Final graphical wheel/scroll and SDL dummy upload checks pass after adding an
  explicit upward-wheel regression for signed NC64 deltas.
- The installed package runs after relocation into a path with spaces, its
  controller recompiles from shipped headers, and bundled Noto/11 plus actual
  wheel/pinch raster changes work without a font override.
- 16 own Coco/R frontend tests, 21 menu tests, five graphical package-selection
  and five preflight tests pass. Current bridge/controller/codec sources and
  interfaces parse with the project's Coco/R Limbo frontend.
- Both upstream manifests verify; documentation source links and new guide
  relative links pass. Core, runtime and UBSan builds are real native builds.

The heavy ReplaceAll matrices are now marked RUN_SERIAL for predictable CPU
ownership without changing their existing internal timeout. Earlier overlapping
runs each hit one 50-second timeout; isolated reruns passed, and the final full
runtime/UBSan suites above pass cleanly without retries.

The resulting five-commit series is v0.1551–v0.1555: Dis navigation, bounded
viewports and mouse, reusable search/file actions and panels, bundled OFL Noto
at size 11, Ctrl+wheel/two-finger scaling, signed channel-field repair and fresh
Inferno JIT/string/UTF integration. No new shared Inferno defect requiring an
additional upstream mutation was identified in this series; the editor codec
fix belongs to the FlashVM-owned boundary, not Inferno's interpreter sources.
