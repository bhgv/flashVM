# v0.1716 — Line backlog and disappearing Pen strokes

The supplied recording showed a long-lived moving Line preview and ambiguous
right-hand controls. Two independently reproduced defects are corrected.

The ordinary full-frame raster fallback discarded each command's stroke width
and even-odd fill rule: it passed zero for both. An open Line/Pen path could thus
be treated as a fill and disappear when its native preview retired. The fallback
now preserves captured style and clip, using the separate `editor_full_raster.h`
algorithm. Stored paths remain immutable; the worker localizes its own path copy.
The new full-frame test fails on the old code's invisible open stroke. It checks
Line, quadratic Pen and a compound hole against independent drawing, including
clipped cases (at most one antialias channel level at translated edges).

Primitive motion was also marked as trajectory-preserving paint. Every queued
Line/Rectangle/Ellipse position therefore required a Dis round trip and snapshot;
release and toolbar clicks could wait behind hundreds of positions. These tools
now coalesce adjacent same-pointer motions into bounded latest endpoints, without
crossing release/control/device boundaries. Brush/Pen still retain their complete
batched native trajectories. The actual SDL test queues600 motions per primitive,
requires at most three updates, then the original release with no motion tail.

## Meaning of the two rightmost controls

- Second from right: closed-shape fill preference (`F`). It affects Rectangle and
  Ellipse. Line is always an open stroke, Brush paints a filled area by definition,
  and Pen remains a stroked centerline. This switch is not a scheduling mode.
- Rightmost: Pen (`P`), a freehand centerline smoothed after release. The old width
  number has been removed from this button. Width remains controlled by +/- and
  is displayed with the current tool/fill state in the window caption.

Labels live in the separate pure Limbo module `idevectorlabels`. Notified vector
owners provide a readable state string; the desktop composes the caption. The
bounded caption limit is96 scalars, with the existing title+body total constrained
to232 scalars so UTF-8 envelopes remain bounded. Runtime and dependent modules
must be rebuilt together. No SWF frame clock or Dis64 file/ABI change is involved.

## Validation

Actual JIT/interpreter desktop replays draw two separate Lines and a Pen after
turning fill on, save SVG, verify three independent paths and three visible ink
colors, and check the displayed Pen state. They distinguish SVG correctness from
pixel visibility. Existing native ink, retained/incremental raster, MDI capture,
style/cache and pane/model regressions remain enabled. Tests use real SDL queue
operations with the dummy video driver; no physical-device latency/FPS is claimed.
