# v0.1637 — scalar, integer and real-branch preflight

The final Inferno pin is `14c3d2c2736936eade4eadfa25e87c8ce5e404ec`: 519 core/reference
files and 174 bootstrap files. Incoming 7254e9e protects eighteen scalar transfer
and conversion paths; 2190eea protects 24 integer ALU/division paths. Our reverse
14c3d2c adds six real branches and preserves embedded numeric oracle definitions.
Together these improve 48 existing C/AMD64/ARM64 paths without adding opcodes.

The concurrent 2190eea division implementation is retained. Our earlier local
division repair was not branch-published over it. Zero divisors precede unused
dividend/result access in C and JIT; signed minimum/-1 and remainder semantics
remain defined. All live scalar operands precede overlapping result stores.

Our BEQF/BNEF/BLTF/BLEF/BGTF/BGEF changes validate both source spans before either
read. False predicates ignore the target; taken predicates validate it before
load and PC publication. ARM64 relocates its inverse branch over the actual
protected sequence. Native NaN decline and C/host floating semantics are preserved.

The composite native diagnostic previously sliced away the standalone definitions
of transfercheck/integercheck while keeping calls in their matrix bodies. Our
always-active single-evaluation wrapper predicate restores linking and execution
in both WORD models, preserving all oracle calls under optimization.

Independent checkpoints are registered for all three families. Our twelve-command
arithmetic checkpoint passes 5,472 C and 67,584 emitted instruction cases; all 36
previous-version command/backend probes reproduce the original null operand read.
Incoming transfer tests pass 16,016 C and 183,072 instruction cases; incoming
integer tests pass 7,680 C and 519,552 instruction cases. Checks cover zero priority,
MIN/-1, full/partial aliases, alignments, NaNs/infinities, conditional target
nonaccess, PC/REG images, FP state, every short output size and exact-size canaries.
The stack-only C fixture passes NDEBUG/ASan/UBSan with unsupported sandbox leak
enumeration disabled; leak detection is not covered.

Синхронизированы 18 входящих путей переносов/преобразований и 24 целочисленных
ALU/делительных пути. Добавлены наши шесть real-переходов: всего улучшены 48

оснастке. Оба WORD-варианта линкуются и исполняют прежние оракулы. Новый подробно

Независимые проверки трёх семейств: 29 168 случаев C и 770 208 случаев эмуляции
команд. Все 36 прежних запусков нашей arithmetic-оснастки воспроизводят дефект.
ABI и доступность команд не менялись, расширения языка не переносились.

## Final verification

The final combined core checkpoint passed 190/190 tests (363.67 s). Runtime/IDE
passed 120/121 in its full run (260.27 s): the million-character interpreter
replace-all exceeded its 50-second subprocess budget while independent core/JIT
matrices were running. The identical binary/scenario passed the isolated replay
with the unchanged budget (CTest total 50.04 s). All 121 runtime checks are thus
verified, but the timing margin is small; this is not evidence of spare performance
headroom. RUN_SERIAL covers a single CTest instance, so heavy component checkpoints
should run sequentially. No timeout or functional oracle was weakened.

Final-source arithmetic preflight also passed NDEBUG/ASan/UBSan. Both final SDKs
passed relocation, newly compiled C99 clients, original/optimized shift and division
tutorials, interpreter/native execution and exact trace values/flags. All 519 core
and 174 bootstrap snapshot hashes match the final owning commit.
