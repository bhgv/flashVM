# v0.1646 — checked signed32 shifts through FIR and Dis

## Русский

Компилятор **0.29.0** расширяет Coco/R big/table-профиль Limbo операциями
int `<<`, `>>`, `<<=`, `>>=`. Счётчик — int в диапазоне 0..31; он не маскируется.
Левый сдвиг оборачивается до signed32, правый распространяет знак. Ошибочный
счётчик вызывает штатное `invalid argument`, даже при нулевом значении или
неиспользуемом результате. Прежние big-сдвиги сохраняют диапазон 0..63.

Две операции i32.shl.checked/i32.shr.checked дописаны в FIR без изменения старых
ID. Оба эффекта MAY_THROW сохраняют ошибки после оптимизации. Свёртка констант
работает с unsigned32 и явно восстанавливает знак. Публичный C99 верификатор
проверяет оба операнда и результат до публикации выходных байтов.

Скалярный и hosted Dis-бэкенды разворачивают операцию в восемь существующих
инструкций, включая проверки счётчика и штатную ошибочную ветку. Все проходы
подсчёта/эмиссии учитывают развёртывание, сохраняя адреса последующих переходов.
Используются существующие SHLL/SHRL, signed32-нормализация и нативные ядра;
новых opcode, ABI, зависимостей от модуля и быстрых путей VM нет.

[Руководство](../../fir/v1/doc/INT_SHIFTS.ru.md),
[комментированный пример](../../fir/v1/examples/tables/int-shifts.b),
[README](../../fir/v1/examples/tables/README.ru.md).
Пример извлекает знак и байтовое поле упакованного слова, проверяет составные
сдвиги и возвращает 42, оставляя ошибочную ветку неисполненной.

## English

Checked typed int shifts now flow through Coco/R semantics, textual/public C99
FIR, conservative optimization, independent reference execution and both direct
NC64 Dis emitters. Count validation precedes result publication. Raw scalar CFG
fixtures check branch targets after eight-instruction expansions; table-loaded
fixtures exercise the hosted backend with dynamic values. Debug JSON preserves
compound operator byte spans after a Unicode prefix.

[Contract and commands](../../fir/v1/doc/INT_SHIFTS.md). The tutorial is exercised
through freshly linked in-process source/FIR C99 SDK clients, before and after
optimization, in actual interpreter and JIT modes.

Inferno experiment remains **5b9bdcf**: no new incoming commit since the prior
series, and the prior reverse fixture fix remains upstream. Exact snapshots
retain 554 core/reference and 174 bootstrap files. No new shared defect requiring
a reverse patch was confirmed. These language/compiler extensions stay FlashVM-only.
