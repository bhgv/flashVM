# v0.1631 — direct full-width big CFG and refreshed x64/ARM64 CASEC

FIR compiler 0.17.0 now emits i64 constants, copy, trace and all ten supported big
arithmetic/bit operations directly in verified scalar control-flow graphs. Pure
big arithmetic no longer loads Bigtable; actual table/key/range/conversion paths
keep their existing checked hosted backend. Existing instructions 118–126,
exact scalar cells, final instruction-PC relocation and empty pointer maps are
used without new opcodes, heap owners or runtime arithmetic helpers.

Both branch outcomes, backward exits, cross-block SSA uses, signed extrema,
values above 2^53 and signed quotient/remainder oracles execute on real DisVM
in interpreter/JIT modes with quantum one. Selected zero errors remain errors
after optimization, including unused results. Unreachable failing arms can be
removed. Trace values and executed flags remain separate; recount after opt.
This expands the FIR/backend capability, not the source big-profile grammar.

The public verifier rejects duplicate value/block spellings. The previous
verifier accepts the new duplicate-value regression (exit 25), making its
canonical output ambiguous; current verification rejects it before lowering.
