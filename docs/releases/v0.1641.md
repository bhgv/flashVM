# v0.1641 — lazy logical expressions and scalar FIR merge cells

## English

Compiler **0.24.0** implements true short-circuit `&&` and `||` in the Coco/R
Limbo big/table profile. The right operand executes only when required. Skipped
reads, casts, mutations and exceptions do not occur; selected RHS effects remain
even if the final bool is unused. Static checking covers both operands. Inferno
precedence is retained: && above ||, both below the comparison/bitwise levels.

Three append-only FIR operations — `bool.local`, `bool.store`, `bool.load` —
and append-only type `bool.slot` implement restricted frame-local bool cells.
Existing IDs remain stable. Cells initialize to false, cannot be copied, cast,
traced or sent, and must dominate every use. They are scalar frame storage,
not heap owners or cross-VM pointers. Effects prevent incorrect CSE/reordering.
Both Dis backends use existing MOVW; pure numeric logical expressions require
no Bigtable import. The C reference runner executes the same cell operations.

This is not a general phi/environment merge, source-loop or remote-atomicity
implementation. The SWF object backend explicitly rejects cells while preserving
old output; complete AS/SWF lazy lowering remains future work. Full IDE debugger
attachment and Build/Run/Debug panels are not completed by this change.

The frontend counts terminal and logical blocks in one 256-block budget. Logical
branch/store origins retain exact authored &&/|| bytes after UTF-8 prefixes.
Type/resource failures preserve prior FIR and sidecar destinations, including
SSA exhaustion precisely when allocating a hidden merge cell.

The tutorial protects an absent-key read and skips a deleting RHS, returning 42.
CLI and C99 API share the authoritative Coco/R grammars and semantic actions.
It is packaged and checked through relocated SDK clients before/after optimization.

Inferno experiment was checked at **b10f81f**, with no incoming commits since the
previous series. Exact snapshots remain 541 core/reference and 174 bootstrap files.
Earlier reverse fixes are present; no additional common native defect required a
new outgoing patch. Language/FIR extensions remain FlashVM-only. Native availability
remains AMD64/ARM64 164/173; no physical ARM64/full OS boot claim is added.

Initial acceptance: FIR **28/28**, build without optional table core **26/26**,
focused UBSan **4/4**. Lazy tests cover both outcomes, mutation/error ordering,
cell independence/initialization, non-dominating uses and escape rejection,
original/optimized CFG, exact origins and the shared block/SSA limits.
Final runtime/SDK acceptance follows below after completion.

## Русский

Компилятор **0.24.0** реализует настоящее короткое замыкание `&&` и `||` в Coco/R
Limbo big/table-профиле. Правая часть исполняется только при необходимости.
Пропущенные чтения, cast, изменения и исключения не происходят; выбранные эффекты
сохраняются даже при неиспользуемом bool. Статически проверяются обе части.
Приоритеты сверены с Inferno: && сильнее ||, оба слабее сравнений/побитовых операций.

В конец enum FIR добавлены `bool.local`, `bool.store`, `bool.load` и тип `bool.slot`.
Прежние ID сохранены. Ячейки исходно false, не копируются, не преобразуются,
не выводятся и не передаются по каналам; определение доминирует над обращениями.
Это скалярный слот кадра, а не владелец кучи или указатель между VM. Эффекты памяти
защищают от ошибочного CSE/переупорядочивания. Оба Dis-backend используют MOVW;
чистая числовая логика не требует Bigtable. C runner исполняет те же операции.

Общее phi/слияние окружений, исходные циклы и удалённая атомарность не добавлены.
SWF object backend отклоняет ячейки с сохранением старого файла; полное AS/SWF-
lowering остаётся отдельной работой. Полное подключение отладчика и панели
Build/Run/Debug IDE этим не завершены.

У терминальных и логических блоков единый бюджет 256. Сохраняются точные позиции
&&/|| после UTF-8-префиксов. Ошибки типов/ресурсов сохраняют прежние FIR/sidecar,
включая исчерпание SSA ровно при создании скрытой ячейки.
