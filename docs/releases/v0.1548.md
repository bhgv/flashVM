# v0.1548: real file positioning and channel-owned IDE binary inspection

Dis Sys now implements seek through the shared FlashVM file port. Ordinary read
and write handles support beginning/current/end-relative offsets, including
negative offsets that resolve to a nonnegative position. Checked arithmetic and
native-long narrowing precede cursor publication. Failed requests leave logical
positions unchanged; borrowed standard streams are rejected. Existing FlashVM
rw append channels retain their independent positions and reject this API.

The new Limbo [Idefiles owner](../../ide/dis/bridge/idefiles.README.md) reads
bounded binary windows through actual open/seek/readn calls. Requests/replies carry
correlation IDs, signed big offsets, exact binary bytes and explicit status.
Files close before the response rendezvous. The service retains no descriptors
or response arrays between calls; acknowledged Shutdown terminates its process.
The real Dis editor adds `inspect PATH` for a file's size and first sixteen bytes
in hex without altering its source/history/saved revision. The root build and
installer include the module, debug symbols, interface, source and guide.

Execution found an LP64 defect in the temporary Inferno C compiler: formatted
big-constant names exceeded a fixed buffer, merging values such as -2 and -5.
Both CMake and direct source builds now derive an ecom view with explicitly masked
32-bit halves. Pinned source manifests remain intact. An
[upstream patch](../../tools/limbo-bootstrap/patches/0001-bound-big-constant-names-on-lp64.patch)
is retained separately; it has not been published to the Inferno repository.
The Limbo compiler reference already uses fixed-width bhex formatting.

Validation: all 33 native Dis/IDE CTest entries pass. New tests execute real Sys
positioned reads/writes, negative/overflow errors, sparse offsets beyond 2 GiB,
EOF/empty windows, binary NUL, invalid paths/counts, ownership isolation and more
requests than available FD slots. Interpreter and JIT paths are both exercised
with actual dispatch counters. Classic and NC64 compiler-output tests retain
all distinct big constants; the direct compiler build is also checked. Interactive
inspection preserves dirty document text and leaves its binary input unchanged.
UBSan passes both file-window and editor suites in both execution modes. Existing
18 menu, four GUI-package selector and five preflight checks pass. Our Coco/R
Limbo parser accepts both the service and updated editor source. Relocating the
installed package to a path with spaces preserves module lookup and caller-relative
resource paths. Installed channel/workspace checks pass without external emu.

This remains experimental Linux AMD64 NC64. File measurements and reads are not
an atomic snapshot against other writers. Native file I/O can block the single
OS owner. Complete Sys/VFS/Styx, graphical IDE wiring, standard Dis64 ABI, other
native runtime platforms and parallel GC/VM owners remain open.

По-русски: добавлены настоящий Sys->seek, общий файловый переходник и Limbo-сервис
бинарных окон по каналам. В редакторе пункт 5 меню запуска доступна команда
`inspect ПУТЬ`. Исправлена коллизия big-констант временного C-компилятора;
отдельный патч для Inferno сохранён, но туда не опубликован. Импортированные
исходники не изменены. Эта серия не объявляет готовыми графическую IDE,
полный Sys/Styx либо рантаймы остальных платформ.
