# v0.1651 — channel-owned IDE directories and exact explicit quotas

Runtime **0.27.0**, IDE backend **0.6.0**, Limbo IDE package **0.11.0**.
[Protocol EN](../../ide/dis/DIRECTORIES.md) / [RU](../../ide/dis/DIRECTORIES.ru.md) ·
[Tutorial EN](../../ide/dis/examples/directory-browser/README.md) / [RU](../../ide/dis/examples/directory-browser/README.ru.md).

`Idefiles.startdirs` adds a typed Limbo owner for OpenDir/NextDir/CloseDir/StatPath
and acknowledged Shutdown. Eight endpoint-local cursor identities bound resource
use. IDs are never reused, result arrays are independent values, EOF releases the
native FD, and failed batches retire their cursor without partial publication.
All native access remains behind the existing per-OS filesystem ports.

The actual console IDE now provides `dir PATH`, `dirnext`, `dirclose`, `stat PATH`.
Each advance prints at most 32 entries. Failed replacement keeps the old cursor;
text/history remain unchanged. Long names are complete and terminal controls are
escaped. This is not yet a graphical file-tree widget.

The lifecycle regression caught an implementation error before publication:
private scalar arrays needed explicit initialization under normal Limbo array
semantics. It also exposed a host bug: quantum 1 hit the implicit 100000-slice
budget even when the caller explicitly allowed more instructions. Explicit
`--max-instructions` now supersedes that legacy budget. The exact pre-fetch quota
and default policy without an explicit limit remain unchanged.

Inferno pin advances to **73a6b5a972ea8854fa8b593569c97a68da0b0748**: Sys formatter
argument/output/String spans are checked and Heap diagnostics retain native
reference-count width. There are 646 exact selected files and 207 bootstrap
files. Original new WORD32/native sys-print-spans regressions are registered.
The upstream revision includes preceding reverse ff21d3c. Reverse **73a6b5a**
repairs two older reduced-address fixtures after packed payload access changed:
they retain narrowed overflow checks but use full native pointers for data.
All 7260 cell and 420 UTF-view cases per WORD model pass ASan/UBSan; no production
handler is weakened. Host/IDE changes stay local.

## Acceptance boundaries

Native target: Linux AMD64. Service tests execute both dispatch modes at quanta
1/2048, including 74 entries, large sparse lengths, malformed native names,
metadata/array ownership, stale IDs, quota and 32 terminal owner cycles.
A console replay verifies unchanged document state, paging, failed replacement,
escaping and termination with an open cursor. The shipped driver compiles from
relocated SDK headers and uses actual filesystem calls.

Blocking native I/O, unconsumed-reply cancellation, graphical tree UI, network
cursor leases and `/prog` remain separate work. Cursor identity is scoped to its
endpoint, not globally unique. Windows/macOS/Android native acceptance and all
Flash compatibility stages remain open.

The detached Idefiles module compiles from a renamed directory using only explicit
compiler/Sys header inputs. The same source also compiles to classic WORD32 Dis;
that is a compile check, not classic-runtime execution acceptance. Both relocated
runtime/editor SDKs compile and execute the shipped browser tutorial.

The final synchronization fence additionally imports 64b8855/e9b187d: packed
String UTF views/comparisons become byte-safe, and C plus AMD64/ARM64 mutation
paths validate owner alignment and expansion before side effects. Original
string-view-native, string-owner-preflight and string-owner-jit regressions are
selected. The hosted negative-index adaptations remain separate and retain
these upstream preflights.

На финальной сверке также приняты 64b8855/e9b187d: побайтовый доступ к упакованным
