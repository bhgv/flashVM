## Visible IDE behavior

Ctrl+I opens the live document inspector. Console watches and bound Undo/Redo
operate on the real Idecore owner; revision-checked typed writes share its history.
Ctrl+L hides/shows the left line-number strip, which is enabled by default;
`--line-numbers 0|1` chooses startup preference. Glyph baselines, width, caret,
selection, scrolling and mouse positions account for the gutter.

Native per-window Close, Resized/SizeChanged, Maximize/Restore and Expose are
handled. Dirty close offers S save, D discard and Esc cancel. Untitled documents
complete Save As before closing; cancellation disarms a pending close. Native
hosts and Limbo modules must be rebuilt together. Font remains packaged Noto, 11.

## Synchronization freshness

A concurrent update/build attempt exposed an old prepared native view despite
updated upstream inputs. Runtime preparation now directly depends on every
selected C/header input. It recognizes the new staged byte-owner validation
without weakening the existing fail-closed source contract. The generation test
compares actual prepared interpreter/JIT files with fresh output from the pinned
source, rather than merely comparing two throwaway generations with each other.

The native view was explicitly regenerated and rebuilt before the final runtime
run. A negative integration check substituted a stale string.c and confirmed an
explicit failure naming that file. No stale-view run is counted as final runtime
acceptance for the new CVTAC implementation.
