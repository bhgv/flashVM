# v0.1791 — rooted guarded HEADP/TAIL

Runtime0.93 extends explicit `--gc-worker --guarded-copies` selection to pointer
list heads and tails. The new shared_list_pointer module captures/roots the source
List through existing list_hold, checks actual field extent and mapped head schema,
then uses guarded MOVP for interior capture/retain/mark/publication. Displaced
output and temporary container owners retire after unlock; first callback errors
survive cleanup errors. Source/result may alias, including `values = tl values`.
Ordinary selection retains the prior operation bodies and ownership semantics.

[Contract](../../disVM/runtime/SHARED-LIST-POINTER.md).
[Commented Limbo example](../../disVM/examples/guarded-pointer-list/README.md).

25 affected console/editor CTests pass. Actual C/JIT/both-poll diagnostics use real
pointer-cons/String/List owners: two preparation refusals, failed-mark rollback,
unaligned/aliased output, source-owner removal, 32 actual callback-driven Cycles,
REG changes, combined errors and final Fast/Type baselines for both operations.
H heads/terminal tails, nil source, geometry/selector and raw-head refusal also
pass. Seven omission controls require semantic exit 10 before unsafe continuation.
Guarded owner tails pass actual cache/error/combined/foreign/held-guard cases and
bad-CALL/old-emitter controls. Actual positives pass TSan; emitted JIT bytes remain
uninstrumented. Installed source suites/examples and retained pins verify. No new
hosted-path UBSan, physical ARM64/RV64 or parallel managed execution is inferred.

Persistent cost record LISTP-093: same image, startup and 20000 iterations of two
HEADP/one TAIL, warmup then median three. C 0.123s default/0.155s guarded (~26%
extra); JIT 0.118s/0.161s (~36% extra). Whole-profile comparison, not isolated
opcode/whole-IDE/cross-target evidence. Two temporary native root blocks per
projection remain. Reuse/locality and cost attribution are future work; the path
stays opt-in. [Performance register](../../disVM/runtime/PERFORMANCE-COSTS.md).

Scalar/raw list heads and constructors, other shared reference/arithmetic writers,
channels/scheduler, root/graph/GC epochs and frame/module/code lifetime remain open.
NativeWorld still serializes managed execution. Shared Dis64 wire/IDs/layout,
ordinary WORD32 LEA, default admission and Inferno launch/cache policy are unchanged.
No upstream snapshot or Draw implementation is imported.
