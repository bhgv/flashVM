# v0.1550: Dis-controlled graphical editor and Inferno reconciliation

The optional `disvm-editor` target executes a fully commented Limbo controller
on our real NC64 Dis interpreter/JIT and displays acknowledged channel snapshots
through a separately owned FlashVM TextField. The existing Idecore and Ideinput
own text, history, Unicode cursor/selection policy and dirty-state checks. Limbo
also owns UTF-8 loading/saving through the actual Sys/native file boundary.
The thin native embedding renderer owns only presentation and input transport.
The existing AS workers/presentation are not yet executed by this target.

`$Idehost` registers ordinary byte-array channels while the entry stack roots
them, returns explicit path/new-document configuration and detaches before that
stack exits. The production channel adapter admits equivalent pointer-free
module-local byte descriptors. The bounded native pump copies messages between
the separate heaps, interleaves scheduler work and renders only complete ordered
snapshots. The pinned TextField, real font/layout/raster, selection/caret geometry
and optional SDL window remain on the one native owner. No document or history
implementation is substituted in C.

The root builder/menu adds component `disvm-editor` and launch 8. Installation
ships the native executable, matching Dis/.sbl modules, compiler, headers,
controller source and linked English/Russian guides. The caller's cwd remains
meaningful for files; module lookup is relative to the entry resource. `--new`
explicitly selects a destination without reading/creating it until Save.
`--events` supports counted deterministic offscreen replay; `--window-events`
adds SDL upload; `--capture` saves real PPM raster pixels. Replay EOF without
acknowledged Quit is an error, not successful UI acceptance.

Both selected Inferno manifests advance from public experiment `dad4b09` to
`3c6f5dca823927d8cec8c86159ccc35029b3bd51`. The four upstream commits add native
byte-slice coverage, channel temporary-owner/ring-index validation and the
portable dtoa/big-constant/Styx fixes. Those portable fixes were already present
upstream, so preparation now verifies them instead of patching them twice.
Imported blobs remain exact and both manifest integrity checks pass.
The remaining general byte-descriptor fix and production-source WORD32/native
string/UTF regressions are exported as local Inferno commit `416c2e1`; its mail
patch is in [patches](../../disVM/patches/README.md). Automatic approval review
blocked remote publication because of an older no-push rule. This local commit
is not advertised as part of the public upstream snapshot; runtime source-view
adaptations remain explicit pending publication.

- 64 Dis core CTest entries pass after the upstream refresh.
- All 42 runtime/editor/port entries pass, including four real graphical checks
  (Dis JIT/interpreter, offscreen and SDL dummy upload). One ReplaceAll JIT run
  initially exceeded its existing 50-second limit during concurrent builds;
  its isolated rerun passed in 32.46 seconds without changing the test or timeout.
- All 40 runtime/IDE entries in a separately compiled UBSan build pass; the two
  graphical checks were rerun successfully after extending new-file/save-error/
  focus-loss coverage. No UBSan recovery or disabled diagnostics were used.
- The real graphical tests verify native dispatch counters, Unicode including
  non-BMP text, history, exact saved bytes/revisions, dirty close/reload guards,
  explicit new files, real create failure, focus reset, invalid UTF-8, source
  limits, snapshot fragmentation and actual raster dimensions/content.
- 16 own Coco/R Limbo frontend tests pass. The frontend separately accepts the
  graphical controller, host interface and updated Idebridge interface.
- 20 build-menu, five graphical package-selection and five preflight tests pass.
- The actual installed package runs after relocation into a path containing
  spaces; its controller recompiles using only its shipped compiler/headers.
- Source documentation links report zero stale pages; new tutorial links,
  shell syntax and Git whitespace checks pass.
- The separate Inferno descriptor regression passes 79,391 string cases and
  1,115,048 UTF cases per WORD model under UBSan. Upstream dtoa's independent
  native-host regression passes 1,032 binary64 cases.

Acceptance remains experimental Linux AMD64 NC64 with one native owner. The
fixed 960×640 viewport previews the first 4096 UTF-8 bytes; Dis still owns/saves
the full admitted document. Physical window/keyboard/IME acceptance, scrolling,
Up/Down, mouse hit-testing, mixed-color syntax, completion popups, AS-worker
execution and compiler/debugger UI commands remain open. Font coverage is
explicit; bidi/grapheme interaction is not certified. Save is checked overwrite,
not atomic replacement. Synchronous I/O can block the sole native owner. No
full VFS/Styx, /prog debugger, complete compiler backend or other-platform claim
is introduced.
