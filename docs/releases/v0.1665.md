# v0.1665 — Ordered real conditions across compiler, DisVM and SWF

[Contract EN](../../fir/v1/doc/REAL_CONDITIONS.md) / [RU](../../fir/v1/doc/REAL_CONDITIONS.ru.md) · [Limbo tutorial](../../fir/v1/examples/dis/real-conditions.b) · [Unordered FIR tutorial](../../fir/v1/examples/dis/real-unordered.fir) · [Synchronization](../../disVM/SYNC.md)

FIR **0.54.0**, source CLI **0.21.0**, SWL **0.3.14**. Homogeneous Limbo real functions now admit bounded terminal if/else trees, six real relations and arm-local aliases/bindings. Three append-only FIR predicates, f64.eq/lt/le, retain strict f64/f64→bool signatures and IEEE unordered behavior. <=/>= use ordered predicates rather than inverse less-than; NaN never makes an ordered relation true. Both operands evaluate once in source order. General mixed casts, nonterminal real CFG and a full module ABI remain outside this source profile.

Verifier, constant folding/CSE/DCE, C99 reference execution, scalar/hosted Dis emission and SWO emission share the new contract. Raw hosted real values occupy plain scalar cells and use nonretaining copies; they never become GC roots. Existing BEQF/BLTF/BLEF instructions supply Dis predicates. SWF lowering uses Less2's undefined result to preserve IEEE NaN rejection independently of the current loaded player's NaN-pair equality. Ordered equality combines both directions with standard Boolean And, which SWL now validates. Existing dynamic AS equality and all container/native ABI versions remain unchanged.

Source and FIR readers now accept nonzero representable subnormal literals when strtod sets ERANGE, including the normal/subnormal rounding boundary. Overflow and complete underflow to zero still reject transactionally. AS numeric adapters receive the same literal correction. NaN/infinity literals remain invalid; runtime arithmetic can produce those values.

The executable FIR reader now accepts the same separated header // comment as the structural frontend, with strict negative/staged-output tests. Numeric SWF trace is treated as display text; exact bits remain a Dis inspection contract and SWF predicate truth is checked exactly.

Two fully line-commented examples and detailed English/Russian guides document types, branch captures, exact commands, GC boundaries and NaN-safe lowering. Installed runtime/editor SDK acceptance relinks a fresh C99 client, compares CLI/library Dis bytes and checks exact 42.5 bits, validity flags and dispatch counters in raw/optimized execution. Coverage and older backend/source guides are reconciled with the new real condition contract.

Inferno **50059a3c7e2bf773b440f2c4bbfedcbac38ff067** adds complete packed-layout and destination-span validation to AMD64/ARM64 leaf/bridge emitters. Both snapshots pin it: **704 Dis / 239 bootstrap files**. The new publication guide and extended emitter fixture are retained. Earlier reverse corrections remain in Inferno history; review found no new shared defect for an outbound patch. Compiler-only changes remain in FlashVM.

## По-русски

Однородный real получил завершающие if/else, все шесть отношений и локальные псевдонимы внутри ветвей. Новые f64.eq/lt/le проходят через verifier, оптимизатор, C99-эталон, оба Dis-пути и обычную цепочку SWO → линкер → SWF. Условия сохраняют IEEE-семантику NaN, бесконечностей и знакового нуля; порядок и однократность вычисления операндов не меняются. Динамическое равенство загруженного AVM1 сохраняется, а FIR адаптируется к нему в компиляторе.

Исправлено ошибочное отклонение представимых субнормальных литералов из-за ERANGE. Нулевой результат слишком сильного underflow и overflow по-прежнему отклоняются без замены прежних файлов. Добавлены построчно прокомментированные примеры и подробные руководства на русском и английском; SDK проверяет библиотечную компиляцию, точные биты 42.5 и оба режима исполнения.

Из Inferno перенесены проверки упакованных LeafLayout и полных диапазонов публикации машинного кода AMD64/ARM64. Исходники и хеши снимков сверены; аппаратная ARM64 и полнота IDE/ABI этим не заявляются. Прежние обратные исправления присутствуют в Inferno; нового общего дефекта для обратного коммита в этой серии не найдено.
