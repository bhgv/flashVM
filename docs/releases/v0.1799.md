# v0.1799 — eighteen jointly guarded integer branches

Runtime0.101 adds existing EQ/NE/LT/LE/GT/GE branches for BYTE/native WORD/LONG
to explicit --gc-worker --guarded-copies. BYTE ordering is unsigned; WORD/LONG
signed. Both complete operands are captured in REG.s versus REG.m order, then
only a true predicate reads its target and publishes the current owner's PC.
Default bodies/emission and all shared file formats remain unchanged.

slot before reads. Invalid target geometry substitutes a source alias; false
conditions ignore invalid slots and nil/H contents. A true invalid target returns

can refuse even an unused valid target span. This is not a claim that false
branches acquire no target metadata. Error propagation occurs after unlock.
PC must be exact current TLS REG.PC; arbitrary shared destinations are refused.
No allocation, FP, reference transfer or VM callback occurs under object guards.
Mapping/root/code lifetime remains a caller obligation; NativeWorld is retained.
