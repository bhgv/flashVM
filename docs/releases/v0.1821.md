# v0.1821 — guarded channel allocation / runtime0.122

In the guarded worker profile all seven NEWC instructions capture capacity as a
native WORD before construction. Raw channels also capture message width.
Mapped channels resolve the payload Type in the live current module. Absent
capacity still encodes an unbuffered channel.

The publication coordinator builds both queues and any owning array privately.
It registers the channel as a root before notifying the monitor about the
channel or its buffer. The buffer is reachable through that root. Both
notifications happen before the destination changes. Refusal to register the
root frees private queues and blocks and drops their descriptor counts.
Monitor errors use rooted retirement. If another writer changes the owning
destination, the same candidate can be used in a bounded retry.

Guarded leaf JIT dispatch routes the seven channel opcodes through C. The x64
fixture checks the actual JIT cache, root refusal, buffer-monitor failure and
descriptor baselines after Fast. The Limbo guest sends and receives values on
word, raw tuple and mapped tuple channels in interpreter and JIT sessions.

NativeWorld still serializes managed execution. Channel construction establishes
the initial ownership graph. Concurrent send, receive and alt also need a
queue and waiter lifetime protocol.
