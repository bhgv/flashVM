# v0.1628 — runtime reflection and exact Limbo casts

Our Coco/R big-result Limbo profile now compiles `typeof expression`,
`big expression` and `string expression` through typed FIR to native DisVM.
`tobig`/`tostring` remain AS projection helper names, not Limbo keywords. Tests
also retain those spellings as ordinary Limbo local identifiers. Compiler version
is 0.14.0; matching hosted runtime is 0.17.0.

Reflection returns supported Limbo type names. A snapshot key reports its actual
numeric/text kind rather than the compiler's internal table.key representation.
Explicit casts preserve exact signed-64 values, format canonical decimal and
reject malformed/overflowing byte-counted text. There is no double intermediate,
partial conversion or silent zero. Text copies preserve Unicode and embedded
zeros at the native module boundary. Tables/snapshots are not cast operands.

FIR appends value.type/value.big/value.text with checked arity/types/dominance.
Conservative effects retain errors in unused expressions after optimization.
The Dis emitter uses existing instructions and signature-checked Bigtable helpers;
String results and snapshot owners have proper frame roots across allocation.
The C reference runner now tracks text byte counts explicitly instead of deriving
copied-key lengths using strlen. Prefix operations preserve their own FIRDBG1
source occurrence through nested expressions, independently of operand spans.

The C99 scalar core adds allocation-free parse/format APIs with documented byte
spans and output-preservation contracts. Its test compares 20,005 exact formats
against an independent snprintf oracle, checks roundtrips, extrema, invalid text,
embedded zero and short buffers. ASan/UBSan passed; restricted process-based LSan
is disabled by the existing fixture hook while allocator accounting remains active.

Changed C implementations/headers are formatted for four-space human reading,
with braces, expanded case branches, aligned field comments and documented
function contracts. Scanner helpers in the authoritative Coco/R grammar now have
braced control bodies and purpose/ownership comments. Generated/upstream code is
not rewritten as a formatting change.

The suite runs original/optimized Dis with quantum=1, tests signed extrema,
namespace changes, dynamic snapshot kinds, forged owners, invalid casts, unused
errors, exact source spans and large GC maps. Full source-to-Dis SBL, automatic
proxy locals/operators, channel any, heterogeneous table values, additional casts
and table CFG/loops remain pending. This series does not import architecture JIT
changes or export the language extension to Inferno. Snapshots stay at 875d122.
