## Lazy syntax service

New portable [Idesyntax](../../ide/dis/bridge/idesyntax.m) provides a complete
revision-bound lexical catalog and a coalescing owner. Recognition comes from
Coco/R-generated Limbo/AS scanners. One active immutable scan plus one newest
pending snapshot bounds stale work; Update/Snapshot do not wait for completion.
Old ticket/revision/profile results cannot replace the current catalog. Unicode
scalar intervals and immutable token values can be reused by lexical context and
search consumers. Semantic scopes and typed completion are separate frontend work.

Build-menu **16**, `--launch syntax`, and installed `run-syntax-check.sh` run the
real service in DisVM without a deployed Python dependency. This entry is a
functional check, **not a coloured GUI**. Mixed-range TextField presentation and
connecting the palette to editor windows remain next work; full AS rich-text/HTML
support is not claimed. Existing uniform text rendering is unchanged.

Parallel editor builds now have a single producer target for both generated SWF

the previously observed clean-build missing-header race; SDL GUI execution was
not rebuilt in this series, so no new graphical/platform acceptance is claimed.
