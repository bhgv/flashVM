# v0.1666 — Lazy numeric decisions and seven Inferno updates

[Contract EN](../../fir/v1/doc/NUMERIC_LOGIC.md) / [RU](../../fir/v1/doc/NUMERIC_LOGIC.ru.md) · [Limbo tutorial](../../fir/v1/examples/dis/numeric-logic.b) · [FIR cells tutorial](../../fir/v1/examples/dis/numeric-logic.fir) · [Synchronization EN](../../disVM/SYNC.md) / [RU](../../disVM/SYNC.ru.md)

FIR **0.55.0**, source CLI **0.22.0**, structural FIR frontend **0.1.4**.
Homogeneous int/real terminal decisions now compose strict relations through lazy
&&, || and grouped logical negation. Conjunction binds above disjunction; each
operand evaluates once and skipped RHS errors remain unobserved. Negation preserves
IEEE unordered semantics rather than reversing an ordered comparison. Private
normalized bool cells merge scalar values without introducing GC roots. Source
parsers remain generated from Coco/R, with the existing depth/SSA/block budgets.

The SWO backend now emits bool.local/store/load as private object-local AVM1
variables, retaining initialization, independent cells and immutable load snapshots.
Verifier type/dominance/nonescape rules run before output. Other table/big cell and
owner operations remain rejected by this backend. No Dis opcode, native frame ABI,
container version or dynamic AS coercion changes. The structural parser now admits
bool.slot, reconciling its grammar with the executable reader.

Source diagnostics preserve exact authored UTF-8 relation/logical positions. CLI
and library paths share lowering; a C99 embedding client repeatedly compiles raw/
optimized int/real modules through both Dis and SWO APIs. Two tutorials comment
every nonblank source line, with detailed bilingual guides. Installed packages ship
those guides and relocate their links. SDK checks compare CLI/library Dis and run
both the previous ordered-real example and the new lazy condition example.

Seven reviewed Inferno experiment commits advance both exact snapshots from
50059a3c to **577940fa699d42593db7c680c5a0aeceeeb04e09**: **741 Dis / 259 bootstrap files**.
They bound GC work/feedback and epoch waiting, preserve full-width native I/O replies,
and replace deep Limbo Type/declaration/stub walks with checked iterative work.
Reference propagation and local sorting retain native metadata width. New production/
oracle fixtures are imported and registered. No new shared defect was confirmed for
an outbound patch; prior reverse corrections remain ancestors. Inferno itself is
unchanged by this series.

## По-русски

Добавлены ленивые составные условия для однородных int/real-функций Limbo: &&, ||,
отрицание !(...). Правые части вычисляются только по нужному ребру CFG. Проверяемая
ошибка деления в пропущенной части не возникает, а в исполненной сохраняется после
оптимизации. NaN, знаковый ноль и порядок операндов сохраняют прежние контракты.
Внутренние bool-ячейки теперь работают и в SWO/SWF; структурная Coco/R-грамматика
приведена в соответствие с reader/verifier. Добавлены проверки публичных C99-библиотек,
два построчно комментированных примера, руководства RU/EN и приёмка перенесённого SDK.

Из Inferno перенесены семь обновлений GC, native I/O и глубоких обходов компилятора.
Исходные файлы сохранены побайтно. Полная семантика Limbo, обычная булева группировка
в ограниченном числовом профиле, итоговые карты Dis/SWF/JIT PC, панели Build/Run/Debug
IDE и аппаратная ARM64 остаются отдельными этапами. Собранная IDE продолжает
исполняться на нашем DisVM с отображением через FlashVM.
