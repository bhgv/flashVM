# FlashVM v0.1729 — captured node motion without per-sample Dis exchange

IDE0.7.14. [English contract](../../ide/FLASHVM-LOCAL-MOTION.md) ·
[Русское описание](../../ide/FLASHVM-LOCAL-MOTION.ru.md).

The recorded Nodes/control drag now applies copied point masks and decoration
bindings locally on the FlashVM owner after initial gesture admission. Intermediate
native movements do not invoke the Dis model or serialize the complete path.
Source controls, grouped points, welded endpoints, guides and squares update from
one immutable baseline; invalid movement preserves the last valid point. The
last point crosses once for authoritative commit/Undo. Owner-produced bindings,
not hardcoded native UI style/selection policy, describe decoration geometry.

Local geometry generations invalidate bitmap keys. Exact matching snapshots
reapply the native position; changed/absent plans retire it. Pointer identity,
release, Escape/focus, lifecycle barriers and the default replay route remain
explicit. Private tool flag0x40000 adds a checked scalar plan to the desktop
stream; it does not change SWF/Dis64 formats or expose managed pointers.

This checkpoint addresses captured Nodes motion. It does not claim that all
IDE operations have moved to FlashVM, or that AS asinc closures now execute on
separate worker threads. Async.post is still owner-loop delivery; executable
closure/capture/task lowering and broader UI ports remain open and documented.
The user's one-asinc-block/one-worker target is retained in IDE development rules.

The production SDL path handles600 queued node movements with only Begin/End
proposals, no intermediate Dis reply and no timeline advance. Detached raster
pixels change before commit acknowledgement; a repeated canonical snapshot does
not rewind the local gesture. Independent copied-modifier C tests and actual
interpreter/JIT model/UI regressions cover its separate boundaries. Full matching
runtime/Dis rebuild is required because private plan/type layouts changed.


Validation:11 affected model/native/UI checks passed, covering both interpreter
and JIT where applicable. Final native SDL checks compare actual retained-baseline
presentation pixels while the mouse is still held. The installed SDK rebuilt its
shipped model sources and passed the real object/node editing and SVG replay.


A staged owner Begin now closes logical input admission until its complete End
(or deferred geometry completion). A captured mouse continuation remains queued
instead of being hit/mapped against partially replaced scene arrays. The native
fixture injects such a partial update during a drag and verifies safe resumption.
