# v0.1731 — node editing, SVG clipboard and local graphic gestures

IDE0.7.15. [Detailed controls and limits](../../ide/NODE-TOOLS.md) ·
[Русский](../../ide/NODE-TOOLS.ru.md).

Nine node-bar operations add/remove/split/join anchors, convert spans to lines or
cubics and retain cusp/smooth/symmetric handle modes through Undo and SVG. Node
algorithms, cutting, caching, clipboard and generic native transforms are separate
modules. Original small operation glyphs use the existing button chrome.

Delete/Backspace removes selected anchor groups or a selected whole figure.
Graphics participates in the existing acknowledged session Copy/Cut/Paste route;
Paste replaces a selected figure and otherwise appends. Revision/selection checks,
SVG validation,64KiB clipboard bound and immutable transaction history remain.

Visible prepared node handles start locally before the Dis Begin reply. Admitted
object moves/scales/rotations and selection frames use immutable native modifiers
until release. Partial scene input remains fenced; cancellation and zero-motion
release retire the correct baseline. Generic copied recipes reconstruct redundant
node decorations in C, and unchanged selection reuses its cached overlay.

A local256-quadratic JIT benchmark,20 Begins: selection123→129ms,
presentation26002→374ms, payload172632→39232 ASCII bytes. This measures the model,
not physical UI/network latency. A real desktop regression also exposed a Pen/
Brush dot preview containing cubic curves under the old header; the header now
advertises both controls before a cubic preview is generated.

Actual model/pane interpreter/JIT tests, real SDL eager/scale/marquee fixtures,
independent C geometry and existing SVG/pixel desktop replays validate separate
boundaries. Read the detailed contract for selection/topology/capacity limits.
Complete AS asinc lowering and parallel Dis scheduling are not claimed here.
The extended-up/REG TLS work remains present; IDE-host still interleaves both VM
owners on one OS thread while raster workers execute on real background threads.
