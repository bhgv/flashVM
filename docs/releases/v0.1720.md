# FlashVM v0.1720 — glazed controls and inset close buttons

Restored the previous dark glazed appearance of right-rail and popup command buttons. Drawing tools and colour swatches now use the same diagonal highlight, preserving their document colour and selected border.

Window close controls have a dedicated ActionScript view using the same dark surface. Limbo places their 17×17 hit area five pixels below the window top, inside the 21-pixel title strip at offset three. MDI document tabs retain their separate appearance and behavior. C only routes the copied close role to the compiled AS view.

The desktop atlas and finite seven-screen layout remain available. IDE version: 0.7.8. Rebuild `disvm-editor` and launch build-menu entry 8.

Validation: all eight affected checks passed with JIT and interpreter dispatch: desktop ownership/close bounds, native workspace, atlas and maximized 1:1 rendering. The native screenshot was inspected.
