# v0.1756 — typed atomic count primitives and checked host references

Runtime0.60.0 introduces disvm/refcount.h and host/refcount.c for native unsigned
Heap-shaped and signed Type-shaped counters. Acquire loads/acquire-release CAS
provide checked retain/release, unique LAST, zero/negative/overflow refusal and
no resurrection. A port-registry-mutex fallback handles types not advertised as
always lock-free; the forced fallback is separately tested. Neither backend
allocates or performs GC/destruction. The caller must already hold storage alive.

Selected hosted module/inspection/table retains and the initial module-owner drop
now use checked operations. Root registrations roll back on failed retain. Deferred
RC eligibility uses an atomic load. Retained Heap/Type/JIT direct accesses and
marking remain unconverted: global managed heap exclusion stays ENABLED. This
is a foundation step, not a claim that Heap.ref is now universally atomic or
that concurrent managed mutation is safe. Heap/Type layout and file IDs are unchanged.

The standalone primitive test uses8 real OS threads,160000 balanced pairs/type,
unique final release and payload visibility through prior releases, null/zero/
maximum/negative boundaries. Native-selected and forced-lock backends plus ten
semantic boundary controls run. The independent CMake library and fully commented
immutable-message handoff example demonstrate retaining a distinct owner BEFORE
thread publication and freeing only by LAST. Installed SDK sources/headers/ports
can compile/run the same example and primitive tests.

The object-lock proposal now explicitly separates copying a reference (retain a
separate container owner) from moving an already-held owner (consume the local).
Source-slot locking/lifetime, Type owners, marking and direct-entry conversion
remain mandatory. [Conversion boundary and audit inventory](../../disVM/runtime/REFCOUNT-CONVERSION.md)
explain why atomic helpers alone do not authorize parallel managed execution.

Validation: all33 selected runtime cases pass in aggregate (four editor cases
were retried after restoring build executable permissions). Seven additional
hybrid-table/guard/lease/boundary cases pass; scalar module inspection passes
C/JIT with the converted retain/drop. Primitive normal/nonrecovering UBSan/TSan
runs cover both backends, ten semantic controls and200 actual native-message
reclamations per backend. The installed primitive suite/example and independent
CMake library/example build/run pass. Public header parses as C89 and C++98.
Actual instrumented Debug INTERPRETER helper-RC4/8/auto and hybrid-table workloads
pass TSan; this is focused evidence, not whole-VM/JIT/UI race freedom. Both vendor
manifests, Python/shell/whitespace checks pass. New hosted execution is Linux x64.
