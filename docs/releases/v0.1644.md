# v0.1644 — int arithmetic and native buffered channels

## Русский

Компилятор 0.27 добавляет int + - * / %, унарные знаки и пять составных
присваиваний в Limbo big/table-профиле. Однородный int-профиль получает деление
и остаток. Каждый результат нормализуется до signed32, включая NC64.
Смешение int/big запрещено; числовые литералы table-профиля остаются big:
используйте `int 1`. Побитовые int-операции и сдвиги пока не реализованы.
Новые FIR i32.div.signed/i32.mod.signed сохраняют ошибки деления на ноль после
оптимизации; MIN32/-1 оборачивается, MIN32%-1 равен нулю. Dis использует
существующие DIVW/MODW. Живые новые операции SWF пока не поддерживает.

Из Inferno импортирован 87785ec: нативные буферизованные SEND/RECV AMD64/ARM64.
Блокирующие случаи, очереди ожидающих, неподдержанные размеры и карты указателей
сохраняют C fallback. Доступность 166/173 — не процент полноты семантики.
В experiment отправлены 046bb1f (проверка без записи pycache) и 6945acaf
(извлечение настоящих channelspan/channelpeer в тесте очередей).
Итоговый снимок 6945acaf: 554 core/reference и 174 bootstrap файла.

## English

Compiler 0.27 introduces same-type int arithmetic and compound updates in the
Coco/R Limbo table profile, signed32 normalization and checked division/remainder
in FIR, reference execution and Dis. Optimizers retain unused throwing operations.
Explicit casts separate int and big. Existing operation IDs and Dis ABI remain
unchanged. [Contract](../../fir/v1/doc/INT_ARITHMETIC.md) and
[tutorial README](../../fir/v1/examples/tables/README.md).

Native buffered channel code comes from Inferno 87785ec; two fixture defects were
fixed in their owning repository and imported back at 6945acaf. Language extensions
remain FlashVM-only. ARM64 validation uses instruction emulation, not hardware.

## Validation / Проверки

- FIR: 32/32; detached compiler: 30/30; focused UBSan: 4/4.
- Relocated headless and editor SDKs: fresh C99 source/FIR clients and the
  original/optimized int tutorial passed in both VM modes.
- Hosted Dis interpreter/JIT: 137/137; selected core channel/readiness tests: 10/10.
- Buffered C/native RX matrix: 1,593,088 accepted/declined cases under UBSan.
- Buffered emitter emulation: 164,480 cases per architecture.
- ASan+UBSan accepted/declined paths passed with BUFFER_NO_C_ERRORS=1;
  full C exception cases were covered by UBSan, not claimed under ASan.
- Queue fixture owner checks: 54,565 cases per word size per emu/os variant.

This series does not complete full language coverage, IDE Build/Run/Debug panels,
Dis debugger attachment or ARM64 hardware acceptance.
