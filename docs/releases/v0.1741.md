# v0.1741 — per-TLS native-call state and sealed owner registration

Runtime 0.48.0 / native host 0.5.0 moves native suspension, before-epoch snapshots
and release/reentry/progress counters from RuntimeGC globals into opaque metadata
embedded in each existing TLS NativeContext. Shared heap/collectors remain shared.
Foreign owners are rejected before reading private mutable state. No extra TLS
key or managed allocation is needed; up/REG layout and shared file ABI are intact.

The lifecycle is detached → idle → active → native → active. Resume requires one
epoch sample, read only after reacquiring the heap; missing/duplicate samples and
out-of-phase transitions refuse. Context unbind refuses attached metadata. Last
active owner sealing atomically closes new root registration, while a live peer
prevents sealing. Service lifetime and OS joins remain the host's responsibility.

Production runtime start/stop and audited sleep/read/write/print paths use these
helpers. Internal attach/detach entry points require a live externally published
service, empty process slots and joined extra owners before controller stop.
They do not start another managed executor. NATIVEGC identifies owner_state=tls;
its native-call counters describe the controller, not a racy sum of other owners.

Two actual native owners check independent overlapping waits/epoch deltas while
executing retained addw, 201 two-root scans, private counter refusals and sealing.
Three active removals detect bypassed admission, lost before-epoch state and
reopened registration. Atomic/locked, no-atomics fallback, UBSan and focused TSan
pass. The public C tutorial is compiled into the fixture and checks native failure
status/unsigned wrap. TSan reports no race but warns about executable-name lookup;
this is focused native evidence, not whole-VM coverage. Nineteen runtime gates,
including the 0070 local-call/cleanup controls, pass.

Inferno 0071 acknowledges the agreed future eight-byte result-address rule; no
wire/CALL/LEA admission changes here. Its new caught-handler repair is under
independent review before import. Both snapshot manifests in this series remain
at the tested 0070 source checkpoint.
