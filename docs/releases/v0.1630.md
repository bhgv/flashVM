# v0.1630 — checked big division/bit operations and guarded string-case JITs

The Coco/R Limbo big profile now supports /, %, &, |, ^ and unary ~ with
reference-Limbo precedence, strict i64 operands and direct Dis ALU lowering.
Division truncates toward zero; remainder has the dividend's sign. MIN/-1 is MIN,
MIN%-1 is zero, and zero divisors raise zero divide even when unused after opt.
Bit operations preserve all 64 bits. No arithmetic uses a floating intermediate.
Compiler version is 0.16.0; matching hosted runtime is 0.19.0.

FIR appends six operations with typed arity/dominance verification. DIV/MOD have
MAY_THROW, so zero errors are neither removed nor treated as pure CSE. Constant
folding guards zero and MIN/-1 before host C arithmetic. Reference execution
shares the checked language behavior and publishes no staged trace on failure.
The emitter uses existing DIVL/MODL/ANDL/ORL/XORL; NOT uses a scalar all-ones
module cell, with no extra heap owner, RPC or arithmetic builtin. Source events
retain the exact operator token. AS conversion helpers and Limbo casts remain
separate language surfaces.
