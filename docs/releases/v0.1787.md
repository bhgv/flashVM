# v0.1787 — guarded scalar/raw copy profile and SELF

Runtime0.89 adds exact small-span and arbitrary byte-range guards sharing the
existing pointer-cell domain, without per-copy allocation. Five scalar/raw copy
opcodes use checked C paths and hosted x64 tails under explicit startup
`--gc-worker --guarded-copies`. Defaults retain their usual scalar fast paths;
other backend guarded JIT profiles refuse. SELF always uses checked MOVP for
count/mark/publication, then destroys the displaced owner after unlock.

[Precise contract and limits](../../disVM/runtime/SHARED-BYTES.md).
[Commented native API example](../../disVM/examples/native-range-access/README.md).

52 selected console/editor CTests pass; new tail cases repeat after held-guard
preflight. Eight native range controls, four actual byte/SELF controls and two
emitter controls require semantic exit 10. Exact byte/canary/overlap/NaN/FP flags,
empty/error behavior, mixed eight-thread native writes, every tail's cache unmap
and errors pass. TSan/UBSan, SDK and vendor pins verify; emitted machine bytes
remain uninstrumented. No new physical-target acceptance is inferred.

Local mixed word/record comparison, startup plus 20000 loops, median 3 after warmup:
C 0.229s default vs 0.263s guarded (~15%); JIT 0.158s vs 0.218s (~38%). Not general
IDE/per-op/cross-target evidence. Opt-in preserves default paths until compiler
local/shared analysis and remaining memory protocols are ready.

NativeWorld still serializes general managed execution. Reference-rich aggregate
retirement, other arithmetic/writers, source/root/GC epochs, channels/scheduler
and code/frame/module lifetime remain open. Shared Dis64 wire/IDs, ordinary LEA
and default loading stay unchanged. Inferno's numeric-call startup/cache profile
is separately agreed; no FlashVM typed-call activation is introduced.
