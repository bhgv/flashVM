# v0.1797 — guarded shifts and independent Dis64 bindings

Runtime0.99 adds eight existing protected shifts: SHL/SHR BYTE/native WORD/LONG,
logical LSR WORD/LONG. Counts always have native WORD width, even for BYTE.
The protected arithmetic/shift set now has 32 operations. Default bodies/emitter,
Dis64 wire/IDs, ordinary WORD32 LEA and executable admission remain unchanged.
