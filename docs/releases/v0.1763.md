# v0.1763 — direct tracked ownership moves

Runtime0.65 adds slot put/take operations. Put moves a local scope owner into an
empty protected slot; take moves the existing slot owner directly into an empty
receiver entry. No retain/drop, allocation, VM callback or caller-owned transfer
envelope intervenes. Occupied/nil/invalid/foreign/guarded roles refuse unchanged.
Calls may wait for mutex exclusion, never for capacity or a message.

[Slot contract/API](../../disVM/runtime/OWNER-SLOTS.md),
[exclusive threaded example](../../disVM/tests/owner_mailbox.c),
[heap parallelism status](../../disVM/runtime/HEAP-PARALLELISM-STATUS.ru.md).
