# v0.1707 — Limbo/AS desktop controls, palettes and native modules

MDI is now a tabbed MovieClip window on the common desktop. Limbo, ActionScript
and graphics use separate groups. Opening or saving under a different source
extension reclassifies membership and detaches incompatible groups. Hidden tabs
retain document owners, selections and live miniature sources. Focused groups are
painted/hit-tested as one root/tab/body unit. Dragging contact entry into the left
shelf docks SDI or a whole group without replacing its saved normal position.

Новые контролы и алгоритмы разделены по файлам Limbo: вкладки, домены исходников,
попадание по сцене, сворачивание, миниатюры, полки, инструменты и последние файлы.
Оформление стола, обеих полок, карточек, шапок, кнопок и полей вынесено в отдельные
исполняемые AS-файлы. C предоставляет общий удерживаемый GC адаптер рисования,
ввод, захват и растеризацию. Тема не вычисляется в C. Старые специализированные
векторные контролы ещё используют существующие нативные примитивы; это не заявление
о завершённом переносе всех старых виджетов.

Desktop and both rails admit empty-space drag, three-contact pan, middle mouse,
and Ctrl+Shift+left drag. Each rail has an independent clamped offset and wheel
routing by pointer position. Portrait miniatures keep their size and can still
be reordered by one-contact dragging. The right rail scrolls to Files/Edit/Search
subpalettes opening left over the desktop. Save, Undo/Redo and Find have independent
shortcuts and duplicate palette commands. Files offers typed new documents, Open,
Save As and four actual session-recent paths. Search is literal case-sensitive
Unicode, with next-match wrap and one-transaction ReplaceAll. It is not regex or
cross-project semantic search. New source language hints do not adopt fake paths.

The reference-like chrome has neutral cards, blue headers and dark glossy right
buttons. The rails use approximately60% alpha with strips fading inward. This is
an imitation of glass, not real backdrop blur. Compiled AS resources go through
Coco/R→FIR→peepholes→SWO→SWF; resource extraction copies one linked DoAction verbatim.
The assignment/arithmetic presentation profile does not imply full AS lowering.
Private UI capacity grows to96 retained nodes; this changes no Dis64 format ID.

FlashVM component v0.1694 adds a separately compiled C namespace tutorial using
existing rooted methods/accessors. It tests actual collection, a retained managed
capture, invalid arguments, cross-context refusal and linked SWF setter execution.
There is no second plugin ABI or automatic shared-library loader. See
[native extensions](../NATIVE-EXTENSIONS.md) / [расширения](../NATIVE-EXTENSIONS.ru.md)
and [desktop controls](../../ide/dis/DESKTOP-CONTROLS.md) /
[контролы стола](../../ide/dis/DESKTOP-CONTROLS.ru.md).
