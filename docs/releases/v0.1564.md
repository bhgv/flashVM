# v0.1564: acknowledged Unicode clipboard and one-Undo paste on Dis

The matched component 0.6.0 host/controller/library implements source Ctrl+C/X/V
through copied channel values. Native code copies only an authorized scalar
range from its immutable source snapshot. Cut deletes only after success at the
captured revision/ticket. Native read snapshots are bounded to 65536 UTF-8 bytes;
Dis stages ordered Unicode-aligned fragments privately and publishes one Replace
only on completion. Empty clipboard is a no-op; native failures, NUL, malformed
identity/extent/offset and stale results cannot publish a partial source edit.
