# v0.1796 — guarded products, quotients and remainders

Runtime0.98 adds nine guarded integer operations: MUL/DIV/MOD for BYTE/native
WORD/LONG. The explicit --gc-worker --guarded-copies set grows from 15 to 24 existing
opcodes. Products keep modular wrap; signed quotient truncates toward zero and
remainder follows the dividend. Existing MIN/-1 behavior is retained without C
signed-overflow evaluation: quotient MIN, remainder 0. Default semantics stay intact.

Valid operations guard both inputs and output through one snapshot. DIV/MOD check
the guarded divisor before dividend/output payload access. Nil/H/wrapping outer
geometry claims only the valid divisor through three aliases: zero gives exZdiv,
nonzero exBounds. All semantic errors are raised after unlock. Native admission/
BUSY refusal still precedes semantic evaluation. No allocation/reference transfer,
FP effect, VM callback or mapping/root proof is added under these guards.

39 affected CTests pass in 261.62 seconds. The actual C oracle covers 1404000 value/
alias cases, unchanged zero-error canaries, dedicated signed MIN/-1 and exception
precedence, guarded divisor reads and unlocked VM-error entry. Three semantic
controls omit admission/publication or alter the zero diagnostic. The real Limbo
guest reaches all 24 x64 tails, each with mapping unmap, inherited C return-PC and
negative emitter checks. Combined cache/error tests inject actual DIVL zero after
mapping retirement. Six failing guests require exit 1/zero-divide/no post-result
output for default/guarded C/JIT. TSan positives pass these three paths; generated
machine code is uninstrumented. No new hosted UBSan/physical target acceptance.

Installed source/test closure and ordinary C/guarded C/guarded JIT example profiles
pass. Vendors verify 1096/312 files at ba26acc. Native WORD64 tests do not define
shared Inferno Frame64 Int32/Ref64 semantics. No Dis64 wire/IDs/default admission,
ordinary WORD32 LEA or immutable named-launch/cache agreement changes.
