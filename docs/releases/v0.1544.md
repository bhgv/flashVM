# v0.1544: complete interactive build settings

`python3 build_menu.py` now offers the actual windowed JIT player explicitly.
Typing `all` and accepting defaults selects the real AGG/JIT window, input and
audio host, automatic SDK bootstrap and installation with examples. Other menu
choices build the windowed interpreter, both variants, or a console-only package.

The advanced menu edits jobs, configuration, source build/output paths, profiles,
installation and command preview without command-line switches. After successful
builds the menu shows installed entry points and offers checks, a graphical demo,
or both. Failed builds do not present stale outputs as successful new products.

JIT output directories now have a `-jit` suffix so both windowed variants survive
one multi-profile build. The graphical launcher prefers JIT and still recognizes
previous installed directory names.

Validation: 16 menu tests, four build/default/installer tests and five preflight
tests passed. An actual previously built player was installed into the new JIT
package directory; its console check passed and the window launcher executed 12
native JIT frames through SDL dummy video/audio with no interpreter fallbacks.
Physical display/device acceptance and full embedded Dis/IDE startup remain open.
