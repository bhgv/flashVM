# v0.1658 — Executable source aliases and shared compiler/JIT fixes

[Source contract EN](../../fir/v1/doc/SOURCE_ALIASES.md) / [RU](../../fir/v1/doc/SOURCE_ALIASES.ru.md) · [Tutorial EN](../../fir/v1/examples/type-aliases/README.md) / [RU](../../fir/v1/examples/type-aliases/README.ru.md) · [Bidirectional sync](../../disVM/SYNC.md)

FIR tools **0.49.0**, format **FIR 1.0**. Our authoritative Coco/R source parser and C library now lower sequential file/module type aliases to executable canonical FIR. int/real results reach both Dis and numeric SWF; big/string/table annotations reach the existing big/table Dis backend. Lexical shadowing does not rebind earlier aliases. No new runtime representation/opcode is needed. AS variables named type and table fields .type remain accepted. Alias state resets between library requests, and rejected source preserves prior outputs. An EOF recovery guard fixes a malformed-header parser hang.

This is a bounded executable teaching profile with at most 128 aliases, not the broader interface resolver or a complete typed body compiler. Forward/local/qualified/generic aliases and alias-name casts remain unsupported. The new line-commented tutorials and bilingual guides document build commands, results and boundaries, and are copied into installed SDKs.

Inferno synchronization pins 2bd9f3c (699 Dis / 216 bootstrap files). Incoming Sys.pctl capture, deep compiler queries and JIT layout/ARM64 target checks retain upstream provenance. Our confirmed left/mixed occurs stack-overflow correction was published back as b151e32d and is included in that pin. A second reverse fix, 2bd9f3c, aligns the cold ARM64 dispatch identity in the unsanitized foreign-host fixture. Flash-specific extensions were not sent upstream.

## По-русски

Наш исполняемый фронтенд Limbo теперь понижает последовательные файловые и модульные псевдонимы в канонический FIR. Числовые результаты проверяются в DisVM и SWF, big/string/table — в Dis-бэкенде. Связывание учитывает область объявления, состояние библиотеки сбрасывается между запросами. Исправлено зависание разбора повреждённого заголовка на EOF. Учебные программы прокомментированы построчно; руководства и примеры входят в SDK.

Это ограниченный исполняемый профиль, а не полный компилятор тел. Приняты исправления Sys, обходов AST и JIT из Inferno; исправление переполнения стека occurs отправлено обратно в experiment. Проверки эмиттера ARM64 не заменяют испытание на ARM64-устройстве. Точные ограничения и протокол синхронизации приведены по ссылкам выше.
