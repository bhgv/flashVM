# v0.1661 — Local Limbo type scopes and Bio boundary synchronization

[Contract EN](../../fir/v1/doc/SOURCE_ALIASES.md) / [RU](../../fir/v1/doc/SOURCE_ALIASES.ru.md) · [Tutorial EN](../../fir/v1/examples/type-aliases/README.md) / [RU](../../fir/v1/examples/type-aliases/README.ru.md) · [Line-commented source](../../fir/v1/examples/type-aliases/local.b) · [Sync](../../disVM/SYNC.md)

FIR **0.51.0**, source CLI **0.18.0**, textual format **FIR 1.0**. Our Coco/R executable Limbo frontend now accepts sequential local type aliases in function bodies, blocks, branches and loop bodies. Statement heads are factored in the grammar before choosing type/value namespaces. Aliases retire at block exit, parent types are restored, canonical local targets remain stable across later shadows and same-scope value conflicts are rejected. The 128-declaration budget includes retired siblings. For-header type aliases and local forward targets remain outside this bounded profile.

Aliases introduce no runtime variable, FIR opcode or native ABI. Tests compare direct/aliased FIR byte-for-byte, execute raw/optimized Dis under both dispatch modes and scheduler quanta, and run numeric aliases through SWO/linker/SWF. The new tutorial has comments on every nonblank source line and detailed bilingual instructions; the installed SDK compiles and executes it after relocation.

Incoming Inferno 6a307e5 fixes Bio pushback/count/position boundaries in the actual source-built bootstrap library. Both snapshots advance to that pin (703 Dis / 222 bootstrap files). The new 35,658-case fixture is registered with bootstrap tests. Previously published reverse fixes remain ancestors; no new shared defect was confirmed, and Flash extensions were not exported.

## По-русски

Добавлены последовательные локальные псевдонимы типов Limbo. Они работают в функциях, блоках, ветвях и телах циклов; после выхода восстанавливается внешний тип. Псевдоним не создаёт переменную или инструкцию FIR. Проверяются конфликты имён, отсутствие утечек области, общий предел 128 и восстановление состояния библиотеки после ошибок.

Из Inferno перенесены граничные исправления Bio и их тесты в исходную сборку компилятора. Файловые операции остаются за существующими портами. Добавлен построчно прокомментированный пример local.b и русские/английские инструкции. Общий компилятор произвольных тел, импорты и новые составные типы остаются отдельными этапами.

An over-budget numeric alias cast now reports the shared nesting limit rather than a misleading value-name collision. Tests exercise the admitted/rejected lexical depth and expired local names in reusable C API requests.
