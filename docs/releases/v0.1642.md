# v0.1642 — captured compound updates and mapped/channel preflight

## English

Compiler **0.25.0** accepts ten compound statement operators in the Coco/R Limbo
big/table profile: +=, -=, *=, /=, %=, &=, |=, ^=, <<=, >>=. Destinations are
initialized big locals or captured numeric/text/snapshot table entries. Arithmetic
requires RHS big; shifts require explicit RHS int and a checked 0..63 count.
Existing signed/modular arithmetic and error rules are reused, without binary64.

The owner/key and old value are captured once before the RHS. The final store
occurs only after successful computation. Plain = remains insertion-capable.
A missing old entry fails before RHS errors. Deleting/reinserting the same key
inside RHS does not make the frontend reevaluate the location or old value.
This is ordinary read/compute/write, not a mutex, remote atomic update or rollback
transaction. Separate int/AS profiles retain their previous operator coverage.

No new FIR IDs/types, Dis opcodes, Bigtable imports or container tags are added.
CLI/C99 APIs share the authoritative Coco/R grammar and typed lowering. Operator
origins retain exact compound bytes after UTF-8 prefixes. Static/type failures
preserve earlier FIR and debug destinations.

[Detailed contract](../../fir/v1/doc/COMPOUND_UPDATES.md) ·
[Commented source](../../fir/v1/examples/tables/compound.b) ·
[Tutorial README](../../fir/v1/examples/tables/README.md).
The tutorial demonstrates all ten operators through aliases/snapshot keys and
returns 42. SDK acceptance relinks a fresh source+FIR C99 host and runs all branching
tutorial sources through its in-process API, then checks original/optimized FIR
with fresh backend/reference clients on both actual VM modes.

Inferno experiment **dd0f5d6** adds complete mapped VM/channel copy preflight:
operand slots, descriptor/map geometry, payload/heap spans and failure publication
order. Zero-size nonaccess and pointer-free native 0..256/C fallback remain.
The exact pin contains **545 core/reference + 174 bootstrap** files. Two new
native/emulation drivers are registered. Previous reverse fixes are in experiment;
no further common native defect requiring an outgoing patch was confirmed.
Hybrid-table language extensions remain FlashVM-only.

Initial evidence: FIR **29/29**, no-table-core **27/27**, focused UBSan **4/4**.
Runtime **133/133**, 332.98 seconds. Incoming preflight checks passed **12,208**
C/RX cases and **120,816** cases each on emulated AMD64/ARM64. Native availability
remains 164/173 with partial operand coverage; no hardware/full OS boot claim.
Complete IDE Build/Run/Debug panels, debugger attachment and self-hosted full
controller compilation remain separate work.

## Русский

Компилятор **0.25.0** принимает десять составных операторов в Coco/R Limbo
big/table-профиле: +=, -=, *=, /=, %=, &=, |=, ^=, <<=, >>=. Назначение —
инициализированное локальное big или элемент таблицы по числу/строке/ключу снимка.
Арифметика требует RHS big, сдвиги — явный RHS int в диапазоне 0..63.
Сохранены точная модульная арифметика, знаковые правила и ошибки без binary64.

Место и старое значение захватываются один раз до RHS; финальная запись следует
только за успешным вычислением. Обычное = по-прежнему вставляет новый ключ.
Отсутствие старого значения проверяется до ошибок RHS. Удаление/повторная вставка
ключа внутри RHS не заставляют вычислять назначение заново. Это обычный
read/compute/write, а не мьютекс, удалённая атомарность или транзакционный откат.
Отдельные int/AS-профили сохраняют прежнее покрытие операторов.

Новых FIR ID/типов, Dis opcode, импортов Bigtable и тегов нет. CLI/C99 API используют
одну Coco/R-грамматику. Сохраняются точные позиции операторов и старые FIR/sidecar
при ошибках. [Подробный контракт](../../fir/v1/doc/COMPOUND_UPDATES.ru.md),
[комментированный пример](../../fir/v1/examples/tables/compound.b),
[README](../../fir/v1/examples/tables/README.ru.md).
SDK заново собирает C99 source+FIR-клиент для in-process компиляции всех ветвящихся
учебных исходников, затем проверяет исходный/оптимизированный FIR и оба режима VM.

Из Inferno **dd0f5d6** забраны проверки mapped-копирований VM/каналов: полные слоты,
метаданные/карты, payload/Heap-границы и порядок публикации при ошибках. Пустые
записи, native-диапазон 0..256 и C fallback сохранены. Снимки **545/174** точны;
два новых native/emulation-драйвера зарегистрированы. Прежние обратные исправления
присутствуют; нового общего дефекта для исходящего патча не подтверждено.
Расширения гибридного языка остаются во FlashVM.

FIR **29/29**, без table core **27/27**, UBSan **4/4**, runtime **133/133**.
Входящие проверки: **12 208** C/RX и по **120 816** случаев AMD64/ARM64 в эмуляции.
Доступность native 164/173 сохранена; аппаратное исполнение и загрузка ОС
не заявляются. Полные панели Build/Run/Debug IDE, подключение отладчика и
self-hosted компиляция всего контроллера остаются отдельной работой.
