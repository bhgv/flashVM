# v0.1561: runnable numeric tutorial and acceptance of the resize/Inferno series

The new [commented Limbo tutorial](../../disVM/examples/decimal-append/README.md)
and [Russian guide](../../disVM/examples/decimal-append/README.ru.md) ship together
with `decimal-append.dis`. It executes runtime real conversions, distinguishes
negative zero by IEEE bits, and retains `AB` while appending to `ABC€😀` with five
Unicode scalars. Both native JIT and interpreter modes check independent answers
before PASS. The installer includes source and matching .m/compiler inputs;
recompilation needs no source checkout or deployed Python.

Series v0.1559–v0.1561 combines:

- Public Inferno experiment `ddbc9f5d6412fe1d4630d7cba00f13502c9b041d`: exact short
  real-decimal leaves, append within unique existing capacity and comparison
  capacity guards. Imported sources remain byte-for-byte and preserve the
  preceding native-dispatch fixture correction.
- Dis-admitted editor resize, bounded pixel storage and actual TextField/texture
  resizing. Canvas, Style, Panel, Viewport and content revisions are checked
  together. Caret/ink/hits, page rows, footer and zoom stay consistent; source,
  history, saved state and modal input remain in their existing Dis owners.
- Fully commented executable numeric/Unicode examples, bilingual guides and
  installed documentation links that continue working after relocation.

Acceptance at this source snapshot:

- All 69 preexisting selected core checks pass after import; all three new
  native/AMD64/ARM64 comparison checks pass. All 72 registered core entries have
  therefore passed, including actual native and instruction-emulation fixtures.
- All 68 runtime/editor/port checks pass in a complete run; all 64 entries in the
  separately compiled UBSan runtime/editor build pass in a complete run.
- Resize boundaries are also rerun after expanding the matrix: minimum canvas,
  maximum font and full 256-scalar field budget pass in both modes, including
  SDL dummy texture upload and the separate UBSan build.
- Own Coco/R frontend: 16 tests pass; 22 current bridge/controller/decimal
  sources and interfaces parse. Build menu 21, package selection five and
  preflight five tests pass.
- The installed package is moved into a path with spaces. Its graphical
  controller and numeric tutorial recompile using only shipped compiler/headers.
  Both numeric dispatch modes and both actual resized-editor modes then pass
  with bundled Noto and no font override. All 38 checked installed Markdown
  guides have valid local links.
- Both vendor manifests verify: 268 Dis files and 174 bootstrap files at the
  public pin. No new shared defect requiring another Inferno production patch
  was identified; local changes remain outside the immutable snapshot.

Global native counters do not establish that every demonstrated opcode is
native; guarded leaves may decline to the real C interpreter. Physical ARM64,
RISC-V, touch devices, high-DPI/window-manager behavior and complete native
64-bit ABI/GC ports are separate from these host/instruction checks. Full
bidi/grapheme navigation, caret blink, syntax/completion and compiler/debugger
UI integration remain open. Resize itself is now implemented in the matched
experimental component 0.5.0 host/controller pair.
