FIR 0.61 compiles signed int32 division and remainder to ordinary AVM1 after
proving a live nonzero literal divisor. The numerator may remain dynamic.
Unknown/zero divisors reject before writing. Quotients truncate toward zero,
MIN/-1 wraps, and remainders retain the dividend sign. SWL 0.3.15 admits standard
Modulo 0x3f while preserving object/archive bytes, branch and record validation.
SWO1/SWF8 containers and extension flags are unchanged.

The optimizer also removes unused i32/big div/mod and shifts when literal
operands prove the operation cannot throw. Operand producers retain their own
effects; inner divide/conversion/key errors remain observable. Unknown/invalid
checks remain. Public fir_effects and conservative memory/CSE rules are unchanged.
The previous integer-identities example now admits raw SWO as well as optimized
SWO because its literal operands satisfy the backend proofs.

CLI, C99 APIs and the Dis-owned IDE compiler worker share these implementations.
The worker fixture now compiles a dynamic signed div/mod loop and still checks
24 exact CLI/native artifacts, debug origins and execution. The new fully
commented source reconstructs -7…7 through `(i/3)*3+i%3` and returns 42. Guides
explain the binary64 intermediate proof, target limits and reproduction commands.
The SDK ships sources, documentation and matching libraries; its relocated
acceptance relinks C99 clients, compares CLI/API Dis/SWO, links SWF8 and executes
both Dis modes.
