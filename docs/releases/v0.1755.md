# v0.1755 — deferred RC admission for every heap executor

Runtime0.59.0 removes the original-controller-only restriction on the deferred
last-reference queue. Every ACTIVE executor of the same NativeWorld can transfer
an eligible last reference and request Fast work. It retains the existing queue
ownership plus external mark protocol. Helper/native waits no longer imply an
unnecessary inline cascade merely because a different OS context runs the Prog.

Admission checks precede payload/queue access. IDLE/NATIVE, unacknowledged native
reentry, detached/collector and another world refuse. Recursive collector-side
destruction still runs retained inline RC and cannot requeue itself. Controller
shutdown closes producers and drains/joins Fast before clearing world identity.
Existing512-owner/4MiB direct-byte bounds still fall back inline. Budgets count
top-level owners; a nested graph destructor remains unbounded by that count.
NATIVERC adds helper_enqueued/helper_saturated/helper_byte_limited counters.

The real managed test runs32 producers replacing arrays of node references,
checks checksum122880, and withholds parent-process stdin until aggregation.
Audited native sleeps distribute continuations across OS executors; the logical
parent can migrate and must not be confused with the original OS controller.
C/JIT and4/8/auto require positive actual helper queue admission, exact final
queued/released balance, zero pending bytes/owners and worker joins.

A separate role-only fixture uses real TLS/NativeWorld lifecycle and a genuine
stopped-world collector context. It performs no managed allocation: forbidden
payload operations are semantic sentinels. Three isolated source controls remove
phase/progress/world guards; each MUST reach status10, never a compiler failure,
signal or sanitizer failure. Whole-program tests separately exercise actual
allocation, references, roots and GC.

This does not enable simultaneous managed heap writers. Fast/Cycles still use
stopped-world access. [The proposed next model](../../disVM/runtime/SHARED-HEAP-CONCURRENCY.ru.md)
uses synchronized allocation, object-level locks, atomic RC and initially STW
cycle collection. No Heap native layout, file IDs, ordinary Dis semantics or
production Dis64 CALL/LEA admission changes in this series.

Validation:32/32 selected runtime tests passed, including new helper programs,
real-role controls and prior native/fixed/elastic/close tests. The installed
editor passes helper C/JIT4/8/auto. Role tests pass normal, nonrecovering UBSan
and focused TSan. The actual instrumented Debug INTERPRETER passes helper RC
programs with4/8/auto under TSan (explicit no-JIT override). That is focused
ownership evidence, not whole-VM/JIT/UI race freedom. C++98 private-header syntax,
Python/shell/whitespace checks and both unchanged vendor manifests pass. New
hosted runs are native Linux x64; no new ARM/RV hosted mutator claim.
