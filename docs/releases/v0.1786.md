# v0.1786 — guarded MOVP source retain and pointer publication

Runtime0.88 applies native range guards to the actual hosted C MOVP and existing
x64 MOVP tails. Source capture/retain/mark and destination publication happen under
ordered guards; displaced-owner destruction and VM errors occur after release.
Unaligned and partially overlapping pointer slots share complete boundary-cell
coverage. One fixed stripe domain avoids per-opcode allocation; collisions only
serialize independent cells. Inline mode preserves its existing serial model.
