# v0.1715 — Independent geometry ports and first fixed Math C-call review

IDE 0.7.4 now gives each vector pane its own Limbo sender and native broker.
Notified pane replies share immutable wire segments instead of concatenating the
large drawing on the document/UI owner. The sender performs fragment encoding,
channel sends and native preview-fence assembly. One bounded mailbox and distinct
queue pair per pane isolate backpressure from sibling ports and ordinary traffic.
No raw managed pointer is handed to a native raster thread.

The ordinary stream declares the snapshot before private fragments arrive.
An explicit counted End opts into a deferred atomic join; the last checked stream
commits it once. Legacy End still refuses missing data. The coordinator retains
the whole-scene completion/hit-test barrier. This series provides independently
scheduled Dis processes and broker state, not per-window partial publication or
an OS thread for each Limbo process. Initial SVG parsing/body preparation can
still run on the file/document owner. [Full contract](../../ide/BULK-GEOMETRY.md),
[Russian](../../ide/BULK-GEOMETRY.ru.md).

Implemented in separate `idebulk.m/.b`, `editor_bulk.c/.h` and the existing typed
host/scene adapters. Registration checks slot bounds, duplicate channels and
cross-use of ordinary ports. Sender stacks root their channels through explicit
retirement. Internal pane/host/vector module signatures changed: rebuild and
install the complete editor runtime and Dis modules together.
