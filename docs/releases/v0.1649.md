Negative indexes address from the end, -1 being last. Tables use only the dense
numeric prefix, ignoring dictionary and sparse keys. Strings count Unicode
scalars. Positive slice ends stay exclusive; negative ends include the indicated
element, so **[0:-1] is a full copy**. Empty full copies work; invalid/reversed
normalized bounds raise without signed-minimum negation overflow.

Отрицательные позиции таблиц поддерживают чтение, запись, membership и delete.
FIR table.index фиксирует канонический ключ до RHS, поэтому изменение len внутри
RHS не меняет цель составной записи. В Bigtable дописан resolveindex; старые
экспорты сохранены. C99 get/set/delete принимают относительные ключи; отдельный
fht_slice_relative сохраняет совместимость старого unsigned fht_slice.

Host-prepared handlers add native array and string relative indexing, character
writes, slicing and slice-store offsets. Relative-bound array slices use the
existing GC-aware arraycpy and then narrow independent storage. Partial copies
currently clone the full source. Positive-only native slices retain shared views;
reference ADT objects retain identity. Native negatives decline from guarded JIT
paths into the adapted C handlers. No upstream snapshot or Dis opcode is changed.

The reference string/table runner uses the same value-only normalization and
independent byte-counted Unicode lookup. The Coco/R frontend remains bounded:
table/string source works there; native-array fixtures use the reference compiler.
AS Array.slice/property semantics are unchanged.

## Concurrency / Многопоточность

[Owner-token contract EN](../../disVM/OWNED_OPERATIONS.md) /
[RU](../../disVM/OWNED_OPERATIONS.ru.md) records the requested reentrant write
ownership: the operation itself may write while competitors wait, with recursive
same-token entry, ordered multi-owner acquisition and exception-safe retirement.
**This is a design contract, not an implemented per-object mutex.** Current C
operations are serialized by the VM owner. Broker metadata locks do not protect
array/table payloads; they remain independent for diagnostics/debug pauses.
