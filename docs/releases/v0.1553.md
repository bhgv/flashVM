# v0.1553: reusable Dis actions and graphical search/file fields

The Limbo controller now owns Find/F3 wrap, two-field ReplaceAll, Open and Save As
panels. Prompt input is bounded Unicode, not source text; Ctrl+A, Backspace,
Enter and Escape stay in Dis. The renderer displays only channel-published panel
values committed with the document view. Native Enter transitions also reach the
ordinary document Replace path when no field is active.

New callable Idefileops and Idesearch libraries isolate strict source-file I/O
and literal document operations from the renderer. Find/SaveAs/Open also accept
revision-bound embedding requests. A failed read does not retire the document;
failed Save As does not change its destination or saved revision. Counted NUL
paths are rejected before native truncation. Open respects dirty guards, and
ReplaceAll remains one existing history operation.

Real graphical interpreter/JIT checks cover Unicode matching/wrap, replacement
and one Undo, empty replacement, successful and failed destination adoption,
Open dirty protection, NUL rejection and prompt budgets/cancellation. The UI
continues to execute actual Dis modules and FlashVM TextFields. Writes remain
checked overwrite, not atomic replace; regex/backward search and physical-device
acceptance are not claimed.
