# v0.1792 — rooted guarded scalar/raw list heads

Runtime0.94 extends explicit `--gc-worker --guarded-copies` to HEADB/W/L/F/M.
The separate shared_list_bytes module roots/retains the real source List before
interior addressing, validates actual pool extent, then uses ordered guarded
bit-preserving memmove. HEADM validates its length after source capture; zero
length avoids payload/destination access. Scalar operations preserve prior refusal
ordering. Cleanup runs on normal and protected error exits, retaining the first
error even when consuming owner release also fails. Default bodies remain intact.

[Contract](../../disVM/runtime/SHARED-LIST-BYTES.md).
[Commented Limbo example](../../disVM/examples/guarded-list-bytes/README.md).

27 affected CTests pass (172.12 seconds). Actual C/JIT/both-poll diagnostics cover
all widths through 6000 bytes, unaligned and overlapping copies, signaling NaN
bits/FP flags, allocation/mark refusal, exact pool bounds, owner/root removal,
32 real Cycles, REG changes and combined errors. Seven omission controls fail at
semantic boundaries. Five actual x64 head tails pass ABI/cache/unmap/error tests;
existing five MOV tails remain independently covered. Both new suites also pass
TSan positives. Generated machine code is not instrumented; no new hosted UBSan,
physical ARM64/RV64 or general parallel-managed acceptance is inferred.

Measured whole-profile cost, median of three local startup-inclusive runs after
warmup, 20000 iterations of five head projections: C 0.130036 → 0.241494 seconds
(+85.71%); JIT 0.091800 → 0.224481 (+144.53%). This includes other guarded copies,
not isolated instruction cost. [Persistent ledger and JSON](../../disVM/runtime/PERFORMANCE-COSTS.md)
record LISTB-094 for later optimization; do not add percentages across workloads.

NativeWorld still serializes general managed code. Remaining gates include list
construction, other writers, channel/scheduler ownership, root/GC epochs and
frame/module/code lifetimes, then compiler-proven local/shared selection. Real OS
executors and GC workers already exist; this series does not claim their general
managed computation now runs concurrently. No Dis64 wire/IDs/layout/default
admission changes and no retained upstream implementation import.
