# v0.1807 — guarded REAL arithmetic / runtime0.108

ADDF/SUBF/MULF/DIVF now use coherent guarded input snapshots, unlocked native FP
evaluation and separately guarded output publication in the explicit startup
profile. All complete geometries preflight before input reads/FP effects. Default
paths and opcode IDs stay unchanged. Native FP divide-by-zero/rounding/trap policy
is retained; integer exZdiv is not substituted. No allocation, reference/root
transfer, callback or destructor is introduced under guards.

[Contract](../../disVM/runtime/REAL-ARITHMETIC.md).
[Commented Limbo example and SDK commands](../../disVM/examples/real-arithmetic/README.md).

Two intervals are explicitly NOT atomic shared RMW. Output admission may fail
after FP effects; mapped cell/frame/GC/code lifetime and NativeWorld are still
required. FP conversion, constructors, graph epochs and simultaneous managed
mutators remain outside scope. RC1 never establishes locality.

Actual C runtime tests cover6912 arbitrary-byte overlapping/unaligned cases and
144 masked native FP boundary cases,7056 total. Independent whole-buffer/result/
flag oracles, phase geometry/cardinality, source update after capture, source/
output BUSY, invalid operation/output, allocator prohibitions and actual unlocked
kprotect/error unwind pass. Four exact-stage actual-source omissions fail as
required; crashes/compiler/resource/sanitizer failures do not count.

Real Limbo C/JIT guests reach all four helpers with both collector polls. Four
actual x64 tails cover individual code-cache unmap, error with retired code,
return-PC and bad-CALL/old-emitter controls. TSan C positives pass; generated
guest machine code is not instrumented. IEEE payload/rounding exhaustive checks,
unmasked signal traps, physical ARM64/RV64 and full GUI are not claimed.

The release adds complete drift-checked adapters, CMake tests, runtime/editor
SDK source/tests/docs and a commented example. Upstream pins remain byte-equal.
Existing root replacement tests and135600 REAL-branch regression cases pass.
