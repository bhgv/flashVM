# v0.1691 — исправление nil-owner при работе с окнами IDE

После закрытия первого редактора кнопка скрытия Help выбирала focus=1,
хотя канала владельца этого окна уже не было. Следующее действие отправляло
запрос в nil: `desktop-ide.dis pc6: dereference of nil`.

Layout теперь перед каждым ответом выбирает существующий дескриптор владельца:
текущий видимый, другой видимый, затем существующий скрытый. Только пустой
реестр имеет focus0. Скрытие не закрывает документ и не меняет его текст;
удалённое окно не восстанавливается самопроизвольно.

Регрессия проходит настоящие UI/channel операции: закрыть Editor1, скрыть Help,
ввести текст, показать Help, создать редактор в освободившемся слоте и изменить
его текст. На v0.1690 отдельная Release-сборка воспроизвела точный pc6/nil error;
с исправлением оба режима DisVM — interpreter/JIT — проходят тот же сценарий.
Новая проверка включена в runtime CTest. Подсветка текста в эту срочную
поправку не входит и продолжается отдельной серией.
