# v0.1545: Dis/JIT and Sys refresh from experiment

Selected upstream sources now pin bhgv/Inferno-OS-bhgv experiment commit
`96935b070dfb28c18ce9ce35c0bcf7b2b96a63bc`, incorporating the four commits since
`f948343b711c8300dbf76417254c18a7a8d2f5ff`. Only the manifest-selected Dis/JIT,
Sys sources and regression fixtures are imported; no full Inferno OS is added.
Original imported files retain their exact upstream bytes and licenses.

AMD64 and ARM64 native leaves now handle more fixed-point VN/WN rounding cases,
subnormal real branches and wider safe real-to-integer conversion ranges. Guarded
unsupported inputs retain the C fallback. These extend existing opcode paths;
they do not add opcode IDs or establish a full block JIT. RISC-V emitter checks
remain part of the suite; no new RISC-V execution support is claimed here.

The emu/os Sys implementations now publish further scalar/tuple results through
byte-addressed slots, validate values before narrowing to native int parameters,
and preserve string/FD ownership across allocation or failure. Stat/fstat/fd2path
and directory helpers use the generated tuple layout, including WORD64 padding.
Shared retstr/retnstr result addresses now use void pointers consistently with
unaligned VM slots. The core and parser adapters compile against this interface.

The snapshot retains 204 selected files with SHA-256 hashes. The native Limbo
bootstrap's 174 selected source files have no content changes in these commits;
its manifest advances to the same audited revision. New status, stat/path and
native real-branch regressions are registered in CTest. The two new Sys suites
run under UBSan automatically.

Validation with CMake 3.10.2: core plus installed native diagnostic programs build;
55 standalone Dis checks pass, including WORD32/WORD64 native AMD64 JIT and eight
foreign-emitter compile/model checks. Separate TLS-context/shared FlashVM host
builds pass 13 integration tests covering channels, sockets, thread registers,
world stop, GC workers and module store. New Sys tests also pass UBSan for both
emu/os and WORD32/WORD64. Snapshot verification and three vendor-sync tests pass.
ARM64/RISC-V machine code was not executed on this AMD64 host. Full native Dis
application/IDE host startup remains unfinished.
