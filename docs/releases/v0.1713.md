# v0.1713 — Repeated vector controls and pointer-owned native ink

Fixed two independently reproduced input failures after live drawing. SDL's
second click was promoted to maximize code10 anywhere in the desktop, including
colors/Fill/Pen. That promotion now requires the actual window header. Native
ink previously accepted motion/release solely by event kind; its capture now
checks the original copied device/contact/window. Foreign coordinates cannot
produce a connecting line or terminate the owning pointer's trajectory.

SDL touch-generated mouse copies are ignored before lifecycle barriers. A missing
mouse release is repaired when the owning mouse next reports no left button:
freeze at the last admitted point and deliver one ordinary frozen-token End,
then consume the hover without drawing. No point arrays move to Limbo while live.
No document/UI policy or appearance is moved from Limbo/AS into C.

The new private pointer classifier is its own commented header and is shipped
with native ink source examples. Bilingual lifecycle documentation describes the
ordering and limits. The actual worker/SVG/history regression alternates blue
and black strokes while earlier native geometry is queued.

Validation includes actual SDL FIFO controls/raster and actual interpreter/JIT
worker tests. Compiling the old editor_view with the new regression fails the
repeated-toolbar predicate; applying only the header fix still fails the
foreign/hover-ink predicate. Thus both corrections have active negative evidence.
Geometry/refinement algorithms, Dis64 agreement and SWF/Dis formats are unchanged.
Headless SDL injection is not physical-device or measured-FPS acceptance.

Final acceptance:363/363 runtime/IDE tests,25/25 focused pointer/vector/MDI tests,
4/4 expanded native ink gates after the final rebuild, and37/37 build-menu tests.
The installed player and new pointer source are byte-compared with tested build
products. editor_view also compiles with the SDL feature macro absent; this is
compile coverage, not headless interaction or a new architecture acceptance claim.
