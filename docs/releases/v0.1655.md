# v0.1655 — Background editor rasterization

[English contract](../../flashVM/doc/RENDER_ASYNC.md) ·
[Русский контракт](../../flashVM/doc/RENDER_ASYNC.ru.md) ·
[Runnable tutorial](../../flashVM/examples/embedding/parallel_render/README.md)

The graphical editor extracts independent native contours on its VM owner and
rasterizes them into a private buffer on one persistent background worker.
An interactive submit/poll does not join the raster worker. Bounded latest-frame
admission replaces pending/ready work and discards stale executing results.
SDL presentation remains owner-only; input waits in the OS queue until displayed
pixels match hit geometry. Dis scheduling/channel polling continue. Replay input advances after owner presentation through nonblocking polling;
capture deliberately waits for completed pixels.

Public queue API permits 1–8 workers, with at most workers+2 owned jobs. Completion
uses existing OS port mutex/conditions. Shutdown joins callbacks before their
dependencies are freed. The queue accepts native snapshots, never live VM objects.
This is the editor raster path, not full SWF asynchronous scene extraction or
parallel tiles within one frame. Layout, outlines, AS and GC still consume owner
time. Physical Android/macOS/Windows and interactive performance acceptance remain open.

Also fixed synchronous render-job fallback after partial thread launch: every
partition is initialized before launch and completes once. The Limbo native C
backend now rejects collisions among emitted callback/typedef/check/global names
before opening output, while permitting noncolliding suffix names.

## Проверки / Validation

- 37 graphical/AS-view/native-module runtime checks passed in interpreter/JIT modes.
- Uncaptured background editor edit/save/close tests pass in both dispatch modes.
- Queue and launch-failure harnesses pass ASan/UBSan (LeakSanitizer disabled because sandbox /proc discovery is unavailable); 100 repeated parked-worker executions pass.
- Detached real AGG pixel parity and independently checked alpha/painter ordering.
- Two deliberately parked native workers: owner admission and nonblocking take
  proceed; replaced/stale jobs are released exactly once, newest status is returned.
- Five injected joined-runner launch failures complete all partitions once.
- Limbo native header checks cover reserved/generated symbol collisions and retain
  old output files on rejection.

Examples are formatted for reading, with comments on every nonblank C line and
RU/EN ownership/build/run guides. Runtime packages ship the async contract pair.
No upstream Inferno snapshot change or graphics-fork publication is included.
