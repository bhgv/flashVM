## One desktop, real source/graphics containers

**MDI / Ctrl+G** groups the selected document with the first compatible container;
**Shift+MDI / Ctrl+Shift+G** creates another. **SDI / Ctrl+D** detaches just that
document, restoring saved ordinary geometry without reopening/discarding it.
Source and graphics tool families cannot mix. Source text/compiler input and
actual vector brush controls stay with their original owners.

Container roots and documents are actual MovieClips. Dragging the exposed root
header composes into both children's native world matrices. A covering SDI
window owns its click; no click-through workaround is used. Thumbnails reveal
whole containers; All and scroll bounds include the outer frames. The last
container identity and tall root bounds have independent owner regression tests.
Empty roots/registry entries retire when the last child detaches/closes.

Native presentation may recreate a subtree when its parent changes. Only that
view moves: Dis source, dirty state, Undo and lazy colour jobs remain at the
same document identity/revision. The copied protocol validates the bounded
root-before-child forest; cycles/arbitrary native parents cannot be proposed.
The native adapter composes document/container/table matrices for paint and hits.
A reproduced capture defect was fixed: roots must not capture their old children
again before per-document capture. Reflow now matches a fresh scene byte-for-byte;
primitive presentation masks are restored on all capture exit paths.

First version: tiled children in one/two columns. Free child movement, individual
MDI child zoom/max/resize, tabs/cascade, container resize/docking and shared group
toolbars are pending. Unsupported child zoom does not modify saved SDI geometry.
There are8 total desktop pane slots shared with system/debug panels. One desktop
is retained; no Source/Graphics/Debug workspace switcher exists.

## `asinc` and frame-free drawing

Coco/R AS1/AS2/AS3 recognize contextual `asinc function`, `asinc { ... }` and
function/block expressions, with AS2/AS3 methods. Ordinary identifiers/calls named
asinc remain valid. **Executable closure/task lowering is not implemented.**
The numeric FIR source profile explicitly refuses the prefix with an exact
five-byte semantic diagnostic and preserves an existing artifact. It emits no
synchronous fallback. Lambda captures, environment cells, task results/errors,
safe points and invocation semantics remain dedicated compiler/runtime work.

Existing Async.post already executes owner callbacks independently of SWF frames.
The new actual runtime test freezes the clock, posts a drawing callback, collects
its pending roots and observes real contours after polling, without advancing a
frame. Captured independent paths survive VM destruction and rasterize to exactly
the same RGBA bytes as ordinary MovieClip rendering. This proves existing public
API drawing behavior, not execution of the new syntax or physical parallel AS.
Managed scene mutation stays on its owner; detached raster workers see no VM
objects. Shared mutable lexical environments are not handed to physical workers.
