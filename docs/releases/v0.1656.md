Imported six experiment commits since 9a87d74: Sys output, byte I/O, fixed status,
file/query creation, stream/directory and aggregate-owner capture. No new JIT
backend paths occur in that incoming range. Existing AMD64/ARM64 coverage and
native diagnostic checks remain separate from the application runtime.

Published a confirmed additional correction back to Inferno:
[9ee638bb](https://github.com/bhgv/Inferno-OS-bhgv/commit/9ee638bbfaff421164e2e7fb1d68e01089720c39).
Sys.pipe validates pointer-element size/map before reading or replacing old owner
slots in emu and os. The regression fails on the parent source and passes across
both ports and WORD models; equivalent independent pointer descriptors are valid.
The selected snapshot is then refreshed byte for byte to this public commit,
including new tests and their provenance. No any/table/projection extensions were
exported to Inferno.

Our independent NC64 host does not compile the complete Inferno Sys OS adapter.
It now separately captures aligned local frames and original complete results for
open/create/fildes/read/readn/write/seek/print/fprint/stat/fstat/dirread. Descriptor
result owners and mapped Dir string aliases are checked before callbacks destroy
anything. Readn uses captured FD/data/count across fragments. Variadic output
retains the original argument area while preserving the fixed prefix/result.
Native I/O remains in OS-selected ports. Original VM roots must outlive the call;
these guards are not a heap registry, new GC roots or shared-heap thread safety.

## Проверки / Validation

- Full runtime: 216 checks passed, interpreter/native-JIT, files/libraries/IDE/GC.
- 19 real-header boundary cases (including all packed offset combinations in the
  first case), wrapped complete tuples and reference multiplicities.
- Ten selected upstream Sys CTest drivers pass with UBSan. FD-owner capture matrices bound
  frame/array shifts in CTest, not a claim of exhaustive upstream combinations.
- Five selected JIT/ARM64 compiler/dispatch coverage drivers pass. Native AMD64
  word32/word64 diagnostic build probes also pass; this is not ARM64 hardware proof.
- New pipe-type regression: ASan/UBSan, emu/os and WORD32/native, 28 cases.
  Existing FD owner matrices and bounded aggregate capture samples pass as well.

Native Sys.pipe/network in our NC64 host, full compiler coverage, tiled raster and
physical platform acceptance remain open. Background editor rasterization from
v0.1655 is retained. Runtime packages include the RU/EN Sys contracts.
