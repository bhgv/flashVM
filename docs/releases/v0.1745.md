# v0.1745 — preserve source/Unicode typing bursts

Runtime 0.49.2 removes unnecessary native typing batch boundaries. Previously
only Latin A-Z key transitions could be absorbed between committed SDL text
records. Digits, spaces, punctuation and layout-dependent Unicode keycodes
split queued source/Russian typing into repeated small owner round trips.

The FIFO batch now absorbs printable ASCII and valid printable-range Unicode
transitions with no Ctrl/Alt/GUI/IME mode modifier. Text still comes exclusively
from committed SDL_TEXTINPUT records; it is never generated from key symbols.
Existing Latin Flash keyboard state remains updated. Modifier transitions,
navigation, Delete/Backspace/Enter, shortcuts, focus, pointers, foreign windows
and capacity limits retain their order. The256-event work bound and whole UTF-8
record boundary remain. No timeline frame or sleep is introduced.

Standalone editor repaint now uses allocation-threshold GC stepping instead of
an unconditional full FlashVM collection on every captured text view. MDI already
uses this policy. Detached raster data and owner-thread root rules are unchanged.

Real SDL FIFO tests require complete mixed-source and Cyrillic/emoji bursts in
one message, preserve exact UTF-8 bytes, and check shortcut/navigation/pointer,
foreign-window and capacity barriers. Interpreter/JIT editor tests exercise
Unicode edit/save/close, asynchronous raster and desktop pointer/selection.
This fixes identified fragmentation/collection costs; no end-to-end latency
number or complete elimination of Dis document round trips is claimed.
