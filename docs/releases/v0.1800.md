same borrowed canonical domain and exact current access. It deduplicates keys,
tries new stripes in ascending order and appends them without releasing original
claims. New keys may precede old ones because acquisition never parks for an
object owner. Native metadata retains its existing mutex contract; this is not a
wall-clock bound. On BUSY/refusal, only additions roll back; original access stays
live and MUST be ended before retry, wait, world transition or error propagation.

semantics. Public headers compile as C89/C++98. No root/provenance grant follows.
