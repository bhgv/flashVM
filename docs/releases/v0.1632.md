# v0.1632 — exact big source decisions and x64/ARM64 CASEC midpoint paths

Our authoritative Coco/R Limbo big-result grammar now accepts fully terminating
nested if/else after its declaration/assignment prelude. All six relations use
strict signed big operands. New appended FIR operations big.lt.signed/big.eq
produce bool; other relations reverse operands/edges without repeated evaluation.
Source order and exact authored relation/if byte spans are preserved.

Direct scalar Dis uses existing BLTL/BEQL and PC fixups to materialize bool.
Same-type big casts now remain scalar copies instead of unnecessarily selecting
an imported backend. Peephole removes those identities, folds exact constant
comparisons and simplifies dead branches. Text/key conversions retain their
checked effects; division/remainder still throw on selected zero divisors.
The single-block table backend and independent C reference runner compare loaded
big values and handle bool constants/copies/traces without GC pointer roots.
