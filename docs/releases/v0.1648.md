# v0.1648 — hybrid table constructors and reusable C99 source services

## Русский

Компилятор **0.31.0** добавляет Coco/R big/table-профилю конструкторы
`table of big {40, 2, font_size = 11, ["ключ"] = 7}`. Позиционные поля идут с нуля;
именованные и явные ключи не двигают счётчик. Повторный ключ допускается —
побеждает последняя выполненная запись. После непустого списка разрешена одна
завершающая запятая. Прежнее `table of big` сохранено.

Поля вычисляются один раз слева направо. Ключ и позиция проверяются до RHS;
ошибка отрицательного ключа предшествует ошибке деления RHS. Новая привязка
объявления появляется после завершения инициализатора, поэтому при затенении
видна внешняя переменная. Алиасы разделяют владельца, числовые срезы копируются,
len/countof/keysof сохраняют прежние разные значения.

Грамматика src1.atg остаётся основной. Лексические предикаты разрешают конфликт
имени поля с обычным выражением, учитывая комментарии и различие =/==. Плоские
поля разбираются итеративно, вложенные выражения используют прежний лимит 64.
Понижение использует только прежние table.new/index/store и константы; новые
операции/типы FIR, opcode Dis и ABI не добавляются. Позиционные ключи создаются
без чтения устаревшего текста токена. Debug JSON сохраняет точные позиции полей.

[Руководство](../../fir/v1/doc/TABLE_LITERALS.ru.md),
[комментированный пример](../../fir/v1/examples/tables/constructors.b),
[README](../../fir/v1/examples/tables/README.ru.md).
Пример проверяет шесть ключей, числовой префикс из двух элементов и независимость
среза после изменения оригинала через алиас; результат 42.

## English

The compiler now accepts positional, named and explicit-key hybrid constructors
in its typed Limbo table profile. It preserves ordered owner/key/RHS effects,
last-store-wins collisions, exact big values and static key/value checks.
Constructor postfix indexing and nested constructors consumed by scalar expressions
use the existing expression grammar. [Contract](../../fir/v1/doc/TABLE_LITERALS.md).

The C99 service checkpoint performs repeated valid/syntax-error/SSA-limit calls
in one process, checking staged FIR/debug output and recovery through FIR parse,
verification and direct Dis emission. Python tests use an independent dictionary
model for mixed fields and collisions; actual interpreter/JIT runs use one-step
scheduler/GC quanta and verify that table/snapshot owners retire. Relocated SDK
checks relink fresh source/FIR C99 clients and run the annotated tutorial before
and after optimization in both VM modes.

Inferno experiment remains **637d618**: no new incoming commit, previous reverse
fixes retained. Exact snapshots remain 560 core/reference + 174 bootstrap files.
No further shared defect requiring a reverse patch was confirmed. Language
extensions remain FlashVM-only. Native availability remains 166/173 guarded
fast paths and 173/173 complete decoded entries, with partial operand domains.
