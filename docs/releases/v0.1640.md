# v0.1640 — comparison values and synchronized array/copy JIT

## English

Compiler **0.23.0** materializes all six Limbo big/int comparisons as normalized
bool values in the bounded big/table profile. Locals may store, copy, convert or
compare them. Bool equality/inequality and logical `!` work without implicit
numeric/string truthiness. Comparisons follow Inferno's ordering/equality levels
above bitwise AND, as checked against `limbo/limbo.y`. Every operand evaluates
once left-to-right; checked conversions and table mutations retain eager effects.
Sticky resource errors cannot become out-of-range SSA type-array accesses.

The implementation reuses existing FIR signed comparisons, scalar casts/constants
and Dis BLTL/BEQL. There are no new FIR operation IDs, native opcodes, Bigtable
imports or container tags. CLI and C99 library source entry points share the
Coco/R grammar and lowering. Short-circuit &&/|| and general mixed-kind comparison
remain future work. No full language, self-hosted controller compiler or complete
IDE Build/Run/Debug/debugger integration is claimed.

[Detailed guide](../../fir/v1/doc/COMPARISON_VALUES.md) ·
[Commented tutorial](../../fir/v1/examples/tables/comparisons.b) ·
[Tutorial README](../../fir/v1/examples/tables/README.md).
The tutorial uses table-loaded adjacent integers above 2^53, stored comparisons,
logical negation, bool equality and exact signed-int comparison to return 42.
It is shipped through the SDK and checked with freshly relinked C99 clients,
original/optimized FIR and both runtime dispatch modes.

Inferno experiment **b10f81f** supplies six array-command slot/header checks and
shared AMD64/ARM64 qword copy kernels for MOVM/HEADM/MOVMP/HEADMP. Native pointer-
free 0..256 limits, descriptor checks, overlap ordering, exact tails and C fallback
remain intact. The snapshot contains 541 exact core/reference and 174 bootstrap
files. Three new native/emulation drivers are registered. Existing reverse fixes
are already in experiment; no new confirmed common native defect requiring a
reverse patch was found. Compiler language extensions remain FlashVM-only.

Incoming focused checks: 1,094,912 C/RX array cases across WORD32/64, 21,906 array
cases per emulated AMD64/ARM64 architecture and 8,288 mapped page-edge copy cases
per architecture. Native availability remains 164/173 with partial operand
coverage. Emulation does not establish physical ARM64 or full OS boot.

## Русский

Компилятор **0.23.0** принимает шесть сравнений Limbo big/int как нормализованные
bool-значения внутри big/table-профиля. Их можно хранить, копировать, преобразовывать
и сравнивать. Поддержаны равенство/неравенство bool и логическое `!` без неявной
истинности чисел/строк. Приоритеты упорядочивания и равенства выше побитового AND
сверены с `limbo/limbo.y` Inferno. Операнды вычисляются один раз слева направо;
эффекты проверяемых преобразований и мутаций сохраняются. Ошибка SSA-лимита не
превращается в выход за границу массива типов.

Используются существующие FIR-сравнения, скалярные cast/константы и Dis BLTL/BEQL.
Новых ID FIR, opcode, импортов Bigtable и тегов нет. CLI и C99 API используют
одну Coco/R-грамматику. &&/|| и общие смешанные сравнения ещё не реализованы.
Полная поддержка языков, self-hosted компиляция контроллера и полная интеграция
панелей Build/Run/Debug/отладчика IDE не заявляются.

Пример возвращает 42, используя точные соседние числа выше 2^53, сохранённые
сравнения, отрицание, равенство bool и знаковое сравнение int. SDK проверяет его
свежими C99-клиентами, до/после opt и в обоих режимах VM.

Из Inferno **b10f81f** забраны проверки шести команд массивов и общие qword-ядра
AMD64/ARM64 для MOVM/HEADM/MOVMP/HEADMP с сохранением диапазонов, проверок descriptor,
перекрытий, хвостов и C fallback. Снимки: 541 core/reference-файл и 174 bootstrap.
Три новых native/emulation-драйвера зарегистрированы. Прежние обратные исправления
уже в experiment; нового подтверждённого общего дефекта для обратного патча
не найдено. Расширения языка остаются во FlashVM.

Входящие проверки: 1 094 912 случаев C/RX, по 21 906 случаев массивов и по 8 288
проверок mapped-copy у границ страниц на эмулируемую архитектуру. Доступность
native остаётся 164/173; эмуляция не заменяет аппаратные испытания/загрузку ОС.
