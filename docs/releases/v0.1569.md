# v0.1566–v0.1569: Inferno slices and Dis-owned IDE fields

The selected Dis core and temporary source-built Limbo bootstrap both pin
Inferno experiment `bf8d88283896abf8509fedc68197795292734e6b`. This imports
`bee814b` and `bf8d882`: guarded AMD64/ARM64 unique nonempty ASCII/Rune SLICEC,
prefix slices without redundant movement, string descriptor checks and direct
byte-array/list/module-link descriptor preflight before allocation. Shared and
empty slice fallbacks remain; public slicer allocation semantics are preserved.
Selected upstream blobs are unchanged and checked by both SHA-256 manifests.
No confirmed upstream defect was found in this review, so no unrelated IDE
policy was submitted to Inferno.

The new [Idefield library](../../ide/dis/FIELDS.md) replaces append-only prompt
editing with scalar caret/anchor state, reverse selections, middle insertion,
word navigation/deletion and atomic admission. Its complete 256-scalar value
must remain single-line. All text and selection policy executes on Dis; native
FlashVM renders copied values and returns glyph-derived hit proposals. Fields
now have a visible independent caret, selected glyph spans and horizontal scroll
that follows the caret. Window close protects dirty source even inside a field.

Ctrl+C/X/V target the active field or source. Field Copy excludes its label;
Cut waits for the native clipboard acknowledgement; Paste validates the complete
staged value before mutation. Mode and field generation prevent a late transfer
from addressing a different field state. Invalid multiline/oversize paste keeps
text, selection, generation and source history intact. Source paste still creates
one document Undo entry. Shift+click, reversed mouse drags, cancellation on focus
loss and release outside the footer are covered by real channel/raster tests.

Runtime component **0.7.0** adds PanelSelection/65560,
ClipboardFieldWrite/65561 and FieldPlace/65562 to the existing typed envelope.
Ship host, controller, Idefield, Ideinput and interfaces together. SWF/Dis file
formats are unchanged. Unicode scalar editing does not claim grapheme/Bidi/IME
preedit support. Physical desktop/touch acceptance remains separate from SDL
dummy/replay checks; the actual executable tested here is Linux AMD64 NC64.

## Acceptance

- Selected core: **80/80** checks, including new byte-array/list-retain UBSan
  drivers, native slices and ARM64 instruction-emulation fixtures. Instruction
  emulation is not an ARM64 hardware/runtime acceptance claim.
- Normal runtime: all **85** registered checks have passed, including the two
  new actual Dis string-slice tests. Full 83-check run passed 82; concurrent
  core/runtime/UBSan load timed out the old interpreter ReplaceAll at 50 seconds.
  Its isolated rerun passed in 36.48 seconds. The other six updated field checks
  also passed together after extending cancellation/Shift/label-hit scenarios.
- UBSan runtime: all **77** registered checks have passed. Full 75-check run
  had the same isolated timeout; its rerun passed in 34.49 seconds. All four
  updated field checks and two added slice tests pass with no UBSan diagnostic.
- Coco/R Limbo frontend: **16/16** checks; new field/module/example/controller
  and string-slice sources also pass the syntax frontend. The temporary legacy
  source-built compiler still emits the tested runtime bytecode.
- Relocated installation in a path containing spaces compiles the controller
  and [commented field tutorial](../../ide/dis/examples/graphical-editor/field-demo.b)
  using shipped interfaces and compiler. The tutorial runs with actual JIT
  counters and with interpreter native count zero. Installed graphics checks use
  bundled Noto. All 49 installed Markdown guides have resolved relative links.
- Documentation source-link index: zero stale files; upstream manifest checks
  and Git whitespace checks pass.

The installation guide linker now covers FILE-WINDOWS, workspace/editor-console
guides and the new tutorial, after their files have been copied. Seven old
broken relative links found by relocated-package inspection are repaired.

## Русский

Серия v0.1566–v0.1569 синхронизирует обе выборки с Inferno `bf8d882` и добавляет
полноценную политику однострочных полей IDE на Dis. [Русский контракт](../../ide/dis/FIELDS.ru.md)
связывает интерфейс, реализацию, контроллер, буфер и подробно комментированный
исполняемый пример. Курсор/якорь, слова, ввод в середину, выделение мышью и
буфер работают с Unicode-скалярами; исходник и Undo не меняются до команды
поля. Ошибочная вставка отвергается целиком. Предел поля — 256 скаляров.

Проверены 80 тестов ядра, все 85 обычных и 77 UBSan-тестов runtime, 16 тестов
Coco/R-фронтенда и перенос установленного пакета. Старый тяжёлый ReplaceAll
сначала достиг тайм-аута при конкурирующих прогонах, затем прошёл отдельно в
обеих сборках. Это результаты полного и прицельных прогонов, а не заявление
о единственном полном запуске без повторов. Проверка 49 установленных Markdown
документов больше не находит разорванных относительных ссылок. Подтверждённых
дефектов для обратного патча Inferno в этой серии не найдено.
