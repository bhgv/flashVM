## Delivered

Eight reviewable commits synchronize Inferno, add a bounded C99 diagnostic broker,
record exact source reads/writes, implement BD1 clients and real FlashVM channel
output, package the SDK, and add a Limbo inspector owner/view model.

The selected Inferno `experiment` revision is
`77d6ca9c4901ae06e2fc22bd926551efeaab93d0`, advancing the prior selection
`74c193724a7352b8fda2724a5cf10029885be68c` through ten upstream commits. The first
refresh selected `5cc2b66`; the second imported `8717f96` and `77d6ca9`.
Updates cover AMD64/ARM64 formatting/parsing and reuse, source/UTF-8/string-cell
span checks, raw-copy limits, list cycles and exception ownership. Snapshot
manifests verify byte-for-byte. Previously returned Loader fixes remain in the
upstream ancestry. No new owning-upstream defect was confirmed in this series;
there is therefore no artificial reverse commit to Inferno.

Our compiler debug metadata now distinguishes repeated occurrences such as the
two right-side `o` reads in `o = o + 5 * o`, even if their SSA identity is the same.
The broker associates an occurrence with the full request/session key. Global
listeners report deviations only; successful exchanges and heartbeat remain silent.
The real FlashVM pump retains a pending diagnostic under backpressure/closure.

The IDE gains portable `ideprojection` and `ideinspect` modules. The demonstrator
owner exposes typed fields and an explicit method through real Dis channels.
The watch-row owner admits only the current ticket/incarnation/revision and
returns independent snapshots. Cooperative pause allows inspection while rejecting
mutation. Method invocation requires an explicit caller request and consent.
The installer includes modules, headers and fully commented runnable examples.

ARM64/RV64 emitter compilation and instruction emulation are distinguished from
native physical-machine execution. The tested full runtime is Linux AMD64 NC64.
Initial reruns exposed this sandbox's unavailable default temporary directory and
lost executable permission on its materialized bootstrap; writable TMPDIR and
restored executable mode resolved those environmental failures. No production
source workaround was added for them.

## Explicit remaining boundaries

This is an IDE service/model foundation, not a completed graphical watch panel.
The projection acceptance uses separate processes in one DisVM. Network RPC,
transport authentication, arbitrary FlashVM object reflection, generic Limbo
`any` lowering, export GC finalizers and automatic instrumentation of every
existing channel remain unimplemented. The current Limbo ADT/channel modules
are compiled with the matching source-built bootstrap, not our numeric FIR
frontend. The AS diagnostic codec is checked under Node and the syntax frontend,
not advertised as full AS-to-SWF runtime acceptance.

A timed-out invocation is not automatically retried. The target owner must
acknowledge completion before an adapter can drop its export root. Cooperative
pause in the sample is not a proof of arbitrary heap access under real debugger
suspension. These limits are documented with the APIs and examples.

## По-русски

Серия переносит актуальные JIT-правки Inferno, добавляет тихую диагностику брокера
с точной позицией выражения и работающие канальные сервисы инспектора IDE.

устаревшая проекция, запоздавшие ответы и независимость данных отрисовки.

принадлежащем ему коде не найдено; прежние исправления Loader сохранены.
