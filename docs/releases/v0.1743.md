# v0.1743 — native continuations leave the runnable queue

Runtime 0.49.0 moves the runnable FIFO to runqueue.c. Normal queue operations are
O(1). Native wrapper metadata preserves the unchanged Prog prefix and records
membership/continuation identity without per-I/O allocation. currun uses the
current OS owner's typed Prog rather than the shared head.

Before audited heap release, complete REG is saved and the current Prog leaves
the runnable FIFO as Prelease. It remains in the actual process/GC root list.
After reentry/epoch sampling only the original OS owner restores it at the head
before managed result publication. Ordinary append, duplicate/foreign restore and
retirement of a leased continuation refuse. Synchronous Native64Caller holds
remain non-releasing; they are not the resumable TLS lease introduced earlier.

An opt-in --native-queue-probe enters the REAL runtime from another OS context
while the caller waits outside the heap. It observes rooted/frozen/not-runnable
state and fully detaches/joins before the original continuation resumes. Both
ACTIVE and explicit-IDLE service detach paths are checked. The test exposed and
fixed an ACTIVE-only retry defect when GC refuses detach after a successful leave.
The probe is disabled by default and is not a performance measurement mode.

The real queue passes an independent 20000-operation oracle and four exact
semantic removal controls, with actual foreign-thread identity checks. Default,
strict UBSan and focused TSan pass (symbolization warnings remain; no whole-VM
TSan claim). Production GC/I/O/file/UI gates and opt-in console/editor observers
pass. Existing managed budget and error paths retain instruction-count semantics.
The metadata/owner hooks do not start a second managed executor.

Inferno replied in 0072: the separation agrees with owning release/acquire and
isave/irestore, with explicit retained synchronous-call guard and wake/kill audits.
Its new fresh-message root-publication fix is being independently replayed before
import. This series retains the tested snapshot pin and unchanged shared Dis64
wire/registry admission.
