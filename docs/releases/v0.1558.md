# v0.1558: reconcile current Inferno read guards and accept the editor series

Inferno experiment advanced during review from fa3b7abf to e6c056c with logical
capacity guards for character reads, slices, duplication, concatenation and UTF
export, including AMD64/ARM64 INDC leaves. The parent character read with forged
length 1000 in four-character storage reproduced an ASan heap-buffer-overread.
The reviewed upstream production fix is retained byte-for-byte; no duplicate
local runtime patch overrides it.

The standalone native publication fixture failed on e6c056c because its manually
constructed valid character strings still had zero capacity. We published the
fixture initialization and additional invalid-capacity C/JIT dispatch checks
back to Inferno as `61a2942bbe51dd3af507862d7c7081ff5ed8e6cf`, author bhgv. Both
selected manifests now pin that public revision. The test verifies destination,
owner storage and PC preservation on both forced C and native JIT rejection.

Acceptance for this series:

- All 68 previously registered core checks pass after the refresh, including
  native AMD64 C/JIT and optional decimal/store instruction emulation. The newly
  registered string-read instruction matrix also passes: 69 entries in total.
- All 60 runtime/editor/ports checks pass in one run; all 58 checks of the
  separately compiled UBSan runtime/editor build pass in one run.
- Own Coco/R frontend: 16 tests pass; 22 current bridge/controller/test sources
  and interfaces parse with the project's frontend.
- Actual caret tests independently inspect glyph ink and blue-caret pixels,
  then generate mouse coordinates from the ink. Both dispatch modes pass at
  sizes 9/11/14, with tabs and AV pairs. The rebuilt parent renderer fails at
  the expected tenth-line drift; the fixed renderer passes.
- The installed editor is relocated into a path containing spaces. Its controller
  recompiles using only shipped compiler/headers, then actual caret, Go To and
  default-Noto/zoom sessions pass without a font override or source checkout.
- 34 installed Markdown guides have valid local links. Editor guides now ship
  together under docs/dis; omitted source links use explicit public GitHub paths.
- Both source manifests verify: 267 selected Dis files and 174 bootstrap files.

The series is v0.1556–v0.1558: scalar word commands, CRLF pair movement/deletion,
Tab and one-Undo block indentation, Ctrl+G/source-location library and request,
fixed caret/mouse/row geometry, fresh Inferno read guards and an upstream fixture
repair. Native author/committer identity is bhgv; publication checks expected
heads and exact resulting source trees, without force-push.
