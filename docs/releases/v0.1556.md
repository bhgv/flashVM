# v0.1556: reusable Dis word, indentation and source-location commands

The real keyboard controller now implements Ctrl+Left/Right, Shift selection,
Ctrl+Backspace/Delete, CRLF pair movement/deletion, Tab stops and one-Undo block
indent/unindent. Pure `Ideinput.locate` resolves one-based source coordinates;
Ctrl+G exposes it through a Dis-owned field and Request/65551 provides the same
revision-checked operation to embedding clients. No native text authority or
new deployed host script is introduced.

[English contract](../../ide/dis/EDITING.md) ·
[Русское руководство](../../ide/dis/EDITING.ru.md).

Real interpreter and JIT checks cover Unicode positions, reversed selections,
CRLF, Undo, no-op history, malformed/overflow/stale locations, retained fields,
final empty lines, actual graphical source edits and offscreen caret reveal.
Scalar word policy and the four-column indent convention are explicit; complete
UAX #29/grapheme/language tokenization is not claimed.
