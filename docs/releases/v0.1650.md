# v0.1650 — OS filesystem ports and real Sys metadata

Runtime **0.26.0**. [English contract](../../disVM/runtime/FILESYSTEM.md) ·
[Русский контракт](../../disVM/runtime/FILESYSTEM.ru.md) ·
[Example EN](../../disVM/examples/filesystem/README.md) / [RU](../../disVM/examples/filesystem/README.ru.md).

Native opening, path validation, metadata and directory traversal live in
`flashVM/ports`, selected separately for Linux, Windows, macOS and Android.
The shared C89 boundary carries copied metadata and owned directory batches,
never OS types or VM heap pointers. Linux/macOS/Android share POSIX mechanics;
Windows uses UTF-16 and actual handles. Android provider URIs are unsupported
before opening, including write mode.

Hosted Sys stat/fstat/dirread are implemented with exact generated Dir layouts,
root publication and protected native-batch cleanup. Directory cursors share the
FD quota with files and close when the last VM FD owner retires. The original
Readdir now traverses and sorts actual directories. The installed runtime/editor
SDKs include readdir.m and a runnable Unicode/large-file tutorial. Standard Regex
resource PATH loading is now included in the bundled-module map and checked from
relocated packages.

The selected Inferno pin advances to **ff21d3ceaa3a0d19aa9d1359bb2d1a71a89678ef**:
heap construction and clone spans are checked before descriptor and owner reads.
There are 636 exact core/reference/library files and 207 bootstrap files. Original
heap-preflight, clone and packed-record regressions are retained. These incoming
changes remain byte-for-byte upstream. Reverse commit **ff21d3c** repairs the aliased nil/H branch oracle and restores
production helper/error dependencies in arithmetic and CALL fixtures. Both priority
emitters pass 101968 branch cases each. The local memory-parser fixture now
extracts the production signed-word decoder as well.

## Boundaries / Границы

Native Linux execution is checked. Separate macOS/Android selection wrappers
compile under strict C89 on the Linux toolchain; this is not native target
acceptance. Windows/macOS/Android device/toolchain execution remains open.
Directory enumeration is not an atomic snapshot. Invalid UTF-8 names, disappearing
entries and dangling links can fail a batch. Windows permissions are attribute
based and uid/gid are empty; POSIX IDs are decimal. Standard-descriptor metadata,
background I/O, cancellation, SAF/JNI, namespaces and `/prog` remain separate work.
No Flash compatibility stage or complete IDE debugger milestone is closed.
