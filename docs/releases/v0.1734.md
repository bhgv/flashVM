# v0.1734 — real Fast/Cycles workers and rooted deferred RC

Runtime0.42.0 uses the existing two-worker service against the production managed
heap. Fast releases a bounded queue of last-reference owners; Cycles performs
retained rungc passes. Both bind private extended-up/REG/error contexts. Heap
passes serialize with each other and stop Dis through existing safepoints.

Queue entries retain a queue-owned reference and external root before returning
from destroy. Fast removes the root and invokes retained destruction; recursive
releases bypass requeue. Admission has512 slots and4MiB direct-block limits,
with inline fallback on saturation, oversized blocks or failed root pinning.
Shutdown drains MORE batches and joins both workers before releasing roots/TLS.

Actual console and graphical tests each execute6 root/cycle-reclamation runs,
2 bounded-queue saturation runs and2 managed-error retirements, interpreter/JIT.
Successful runs also check oversized6MiB fallback. Diagnostics require equal
transfers/releases, zero pending owners/bytes, actual Fast passes and two workers.
Real graphical object/node SVG editing is checked in interpreter and JIT.

--gc-worker enables this route; --gc-inline remains the default reference.
Retained movp already orders retain/mark, publish, release. Concurrent marking
still needs a complete rooted mutation/epoch protocol across native/JIT stores;
parallel shared-heap spawn and blocking Sys release/reentry remain open.
No shared Dis64 format changes. Native Linux x64 is the executed platform.
