# v0.1639 — lexical terminal arms and fixed/copy JIT synchronization

## English

Compiler **0.22.0** now accepts lexical statement preludes in both terminal
`if/else` arms for Limbo int and big/table profiles. Local declarations,
initialization, outer assignments, owner reassignment and table mutations precede
the terminal return. Initializers read an outer name before shadowing; shadows
can have different supported static types. Each decision saves the incoming SSA
binding environment and restores it before parsing its sibling. Nested decisions
retain independent environments. No phi, continuation, source loop, runtime
transaction or remote atomicity is claimed.

Balanced lexical debug events preserve exact UTF-8 brace spans and binding owners.
Invalid types, sibling-local reads and resource errors preserve existing FIR/debug
destinations. CLI and C99 APIs share the authoritative Coco/R grammar and lowering.
There are no new FIR IDs, Dis opcodes, Bigtable imports or container tags.

See the [detailed guide](../../fir/v1/doc/TERMINAL_ARMS.md),
[commented source](../../fir/v1/examples/tables/arms.b) and
[example README](../../fir/v1/examples/tables/README.md). The tutorial exercises
local typed initialization, shadowing, table aliases and outer owner reassignment;
both outcomes return 42. It is included in relocated C99 SDK acceptance in both
VM modes, before and after optimization. Scalar int arms also emit SWF objects.

Inferno experiment **80f859e** supplies nine fixed-command operand/frame guards
and qword MOVM/HEADM kernels on AMD64/ARM64. Existing overlap ordering, empty-copy
nonaccess, exact byte tails, 0..256 native domain and larger C fallback remain.
The owning upstream snapshot is imported byte-for-byte. Three new C/emulation
drivers are registered. No new shared native defect requiring a reverse patch
was confirmed; our earlier branch/JMP reverse commit is already in experiment.
Language extensions remain FlashVM-only.

Focused incoming checks passed: 24,328 WORD32 plus 26,568 WORD64 C/RX cases,
15,726 fixed cases per emulated architecture, and 8,224 page-edge copy cases per
architecture. FIR passed 26/26; the optional-table-core-disabled build passed
24/24; five focused UBSan checks passed. Further final acceptance is recorded
below after completion. Native availability remains AMD64/ARM64 164/173 with
partial operand coverage. Emulation is not physical ARM64 or full OS boot.

IDE application `ide.dis` still runs on our own DisVM with typed channels to
FlashVM rendering. Build/Run/Debug GUI panels, full debugger attachment and full
Coco/R self-compilation of the controller remain unfinished. The bootstrap-built
controller is not silently relabeled as compiled by this bounded frontend.

## Русский

Компилятор **0.22.0** принимает лексические прологи в обеих терминальных ветвях
Limbo int и big/table: объявления, инициализацию, присваивания внешним переменным,
переназначение владельцев и операции с таблицами перед `return`. Инициализатор
читает внешнее имя до создания затенения; тип локального затенения может отличаться.
Перед разбором соседней ветви восстанавливается входное SSA-окружение. Снимки
вложенных решений независимы. Phi, продолжение после дерева, циклы, транзакции
и удалённая атомарность не добавлены.

Отладочные области сохраняют точные байты скобок и владельцев привязок в UTF-8.
Ошибки типов, доступ к локальным именам соседней ветви и превышение лимитов
сохраняют старые FIR/sidecar. CLI и C99 API используют одну Coco/R-грамматику.
Новых FIR ID, opcode Dis, импортов Bigtable и тегов контейнера нет.

[Подробное руководство](../../fir/v1/doc/TERMINAL_ARMS.ru.md),
[комментированный исходник](../../fir/v1/examples/tables/arms.b),
[README примеров](../../fir/v1/examples/tables/README.ru.md). Обе ветви учебного
примера возвращают 42; SDK проверяет исходный и оптимизированный код в двух VM-
режимах. Для int-ветвей также проверяется генерация объекта SWF.

Из Inferno experiment **80f859e** забраны проверки девяти fixed-команд и
восьмибайтные ядра MOVM/HEADM для AMD64/ARM64 с сохранением перекрытий, пустых
операций, хвостов и native-диапазона 0..256. Три новых C/emulation-драйвера
зарегистрированы. Нового общего native-дефекта для обратного патча не найдено;
прежнее обратное исправление переходов/JMP уже находится в experiment.
Расширения языка в Inferno не переносились.

Первичные проверки: 50 896 случаев C/RX, по 15 726 fixed-случаев и по 8 224
проверки копирования у границ страниц на каждую эмулируемую архитектуру.
FIR 26/26, без optional table core 24/24, выбранный UBSan-набор 5/5.
Доступность native AMD64/ARM64 — 164/173, покрытие операндов частичное.
Аппаратное исполнение ARM64 и загрузка всей Inferno не заявляются.

IDE продолжает исполняться на нашем DisVM с типизированными каналами графики.
Панели Build/Run/Debug, полное подключение отладчика и компиляция всего контроллера
нашим Coco/R-фронтендом пока не завершены.
